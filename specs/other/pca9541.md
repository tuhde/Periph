# Chip Spec: PCA9541

**Manufacturer:** NXP Semiconductors  
**Datasheet:** `datasheets/other/pca9541.pdf` (Rev. 7.1, 24 June 2015; fetched from the NXP URL in the issue)  
**Category:** `other` (the issue form listed "IO Expander"; the PCA9541 is an I²C-bus master selector, not a GPIO expander, and fits no other category)  
**Transports:** I²C (SMBus-compatible)

## Overview

The PCA9541 is a 2-to-1 I²C-bus master selector for high-reliability dual-master systems. Two upstream masters (for example a primary and a back-up) sit on separate I²C buses and share one downstream bus of slave devices; each master can, at any time, connect its bus to the downstream channel through the PCA9541's pass gates, or disconnect both. The failed master is isolated and cannot disturb the on-line master. There is **no arbitration** — whichever master writes its Control register last before a STOP wins. The chip offers a built-in bus recovery / initialization (nine clock pulses, a not-acknowledge and a STOP on the downstream channel before the switch), a bus-traffic sensor that reports a non-idle downstream bus at switching time, interrupt logic (`INT0` / `INT1` per master, `INT_IN` collecting a downstream interrupt), a functional interrupt test, and an active-low `RESET`. It works from 2.3–5.5 V, is 6 V tolerant and level-translating (1.8 / 2.5 / 3.3 / 5 V buses), and supports hot insertion. Two ordering versions differ only in the power-up state: **PCA9541/01** powers up with master 0 connected, **PCA9541/03** powers up with no channel connected. Typical uses: redundant controller cards, gatekeeper multiplexing of same-address devices, shared slave access for masters that cannot share a bus, recovery of hung buses. The driver is used by **one** of the two masters; the same software runs on both.

## Transport Configuration

### I²C
- **Address:** `0x70` + A (A = A3A2A1A0, 4 address pins, 16 addresses); the address byte is `1 1 1 A3 A2 A1 A0 R/W`. Prefer `A3` = 0 (`0x70`–`0x77`): addresses `0x78`–`0x7F` fall into the I²C reserved ranges (`1111 0XX` 10-bit addressing, `1111 1XX` reserved), which the datasheet says must be used with caution

| A3 A2 A1 A0 | 7-bit address |
|-------------|---------------|
| 0 0 0 0 … 0 1 1 1 | `0x70` … `0x77` |
| 1 0 0 0 … 1 1 1 1 | `0x78` … `0x7F` (reserved ranges, avoid) |

- **Max clock:** 400 kHz (fast mode); 100 kHz standard mode; 0–400 kHz
- **Identity register:** none; chip has no ID register (feeds `registry/chips.json` with `"id_probe": null` and `"driver": null` until implemented, see `specs/feature_i2c_discovery.md`; the registry lists only `0x70`–`0x77` because discovery accepts addresses up to `0x77`); the /01 and /03 versions cannot be told apart other than by the CONTROL register power-up value (Table 11)
- **Probe safety:** `register_pointer` — a 1-byte write is the command code; any value other than `000A 0000`, `000A 0001`, `000A 0010` (A = auto-increment) is not acknowledged, so a stray probe write changes nothing
- **Register addressing:** command code `000 AI 00 B1 B0` (`RegisterConnection`, `reg_bytes = 1`): bits 1:0 select the register (`00` IE, `01` CONTROL, `10` ISTAT, `11` not allowed); `AI` = bit 4 (`0x10`) enables **auto-increment** of the register number after each byte (read: wraps `00` → `01` → `10` → `00`; write: stays at `10`, ISTAT is read-only and not acknowledged). Unused command-code bits must be 0. The register contents seen by a master are **its own** copy: each master has its own IE, CONTROL and ISTAT registers behind the same addresses (Figure 7)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| SDA_MST0, SCL_MST0 | — | Upstream bus of master 0 (external pull-ups required) |
| SDA_MST1, SCL_MST1 | — | Upstream bus of master 1 (external pull-ups required) |
| SDA_SLAVE, SCL_SLAVE | — | Downstream (slave) bus (external pull-ups required) |
| INT0, INT1 | low, open-drain | Interrupt output to master 0 / master 1; external pull-up required |
| INT_IN | low | Interrupt input from downstream devices (no internal pull-up — must not float; pull up to VDD) |
| RESET | low | Reset input; ≥ 4 ns resets the registers and the I²C state machine (connects master 0 for /01, no channel for /03); pull up to VDD if unused |
| A0–A3 | — | Address inputs, tied to VSS or VDD |
| VDD, VSS | — | Supply 2.3–5.5 V; the VDD voltage limits the pass-gate high level (voltage translation) |

The PCA9541 does not isolate the capacitance of either side: all trace and device capacitance of both buses counts, and pull-ups are needed on all channels.

## Register Map

| Command code | Name | R/W | Reset | Description |
|--------------|------|-----|-------|-------------|
| `0x00` | IE | R/W | `0x00` | Interrupt enable (mask) register of the accessing master |
| `0x01` | CONTROL | R/W | see below | Control register of the accessing master (bus selection, bus initialization, interrupt test) |
| `0x02` | ISTAT | R | `0x00` | Interrupt status register of the accessing master |

Adding `0x10` (AI) to a command code enables auto-increment. Only these three registers exist.

### Bit Fields

#### `IE` (`0x00`) — all bits 0 at reset (interrupts enabled), bits 7:4 read-only 0

| Bits | Name | Description |
|------|------|-------------|
| 3 | BUSLOSTMSK | 1 = no interrupt on `INT` when this master is disconnected by the other master |
| 2 | BUSOKMSK | 1 = no interrupt when, without bus initialization, the bus sensor found the downstream bus non-idle at the switch |
| 1 | BUSINITMSK | 1 = no interrupt when a requested bus initialization is done |
| 0 | INTINMSK | 1 = an interrupt on `INT_IN` does not generate an interrupt on `INT` |

#### `CONTROL` (`0x01`)

| Bits | Name | Access | Description |
|------|------|--------|-------------|
| 7 | NTESTON | R/W | 1 = drive the **other** master's `INT` low (functional test) |
| 6 | TESTON | R/W | 1 = drive this master's own `INT` low (functional test) |
| 5 | — | R | Unused (0) |
| 4 | BUSINIT | R/W | 1 = request bus initialization / recovery (9 clocks, NACK, STOP on the downstream bus) before the switch |
| 3 | NBUSON | R | Read-only complement bit of `BUSON` (see Table 10) |
| 2 | BUSON | R/W | With `NBUSON`: bus connection |
| 1 | NMYBUS | R | Read-only complement bit of `MYBUS` (see Table 9) |
| 0 | MYBUS | R/W | With `NMYBUS`: which master owns the downstream bus |

`MYBUS` / `NMYBUS` (XOR-type): equal values (`00` or `11`) = **the master reading has control**; different values = no control. `BUSON` / `NBUSON`: equal values (`00` or `11`) = upstream and downstream **disconnected (off)**; different values = connected (on). The `N…` bits are read-only; to change the connection a master writes `MYBUS` / `BUSON` only (the written value of the N bits is ignored).

Reset values of CONTROL (datasheet Table 11):

| Version | Master | Value | Meaning |
|---------|--------|-------|---------|
| /01 | master 0 | `0x04` | bus on, master 0 has control |
| /01 | master 1 | `0x0A` | bus on (NBUSON = 1, BUSON = 0), no control |
| /03 | master 0 | `0x00` | bus **off**, "has control" bits equal |
| /03 | master 1 | `0x02` | bus off, no control |

#### `ISTAT` (`0x02`) — read only

| Bits | Name | Description |
|------|------|-------------|
| 7 | NMYTEST | 1 = interrupt generated by the other master's `NTESTON` |
| 6 | MYTEST | 1 = interrupt generated by this master's `TESTON` |
| 5:4 | — | Unused (0) |
| 3 | BUSLOST | 1 = this master was disconnected because the other master took the bus |
| 2 | BUSOK | 1 = the bus sensor found the downstream bus non-idle at the switch (no STOP seen; external recovery needed); masked when bus initialization was requested |
| 1 | BUSINIT | 1 = the requested bus initialization is done and this master is connected |
| 0 | INTIN | 1 = an interrupt is present on `INT_IN` |

`BUSLOST`, `BUSOK` and `BUSINIT` are cleared by reading ISTAT (on the second clock pulse of the read). `MYTEST` / `NMYTEST` are cleared by clearing `TESTON` / `NTESTON`; `INTIN` follows the `INT_IN` pin (if the condition persists after the read another interrupt is generated).

### Bus control sequences (datasheet Table 12)

A master reads CONTROL and writes the byte below, then sends a STOP (the switch happens **on the STOP** of the requesting master). Only the four low bits matter; `x` bits are read-only.

| Read (low nibble) | State | Write to take mastership |
|-------------------|-------|--------------------------|
| `0` | bus off, has control | `4` (bus on) |
| `1` | bus off, no control | `4` (bus on, take control) |
| `2` | bus off, no control | `5` (bus on, take control) |
| `3` | bus off, has control | `5` (bus on) |
| `4`, `7`, `8`, `B` | bus on, has control | no write required |
| `5` | bus on, no control | `4` (take control) |
| `6` | bus on, no control | `5` (take control) |
| `9` | bus on, no control | `0` (take control) |
| `A` | bus on, no control | `1` (take control) |
| `C` | bus off, has control | `0` (bus on) |
| `D` | bus off, no control | `0` (bus on, take control) |
| `E` | bus off, no control | `1` (bus on, take control) |
| `F` | bus off, has control | `1` (bus on) |

The table follows one rule, which the driver implements directly on the bit values read (`N…` = the read-only bits as read):

```
BUSON_written  = NOT NBUSON_read         # connect (BUSON != NBUSON)  -> bus on
BUSON_written  = NBUSON_read             # disconnect (BUSON == NBUSON) -> bus off
MYBUS_written  = NMYBUS_read             # take control (MYBUS == NMYBUS)
MYBUS_written  = NOT NMYBUS_read         # give control to the other master
```

## Initialization Sequence

1. Power up (VDD above VPOR, 1.5 V typical / 2.1 V maximum; VDD must drop below 0.2 V to reset by power cycling). The registers take their reset values; the I²C interface needs no start-up delay (datasheet gives none).
2. Read `CONTROL` (`0x01`) as a bus check; raise a descriptive error if the transfer is not acknowledged (the chip has no identity register).
3. Read `ISTAT` (`0x02`) once to clear stale `BUSLOST` / `BUSOK` / `BUSINIT` flags.

`init` writes nothing: the connection state (and `IE`) stay as power-up left them, so initialising a master never changes which master owns the downstream bus.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `INT0` (master 0) / `INT1` (master 1): active-low, open-drain, pull-up required — the host uses the pin of its own channel |
| Level | 2 (selectable sources on one pin) |
| Condition(s) | this master lost the bus (`BUSLOST`); bus non-idle at switch (`BUSOK`); bus initialization done (`BUSINIT`); downstream interrupt on `INT_IN` (`INTIN`); functional tests (`MYTEST`, `NMYTEST`) |
| Clear mechanism | read `ISTAT` clears `BUSLOST` / `BUSOK` / `BUSINIT`; `INTIN` follows `INT_IN`; test interrupts are cleared by clearing `TESTON` / `NTESTON` |

`INT_IN` is valid at `INTn` within 4 µs and released within 2 µs; `INT_IN` pulses shorter than 1 µs (low) / 0.5 µs (high) are rejected. A read of `ISTAT` is not possible if the switch away from this master happened in the middle of a read (the master no longer drives SDA).

### Interrupt sources

| Constant | Value | Condition | Masked by `IE` bit |
|----------|-------|-----------|--------------------|
| `SOURCE_INT_IN` | `0x01` | Downstream device asserts `INT_IN` (`INTIN`) | 0 `INTINMSK` |
| `SOURCE_BUS_INIT` | `0x02` | Requested bus initialization finished (`BUSINIT`) | 1 `BUSINITMSK` |
| `SOURCE_BUS_NOT_IDLE` | `0x04` | Downstream bus was not idle at the switch (`BUSOK`) | 2 `BUSOKMSK` |
| `SOURCE_BUS_LOST` | `0x08` | The other master took the bus (`BUSLOST`) | 3 `BUSLOSTMSK` |
| `SOURCE_TEST` | `0x40` | Own functional test interrupt (`MYTEST`) | not maskable |
| `SOURCE_OTHER_TEST` | `0x80` | Other master's functional test interrupt (`NMYTEST`) | not maskable |

The `IE` mask bits have the same bit positions as the `ISTAT` flags but are **active-high masks** (1 = no interrupt).

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on this master's `INT` pin (falling edge); `callback(status)` receives the `ISTAT` byte read (which clears the self-clearing flags). Uses `connection.int_pin` (or `int_pin`), otherwise polls ISTAT |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read `ISTAT` and return it (bits as in the table) |
| `enable_interrupt` | `enable_interrupt(source)` | Clear the mask bit of the source in `IE` (read-modify-write); the test sources need no enable |
| `disable_interrupt` | `disable_interrupt(source)` | Set the mask bit of the source in `IE` |

### Status register bit layout (`poll_interrupt()` return value)

Bit n of the returned byte is bit n of `ISTAT` (the `SOURCE_*` values above).

## Implementation Stages

Each chip is implemented in two stages. The Full class extends Minimal — it inherits everything and adds the rest.

### Minimal

Goal: let this master take, give up and check ownership of the downstream bus.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection | — | Runs the Initialization Sequence (bus check, clears stale status); writes nothing |
| `has_control` | — | `bool` | Reads `CONTROL`; `True` if `MYBUS` equals `NMYBUS` **and** the bus is connected (`BUSON` ≠ `NBUSON`) — i.e. this master's channel is connected to the downstream bus |
| `acquire` | `bus_init: bool = False`, `timeout_ms: float = 20` | `bool` | Takes the downstream bus: reads `CONTROL`, writes `MYBUS` / `BUSON` per the rule above (with `BUSINIT` set when `bus_init`), the write ends with a STOP which makes the switch; with `bus_init` waits for `BUSINIT` in `ISTAT`; then re-reads `CONTROL` and returns `True` if `has_control()` is true (`False` if not within `timeout_ms`) |
| `release` | — | — | Gives the downstream bus to the other master: writes `MYBUS` = NOT `NMYBUS` (bus left connected); the other master then owns the bus |

**Sensible defaults:** no register is written by `init`; `acquire` does not request bus initialization (`BUSINIT` = 0) unless asked; interrupt masks stay at their reset value (all interrupts enabled); the test bits stay 0.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection | — | As Minimal |
| *(inherits Minimal)* | | | |
| `get_control` | — | `int` | Raw `CONTROL` byte |
| `is_connected` | — | `bool` | `BUSON` ≠ `NBUSON` (the downstream bus is connected to *some* master, not necessarily this one) |
| `status` | — | `dict` | `{has_control, connected, bus_init_requested, own_test, other_test}` decoded from `CONTROL` |
| `connect` | — | — | Turns the connection on without changing ownership: writes `BUSON` = NOT `NBUSON`, `MYBUS` unchanged from the read value |
| `disconnect` | — | — | Disconnects both masters from the downstream bus (`BUSON` = `NBUSON`); ownership bits are left; used to isolate the downstream devices |
| `recover_bus` | `timeout_ms: float = 20` | `bool` | `acquire(bus_init=True)`: the PCA9541 sends nine clocks, a NACK and a STOP on the downstream bus, then connects this master; waits for `BUSINIT` |
| `set_interrupt_mask` | `bus_lost=False, bus_not_idle=False, bus_init=False, int_in=False` | — | Writes `IE` (`True` = masked, no interrupt); `set_interrupt_mask()` with defaults re-enables everything |

**Additional configuration options:** connect / disconnect without changing ownership, bus recovery before switching, per-source interrupt masking, `INT` line functional test.

## Data Conversion

```
has_control(c) = ((c >> 0) & 1) == ((c >> 1) & 1)      # MYBUS == NMYBUS (XNOR)
connected(c)   = ((c >> 2) & 1) != ((c >> 3) & 1)      # BUSON != NBUSON (XOR)

acquire write  : w = (bus_init << 4)                               # BUSINIT as requested, test bits written 0
                    | (1 - ((c >> 3) & 1)) << 2                    # BUSON  = NOT NBUSON_read (bus on)
                    | ((c >> 1) & 1)                               # MYBUS  = NMYBUS_read (take control)
release write  : MYBUS = 1 - NMYBUS_read, BUSON = 1 - NBUSON_read (bus stays on)
disconnect     : BUSON = NBUSON_read
```

(`w` is the whole CONTROL byte written: bit 7 NTESTON, bit 6 TESTON, bit 5 0, bit 4 BUSINIT, bit 3 0 (N bit, ignored), bit 2 BUSON, bit 1 0 (N bit, ignored), bit 0 MYBUS. The driver keeps NTESTON / TESTON at 0 except in `test_interrupt`.)

## Timing Constraints

- **Switch on STOP:** the connection change happens when the requesting master sends the STOP after writing CONTROL (registers are updated on the 9th clock of the write); writing and stopping on one master's channel only; a STOP on the other channel does not update the connection.
- **Bus-free time:** after the switch (STOP) the new master must wait the I²C bus-free time (tBUF ≥ 1.3 µs fast mode, ≥ 4.7 µs standard mode) before sending commands to downstream devices; with bus initialization the new master is connected after the nine clocks and STOP (INT to the new master).
- **Bus initialization clock:** fSCL(init/rec) 50–150 kHz on `SCL_SLAVE`; nine clocks therefore take roughly 60–180 µs; the datasheet gives no maximum duration, so `acquire` waits up to `timeout_ms` (default 20 ms, driver choice) for `BUSINIT`.
- **Write timing:** a write to IE or CONTROL takes effect on the rising edge of the acknowledge clock (9th clock).
- **Reset:** `RESET` low ≥ tw(rst)L = 4 ns; reset time trst = 500 ns for the SDA clear; recovery to the next START tREC;STA = 0 ns; resetting while communicating can cause glitches or an errant STOP. Power-on reset: VDD must drop below 0.2 V to re-arm.
- **Pass gate:** propagation delay 0.3 ns (typ., Ron ≈ 20 Ω), Ron 4–24 Ω at 5 V, 5–30 Ω at 3.3 V, 7–55 Ω at 2.5 V; output limited by VDD (voltage translation, Figure 8).
- **I²C (fast mode):** fSCL ≤ 400 kHz, tBUF ≥ 1.3 µs, tHD;STA ≥ 0.6 µs, tLOW ≥ 1.3 µs, tHIGH ≥ 0.6 µs, tSU;STA ≥ 0.6 µs, tSU;STO ≥ 0.6 µs, tSU;DAT ≥ 100 ns; standard mode 4.7 / 4.0 / 4.7 / 4.0 / 4.7 / 4.0 µs and 250 ns.
- **Conformance:** none of these has a bus-decodable start / end annotation pair on the master's own bus that the host must honour (the bus-free wait is on the downstream bus and the reset / interrupt timings are pin-level), so `specs/other/pca9541_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed:** accept `RegisterConnection` (1-byte command code) and call `connection.read(reg, n)` / `connection.write(reg, data)` directly — no chip-local `_read_reg`/`_write_reg` and no `bus_type` branch (see `specs/feature_register_access_design.md`). Command codes: `0x00` IE, `0x01` CONTROL, `0x02` ISTAT, `0x10` = IE with auto-increment (3-byte read `IE, CONTROL, ISTAT`; 2-byte write `IE, CONTROL`).
- **Never write ISTAT:** a write to command code `0x02` (or `0x12`) is not acknowledged and raises a bus error; the driver only reads it.
- **Read before every write of CONTROL:** the correct byte depends on the read-only complement bits of the master's own register (Table 12), which change when the other master acts. `acquire`, `release`, `connect`, `disconnect` and `test_interrupt` therefore read-modify-write by the rule above; they are not atomic against the other master (no arbitration): if both write, the master that wrote last before the STOP wins.
- **The switch needs a STOP:** `RegisterConnection.write` ends with a STOP, which is what applies the change; a driver using a bus layer without STOP semantics cannot use the chip. After the switch the master that lost the bus gets `BUSLOST` on its `INT` line and cannot reach the downstream devices; the PCA9541's own registers stay reachable from both upstream buses.
- **`has_control` ≠ "bus on":** a master can "have control" (`MYBUS` = `NMYBUS`) while the downstream bus is off; `has_control()` reports control *and* connection, `status()` reports both separately.
- **Bus initialization:** `BUSINIT` is set in the same write as `MYBUS` / `BUSON`; the PCA9541 then drives nine clocks (SDA released = eight data bits plus NACK) and a STOP on `SCL_SLAVE` before connecting the new master and flagging `BUSINIT` in its ISTAT / `INT`. This completes a read the previous master left half-done. The bus sensor's `BUSOK` interrupt is masked when initialization was requested.
- **No bus-sensor result without initialization:** with `BUSINIT` = 0, `BUSOK` = 1 in ISTAT means the downstream bus was non-idle at the switch (no STOP seen); the application then runs its own recovery (e.g. `recover_bus()` on the next switch, or nine clocks from the master).
- **Versions /01 and /03:** differ only in the reset state (master 0 connected vs. no channel connected); software is identical. `init` must therefore not assume ownership — read it.
- **Hot insertion:** the chip supports hot insertion; the registers are initialised when VDD exceeds VPOR; pull-ups on all channels.
- **Voltage translation:** VDD limits the pass-gate high level (Figure 8); set VDD ≈ the lowest bus voltage. All I/O pins are 6 V tolerant.
- **Capacitance is not isolated** and an SDA stuck low on the downstream side blocks the connected master; the recovery function (nine clocks) is the way out.
- **Interrupt wiring:** `INT_IN` needs a pull-up and must not float. In a two-master system each master wires only its own `INTn`.
- **Siblings:** the PCA9541 is not related to the PCA9548 / TCA9548 channel switches (no channel registers, one downstream bus); the driver is independent of any mux driver. The PCA9541/01 and /03 share one driver.
- **Datasheet revision:** NXP Rev. 7.1 (24 June 2015), 42 pages, fetched from the NXP URL in the issue.

## Sigrok Decoder

Decoder id `pca9541`, input `['i2c']`. Matches I²C addresses `0x70`–`0x7F`. Annotates each access by register name (IE, CONTROL, ISTAT) with command-code decoding (`AI` flag, register number, invalid command codes `0x03` and codes with unused bits set flagged); decodes `IE` into mask flags, `CONTROL` into `MYBUS` / `NMYBUS` / `BUSON` / `NBUSON` with the derived state ("has control, bus on" etc.) plus `BUSINIT`, `TESTON`, `NTESTON`, and `ISTAT` into the interrupt flags; handles auto-increment (each byte of a multi-byte read or write is named by its own register, including the read wrap-around `ISTAT` → `IE`). A CONTROL write is annotated with the action it implies (take control / give control / bus on / bus off / init requested) by comparing its `BUSON` / `MYBUS` bits with the preceding CONTROL read. Warnings: a write to ISTAT (not acknowledged), and a write with unused command-code bits. No timing annotation pair is emitted, since no constraint is conformance-checked.
