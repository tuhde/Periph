# Chip Spec: ITG3200

**Manufacturer:** InvenSense  
**Datasheet:** `datasheets/gyroscope/itg3200.pdf` (ITG-3200 Product Specification, Rev. 1.4, 30 March 2010)  
**Category:** gyroscope  
**Transports:** I²C

## Overview

The ITG-3200 is a 3-axis MEMS gyroscope with three 16-bit ADCs, a digital low-pass filter, a die-temperature sensor and a fixed full-scale range of ±2000 °/s (sensitivity 14.375 LSB per °/s). It has a programmable sample rate (up to 8 kHz internal), a selectable clock source (internal oscillator, X/Y/Z-gyro PLL or an external 32.768 kHz / 19.2 MHz reference), per-axis standby, a sleep mode and a data-ready / PLL-ready interrupt on the INT pin. It runs from 2.1–3.6 V with a separate VLOGIC reference for the I²C levels and is accessed over I²C at up to 400 kHz. Typical uses: gaming and 3D pointing, image stabilisation, motion tracking.

## Transport Configuration

### I²C
- **Address:** `0x68` (AD0 = 0) — `0x69` (AD0 = 1); the address lives in WHO_AM_I bits 6:1 and can be rewritten
- **Max clock:** 400 kHz (fast mode)
- **Register addressing:** 8-bit register address; single and burst reads/writes, the pointer auto-increments (burst reads of `0x1B`–`0x22` return temperature and the three axes in one transaction)
- **Identity register:** `0x00` WHO_AM_I, bits 6:1 = `110100` → value `0x68` (mask `0x7E`, expected `0x68`); registered in `registry/chips.json` (shares `0x68`–`0x69` with MPU6050 (`0x75`), MPU9250, L3G4200D, ICM-20948)
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer (writing *data* to WHO_AM_I would change the I²C address, but a pointer-only write does not)

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | WHO_AM_I | R/W | `0x68` | Bits 6:1 = I²C address (`110100`) |
| `0x15` | SMPLRT_DIV | R/W | `0x00` | Sample-rate divider 0–255 |
| `0x16` | DLPF_FS | R/W | `0x00` | Full-scale select and low-pass filter |
| `0x17` | INT_CFG | R/W | `0x00` | Interrupt pin configuration and enables |
| `0x1A` | INT_STATUS | R | `0x00` | Interrupt status |
| `0x1B` / `0x1C` | TEMP_OUT_H / L | R | — | Temperature, 16-bit two's complement |
| `0x1D` / `0x1E` | GYRO_XOUT_H / L | R | — | X rate, 16-bit two's complement |
| `0x1F` / `0x20` | GYRO_YOUT_H / L | R | — | Y rate |
| `0x21` / `0x22` | GYRO_ZOUT_H / L | R | — | Z rate |
| `0x3E` | PWR_MGM | R/W | `0x00` | Reset, sleep, axis standby, clock source |

### Bit Fields

#### `DLPF_FS` (`0x16`)

| Bits | Name | Description |
|------|------|-------------|
| 4:3 | FS_SEL | Full-scale range; **must be set to `3`** (±2000 °/s) for proper operation (power-on value `0` is reserved) |
| 2:0 | DLPF_CFG | Low-pass bandwidth / internal rate: `0` 256 Hz / 8 kHz, `1` 188 Hz / 1 kHz, `2` 98 Hz / 1 kHz, `3` 42 Hz / 1 kHz, `4` 20 Hz / 1 kHz, `5` 10 Hz / 1 kHz, `6` 5 Hz / 1 kHz, `7` reserved |

#### `INT_CFG` (`0x17`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | ACTL | INT level: `1` active low, `0` active high |
| 6 | OPEN | INT drive: `1` open drain, `0` push-pull |
| 5 | LATCH_INT_EN | `1` latch until cleared, `0` 50 µs pulse |
| 4 | INT_ANYRD_2CLEAR | Latch clear: `1` any register read, `0` INT_STATUS read only |
| 3 | — | write `0` |
| 2 | ITG_RDY_EN | Interrupt when the PLL is ready after a clock-source change |
| 1 | — | write `0` |
| 0 | RAW_RDY_EN | Interrupt when new data is available |

#### `INT_STATUS` (`0x1A`)

| Bits | Name | Description |
|------|------|-------------|
| 2 | ITG_RDY | PLL ready |
| 0 | RAW_DATA_RDY | New raw data available |

The status bits are set regardless of the INT polarity/latch settings but only for enabled interrupts.

#### `PWR_MGM` (`0x3E`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | H_RESET | Reset the device and all registers to power-up defaults |
| 6 | SLEEP | Low-power sleep (only the serial interface and registers stay active) |
| 5 | STBY_XG | Put the X gyro in standby |
| 4 | STBY_YG | Put the Y gyro in standby |
| 3 | STBY_ZG | Put the Z gyro in standby |
| 2:0 | CLK_SEL | `0` internal oscillator, `1` PLL X gyro, `2` PLL Y gyro, `3` PLL Z gyro, `4` PLL external 32.768 kHz, `5` PLL external 19.2 MHz, `6`/`7` reserved |

## Initialization Sequence

1. Power up (VDD 2.1–3.6 V); the registers are readable/writable after ≈ 20 ms (start-up time for register read/write). The device runs from the internal oscillator.
2. Write `DLPF_FS` ← `0x18 | DLPF_CFG` (FS_SEL = 3; default DLPF_CFG = 0 → 256 Hz, 8 kHz internal).
3. Write `SMPLRT_DIV` (sample rate = internal rate / (divider + 1)).
4. Write `PWR_MGM` ← `0x01` (PLL with X-gyro reference, recommended for stability); allow ≈ 1 ms PLL settling (and ≈ 50 ms for the zero-rate output to settle to ±1 °/s).
5. Read `GYRO_XOUT_H` … 6 bytes (or `TEMP_OUT_H` … 8 bytes).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | configurable level and drive (`ACTL`, `OPEN`); requires a pull-up when open drain |
| Level | 2 (selectable sources) |
| Condition(s) | new data available; PLL ready after changing the clock source |
| Clear mechanism | read `INT_STATUS`, or any register read when `INT_ANYRD_2CLEAR` = 1; a non-latched interrupt is a 50 µs pulse |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_DATA_READY` | `0x01` | New raw data available (`RAW_RDY_EN`) |
| `SOURCE_PLL_READY` | `0x04` | PLL locked to the new clock reference (`ITG_RDY_EN`) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Configure INT (push-pull, active high, latched, any-read clear), enable the data-ready source, subscribe on `connection.int_pin` (or `int_pin`), otherwise poll; `callback(status)` |
| `off_interrupt` | `off_interrupt()` | Unsubscribe and disable the sources |
| `poll_interrupt` | `poll_interrupt() -> int` | Read `INT_STATUS` (clears it), returns the `SOURCE_*` mask |
| `enable_interrupt` | `enable_interrupt(source)` | Set the enable bit for one source |
| `disable_interrupt` | `disable_interrupt(source)` | Clear the enable bit |

## Implementation Stages

### Minimal

Goal: read angular rates in °/s with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Stores the `RegisterConnection` (`reg_bytes` = 1); writes `DLPF_FS` ← `0x18` (±2000 °/s, 256 Hz, 8 kHz), `SMPLRT_DIV` ← 7 (1 kHz output rate) and `PWR_MGM` ← `0x01` (PLL, X gyro) |
| `read_gyro` | — | `(x, y, z)` | °/s; burst read of 6 bytes from `0x1D` |

**Sensible defaults:** ±2000 °/s (the only valid range), DLPF 256 Hz, 1 kHz output rate, PLL clock from the X gyro, interrupts off.

### Full

Goal: complete chip functionality. Extends Minimal.

**Additional configuration options:** sample-rate divider, DLPF bandwidth, clock source, axis standby/sleep, INT pin configuration (via `configure_interrupt(active_low, open_drain, latch, any_read_clear)`), software zero-rate offset.

## Data Conversion

```
rate_dps    = signed16(GYRO_xOUT_H << 8 | GYRO_xOUT_L) / 14.375 - offset
temperature_c = 35 + (signed16(TEMP_OUT_H << 8 | TEMP_OUT_L) + 13200) / 280
sample_rate_hz = (8000 if DLPF_CFG == 0 else 1000) / (SMPLRT_DIV + 1)
```

Sensitivity tolerance at 25 °C is ±6 %, variation over temperature ±10 %; the temperature output is for compensation, not a calibrated thermometer.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Start-up for register read/write | 20 ms max |
| Gyro ZRO settling | 50 ms typ. (to ±1 °/s of final value) |
| PLL settling (CLK_SEL 1–5) | 1 ms typ. |
| Sample rate | 8 kHz (DLPF 256 Hz) or 1 kHz (other DLPF settings) divided by `SMPLRT_DIV + 1` |
| I²C clock | ≤ 400 kHz |

**Conformance:** the settling times are typical values without a bus-visible completion marker (ITG_RDY is an interrupt-status bit, not bounded by the datasheet), so `specs/gyroscope/itg3200_timing.conf` defines no checks.

## Implementation Notes

- **FS_SEL must be 3.** The power-on value `0` is documented as reserved; always write `0x18 | DLPF_CFG` (the driver never exposes other values).
- **Clock source:** the internal oscillator is the default; the datasheet strongly recommends a gyro PLL (`CLK_SEL = 1`) for stability.
- **Burst reads:** `0x1B`–`0x22` (temperature + X, Y, Z) can be read in one transaction; data may be read at any time, but data-ready is the right trigger when every sample matters.
- **WHO_AM_I is writable** and holds the I²C address; the driver never writes it.
- **Sample rate vs DLPF:** DLPF 256 Hz selects the 8 kHz internal rate, all others 1 kHz; changing the DLPF changes the effective output rate unless the divider is adjusted.
- **Reserved bits:** write `0` to undefined bits and to INT_CFG bits 3 and 1.
- **Address overlap:** `0x68`/`0x69` is shared with MPU-6050/9250, ICM-20948, L3G4200D and RTCs; identify by WHO_AM_I (`0x68` at register `0x00`).

## Sigrok Decoder

Decoder id `itg3200`, input `['i2c']`. Matches I²C addresses `0x68` and `0x69`. Annotates register names for every access, decodes `DLPF_FS`, `INT_CFG`, `INT_STATUS` and `PWR_MGM` into their fields, decodes burst reads of `0x1B`–`0x22` into temperature (°C) and X/Y/Z rates (°/s), computes the sample rate from `SMPLRT_DIV`/`DLPF_CFG`, and verifies WHO_AM_I (bits 6:1 = `110100`). No timing annotation pair is emitted.
