# Chip Spec: FXAS21002C

**Manufacturer:** NXP Semiconductors (formerly Freescale)  
**Datasheet:** `datasheets/gyroscope/fxas21002c.pdf` (Rev. 2.1, 5/2015)  
**Category:** `gyroscope`  
**Transports:** I²C, SPI

## Overview

The FXAS21002C is a 3-axis MEMS gyroscope with 16-bit output, four selectable full-scale ranges (±250, ±500, ±1000, ±2000 dps, doubled to ±4000 dps with `FS_DOUBLE`), output data rates from 12.5 to 800 Hz, a programmable low-pass and high-pass filter, a 32-sample FIFO, a rate-threshold interrupt with debounce counter, an 8-bit temperature sensor (1 °C/LSB), and two interrupt pins (INT1, INT2) to which data-ready, FIFO and rate-threshold events are individually routed. It has three power modes: Standby (default after power-on, register access only), Ready (drive circuits running, no measurement) and Active. Typical uses: orientation sensing, stabilization, motion capture and sport-equipment monitoring (±4000 dps).

## Transport Configuration

### I²C
- **Address:** `0x20` (SA0 = GND) — `0x21` (SA0 = VDDIO)
- **Max clock:** 400 kHz (fast mode); 100 kHz standard mode
- **Interface select:** pin `SPI/I2C_B` low = I²C
- **Auto-increment:** every register read/write auto-increments the register address (no special address bit); the address after `OUT_Z_LSB` (`0x06`) wraps to `0x00` (STATUS) or, with `CTRL_REG3[WRAPTOONE]` = 1, to `0x01` (OUT_X_MSB).
- **Software reset:** the device does not ACK the data byte of a `CTRL_REG1[RST]` write (it resets immediately); the driver must tolerate that NACK.
- **Identity register:** `WHO_AM_I` (`0x0C`) reads `0xD7` (feeds `registry/chips.json` `id_probe`).
- **Probe safety:** `register_pointer` — reading `WHO_AM_I` only moves the register pointer.

### SPI
- **Mode:** CPOL = 0, CPHA = 0 (mode 0); MSB first; max clock 2 MHz (4-wire) / 1.4 MHz (3-wire)
- **CS:** active low (`SPI_CS_B`); pin `SPI/I2C_B` high selects SPI
- **First byte:** `[R/W][A6..A0]` — R/W = 1 read, 0 write; the register address auto-increments across a burst
- **3-wire mode:** `CTRL_REG0[SPIW]` = 1 makes MOSI bidirectional (4-wire default)

|------|------|-------------|
| 6 | RST | Software reset (self-clearing; the device does not ACK this write) |

| 1 | ACTIVE | `1` = Active mode (higher priority than READY) |
| 0 | READY | `1` (with ACTIVE = 0) = Ready mode; both 0 = Standby |

| Bits | Name | Description |
|------|------|-------------|
| 7 | INT_CFG_FIFO | FIFO interrupt routing: `0` INT2, `1` INT1 |
| 6 | INT_EN_FIFO | FIFO interrupt enable |

| 4 | INT_EN_RT | Rate-threshold interrupt enable |
| 3 | INT_CFG_DRDY | Data-ready interrupt routing: `0` INT2, `1` INT1 |

#### `CTRL_REG3` (`0x15`)
| Bits | Name | Description |
|------|------|-------------|
| 3 | WRAPTOONE | `0` auto-increment wraps to `0x00` after `0x06` (default); `1` wraps to `0x01` (read FIFO samples in one burst) |
| 2 | EXTCTRLEN | `1` = INT2 becomes the PWR_CTRL input controlling Active; ACTIVE bit read-only |
| 0 | FS_DOUBLE | `1` doubles every full-scale range (±500/1000/2000/4000 dps) |

#### `DR_STATUS` (`0x07`)
| Bits | Name | Description |
|------|------|-------------|
| 7 | ZYXOW | Data overwritten before read (any axis set) |
| 6:4 | ZOW, YOW, XOW | Per-axis overwrite |
| 3 | ZYXDR | New data available on all axes; cleared by reading the three MSB registers |
| 2:0 | ZDR, YDR, XDR | Per-axis data ready |

#### `F_STATUS` (`0x08`) / `F_SETUP` (`0x09`) / `F_EVENT` (`0x0A`)
| Register | Bits | Description |
|----------|------|-------------|
| F_STATUS | 7 | F_OVF overflow (F_CNT = 32 and a new sample arrives) |
| F_STATUS | 6 | F_WMKF watermark reached (F_CNT ≥ F_WMRK) |
| F_STATUS | 5:0 | F_CNT sample count (0 = empty, max 32) |
| F_SETUP | 7:6 | F_MODE: `00` disabled, `01` circular buffer, `1x` stop mode (change only via `00`) |
| F_SETUP | 5:0 | F_WMRK watermark (0 = no watermark flag) |
| F_EVENT | 5 | F_EVENT = F_OVF or F_WMKF |
| F_EVENT | 4:0 | FE_TIME: ODR periods since the event |

With the FIFO on, the host reads `OUT_X_MSB` first (to update the other registers with the head sample); the head pointer advances when `OUT_Z_MSB` is read.

#### `INT_SRC_FLAG` (`0x0B`)
| Bit | Name | Description |
|-----|------|-------------|
| 3 | BOOTEND | Boot sequence complete (1 after boot) |
| 2 | SRC_FIFO | FIFO event raised the interrupt |
| 1 | SRC_RT | Rate-threshold event raised the interrupt |
| 0 | SRC_DRDY | Data-ready raised the interrupt (cleared by reading the MSB registers) |

#### Rate threshold: `RT_CFG` (`0x0E`), `RT_SRC` (`0x0F`), `RT_THS` (`0x10`), `RT_COUNT` (`0x11`)
| Register | Bits | Description |
|----------|------|-------------|
| RT_CFG | 3 | ELE event latch enable |
| RT_CFG | 2:0 | ZTEFE, YTEFE, XTEFE per-axis enable |
| RT_SRC | 6 | EA event active (any axis) |
| RT_SRC | 5/3/1 | ZRT/YRT/XRT per-axis event |
| RT_SRC | 4/2/0 | Z/Y/X_RT_POL polarity (1 = negative) |
| RT_THS | 7 | DBCNTM: `1` clear debounce counter when rate below threshold, `0` decrement |
| RT_THS | 6:0 | THS: threshold = (THS + 1) × 256 LSB = (THS + 1) × 256 × sensitivity |
| RT_COUNT | 7:0 | Debounce count (ODR periods); reset 1 |

Configure the FIFO, rate threshold and CTRL_REG0/1/3 only in Standby or Ready mode; the rate-threshold state resets on every transition into Active.

## Initialization Sequence

1. Power up VDDIO and VDD (POR at VDD > 1.95 V); the chip boots and enters Standby. (`INT_SRC_FLAG[BOOTEND]` = 1 when the boot finished; the datasheet gives no boot time.)
2. Read `WHO_AM_I` (`0x0C`); it must be `0xD7`, else raise an error.
3. In Standby write `CTRL_REG0` (full scale, filters) and `CTRL_REG1` with `DR` selected and ACTIVE = 0.
4. Write `CTRL_REG1` with ACTIVE = 1 (Active mode).
5. Wait 1/ODR + 60 ms (Standby → Active, typ.) — 1/ODR + 5 ms when coming from Ready — before using the data.
6. Read `STATUS`/`DR_STATUS` for data-ready and burst-read `0x01`–`0x06` (MSB of X first).

## Interrupt

| Property | Value |
|----------|-------|
| INT pins | `INT1`, `INT2` (the latter is not usable when `EXTCTRLEN` = 1); polarity and driver configurable (`IPOL`, `PP_OD`); default active low push-pull |
| Level | 3 (multiple INT lines, selectable sources routed per source) |
| Condition(s) | data ready, FIFO overflow/watermark, rate threshold |
| Clear mechanism | data-ready: read `OUT_X_MSB`/`OUT_Y_MSB`/`OUT_Z_MSB`; FIFO: read `F_STATUS` and drain/clear the condition; rate threshold: read `RT_SRC` when latched (`ELE` = 1) |

## Data Conversion

### Angular rate

Sensitivity by full scale (`CTRL_REG0[FS]`), mdps/LSB with `FS_DOUBLE` = 0 / 1:

| FS | Full scale | Sensitivity (mdps/LSB) | with FS_DOUBLE |
|----|-----------|------------------------|----------------|
| `00` | ±2000 dps | 62.5 | 125.0 |
| `01` | ±1000 dps | 31.25 | 62.5 |
| `10` | ±500 dps | 15.625 | 31.25 |
| `11` | ±250 dps | 7.8125 | 15.625 |

```
raw = signed16((OUT_x_MSB << 8) | OUT_x_LSB)     # big-endian
rate_dps   = raw * sensitivity_mdps / 1000.0
rate_rad_s = rate_dps * π / 180.0
```

### Temperature

`TEMP` is an 8-bit two's complement value, 1 °C/LSB, range −128…+127 °C; it is factory-compensated only while the device is Active (operating range −40…+85 °C).

### Rate threshold
```
threshold_LSB = (THS + 1) * 256
threshold_dps = threshold_LSB * sensitivity_mdps / 1000.0
debounce_time = RT_COUNT / ODR
```

## Implementation Notes

- **Burst-read order:** always read from `0x01` (MSB X first). In FIFO mode the head sample is exposed only after the OUT_X_MSB read and advances on the OUT_Z_MSB read, so partial reads lose samples.
- **Big-endian output:** unlike the L3GD20H, the MSB is at the lower address.
- **Mode rules:** CTRL_REG0, CTRL_REG1 (except ACTIVE/READY/RST), CTRL_REG3, F_SETUP, RT_CFG, RT_THS and RT_COUNT must be changed only in Standby or Ready; the driver switches to Standby, writes, then restores the previous mode.
- **Soft reset NACK:** the device resets immediately and does not ACK the written byte; treat the I²C NACK of that single transfer as success and wait for the boot (poll `WHO_AM_I`).
- **Undefined output after reset:** registers `0x01`–`0x06` have indeterminate values after a reset; discard the first sample set.
- **Temperature:** valid only in Active mode; sensitivity 1 °C/LSB.
- **EXTCTRLEN:** when set, INT2 is a power-control input and the INT2 interrupt routing is ignored; `EXTCTRLEN` is not exposed in the driver API (hardware-only), so the driver always routes to INT1 or INT2 as requested.
- **VDDIO without VDD** puts the part in shutdown — bus transactions are ignored.
- **Address overlap:** `0x20`/`0x21` also used by PCA6408A/PCA6416A (no identity register); `WHO_AM_I` (`0xD7` at `0x0C`) identifies the FXAS21002C when probing.

## Sigrok Decoder

Decoder id `fxas21002c`, input `['i2c', 'spi']`. Matches I²C addresses `0x20` and `0x21`, and SPI by protocol type. Annotates register writes with the register name and decoded fields (e.g. `CTRL_REG1: DR=100Hz ACTIVE=1 READY=0`), burst reads of `0x01`–`0x06` as three signed rates and rad/s values for the current full-scale setting, `STATUS`/`DR_STATUS`/`F_STATUS` flags, `TEMP` in °C, and `INT_SRC_FLAG` sources. The soft-reset write with its missing ACK is annotated as "software reset".
