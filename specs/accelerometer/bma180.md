# Chip Spec: BMA180

**Manufacturer:** Bosch Sensortec  
**Datasheet:** `datasheets/accelerometer/bma180.pdf`  
**Category:** accelerometer  
**Transports:** I²C (the chip also supports 4-wire SPI; out of scope for this issue — see Implementation Notes)

## Overview

The BMA180 is a triaxial, low-g MEMS accelerometer with 14-bit digital output and seven selectable full-scale ranges (±1 to ±16 *g*). It offers eight low-pass digital filters (10–1200 Hz), a high-pass and a band-pass option, four noise/power sub-modes (650 µA low-power to 1025 µA low-noise), an 8-bit temperature output, and an on-chip interrupt engine: new-data, low-g (free-fall), high-g, slope (any-motion) with alert mode, and double-tap sensing — each with per-axis enables and latched or self-resetting behaviour. A self-wake-up mode lets the chip sleep at < 1 µA and wake periodically to evaluate interrupt criteria; an on-chip offset-regulation routine allows in-field zero-g calibration. Typical uses: tilt/orientation, free-fall and shock detection, tap gestures, motion wake-up for battery devices.

## Transport Configuration

### I²C
- **Address:** `0x40` (SDO = GND) — `0x41` (SDO = VDDIO)
- **Max clock:** 3.4 MHz (high-speed mode); use ≤ 400 kHz on typical hosts
- **Identity register:** `0x00` bits 2:0 = `0b011` (`chip_id`) — read with mask `0x07`, expected `0x03`
- **Probe safety:** `register_pointer` — the identity read has no side effects

I²C framing: a write is `[reg, data]` after the slave address; the control byte is a dummy bit plus the 7-bit register address (the plain register number). A read is a register-address write, then stop + start (or repeated start) with R/W=1; data bytes follow with automatic address increment. CSB must be tied to VDDIO to select I²C (CSB = 0 selects SPI); SDO selects the address and must not float.

## Register Map

Operational registers are `0x00–0x10`; image (setting) registers `0x20–0x3B` mirror the EEPROM and are loaded from it at power-on / soft reset. **Writing image registers requires `ee_w = 1`** (`CTRL_REG0` bit 4); reads need no unlock. The driver never writes the EEPROM (`0x40–0x5F`). Reset values for `0x20–0x3B` come from EEPROM and are calibrated per device.

### Bit Fields

#### `CTRL_REG0` (`0x0D`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | — | Reserved |
| 6 | reset_int | One-shot: clears a latched interrupt |
| 5 | update_image | One-shot: reload image registers from EEPROM (self-clears) |
| 4 | ee_w | 1 = image registers `0x20–0x3B` writable; 0 after power-on/reset |

| 0 | dis_wake_up | 1 = mask wake-up mode |

|------|------|-------------|
| 7 | en_offset_x | One-shot: start offset regulation on X |
| 6 | en_offset_y | One-shot, Y |

| Bits | Name | Description |
|------|------|-------------|
| 7 | slope_alert | Slope criterion drives alert mode (exclusive with `slope_int`; needs `adv_int`) |
| 6 | slope_int | Slope criterion drives INT (needs `adv_int`) |
| 5 | high_int | Enable high-g interrupt |
| 4 | low_int | Enable low-g interrupt |
| 3 | tapsens_int | Enable tap-sensing interrupt |

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | low_hy<1:0> | Low-g hysteresis, low bits (high bits in `HY`) |
| 5:4 | mot_cd_r | High-g debounce counter when criterion false: `00` reset, `01`/`10`/`11` count down 1/2/3 per step |
| 3:2 | ff_cd_r | Low-g debounce counter, same encoding |
| 1:0 | offset_finetuning | `00` none, `01` fine, `10` coarse, `11` full offset calibration (disables low-g interrupt while ≠ `00`) |

#### `BW_TCS` (`0x20`), `OFFSET_LSB1` (`0x35`), `TCO_Z` (`0x30`), `TCO_Y` (`0x2F`), `TCO_X` (`0x2E`), `GAIN_T` (`0x31`)

| Field | Values |
|-------|--------|
| `range<2:0>` | `000` ±1 *g*, `001` ±1.5, `010` ±2, `011` ±3, `100` ±4, `101` ±8, `110` ±16, `111` not authorised |
| `bw<3:0>` | `0000` 10 Hz, `0001` 20, `0010` 40, `0011` 75, `0100` 150, `0101` 300, `0110` 600, `0111` 1200, `1000` high-pass 1 Hz, `1001` band-pass 0.2–300 Hz, `1010–1111` not authorised |
| `mode_config<1:0>` | `00` low-noise (1200 Hz, 1025 µA), `01` ultra-low-noise (reduced bw), `10` low-noise/reduced power (150 Hz, 900 µA), `11` low-power (bw halved, 650 µA) |
| `wake_up_dur<1:0>` | `00` 20 ms, `01` 80 ms, `10` 320 ms, `11` 2560 ms (doubled in low-power mode) |
| `slope_dur<1:0>` | `00` 1, `01` 3, `10` 5, `11` 7 consecutive samples |
| `tapsens_dur<2:0>` | `000` 50 ms, `001` 75, `010` 100, `011` 150, `100` 250, `101` 500, `110` 750, `111` 1000 ms (low-noise mode; halved in low-power) |

#### `STATUS_REG1–4` (`0x09–0x0C`)

| Reg | Bit 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-----|-------|---|---|---|---|---|---|---|
| `0x09` | first_tapsens_s | — | alert | slope_sign_x | slope_sign_y | slope_sign_z | offset_st_s | ee_write |
| `0x0A` | high_th_s | low_th_s | slope_s | tapsens_s | — | low_sign_x | low_sign_y | low_sign_z |
| `0x0B` | high_th_int | low_th_int | slope_int_s | tapsens_int | — | x_first_int | y_first_int | z_first_int |
| `0x0C` | high_sign_x | high_sign_y | high_sign_z | tapsens_sign_x | tapsens_sign_y | tapsens_sign_z | — | — |

`*_s` bits follow the live criterion; `*_int` bits are latched (cleared by `reset_int`). Sign bits: 0 = positive, 1 = negative.

#### Interrupt per-axis registers

`HIGH_LOW_INFO` (`0x25`): bits 7:5 `high_int_x/y/z`, bit 4 `high_filt`, bits 3:1 `low_int_x/y/z`, bit 0 `low_filt`.  
`SLOPE_TAPSENS_INFO` (`0x24`): bits 7:5 `slope_int_x/y/z`, bit 4 `slope_filt`, bits 3:1 `tapsens_int_x/y/z`, bit 0 `tapsens_filt`.  
`*_filt` = 1 evaluates the criterion on filtered data, 0 on unfiltered data.

## Initialization Sequence

1. Power up (VDDIO before or with VDD); wait ≥ 3.5 ms (start-up time).
2. Perform one dummy read (e.g. `CHIP_ID`) — a first transaction that reads an acc LSB register returns MSB `0x00`.
3. Read `CHIP_ID` (`0x00`); verify `(value & 0x07) == 0x03`.
4. Write `CTRL_REG0` ← `0x10` (`ee_w = 1`) to unlock the image registers.
5. Read-modify-write `OFFSET_LSB1` (`0x35`): `range` ← `010` (±2 *g*), preserving `offset_x` LSBs and `smp_skip`.
6. Read-modify-write `BW_TCS` (`0x20`): `bw` ← `0100` (150 Hz), preserving `tcs`.
7. Wait ≥ 1/(2·bandwidth) (≈ 3.4 ms at 150 Hz); then the first sample is valid.

`mode_config` is left at its factory value `00` (low-noise) — the chip is calibrated for it; changing it shifts the offset.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-high |
| Level | 2 |
| Condition(s) | new data; low-g; high-g; slope (any-motion) or alert; double tap |
| Clear mechanism | non-latched: automatic; latched: write `reset_int`; new-data: read `0x02–0x07` |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_LOW_G` | `0x01` | All enabled axes |a| ≤ `low_th` for `low_dur` (free-fall) |
| `SOURCE_HIGH_G` | `0x02` | Any enabled axis |a| ≥ `high_th` for `high_dur` |
| `SOURCE_SLOPE` | `0x04` | Slope ≥ `slope_th` on any enabled axis for `slope_dur` samples |
| `SOURCE_ALERT` | `0x08` | Slope arms alert mode (exclusive with slope) |
| `SOURCE_TAP` | `0x10` | Second slope shock after `tapsens_shock` (50 ms) and before `tapsens_dur` |
| `SOURCE_NEW_DATA` | `0x20` | All axes updated |

The driver enforces the exclusions (slope ↔ alert) and sets `adv_int` for slope/alert. Interrupts are blocked briefly after wake-up, reset or bandwidth change (1 sample for thresholds, 4 for slope/tap) — the driver disables sources before changing `bw`/`range`/`mode_config` and re-enables them afterwards.

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback)` | Subscribe; callback receives `STATUS_REG3` byte |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read `STATUS_REG3` (latched flags); does not clear |
| `enable_interrupt` | `enable_interrupt(source)` | Enable one source |
| `disable_interrupt` | `disable_interrupt(source)` | Disable one source |

`clear_interrupt()` (Full) writes `reset_int` — the clear mechanism for latched interrupts.

## Data Conversion

Acceleration, per axis (14-bit two's complement; LSB register first):

```
raw = (MSB << 6) | (LSB >> 2)          # 0..16383
if raw >= 8192: raw -= 16384           # sign-extend
acceleration_g = raw / sensitivity
```

| Range (±g) | 1 | 1.5 | 2 | 3 | 4 | 8 | 16 |
|-----------|---|-----|---|---|---|---|----|
| Sensitivity (LSB/g) | 8192 | 5460 | 4096 | 2730 | 2048 | 1024 | 512 |
| Resolution (mg/LSB) | 0.13 | 0.19 | 0.25 | 0.38 | 0.50 | 0.99 | 1.98 |

Bit 0 of each LSB register is `new_data` and bit 1 is 0; the shift above discards both. With `readout_12bit = 1` the two lowest data bits read as 0. Acceleration in m/s² is not provided; values are in *g*.

Temperature (two's complement, 0.5 K/LSB; code `0x02` ≈ 25 °C, `0x80` ≈ −40 °C, trimmable with `offset_t`):

```
temperature_C = 25.0 + (int8(raw) - 2) * 0.5      # approx. -40 .. 87.5 °C
```

Thresholds and timing (`range_g` = current full-scale):
```
low_th_code  = round(threshold_g / range_g * 255)    # 8 MSBs of |a|
high_th_code = round(threshold_g / range_g * 255)
slope_th_code = round(threshold_g / (0.0156 * range_g / 2))   # 15.6 mg/LSB at ±2 g, scales with range
low_dur / high_dur code = round(duration_ms / 2.085)          # 5 * T_update, T_update = 417 us
tapsens_th_code: as slope threshold
low_hy / high_hy code = round(hysteresis_g / range_g * 255 / 32)   # 0..31
```
Datasheet constraints: interrupt fires when the counter equals `*_dur` (`*_dur = 0` fires immediately). Re-apply thresholds after `set_range`. Time base ±10 %.

## Examples

### Demo

Tilt meter with tap and free-fall detection. Configure ±2 *g*, 40 Hz bandwidth. Run `calibrate_offset` once with the board flat (asks the user to place it level), arm `set_tap(threshold_g=0.5, window_ms=250)` and `set_low_g(threshold_g=0.3, duration_ms=40)` with latching, and print every 100 ms the pitch and roll in degrees computed from x, y, z (`atan2`), the vector magnitude and the temperature. When `poll_interrupt()` reports `STATUS_TAP` print "DOUBLE TAP"; for `STATUS_LOW_G` print "FREE FALL"; then `clear_interrupt()`. Run 60 s and exit. Exercises `init`, `set_bandwidth`, `calibrate_offset`, `set_tap`, `set_low_g`, `set_latch`, `read`, `read_temperature`, `poll_interrupt`, `clear_interrupt`.

## Timing Constraints

- **Start-up:** < 3.5 ms from power-off to first valid bus access.
- **Wake-up from sleep:** < 2 ms (1 ms stable-data time) after clearing `sleep` before data is stable (> 99 %); bandwidth starts at maximum and settles. **Conformance-checked**: `wake_up` — sigrok annotation pair `wake_start` (write to `CTRL_REG0` `0x0D` with `sleep = 0`) → `wake_done` (next read starting at `0x02`). See `specs/accelerometer/bma180_timing.conf`.
- **Soft reset:** no serial transaction within 10 µs after writing `0xB6`; allow 30 ms (data ready sooner when issued from normal mode).
- **Range / mode change:** wait ≈ 1/(2·bandwidth) for filtered data; `mode_config` change causes a transient of 6–253 samples (1200–10 Hz) and possible spurious interrupts.
- **`bw` writes:** at least 10 µs between two successive `bw` writes.
- **Update rate:** T/X/Y/Z conversions at 2.4 kHz (417 µs per cycle, 1200 Hz bandwidth). New-data read-out should start within ~100 µs of INT high; I²C read-out can exceed 417 µs, so prefer polling `new_data_available` on I²C.
- **Self-test:** the electrostatic sequence takes < 10 ms; no acceleration change allowed; soft-reset afterwards.
- **EEPROM:** unused by the driver (≥ 10 ms after reset/wake before any write; 1000-cycle endurance).

## Implementation Notes

- **Calibration bits:** registers `0x2E–0x37` and `0x20` (`tcs`) and `0x26` (`tco_range`) mix factory calibration with configuration. Always read-modify-write and touch only the configuration field.
- **`ee_w`:** image registers `0x20–0x3B` ignore writes until `ee_w = 1`; the driver sets it in `init`. `ee_w` is not an EEPROM write — the EEPROM is only written by transactions to `0x40–0x5F`, which the driver never issues.
- **LSB first:** with `shadow_dis = 0` the MSB is frozen after its LSB is read; always read LSB before MSB (the 6-byte burst does). The first read of an acc LSB straight after power-on returns MSB `0x00` — do any other transaction first.
- **Reserved codes:** `range = 111`, `bw = 1010–1111` are not authorised; the driver rejects them.
- **Mode change:** the part is calibrated for `mode_config = 00`; other modes shift the offset and need `calibrate_offset`. Intermediate modes (`01`, `10`) have limited specification.
- **Offset calibration side effects:** while `offset_finetuning ≠ 00` the low-g interrupt is disabled and the fine-offset values live in the low-g registers (`0x23`, `0x25`, `0x26`, `0x29`); set it back to `00` when done and restore low-g settings.
- **Sleep / wake-up exclusion:** never set `sleep` while `wake_up` is on. All bus access except wake / soft reset is forbidden while asleep; the Full class tracks sleep state and raises on other calls.
- **Temperature description:** the datasheet's temperature text is internally inconsistent (code `0x80` ↔ −40 °C, `0x02` ↔ 25 °C, 0.5 K/LSB); the formula above satisfies all three points. Values are indicative; calibrate `offset_t` for accuracy.
- **Reset value of `0x20`:** the memory map lists `0x70` while the EEPROM-defaults table lists `bw = 0100`; the driver always writes `bw` explicitly and never relies on the power-on value.
- **Wake-up in EEPROM:** persisting `wake_up` needs the datasheet's dummy-write-to-`0x54` procedure; this is out of scope (volatile only).
- **SPI mode:** the chip also supports 4-wire SPI (mode 3: CPOL=1 CPHA=0 per datasheet, CSB low, read bit `0x80`, auto-increment, `dis_i2c = 1` recommended). This issue covers I²C only; SPI can be added later.
- **Sibling:** the BMA180 supersedes the BMA150/SMB380 family but is **not** register-compatible (different map, 14-bit data, `chip_id = 0x03`).

If this chip is register-addressed (I²C, SMBus, or SPI), accept `RegisterConnection` (not
the bare `Connection`) and call `connection.read(reg, length)` / `connection.write(reg,
data)` directly — no chip-local `_read_reg`/`_write_reg` and no `bus_type` branch. See
`specs/feature_register_access_design.md`.

## Sigrok Decoder

Decoder id `bma180`, input `['i2c']`. Matches I²C addresses `0x40` and `0x41`. Annotates every register in the Register Map by name; decodes `CTRL_REG0/1/3/4`, `BW_TCS`, `HY`, the per-axis info registers and the four status registers into named flags; decodes `range`, `bw`, `mode_config`, `wake_up_dur`, `slope_dur` and `tapsens_dur` into human-readable values; assembles the burst read of `0x02–0x07` into 14-bit signed values converted to *g* at the last-seen range, and `TEMP` into °C. `CHIP_ID` reads are checked against `0x03` (mask `0x07`); a write of `0xB6` to `0x10` is annotated "soft reset". For the Wake-up Timing Constraint the decoder emits the `timing` annotation row markers `wake_start` (write to `0x0D` with `sleep = 0`) and `wake_done` (next read starting at `0x02`), shaped per `specs/sigrok_annotations.md`'s Variable-Length Annotation Convention.
