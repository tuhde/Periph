# Chip Spec: VCNL4200

**Manufacturer:** Vishay Semiconductors  
**Datasheet:** `datasheets/light/vcnl4200.pdf` (VCNL4200 High Sensitivity Long Distance Proximity and Ambient Light Sensor With I²C Interface, Rev. 1.8, 17-Mar-2025, document 84430)  
**Category:** light  
**Transports:** I²C

## Overview

The VCNL4200 integrates a long-distance proximity sensor (PS, up to 1.5 m with an external 940 nm IRED driven by the on-chip current sink, 12- or 16-bit output, background-light cancellation, sunlight cancellation and protection, programmable multi-pulse and IRED current of 50–200 mA), a 16-bit ambient-light sensor (ALS) with a spectral response close to the human eye (resolution down to 0.003 lx/step, maximum range 1573 lx at the shortest integration time) and a separate white-light channel in a single 10-pin package. Both functions share one interrupt pin with independent high/low thresholds and persistence, and a proximity logic-output mode lets the `INT` pin act as a close/away output. The interface is a 7-bit I²C slave (SMBus compatible word protocol, 16-bit command registers, low byte first). Supply 2.5–3.6 V (IRED 2.6–5 V direct or 3.8–5.5 V with an external FET), 350 µA operating current (excluding the IRED), 0.2 µA in shutdown. Typical uses: presence detection to wake displays, collision detection in robots, parking-space and lavatory/hygienic proximity detection, ambient-light control.

## Transport Configuration

### I²C
- **Address:** `0x51` (7-bit, fixed)
- **Max clock:** 400 kHz (standard I²C/SMBus word protocol)
- **Identity register:** `0x0E` (`ID`, word) = `0x1058` (`ID_L` = `0x58`; `ID_H` bits 5:4 = `01` mean slave address `0x51`, bits 3:0 are the version code, `0000` = ES1); the probe reads 2 bytes little-endian with mask `0xF0FF` and expects `0x1058`. Registered in `registry/chips.json`
- **Probe safety:** `register_pointer` — plain command-code reads; no read has side effects except `INT_Flag` (`0x0D`, clears), which a probe does not touch
- **Register addressing:** 8-bit command code selecting a 16-bit register (`_L` byte first, then `_H`); write word = `S addr W cmd lo hi P`, read word = `S addr W cmd Sr addr R lo hi P`. Use `RegisterConnection` with `read(cmd, 2)` / `write(cmd, [lo, hi])`; there is no auto-increment across commands. All command registers are readable

## Register Map

Each command code addresses a 16-bit register; the low byte is `_L`, the high byte `_H` (read or written as one word).

| Command | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | ALS_CONF (L) / reserved (H) | R/W | `0x01` / `0x01` | ALS integration time, persistence, interrupt, shutdown; high byte reserved — **keep at `0x01`** |
| `0x01` | ALS_THDH | R/W | `0x0000` | ALS high interrupt threshold (16 bit) |
| `0x02` | ALS_THDL | R/W | `0x0000` | ALS low interrupt threshold (16 bit) |
| `0x03` | PS_CONF1 (L) / PS_CONF2 (H) | R/W | `0x01` / `0x00` | PS duty, persistence, integration time, shutdown / output width, interrupt mode |
| `0x04` | PS_CONF3 (L) / PS_MS (H) | R/W | `0x00` / `0x00` | PS multi-pulse, smart persistence, active force, sunlight / mode select, IRED current |
| `0x05` | PS_CANC | R/W | `0x0000` | PS cancellation level (16 bit) |
| `0x06` | PS_THDL | R/W | `0x0000` | PS low interrupt threshold (16 bit) |
| `0x07` | PS_THDH | R/W | `0x0000` | PS high interrupt threshold (16 bit) |
| `0x08` | PS_DATA | R | `0x0000` | PS output (12 or 16 bit) |
| `0x09` | ALS_DATA | R | `0x0000` | ALS output (16 bit) |
| `0x0A` | WHITE_DATA | R | `0x0000` | White-channel output (16 bit) |
| `0x0D` | INT_FLAG (H) | R | `0x00` | Interrupt flags in the high byte (low byte reserved); reading clears the flags |
| `0x0E` | ID | R | `0x1058` | Device ID (`ID_L` = `0x58`, `ID_H` = `0x10`) |

`0x0B`, `0x0C` are reserved (read 0).

### Bit Fields

#### `ALS_CONF` (`0x00` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | ALS_IT | Integration time: `00` 50 ms, `01` 100 ms, `10` 200 ms, `11` 400 ms |
| 5 | ALS_INT_SWITCH | 0 = ALS channel generates the interrupt, 1 = white channel |
| 3:2 | ALS_PERS | Persistence: `00` 1, `01` 2, `10` 4, `11` 8 consecutive refreshes |
| 1 | ALS_INT_EN | 1 = ALS interrupt enabled |
| 0 | ALS_SD | 0 = ALS on, 1 = ALS shut down (reset: 1) |

#### `PS_CONF1` (`0x03` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | PS_DUTY | IRED on/off duty ratio: `00` 1/160, `01` 1/320, `10` 1/640, `11` 1/1280 |
| 5:4 | PS_PERS | Interrupt persistence 1, 2, 3, 4 |
| 3:1 | PS_IT | Integration time: `000` 1T, `001` 1.5T, `010` 2T, `011` 4T, `100` 8T, `101` 9T; `110`/`111` reserved |
| 0 | PS_SD | 0 = PS on, 1 = PS shut down (reset: 1) |

#### `PS_CONF2` (`0x03` high byte)

| Bits | Name | Description |
|------|------|-------------|
| 3 | PS_HD | 0 = 12-bit PS output, 1 = 16-bit |
| 1:0 | PS_INT | `00` disabled, `01` trigger by closing, `10` trigger by away, `11` both |

#### `PS_CONF3` (`0x04` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 6:5 | PS_MPS | Multi-pulse count: `00` 1, `01` 2, `10` 4, `11` 8 |
| 4 | PS_SMART_PERS | 1 = smart persistence enabled |
| 3 | PS_AF | 1 = active force mode (one measurement per trigger) |
| 2 | PS_TRIG | Write 1 to trigger one measurement cycle in active force mode (self-clearing) |
| 1 | PS_SC_ADV | 1 = 2 × typical sunlight immunity |
| 0 | PS_SC_EN | 1 = sunlight cancellation enabled |

#### `PS_MS` (`0x04` high byte)

| Bits | Name | Description |
|------|------|-------------|
| 5 | PS_MS | 0 = normal operation with interrupt, 1 = proximity detection logic-output mode (`INT` pin = close/away output) |
| 4 | PS_SP | 1 = 1.5 × typical sunlight capability |
| 3 | PS_SPO | Output in sunlight-protect mode: 0 = `0x00`, 1 = `0xFF` |
| 2:0 | LED_I | IRED current: `000` 50 mA, `001` 75, `010` 100, `011` 120, `100` 140, `101` 160, `110` 180, `111` 200 mA |

#### `INT_FLAG` (`0x0D` high byte)

| Bit | Name | Description |
|-----|------|-------------|
| 7 | PS_UPFLAG | PS code saturation |
| 6 | PS_SPFLAG | PS entered sunlight protection |
| 5 | ALS_IF_L | ALS crossed below the low threshold |
| 4 | ALS_IF_H | ALS crossed above the high threshold |
| 1 | PS_IF_CLOSE | PS rose above `PS_THDH` |
| 0 | PS_IF_AWAY | PS dropped below `PS_THDL` |

## Initialization Sequence

1. Power VDD (2.5–3.6 V) and the IRED supply; `ALS_SD` and `PS_SD` are 1 after reset (both functions off).
2. Read `ID` (`0x0E`) and check for `0x1058` (mask `0xF0FF`).
3. Write `ALS_CONF` = `0x0100 | (IT << 6)` with `ALS_SD` = 0 (keep the high byte at `0x01`).
4. Write `PS_CONF1`/`PS_CONF2` (`0x03`): `PS_SD` = 0, `PS_HD` = 1 for the 16-bit output; optionally `PS_CONF3`/`PS_MS` (`0x04`) for multi-pulse and IRED current.
5. Wait one refresh time, read `PS_DATA` (`0x08`) and `ALS_DATA` (`0x09`).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-low, open-drain — requires external pull-up |
| Level | 2 |
| Condition(s) | ALS above `ALS_THDH` or below `ALS_THDL` (persistence 1/2/4/8); PS above `PS_THDH` (close) and/or below `PS_THDL` (away) (persistence 1–4); PS saturation and sunlight protection are reported in the flags |
| Clear mechanism | read `INT_FLAG` (`0x0D`); the pin returns high once the flags are read |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_ALS_HIGH` | `0x10` | ALS above the high threshold |
| `SOURCE_ALS_LOW` | `0x20` | ALS below the low threshold |
| `SOURCE_PS_CLOSE` | `0x02` | PS above `PS_THDH` |
| `SOURCE_PS_AWAY` | `0x01` | PS below `PS_THDL` |

(The values equal the `INT_FLAG` bit masks. ALS interrupt = `ALS_INT_EN` enables both ALS sources; PS sources are selected by `PS_INT`.)

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback)` | Subscribe; callback receives the `INT_FLAG` byte |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read and clear `INT_FLAG`, return the high byte |
| `enable_interrupt` | `enable_interrupt(source)` | `ALS_INT_EN` for the two ALS sources, `PS_INT` bits for the two PS sources |
| `disable_interrupt` | `disable_interrupt(source)` | Clear the corresponding enable bits |

### Status register bit layout

| Bit | Constant | Meaning |
|-----|----------|---------|
| 7 | `FLAG_PS_SATURATED` | PS saturated |
| 6 | `FLAG_SUNLIGHT_PROTECT` | PS in sunlight protection |
| 5 | `SOURCE_ALS_LOW` | ALS below low threshold |
| 4 | `SOURCE_ALS_HIGH` | ALS above high threshold |
| 1 | `SOURCE_PS_CLOSE` | PS close |
| 0 | `SOURCE_PS_AWAY` | PS away |

Goal: read proximity and ambient light with one call, no configuration beyond the connection.

| `init` | `connection` | — | Takes the `RegisterConnection`; checks `ID` (`0x1058` with mask `0xF0FF`), powers on ALS (50 ms integration) and PS (16-bit output, duty 1/160, 1T, 50 mA IRED), keeps the reserved byte of `0x00` at `0x01` |

## Data Conversion

```
als_counts   = ALS_DATA                                 # 16 bit
white_counts = WHITE_DATA
ps_counts    = PS_DATA                                  # 12 bit (<= 4095) or 16 bit (<= 65535)

sensitivity_lx_per_step = {50: 0.024, 100: 0.012, 200: 0.006, 400: 0.003}[ALS_IT]   # ms
lux                     = als_counts * sensitivity_lx_per_step
max_range_lx            = {50: 1573, 100: 786, 200: 393, 400: 197}[ALS_IT]
als_threshold_counts    = lux / sensitivity_lx_per_step
```

The ALS dark offset is 0–3 counts. PS output is a reflected-light count, not a distance; calibrate `PS_CANC` (cancellation) with no target in front of the sensor and choose thresholds for the mechanical design. Units: lx for the ALS (the SI unit of illuminance), counts for the proximity.

## Implementation Notes

- **RegisterConnection:** accept `RegisterConnection` and use `connection.read(cmd, 2)` / `connection.write(cmd, [lo, hi])` directly; low byte first. See `specs/feature_register_access_design.md`.
- **Read-modify-write of paired bytes:** the low and high byte of `0x00`, `0x03` and `0x04` hold unrelated settings; always rewrite both (read the word, change the field, write the word back). Keep the reserved high byte of `0x00` at `0x01` ("to achieve the stated IDD").
- **Shutdown after reset:** `ALS_SD` and `PS_SD` are 1 after power-up; nothing is measured until `init` clears them.
- **INT_FLAG clears on read:** reading `0x0D` clears the flags and releases `INT`; the driver reads it once per interrupt in `poll_interrupt` and passes the value to the callback.
- **Logic-output mode:** with `PS_MS` = 1 the `INT` pin is a close/away logic output and cannot signal ALS interrupts; the driver refuses `enable_interrupt` for ALS sources while it is on.
- **IRED supply:** `VIRED` is 2.6–5 V when the IRED is connected directly to the on-chip driver, 3.8–5.5 V with an external FET; the IRED current is up to 800 mA peak in pulses, so add the 2.2 µF reservoir capacitor.
- **Viewing angle:** the ALS has a very small viewing angle; accurate lux values need the light source directly above the sensor.
- **Sunlight:** in sunlight-protect mode the PS output is `0x00` or `0xFF` (`PS_SPO`) and `PS_SPFLAG` is set.

## Sigrok Decoder

Decoder id `vcnl4200`, input `['i2c']`. Matches I²C address `0x51`. Annotates each word access with the register name, decodes `ALS_CONF`, `PS_CONF1`–`PS_CONF3`, `PS_MS`, the thresholds, cancellation level, the PS/ALS/white data (with the computed lux for the last seen integration time), `INT_FLAG` and `ID`; warns on a write of `ALS_CONF` with a high byte other than `0x01`, on a read of `INT_FLAG` that clears flags, on a PS threshold write outside the 12-bit range when `PS_HD` = 0 and on reserved `PS_IT` codes. No conformance annotation pair is emitted (no checked timing constraint).
