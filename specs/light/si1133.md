# Chip Spec: Si1133

**Manufacturer:** Silicon Labs  
**Datasheet:** `datasheets/light/si1133.pdf` (Si1133 Data Sheet — UV Index/Ambient Light Sensor IC with I²C Interface, **Rev. 0.91, preliminary**)  
**Category:** light  
**Transports:** I²C

## Overview

The Si1133 is a UV index and ambient-light sensor with a six-channel measurement engine. Each of up to six channels ("tasks") selects a photodiode combination (small/medium/large IR, white, large white, UV, deep UV), an integration time (`HW_GAIN`), a software accumulation count (`SW_GAIN`, up to 128 samples), a decimation rate, an output width (16-bit unsigned or 24-bit signed) and an optional threshold and measurement period; results are packed sequentially into a 26-byte output area (`HOSTOUT0..25`). Channels run once on a `FORCE` command, or autonomously on `START` with a main rate (800 µs units) and three counters, optionally in burst mode. The device is configured entirely through an indirect parameter table (64 bytes) written with `PARAM_SET`; an interrupt pin signals finished channels. Supply 1.62–3.6 V, 125 nA standby, 4.5 mA for about 155 µs of processing per measurement; operating range −40…+85 °C. Typical uses: wearables, outdoor UV and ambient-light monitoring, display backlight control.

## Transport Configuration

### I²C
- **Address:** `0x55` (default, `AD` pin pulled up to VDD through 47 kΩ) or `0x52` (alternate, `AD` pulled down through 47 kΩ); sampled during start-up. The address can be changed at run time through the `I2C_ADDR` parameter (volatile, reverts on reset)
- **Max clock:** 400 kHz
- **Register addressing:** 8-bit register address (bits 5:0 address, bit 6 = auto-increment disable, default enabled)
- **Identity register:** `PART_ID` (`0x00`) = `0x33`; registered in `registry/chips.json` as `id_probe` register `0x00`, `reg_bytes` 1, `length` 1, mask `0xFF`, expected `[0x33]`.
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer (the `COMMAND` register `0x0B` is only acted on by an explicit write)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| INT | low, open-drain | interrupt output; **must be high during the power-up sequence** for low-power operation; needs a pull-up |
| AD | — | I²C address select, sampled at start-up: pull-up 47 kΩ → `0x55`, pull-down 47 kΩ → `0x52` |
| RPullup (pins 7, 9) | — | connect to VDD through the pull-up resistors specified in the datasheet's application circuit |
| SDA, SCL | — | I²C; pull-ups required |
| VDD, GND | — | 1.62–3.6 V; ≥ 25 ms start-up time after VDD > 1.62 V; the VDD_OFF level (≤ 1.0 V) resets the part without a reset pin |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | PART_ID | R | `0x33` | Part number |
| `0x01` | HW_ID | R | — | bits 4:0 implementation code (`0x03` for the Si1133-AA00), bits 7:5 silicon revision |
| `0x02` | REV_ID | R | — | product revision `0xMN` |
| `0x03`/`0x04` | INFO0/INFO1 | R | `0x00` | |
| `0x0A` | HOSTIN0 | R/W | `0x00` | input byte for `PARAM_SET` |
| `0x0B` | COMMAND | R/W | `0x00` | command opcode |
| `0x0F` | IRQ_ENABLE | R/W | `0x00` | bits 5:0 enable the interrupt of channel 5…0 (the datasheet's register table calls this register `RESET`, the section 5.4.8 `IRQENABLE`) |
| `0x10` | RESPONSE1 | R | `0x00` | parameter read-back (`PARAM_QUERY`) or echo of `PARAM_SET` |
| `0x11` | RESPONSE0 | R | `0x0F` | bit 7 `RUNNING`, bit 6 `SUSPEND`, bit 5 `SLEEP`, bit 4 `CMD_ERR`, bits 3:0 `CMMND_CTR` (counter, or error code if `CMD_ERR`) |
| `0x12` | IRQ_STATUS | R | `0x00` | bits 5:0 = channel 5…0 result ready (cleared when read) |
| `0x13`–`0x2C` | HOSTOUT0–25 | R | `0x00` | measurement results, packed sequentially from the lowest enabled channel |

`RESPONSE0` after reset is `0xXXX01111` (counter = `0xF` marks a fresh reset); the state bits show `RUNNING` right after reset and then `SLEEP` after initialisation. Error codes (with `CMD_ERR = 1`): `0x10` invalid command, `0x11` parameter access to an invalid location, `0x12` ADC saturation/overflow of accumulation, `0x13` output buffer overflow (burst mode with more than 26 bytes).

### Commands (`COMMAND`, `0x0B`)

| Command | Code | Description |
|---------|------|-------------|
| `RESET_CMD_CTR` | `0x00` | Sets the `RESPONSE0` counter to 0 and clears errors |
| `RESET_SW` | `0x01` | Software reset (parameter table and registers return to power-up values); counter = `0xF` |
| `FORCE` | `0x11` | Runs once every channel in `CHAN_LIST` that has no counter selected (`MEASCONFIGx.COUNTER_INDEX = 0`) |
| `PAUSE` | `0x12` | Pauses autonomous measurements |
| `START` | `0x13` | Starts autonomous measurements for channels with a counter selected |
| `PARAM_QUERY` | `0b01pppppp` | Reads parameter `pppppp` to `RESPONSE1` |
| `PARAM_SET` | `0b10pppppp` | Writes `HOSTIN0` to parameter `pppppp`; `RESPONSE1` echoes it |

Every successfully completed command except `RESET_CMD_CTR`/`RESET_SW` increments `CMMND_CTR` (wraps within 4 bits).

### Parameter table (via `PARAM_SET` / `PARAM_QUERY`)

| Address | Name | Description |
|---------|------|-------------|
| `0x00` | I2C_ADDR | new I²C address |
| `0x01` | CHAN_LIST | bits 5:0 enable channels 5…0 |
| `0x02 + 4c` | ADCCONFIGc | bits 6:5 `DECIM_RATE`, bits 4:0 `ADCMUX` (c = channel 0…5) |
| `0x03 + 4c` | ADCSENSc | bit 7 `HSIG`, bits 6:4 `SW_GAIN`, bits 3:0 `HW_GAIN` |
| `0x04 + 4c` | ADCPOSTc | bit 6 `24BIT_OUT`, bits 5:3 `POSTSHIFT`, bits 1:0 `THRESH_SEL` (threshold 0–2, 0 = none) |
| `0x05 + 4c` | MEASCONFIGc | bits 7:6 `COUNTER_INDEX` (0 = none → forced only; 1–3 select a `MEASCOUNT` counter, see notes) |
| `0x1A`/`0x1B` | MEASRATE_H/L | main measurement-rate counter, 800 µs per count |
| `0x1C`–`0x1E` | MEASCOUNT0–2 | three rate-extension counters |
| `0x25`–`0x2A` | THRESHOLD0..2_H/L | three 16-bit thresholds |
| `0x2B` | BURST | bit 7 enable, bits 6:0 number of readings |

`ADCMUX` photodiode selections: `0x00` small IR, `0x01` medium IR, `0x02` large IR, `0x0B` white, `0x0D` large white, `0x18` UV, `0x19` deep UV. `DECIM_RATE`: `0` 1024 clocks (48.8 µs at `HW_GAIN` 0, normal), `1` 2048, `2` 4096, `3` 512 clocks (21 MHz clock). `HW_GAIN`: integration time doubles per step (0 = 24.4 µs for 512 clocks, … 10 = 25 ms, 11 = 50 ms, 12–15 unused); each measurement is made twice internally for offset cancellation. `SW_GAIN` = 2^n accumulated samples (1…128). `HSIG = 1` divides the sensitivity by 14.5 (direct sunlight). `POSTSHIFT` right-shifts the accumulated result.

## Initialization Sequence

1. Power up VDD (> 1.62 V) with INT high and wait ≥ 25 ms; read `PART_ID` (`0x33`).
2. Optionally send `RESET_SW` and wait for `RESPONSE0` to show `SLEEP`.
3. Read `RESPONSE0` (store the counter), write the parameter value to `HOSTIN0` and `COMMAND = 0x80 | address`, read `RESPONSE0` again and check that the counter incremented (no `CMD_ERR`).
4. Configure channel 0 for UV (`ADCCONFIG0 = 0x18`, `ADCSENS0`, `ADCPOST0 = 0x40` for 24-bit output), channel 1 for white light (`0x0B`), then `CHAN_LIST = 0x03`.
5. Forced mode: `COMMAND = FORCE` (`0x11`), poll `IRQ_STATUS` (or wait), read `HOSTOUT0…` and decode the 24-bit signed values.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-low, open-drain — requires external pull-up (must be high at power-up) |
| Level | 2 (one source per channel) |
| Condition(s) | a channel in `CHAN_LIST` with its `IRQ_ENABLE` bit finished a measurement (in burst mode: the readings count was reached or the buffer is full); a threshold crossing when `THRESH_SEL` is set |
| Clear mechanism | reading `IRQ_STATUS` clears it |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_CHANNEL0` … `SOURCE_CHANNEL5` | `0x01` … `0x20` | channel 0…5 result ready |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on INT (falling edge) via `connection.int_pin` (or `int_pin`), otherwise a polling task calling `poll_interrupt`; `callback(status)` receives the `IRQ_STATUS` bit mask |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `IRQ_STATUS` (clears it), returns the channel mask (0 = none) |
| `enable_interrupt` | `enable_interrupt(source)` | sets the channel bit in `IRQ_ENABLE` |
| `disable_interrupt` | `disable_interrupt(source)` | clears it |

## Implementation Stages

### Minimal

Goal: read UV and white-light counts with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Stores the register-addressed `Connection`; waits 25 ms, verifies `PART_ID = 0x33`, `RESET_SW`, configures channel 0 = UV (`ADCMUX 0x18`, `HW_GAIN` 9, `24BIT_OUT`) and channel 1 = white (`ADCMUX 0x0B`, `HW_GAIN` 7, `24BIT_OUT`), `CHAN_LIST = 0x03` |
| `read` | — | `{uv, white}` | `FORCE`, waits for both `IRQ_STATUS` bits, returns the two signed 24-bit counts (raw ADC counts; negative values are possible near dark) |

**Sensible defaults:** forced mode, 24-bit output, decimation rate 0, no software accumulation, normal signal range.

### Full

Goal: complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|

**Constants:** `MUX_SMALL_IR` (`0x00`), `MUX_MEDIUM_IR` (`0x01`), `MUX_LARGE_IR` (`0x02`), `MUX_WHITE` (`0x0B`), `MUX_LARGE_WHITE` (`0x0D`), `MUX_UV` (`0x18`), `MUX_UV_DEEP` (`0x19`).

**Additional configuration options:** per-channel photodiode, integration time, accumulation, decimation, signal range, output width and shift, thresholds, autonomous rates/counters, burst mode, interrupt mask, I²C address.

## Data Conversion

```
# 16-bit channel:  value = (b0 << 8) | b1                    (unsigned, MSB first)
# 24-bit channel:  value = (b0 << 16) | (b1 << 8) | b2        (signed two's complement)
# Channels are packed in HOSTOUT0.. in channel order (lowest enabled first); 24BIT_OUT selects 3 bytes, otherwise 2.

integration_time_s = 48.8e-6 * 2**hw_gain      # DECIM_RATE 0 (1024 clocks), per half-measurement; two are summed per result

autonomous_period_s = 800e-6 * MEASRATE * MEASCOUNTk
```

Counts are raw ADC values (white minus dark response for the visible channels); the datasheet gives the responsivity per photodiode combination and light source but **no** lux or UV-index formula, so the driver reports counts. A UV index needs the Silicon Labs UV algorithm and calibration for the product's window; apply it above the driver. The preliminary datasheet (Rev. 0.91) leaves the byte order of the multi-byte `HOSTOUT` fields implicit; the driver assumes the standard MSB-first layout of the Si113x family (verify on hardware before the first release).

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Start-up after VDD > 1.62 V | ≥ 25 ms |
| Processing time per measurement (UV or ALS) | ≈ 155 µs typ. |
| A/D start-up time per measurement | ≈ 48.8 µs typ. |
| Measurement time | `48.8 µs × 2^HW_GAIN` per half-measurement (two per result), × `SW_GAIN` samples, scaled with the decimation rate |
| Autonomous period | 800 µs × `MEASRATE` × `MEASCOUNTk` |
| I²C clock | ≤ 400 kHz |

`IRQ_STATUS` and the `RESPONSE0` counter mark the end of a measurement/command but the preliminary datasheet gives no maximum time for them, so `si1133_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed connection:** accept `RegisterConnection` and use `read(reg, n)` / `write(reg, data)` directly; no chip-local helpers (see `specs/feature_register_access_design.md`).
- **Command handshake:** read `RESPONSE0` before every command, write the command, and read `RESPONSE0` again until the counter changed (or `CMD_ERR` is set); the `HOSTIN0` write and the `COMMAND` write can be one I²C transaction, the `RESPONSE0` and `RESPONSE1` reads must not be in one transaction.
- **On error:** send `RESET_CMD_CTR` (or `RESET_SW`); an invalid parameter address sets `CMD_ERR` with code `0x11`. One safe option is a `RESET_CMD_CTR` before every command.
- **Parameters are volatile:** the parameter table is lost on power-down and `RESET_SW`; configure after every reset.
- **INT high at power-up:** the open-drain INT pin must be high while the part powers up (use the pull-up), otherwise it does not enter low-power operation.
- **Data validity:** in autonomous mode the data stays valid until the next reading; read it within the next measurement period (an I²C burst read starting at `IRQ_STATUS` is the efficient way), otherwise the values may be overwritten or smeared.
- **`COUNTER_INDEX` meaning:** 0 = no counter (the channel is only run by `FORCE`/burst); 1–3 select `MEASCOUNT0..2` (the datasheet numbers them 1–3 in the field table and 0–2 in the register table: keep the table-numbering consistent in the driver and verify on hardware).
- **Preliminary datasheet:** Rev. 0.91 contains typos (e.g. `MEASCONFIGx` listed at `0x0A` instead of `0x09`, field names `THRESH_SEL` vs. `THRESH_EN`, `HW_GAIN[2:0]` vs. `[3:0]`); the spec uses the parameter-table addresses (`0x05 + 4c`) and `[3:0]`. Validate the spec against the production datasheet (and Silicon Labs' reference code) when hardware is available.
- **Address overlap:** `0x52`/`0x55` are shared with other sensors; the `PART_ID` check at `0x00` identifies the Si1133.

## Sigrok Decoder

Decoder id `si1133`, input `['i2c']`. Matches I²C addresses `0x52` and `0x55`. Annotates every register access with the register name, decodes the `COMMAND` opcodes (parameter query/set with the parameter name, `FORCE`, `START`, `PAUSE`, resets), `RESPONSE0` (state, counter, error code), `IRQ_STATUS`, and the channel parameters (`ADCMUX` photodiode name, gains, decimation, output width); assembles the `HOSTOUT` fields into values per enabled channel. Warns on `CMD_ERR`, a missing counter increment after a command, and a `FORCE` with an empty `CHAN_LIST`. No conformance annotation pair is emitted (no checked timing constraint).
