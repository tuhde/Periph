# Chip Spec: Si1132

**Manufacturer:** Silicon Labs  
**Datasheet:** `datasheets/light/si1132.pdf` (Si1132 UV Index and Ambient Light Sensor with I²C Interface, Rev. 1.2)  
**Category:** light  
**Transports:** I²C

## Overview

The Si1132 is a UV index and ambient-light sensor in the Si114x family: a visible-light photodiode, a small infrared photodiode and a UV-sensitive channel feed a 17-bit ADC controlled by a small sequencer. The sensor can report the **UV index** directly (`AUX_DATA / 100`, with the UV coefficient registers set to the default `0x7B, 0x6B, 0x01, 0x00`), the visible and infrared ambient-light counts, and the auxiliary measurements (die temperature, supply voltage). Measurements are started by commands (forced) or run autonomously at a programmed interval; an interrupt pin signals completed conversions. Configuration is partly in I²C registers and partly in an indirect parameter RAM written through `PARAM_WR`/`COMMAND` and read through `PARAM_RD`. Supply 1.71–3.6 V, 150 nA standby, 4.3 mA for about 285 µs per measurement; operating range −40…+85 °C. Typical uses: wearables, outdoor UV and ambient-light monitoring, display backlight control.

## Transport Configuration

### I²C
- **Address:** `0x60` (7-bit, fixed; changeable at run time with the `BUSADDR` command, volatile); the chip also answers the global address `0x00` and the global reset command `0x06`
- **Max clock:** 400 kHz (the datasheet specifies standard and fast mode)
- **Register addressing:** 8-bit register address (bits 5:0 address, bit 6 = auto-increment **disable**, bit 7 reserved); auto-increment is on by default, so a multi-byte access walks through consecutive registers
- **Identity register:** `PART_ID` (`0x00`) = `0x32` (Si1132); registered in `registry/chips.json` as `id_probe` register `0x00`, `reg_bytes` 1, `length` 1, mask `0xFF`, expected `[0x32]`. The Si1145/46/47 (`0x45`/`0x46`/`0x47`) share the address `0x60` and register map
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer (a COMMAND write of a defined opcode is a real write, but the register address alone is harmless)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| INT | low | interrupt output: asserted while `IRQ_STATUS & IRQ_ENABLE` is non-zero and `INT_CFG.INT_OE = 1`; cleared by writing the status bits back |
| SDA, SCL | — | I²C; pull-ups required |
| VDD, GND | — | 1.71–3.6 V; ≥ 25 ms start-up time after VDD exceeds 1.71 V before the first I²C access |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | PART_ID | R | `0x32` | Part number (Si1132) |
| `0x01` | REV_ID | R | — | Hardware revision |
| `0x02` | SEQ_ID | R | — | Sequencer firmware revision |
| `0x03` | INT_CFG | R/W | `0x00` | bit 0 `INT_OE`: 1 = INT pin driven low on an enabled interrupt |
| `0x04` | IRQ_ENABLE | R/W | `0x00` | bit 0 `ALS_IE`: interrupt when VIS/UV (CHLIST) results are ready |
| `0x07` | HW_KEY | R/W | `0x00` | must be written `0x17` after power-up for proper operation |
| `0x08` | MEAS_RATE0 | R/W | `0x00` | `MEAS_RATE` bits 7:0 |
| `0x09` | MEAS_RATE1 | R/W | `0x00` | `MEAS_RATE` bits 15:8; the 16-bit value × 31.25 µs is the wake-up interval; 0 = forced mode |
| `0x13`–`0x16` | UCOEF0–UCOEF3 | R/W | — | UV index coefficients (default `0x7B`, `0x6B`, `0x01`, `0x00`) |
| `0x17` | PARAM_WR | R/W | `0x00` | data written to the parameter RAM by `PARAM_SET` |
| `0x18` | COMMAND | R/W | `0x00` | command opcode (see below) |
| `0x20` | RESPONSE | R | `0x00` | command result / error (see below) |
| `0x21` | IRQ_STATUS | R/W | `0x00` | bit 5 `CMD_INT`, bit 0 `ALS_INT`; write 1 to clear |
| `0x22`/`0x23` | ALS_VIS_DATA0/1 | R | `0x00` | visible ambient light, 16-bit little-endian (low byte first) |
| `0x24`/`0x25` | ALS_IR_DATA0/1 | R | `0x00` | infrared ambient light, 16-bit little-endian |
| `0x2C`/`0x2D` | AUX_DATA0/1 (UVINDEX0/1) | R | `0x00` | auxiliary data or UV index × 100, 16-bit little-endian |
| `0x2E` | PARAM_RD | R | `0x00` | parameter RAM read-back |
| `0x30` | CHIP_STAT | R | `0x00` | bit 2 `RUNNING`, bit 1 `SUSPEND`, bit 0 `SLEEP` |

`0x22`–`0x2D` also report the factory calibration data after the `GET_CAL` command.

### Commands (`COMMAND`, `0x18`)

| Command | Encoding | Description |
|---------|----------|-------------|
| `PARAM_QUERY` | `100 aaaaa` | Reads parameter `aaaaa` into `PARAM_RD` (and `RESPONSE`) |
| `PARAM_SET` | `101 aaaaa` | Writes `PARAM_WR` to parameter `aaaaa`; the value is echoed in `PARAM_RD` |
| `NOP` | `0x00` | Clears the `RESPONSE` counter/error |
| `RESET` | `0x01` | Software reset of the firmware; no commands for ≥ 1 ms afterwards; `RESPONSE` is not incremented |
| `BUSADDR` | `0x02` | Applies the I²C address in the `I2C_ADDR` parameter |
| `ALS_FORCE` | `0x06` | One forced ALS (and UV) measurement of the channels enabled in `CHLIST` |
| `ALS_PAUSE` | `0x0A` | Pauses autonomous measurements |
| `ALS_AUTO` | `0x0E` | Starts/restarts the autonomous measurement loop |
| `GET_CAL` | `0x12` | Writes the factory calibration to `0x22`–`0x2D` |

### `RESPONSE` (`0x20`)

`0000 cccc` = no error; `cccc` is a circular counter incremented after each completed command. `1000 0000` INVALID_SETTING; `1000 1100` ALS_VIS_ADC_OVERFLOW; `1000 1101` ALS_IR_ADC_OVERFLOW; `1000 1110` AUX_ADC_OVERFLOW (cleared with `NOP`).

### Parameter RAM (via `PARAM_SET` / `PARAM_QUERY`)

| Parameter | Offset | Description |
|-----------|--------|-------------|
| `I2C_ADDR` | `0x00` | new I²C address (used by `BUSADDR`) |
| `CHLIST` | `0x01` | bit 7 `EN_UV`, bit 6 `EN_AUX`, bit 5 `EN_ALS_IR`, bit 4 `EN_ALS_VIS`; must be non-zero before measurements |
| `ALS_ENCODING` | `0x06` | bit 5 `ALS_IR_ALIGN`, bit 4 `ALS_VIS_ALIGN`: 1 = report the least significant 16 bits of the 17-bit ADC, 0 = the 16 MSBs |
| `ALS_IR_ADCMUX` | `0x0E` | `0x00` = small IR photodiode |
| `AUX_ADCMUX` | `0x0F` | `0x65` = temperature (relative only), `0x75` = VDD voltage |
| `ALS_VIS_ADC_COUNTER` | `0x10` | bits 6:4 `VIS_ADC_REC` (recommended: one's complement of `ALS_VIS_ADC_GAIN`) |
| `ALS_VIS_ADC_GAIN` | `0x11` | bits 2:0: integration time × 2^n (0–7) |
| `ALS_VIS_ADC_MISC` | `0x12` | bit 5 `VIS_RANGE`: 1 = high signal range (sensitivity ÷ 14.5, for direct sunlight) |
| `ALS_IR_ADC_COUNTER` | `0x1D` | bits 6:4 `IR_ADC_REC` |
| `ALS_IR_ADC_GAIN` | `0x1E` | bits 2:0: integration time × 2^n |
| `ALS_IR_ADC_MISC` | `0x1F` | bit 5 `IR_RANGE` |

`VIS_ADC_REC` / `IR_ADC_REC`: `000` 1 ADC clock (50 ns × 2^gain), `001` 7, `010` 15, `011` 31, `100` 63, `101` 127, `110` 255, `111` 511 clocks (default `0x70` = `111`); `ALS_VIS_ADC_GAIN` / `ALS_IR_ADC_GAIN` default 0.

## Initialization Sequence

1. Power up VDD (> 1.71 V) and wait ≥ 25 ms.
2. Write `HW_KEY = 0x17`.
3. Write the UV coefficients `UCOEF0..3 = 0x7B, 0x6B, 0x01, 0x00`.
4. Write the parameters `CHLIST` (e.g. `0xB0` = UV + ALS IR + ALS VIS), `ALS_VIS_ADC_MISC` / `ALS_IR_ADC_MISC` ranges as needed, each with `PARAM_SET` (write `PARAM_WR`, then `COMMAND = 0xA0 | offset`) and check that `RESPONSE`'s counter incremented.
5. Forced mode: write `ALS_FORCE` (`0x06`), poll `IRQ_STATUS.ALS_INT` (or wait the measurement time), read `0x22`–`0x2D`, clear `IRQ_STATUS`. Autonomous mode: write `MEAS_RATE`, then `ALS_AUTO` (`0x0E`).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-low |
| Level | 1 |
| Condition(s) | ALS/UV measurement complete (`IRQ_STATUS.ALS_INT`) |
| Clear mechanism | write 1 to the status bits in `IRQ_STATUS` |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on INT (falling edge) via `connection.int_pin` (or `int_pin`), otherwise a polling task calling `poll_interrupt`; `callback(status)` receives the `IRQ_STATUS` value |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `IRQ_STATUS`, writes it back to clear it, returns the value (0 = none) |
| `enable_interrupt` | `enable_interrupt()` | `INT_CFG.INT_OE = 1`, `IRQ_ENABLE.ALS_IE = 1` |
| `disable_interrupt` | `disable_interrupt()` | clears both |

## Implementation Stages

### Minimal

Goal: read the UV index and the ambient-light counts with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Stores the register-addressed `Connection`; waits 25 ms, verifies `PART_ID = 0x32`, writes `HW_KEY`, `UCOEF`, `CHLIST` = UV + IR + VIS (`0xB0`) |
| `read` | — | `{uv_index, visible, infrared}` | Forced measurement (`ALS_FORCE`), waits for `ALS_INT`, returns the UV index (`AUX_DATA / 100`) and the raw 16-bit visible/infrared counts |

**Sensible defaults:** forced mode (lowest power), gain 0 / normal signal range, all three channels enabled, UV coefficients at the datasheet defaults (open-air UV index).

### Full

Goal: complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `read_uv_index` | — | float | UV index from a forced UV measurement |
| `read_visible` / `read_infrared` | — | int | 16-bit raw ALS count of the corresponding channel |
| `read_raw` | — | `{visible, infrared, aux}` | Latest data registers without starting a measurement |
| `read_temperature_raw` | — | int | Auxiliary channel with `AUX_ADCMUX = 0x65` (relative die temperature only) |
| `read_vdd_raw` | — | int | Auxiliary channel with `AUX_ADCMUX = 0x75` |
| `set_channels` | `uv: bool, visible: bool, infrared: bool, aux: bool = False` | — | Writes `CHLIST` (at least one channel) |
| `set_gain` | `visible: int = 0, infrared: int = 0` | — | `ALS_*_ADC_GAIN` (0–7, integration time × 2^n) and the recommended recovery count |
| `set_high_range` | `visible: bool, infrared: bool` | — | `VIS_RANGE` / `IR_RANGE` (sensitivity ÷ 14.5, direct sunlight) |
| `set_alignment` | `visible_low: bool, infrared_low: bool` | — | `ALS_ENCODING` align bits (least significant 16 bits vs. the 16 MSBs) |
| `set_uv_coefficients` | `ucoef: tuple[int, int, int, int]` | — | Writes `UCOEF0..3` (use the calibration values to correct part-to-part variation) |
| `read_calibration` | — | `list[int]` | `GET_CAL` then `0x22`–`0x2D` (12 bytes; the Silicon Labs Si114x calibration structure) |
| `start_autonomous` | `interval: float` | — | `MEAS_RATE = round(interval / 31.25 µs)` then `ALS_AUTO`; `interval = 0` returns to forced mode |
| `pause` | — | — | `ALS_PAUSE` |
| `force` | — | — | `ALS_FORCE` without waiting |
| `measurement_ready` | — | bool | `IRQ_STATUS.ALS_INT` |
| `read_response` | — | `(counter, error)` | `RESPONSE` decoded |
| `set_i2c_address` | `address: int` | — | `I2C_ADDR` parameter then `BUSADDR` (volatile) |
| `reset` | — | — | `RESET` command, waits 1 ms, writes `HW_KEY` again |
| interrupt API | | | see Interrupt section |

**Additional configuration options:** channel list, ADC gain and range per channel, alignment, UV coefficients, measurement interval, interrupt.

## Data Conversion

```
visible  = (ALS_VIS_DATA1 << 8) | ALS_VIS_DATA0          # little-endian pairs
infrared = (ALS_IR_DATA1  << 8) | ALS_IR_DATA0
aux      = (AUX_DATA1     << 8) | AUX_DATA0

uv_index = aux / 100                                     # CHLIST.EN_UV, UCOEF = 7B 6B 01 00

# raw ADC response at gain 0 (datasheet, typical):
#   visible 0.282 counts/lux (sunlight), 0.319 (2500 K bulb), 0.146 (cool white fluorescent)
#   infrared 2.44 counts/lux (sunlight), 8.46 (2500 K bulb), 0.71 (cool white fluorescent)
# a higher gain multiplies the integration time (and the count) by 2^gain;
# VIS_RANGE / IR_RANGE reduce the sensitivity by 14.5.
```

The datasheet gives the UV index as 100× the value in `AUX_DATA` and the counts-per-lux responsivities only as ADC-count figures per light source; there is no source-independent lux formula, so the driver reports **counts** and the UV index, not lux. Apply a lux factor suited to the light source in the application. The datasheet gives a UV measurement time of about 285 µs; the UV index needs the `VIS_RANGE`/`IR_RANGE` bits set for outdoor sunlight.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Start-up after VDD > 1.71 V | ≥ 25 ms |
| Active measuring time (UV or VIS + IR) | ≈ 285 µs at default settings |
| After `RESET` | no command for ≥ 1 ms |
| `MEAS_RATE` unit | 31.25 µs per count (wake-up interval) |
| I²C clock | ≤ 400 kHz |

`ALS_INT` and the `RESPONSE` counter mark the end of a command or measurement but the datasheet gives no maximum time for them, so `si1132_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed connection:** accept `RegisterConnection` and use `read(reg, n)` / `write(reg, data)` directly; no chip-local helpers (see `specs/feature_register_access_design.md`).
- **Parameter RAM access is a 2-step command:** write `PARAM_WR`, then `COMMAND = 0xA0 | offset`; verify by reading `RESPONSE` (the counter must have incremented, no error bit) and/or `PARAM_RD`. A read uses `COMMAND = 0x80 | offset` and `PARAM_RD`. Read `RESPONSE` before the command to detect the increment. After an error send `NOP`.
- **`HW_KEY` first:** nothing works until `0x17` has been written to `HW_KEY` after each power-up and `RESET`.
- **CHLIST must be non-zero** before forced or autonomous measurements.
- **Little-endian data registers:** the low byte is at the lower address.
- **Erratum (SEQ_ID = `0x01`):** a code error swaps the `MEAS_RATE` bytes (low byte at `0x0A`, high byte at `0x08`); the driver reads `SEQ_ID` and writes the matching byte order.
- **UV needs the high-range bits and coefficients:** configure `UCOEF = 7B 6B 01 00` and the `VIS_RANGE`/`IR_RANGE` bits for the UV index in sunlight; with an overlay that is not 100 % transmissive contact Silicon Labs for the coefficients.
- **UV channel and AUX share the data registers:** `EN_UV` and `EN_AUX` both write `AUX_DATA`; do not enable both. The temperature channel is relative only.
- **Interrupt clearing:** write the read value back to `IRQ_STATUS`; the chip does not clear it by itself.
- **Address overlap:** `0x60` is shared with the Si1145/46/47 (different `PART_ID`), other parts; use the ID check.

## Sigrok Decoder

Decoder id `si1132`, input `['i2c']`. Matches I²C address `0x60`. Annotates every register access with the register name, decodes the `COMMAND` opcodes (parameter query/set with the parameter name, `ALS_FORCE`, `ALS_AUTO`, `RESET`, …), `RESPONSE` (counter or error), `IRQ_STATUS`, `CHLIST` and the ADC parameters, assembles the 16-bit data registers and the UV index (`AUX / 100`), and warns when `HW_KEY` was not written, when a measurement is requested with an empty `CHLIST`, and on `RESPONSE` error codes. No conformance annotation pair is emitted (no checked timing constraint).
