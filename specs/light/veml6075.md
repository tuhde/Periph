# Chip Spec: VEML6075

**Manufacturer:** Vishay Semiconductors  
**Datasheet:** `datasheets/light/veml6075.pdf` (VEML6075 UVA and UVB Light Sensor with I²C Interface, Rev. 1.2, 23-Nov-16, document 84304)  
**Category:** light  
**Transports:** I²C

## Overview

The VEML6075 senses ultraviolet light in two bands — UVA (peak sensitivity 365 nm) and UVB (peak 330 nm), each ±10 nm half-bandwidth — and provides 16-bit digital outputs for each, plus two compensation channels (UVcomp1 for the visible, UVcomp2 for the infrared response) that allow a UV-index calculation with the visible/IR contribution subtracted. The visible/IR response is below 1 % (typically 0.5 %). It has built-in temperature compensation over −40 to +85 °C, a selectable integration time of 50–800 ms, a high-dynamic-range setting and an active-force mode (one measurement per trigger). The interface is a 7-bit I²C slave (SMBus compatible word protocol, 16-bit registers, low byte first, 100–400 kHz). Supply 1.7–3.6 V, 480 µA typical at 1.8 V, 0.8 µA in shutdown, 4-pin OPLGA package (2.0 × 1.25 × 1.0 mm). There is no interrupt output. Typical uses: UV-index measurement in handheld devices, wearables, notebooks and industrial/medical applications.

## Transport Configuration

### I²C
- **Address:** `0x10` (7-bit, fixed)
- **Max clock:** 400 kHz (standard and fast mode)
- **Identity register:** `0x0C` (`ID`, word) = `0x0026` (`ID_L` = `0x26` = device ID LSB; `ID_H` carries the company code, the slave-address bits and the version code); the probe reads 2 bytes little-endian with mask `0x0FFF` and expects `0x0026`. Registered in `registry/chips.json`
- **Probe safety:** `register_pointer` — plain command-code reads, no side effects
- **Register addressing:** 8-bit command code selecting a 16-bit register (low byte first); write word = `S addr W cmd lo hi P`, read word = `S addr W cmd Sr addr R lo hi P` (a repeated start is required, no STOP between the command and the read). Use `RegisterConnection` with `read(cmd, 2)` / `write(cmd, [lo, hi])`; no auto-increment across commands

## Register Map

| Command | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | UV_CONF (L) / reserved (H) | R/W | `0x0000` | Integration time, dynamic, active force, trigger, shutdown |
| `0x01`–`0x06`, `0x08` | reserved | R/W | `0x0000` | Reserved |
| `0x07` | UVA_DATA | R | `0x0000` | UVA output (16 bit) |
| `0x09` | UVB_DATA | R | `0x0000` | UVB output (16 bit) |
| `0x0A` | UVCOMP1_DATA | R | `0x0000` | UVcomp1 (visible-noise compensation) output |
| `0x0B` | UVCOMP2_DATA | R | `0x0000` | UVcomp2 (infrared-noise compensation) output |
| `0x0C` | ID | R | `0x0026` | Device ID |

The device keeps the last results until the next measurement is made after a wake-up (data auto-memorisation).

### Bit Fields

#### `UV_CONF` (`0x00` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 6:4 | UV_IT | Integration time: `000` 50 ms, `001` 100 ms, `010` 200 ms, `011` 400 ms, `100` 800 ms; `101`–`111` reserved |
| 3 | HD | 0 = normal dynamic setting, 1 = high dynamic setting |
| 2 | UV_TRIG | In active-force mode, writing 1 triggers one measurement (returns to 0 automatically) |
| 1 | UV_AF | 0 = normal (continuous) mode, 1 = active force mode |
| 0 | SD | 0 = power on, 1 = shut down |

Bit 7 and the high byte (`0x00` high) are reserved and must be written as 0.

## Initialization Sequence

1. Power VDD (1.7–3.6 V).
2. Read `ID` (`0x0C`) and check `0x0026` (mask `0x0FFF`).
3. Write `UV_CONF` = `0x00` (50 ms, normal dynamic, continuous, powered on) or the desired integration time.
4. Wait one integration time (plus margin), then read `UVA_DATA` (`0x07`), `UVB_DATA` (`0x09`), `UVCOMP1_DATA` (`0x0A`), `UVCOMP2_DATA` (`0x0B`) with read-word transactions.

## Implementation Stages

### Minimal

Goal: read UVA, UVB and the UV index with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Takes the `RegisterConnection`; checks `ID` (`0x0026` with mask `0x0FFF`), writes `UV_CONF` = `0x10` (100 ms integration, normal dynamic, continuous, powered on) |
| `read` | — | `{uva, uvb, uv_index}` | Reads the four data words, returns the raw UVA/UVB counts and the compensated UV index (see Data Conversion) |

**Sensible defaults:** `UV_CONF` = `0x10` (100 ms), normal dynamic range, continuous mode.

## Data Conversion

```
uva, uvb, uvcomp1, uvcomp2 = unsigned 16-bit words (low byte first)

# UV index per Vishay application note 84339 (not in the datasheet; coefficients to be
# confirmed against the application note before implementation, values quoted below
# are those commonly published for the open-air sensor):
uva_comp = uva - a * uvcomp1 - b * uvcomp2          # a = 2.22, b = 1.33
uvb_comp = uvb - c * uvcomp1 - d * uvcomp2          # c = 2.95, d = 1.74
uv_index = ((uva_comp * uva_response) + (uvb_comp * uvb_response)) / 2
           # uva_response = 0.001461, uvb_response = 0.002591  (for 100 ms, normal dynamic)

# responsivity from the datasheet at 50 ms:  UVA 0.93 counts per uW/cm^2, UVB 2.1 counts per uW/cm^2
irradiance_w_m2 = counts / (responsivity * IT_ms / 50) * 0.01      # 1 uW/cm^2 = 0.01 W/m^2
```

The datasheet gives responsivities only for 50 ms integration and refers to the application note for the UV-index calculation; the driver exposes the coefficients as parameters. Units are SI (W/m²); counts and the dimensionless UV index otherwise.

## Implementation Notes

- **RegisterConnection:** accept `RegisterConnection` and use `connection.read(cmd, 2)` / `connection.write(cmd, [lo, hi])` directly; low byte first. See `specs/feature_register_access_design.md`.
- **Repeated start on read:** the datasheet requires a repeated START (no STOP) between the command code and the read.
- **Reserved bits:** write 0 to bit 7 of `UV_CONF` and to the high byte; the reserved registers `0x01`–`0x06`, `0x08` are not written.
- **Wait for a result:** after power-on, a change of integration time or a trigger, wait at least one integration time before reading; the chip returns the previous result until a new measurement completes.
- **UV index requires the application note:** the datasheet does not give the compensation formula; the coefficients above come from the vendor application note (Designing the VEML6075 into an Application, document 84339) and depend on the cover glass; verify them when implementing and keep them configurable.
- **Cover glass / angle:** the cosine response and the UV transmittance of any window change the readings; calibrate against a reference for accurate UV index values.
- **Address:** the fixed `0x10` is shared with other chips (e.g. VEML7700); confirm with `ID` (probe group on register `0x0C`).

## Sigrok Decoder

Decoder id `veml6075`, input `['i2c']`. Matches I²C address `0x10`. Annotates each word access with the register name, decodes `UV_CONF` (integration time, `HD`, `UV_AF`, `UV_TRIG`, `SD`), the four data words (with the compensated UV index for the last seen integration time using the default coefficients) and `ID`; warns on writes of reserved bits or reserved `UV_IT` codes, on a read without a repeated start and on a data read earlier than one integration time after a configuration write. No conformance annotation pair is emitted (no checked timing constraint).
