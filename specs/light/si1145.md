# Chip Spec: Si1145

**Manufacturer:** Silicon Labs  
**Datasheet:** `datasheets/light/si1145.pdf` (Si1145/46/47 Proximity/UV/Ambient Light Sensor IC with I²C Interface, Rev. 1.1)  
**Category:** light  
**Transports:** I²C

## Overview

The Si1145 is a reflectance-based infrared proximity detector, UV index sensor and ambient-light sensor in the Si114x family. It drives one external IR LED (Si1146: two, Si1147: three) with a programmable current (up to 359 mA in 15 steps), measures the reflected light with up to three proximity channels (PS1–PS3) using the large or small IR photodiode, and also measures visible and infrared ambient light and the UV index (`AUX_DATA / 100`, with the UV coefficient registers set to the default `0x7B, 0x6B, 0x01, 0x00`). A sequencer runs forced measurements on command or autonomous loops at a programmed interval, with an interrupt pin. Configuration is partly in I²C registers and partly in an indirect parameter RAM (`PARAM_WR`/`COMMAND`/`PARAM_RD`). This spec targets the Si1145; the Si1146/47 only add LED2/LED3 drive and the `PART_ID` values `0x46`/`0x47` of the same register map. Supply 1.71–3.6 V, standby 150 nA, operating range −40…+85 °C. Typical uses: gesture/proximity switches, wearables, UV monitoring, display backlight control.

## Transport Configuration

### I²C
- **Address:** `0x60` (7-bit, fixed; changeable at run time with `BUSADDR`, volatile); the chip also answers the global address `0x00` and global reset `0x06`. (Older silicon used `0x5A`.)
- **Max clock:** 400 kHz
- **Register addressing:** 8-bit register address (bit 6 = auto-increment disable, default enabled)
- **Identity register:** `PART_ID` (`0x00`) = `0x45` (Si1145), `0x46` (Si1146), `0x47` (Si1147); registered in `registry/chips.json` as `id_probe` register `0x00`, `reg_bytes` 1, `length` 1, mask `0xFF`, expected `[0x45, 0x46, 0x47]`. The Si1132 (`0x32`) shares the address and register map
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| INT | low | interrupt output: asserted while `IRQ_STATUS & IRQ_ENABLE` is non-zero and `INT_CFG.INT_OE = 1`; cleared by writing the status bits back |
| LED1 (LED2, LED3) | — | current-sink outputs for the IR LED(s) (LED2: Si1146/47, LED3: Si1147); the LED supply is separate from VDD (start-up VDDx0.77 limit on LED3); anode to the LED supply |
| SDA, SCL | — | I²C; pull-ups required |
| VDD, GND | — | 1.71–3.6 V; wait ≥ 25 ms after VDD > 1.71 V before the first I²C access |

|---------|------|-----|-------|-------------|
| `0x00` | PART_ID | R | `0x45` | Part number |
| `0x01` | REV_ID | R | — | Hardware revision |
| `0x02` | SEQ_ID | R | — | Sequencer firmware revision |
| `0x03` | INT_CFG | R/W | `0x00` | bit 0 `INT_OE`: INT pin drive enable |
| `0x04` | IRQ_ENABLE | R/W | `0x00` | bit 4 `PS3_IE`, bit 3 `PS2_IE`, bit 2 `PS1_IE`, bit 0 `ALS_IE` (bit meaning as in the datasheet register table) |

| `0x26`/`0x27` | PS1_DATA0/1 | R | `0x00` | proximity channel 1 |
| `0x28`/`0x29` | PS2_DATA0/1 | R | `0x00` | proximity channel 2 (Si1146/47) |
| `0x2A`/`0x2B` | PS3_DATA0/1 | R | `0x00` | proximity channel 3 (Si1147) |
| `0x2C`/`0x2D` | AUX_DATA0/1 (UVINDEX0/1) | R | `0x00` | auxiliary data or UV index × 100 |
| `0x2E` | PARAM_RD | R | `0x00` | parameter RAM read-back |
| `0x30` | CHIP_STAT | R | `0x00` | bit 2 `RUNNING`, bit 1 `SUSPEND`, bit 0 `SLEEP` |

### Commands (`COMMAND`, `0x18`)

| Command | Encoding | Description |
|---------|----------|-------------|
| `PARAM_QUERY` | `100 aaaaa` | Reads parameter `aaaaa` into `PARAM_RD` |
| `PARAM_SET` | `101 aaaaa` | Writes `PARAM_WR` to parameter `aaaaa` |
| `NOP` | `0x00` | Clears the `RESPONSE` counter/error |
| `RESET` | `0x01` | Software reset; no commands for ≥ 1 ms afterwards |
| `BUSADDR` | `0x02` | Applies the `I2C_ADDR` parameter |
| `PS_FORCE` | `0x05` | One forced PS measurement (channels in `CHLIST`) |
| `ALS_FORCE` | `0x06` | One forced ALS (and UV) measurement |
| `PSALS_FORCE` | `0x07` | One forced PS and ALS measurement |
| `PS_PAUSE` / `ALS_PAUSE` / `PSALS_PAUSE` | `0x09` / `0x0A` / `0x0B` | Pauses the autonomous loop |
| `PS_AUTO` / `ALS_AUTO` / `PSALS_AUTO` | `0x0D` / `0x0E` / `0x0F` | Starts/restarts the autonomous loop |
| `GET_CAL` | `0x12` | Writes the factory calibration to `0x22`–`0x2D` |

`RESPONSE` (`0x20`): `0000 cccc` = OK with a circular counter; `1000 0000` INVALID_SETTING; `1000 1000`/`1001`/`1010` PS1/PS2/PS3_ADC_OVERFLOW; `1000 1100` ALS_VIS_ADC_OVERFLOW; `1000 1101` ALS_IR_ADC_OVERFLOW; `1000 1110` AUX_ADC_OVERFLOW (clear with `NOP`).

### Parameter RAM (via `PARAM_SET` / `PARAM_QUERY`)

| Parameter | Offset | Reset | Description |
|-----------|--------|-------|-------------|
| `I2C_ADDR` | `0x00` | `0x60` | new I²C address |
| `CHLIST` | `0x01` | `0x00` | bit 7 `EN_UV`, bit 6 `EN_AUX`, bit 5 `EN_ALS_IR`, bit 4 `EN_ALS_VIS`, bit 2 `EN_PS3`, bit 1 `EN_PS2`, bit 0 `EN_PS1`; non-zero before measuring |
| `PSLED12_SELECT` | `0x02` | `0x21` | bits 6:4 `PS2_LED`, bits 2:0 `PS1_LED` (`xx1` LED1, `x1x` LED2, `1xx` LED3; Si1145: LED1 only) |
| `PSLED3_SELECT` | `0x03` | `0x04` | bits 2:0 `PS3_LED` |
| `PS_ENCODING` | `0x05` | `0x00` | bits 6:4 `PS3/2/1_ALIGN` (use the 16 LSBs instead of the MSBs) |
| `ALS_ENCODING` | `0x06` | `0x00` | bit 5 `ALS_IR_ALIGN`, bit 4 `ALS_VIS_ALIGN` |
| `PS1_ADCMUX`/`PS2_ADCMUX`/`PS3_ADCMUX` | `0x07`/`0x08`/`0x09` | `0x03` | `0x03` large IR photodiode, `0x00` small IR photodiode (`PS_ADC_MODE = 1`); `0x02` visible photodiode when `PS_ADC_MODE = 0` |
| `PS_ADC_COUNTER` | `0x0A` | — | bits 6:4 `PS_ADC_REC` (ADC recovery) |
| `PS_ADC_GAIN` | `0x0B` | `0x00` | bits 2:0: LED pulse width and ADC integration time × 2^n (higher gain with high LED current can exceed the device limits: do not combine) |
| `PS_ADC_MISC` | `0x0C` | `0x04` | bit 5 `PS_RANGE` (1 = high signal range, sensitivity ÷ 14.5), bit 2 `PS_ADC_MODE` (1 = normal proximity detection) |
| `ALS_IR_ADCMUX` | `0x0E` | — | `0x00` small IR photodiode |
| `AUX_ADCMUX` | `0x0F` | `0x65` | `0x65` temperature (relative), `0x75` VDD |
| `ALS_VIS_ADC_COUNTER` / `_GAIN` / `_MISC` | `0x10` / `0x11` / `0x12` | `0x70` / `0x00` / `0x00` | `VIS_ADC_REC` / gain 0–7 / `VIS_RANGE` (bit 5) |
| `LED_REC` | `0x1C` | — | LED recovery time (reserved, do not change) |
| `ALS_IR_ADC_COUNTER` / `_GAIN` / `_MISC` | `0x1D` / `0x1E` / `0x1F` | `0x70` / `0x00` / `0x00` | `IR_ADC_REC` / gain / `IR_RANGE` (bit 5) |

## Initialization Sequence

1. Power up VDD and wait ≥ 25 ms; write `HW_KEY = 0x17`.
2. Write `UCOEF0..3 = 0x7B, 0x6B, 0x01, 0x00`.
3. `PARAM_SET CHLIST` (e.g. `0xB1` = UV + ALS IR + ALS VIS + PS1), `PARAM_SET PS1_ADCMUX = 0x03`, `PARAM_SET PSLED12_SELECT = 0x01`, and write the LED current to `PS_LED21` (e.g. `0x06`).
4. Set the high-range bits for outdoor use. Forced mode: `PSALS_FORCE` (`0x07`), wait, read `0x22`–`0x2D`. Autonomous mode: write `MEAS_RATE`, then `PSALS_AUTO` (`0x0F`).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-low |
| Level | 2 (selectable sources) |
| Condition(s) | ALS/UV complete, PS1/PS2/PS3 complete |
| Clear mechanism | write 1 to the status bits in `IRQ_STATUS` |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_ALS` | `0x01` | `IRQ_STATUS.ALS_INT`: ALS/UV channels complete |
| `SOURCE_PS1` | `0x04` | `IRQ_STATUS.PS1_INT`: PS1 complete |
| `SOURCE_PS2` | `0x08` | `IRQ_STATUS.PS2_INT` (Si1146/47) |
| `SOURCE_PS3` | `0x10` | `IRQ_STATUS.PS3_INT` (Si1147) |
| `SOURCE_CMD` | `0x20` | `IRQ_STATUS.CMD_INT`: command completed |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on INT (falling edge) via `connection.int_pin` (or `int_pin`), otherwise a polling task calling `poll_interrupt`; `callback(status)` receives the masked `IRQ_STATUS` |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `IRQ_STATUS`, writes it back to clear it, returns the masked sources (0 = none) |
| `enable_interrupt` | `enable_interrupt(source)` | `INT_CFG.INT_OE = 1` and the matching `IRQ_ENABLE` bit |
| `disable_interrupt` | `disable_interrupt(source)` | clears the `IRQ_ENABLE` bit |

## Implementation Stages

### Minimal

Goal: read proximity, UV index and ambient light with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Stores the register-addressed `Connection`; waits 25 ms, verifies `PART_ID` ∈ {`0x45`, `0x46`, `0x47`}, writes `HW_KEY`, `UCOEF`, `CHLIST` = UV + IR + VIS + PS1, `PSLED12_SELECT = 0x01`, `PS_LED21 = 0x03` (LED1 at current level 3 of 15) |
| `read` | — | `{proximity, uv_index, visible, infrared}` | `PSALS_FORCE`, waits for `ALS_INT` and `PS1_INT`, returns the raw PS1 count, the UV index (`AUX_DATA / 100`) and the raw visible/infrared counts |

**Sensible defaults:** forced mode, PS1 on the large IR photodiode with LED1, gain 0, normal signal range, UV coefficients at the datasheet defaults.

## Data Conversion

```
vis = (D1 << 8) | D0                                  # all data registers little-endian
proximity = (PS1_DATA1 << 8) | PS1_DATA0              # raw counts (no unit conversion)
uv_index  = ((AUX_DATA1 << 8) | AUX_DATA0) / 100      # CHLIST.EN_UV, UCOEF = 7B 6B 01 00

meas_interval_s = MEAS_RATE * 31.25e-6                # MEAS_RATE = (MEAS_RATE1 << 8) | MEAS_RATE0
```

Proximity counts rise as an object approaches (reflected IR light); the response depends on LED current, photodiode, gain and target reflectance (datasheet Figure 3 uses Kodak gray cards), so the driver reports raw counts. Visible/infrared counts are likewise raw (no source-independent lux formula). The die-temperature channel is relative only.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Start-up after VDD > 1.71 V | ≥ 25 ms |
| After `RESET` | no command for ≥ 1 ms |
| `MEAS_RATE` unit | 31.25 µs per count |
| I²C clock | ≤ 400 kHz |

`IRQ_STATUS` and `RESPONSE` mark the end of a measurement/command, but the datasheet gives no maximum time for them, so `si1145_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed connection:** accept `RegisterConnection` and use `read(reg, n)` / `write(reg, data)` directly; no chip-local helpers (see `specs/feature_register_access_design.md`).
- **Parameter access:** write `PARAM_WR` then `COMMAND = 0xA0 | offset`; verify with the `RESPONSE` counter (read it first to see the increment) and `PARAM_RD`. After an error send `NOP`.
- **`HW_KEY` after every power-up and reset:** write `0x17` or the part does not operate.
- **MEAS_RATE datasheet inconsistency:** the Rev. 1.1 text of `MEAS_RATE1` says 31.25 **ms**, while `MEAS_RATE0` (and the Si1132 datasheet) say 31.25 **µs**; the driver uses 31.25 µs. For parts with `SEQ_ID = 0x01` the two `MEAS_RATE` bytes are swapped (low byte at `0x0A`, high at `0x08`), so check `SEQ_ID`.
- **LED current limits:** the sequencer does not protect the part against a combination of high LED current, high `PS_ADC_GAIN` and multiple LEDs (e.g. three LEDs at 359 mA); keep the LED supply separate from VDD as the datasheet's application circuit (Si1147) shows and do not exceed the thermal limit.
- **Si1145 has one LED:** keep `LED2_I`/`LED3_I` and the LED2/3 select bits clear on the Si1145; PS2/PS3 data are not meaningful on the Si1145.
- **PS needs `PS_ADC_MODE = 1`** (reset value) for normal proximity detection; with `0` the LED drives are disabled and results have no reference.
- **UV channel and AUX share the data registers;** do not enable `EN_UV` and `EN_AUX` together. Set the `VIS_RANGE`/`IR_RANGE` bits for UV in sunlight.
- **Address history:** parts before a datasheet revision used `0x5A`; the current datasheet states `0x60`.
- **Address overlap:** `0x60` is shared with the Si1132 and with other parts; use the ID check.

## Sigrok Decoder

Decoder id `si1145`, input `['i2c']`. Matches I²C address `0x60`. Annotates every register access with the register name, decodes the `COMMAND` opcodes (parameter query/set with the parameter name, forced/autonomous/pause commands, `RESET`, `GET_CAL`), `RESPONSE`, `IRQ_STATUS`/`IRQ_ENABLE`, `CHLIST`, `PS_LED21`/`PS_LED3`, assembles the 16-bit data registers (proximity counts, UV index = `AUX / 100`), and warns when `HW_KEY` was not written, when a measurement is started with an empty `CHLIST` and on `RESPONSE` error codes. No conformance annotation pair is emitted (no checked timing constraint).
