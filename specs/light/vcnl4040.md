# Chip Spec: VCNL4040

**Manufacturer:** Vishay Semiconductors  
**Datasheet:** `datasheets/light/vcnl4040.pdf` (VCNL4040 Proximity Sensor with Ambient Light Sensor and I²C Interface, Vishay Semiconductors)  
**Category:** light  
**Transports:** I²C

## Overview

The VCNL4040 integrates a proximity sensor (PS, 12- or 16-bit output, detection range up to about 200 mm, with a built-in 940 nm IRED driven through a programmable current sink of 50–200 mA, intelligent cancellation and sunlight cancellation, smart persistence, multi-pulse, active-force mode), a 16-bit ambient-light sensor (ALS, 0.0125–0.1 lx/step, maximum range 819.2–6553.5 lx) and a white-light channel in one small package. Both functions share one interrupt pin with independent thresholds and persistence, and a logic-output mode lets the `INT` pin act as a close/away output. The interface is a 7-bit I²C slave (SMBus compatible word protocol, 16-bit command registers, low byte first). Supply 2.5–3.6 V, 300 µA operating current (excluding the IRED), 0.2 µA in shutdown. Typical uses: presence detection to wake displays and phones, ambient-light-based backlight control, proximity switching.

## Transport Configuration

### I²C
- **Address:** `0x60` (7-bit, fixed)
- **Max clock:** 400 kHz (standard I²C/SMBus word protocol)
- **Identity register:** `0x0C` (`ID`, word) = `0x0186` (`ID_L` = `0x86` device ID LSB; `ID_M` = `0x01`: bits 5:4 = `00` slave address `0x60`, bits 3:0 = `0001`); the probe reads 2 bytes little-endian with mask `0xFFFF` and expects `0x0186`. Registered in `registry/chips.json`
- **Probe safety:** `register_pointer` — plain command-code reads; no read has side effects except `INT_Flag` (`0x0B`, clears), which a probe does not touch
- **Register addressing:** 8-bit command code selecting a 16-bit register (`_L` byte first, then `_H`); write word = `S addr W cmd lo hi P`, read word = `S addr W cmd Sr addr R lo hi P`. Use `RegisterConnection` with `read(cmd, 2)` / `write(cmd, [lo, hi])`; there is no auto-increment across commands. All command registers are readable

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| INT | low, open-drain | interrupt output shared by ALS and PS (and the proximity logic output) — requires external pull-up |
| LED_A / LED_K | — | internal IRED anode and on-chip current-sink cathode |
| SDAT, SCLK | — | I²C, external pull-ups |
| VDD, GND | — | 2.5–3.6 V |
| NC | — | not connected |

## Register Map

Each command code addresses a 16-bit register; the low byte is `_L`, the high byte `_H` (read or written as one word).

| Command | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | ALS_CONF (L) / reserved (H) | R/W | `0x01` / `0x00` | ALS integration time, persistence, interrupt, shutdown; high byte reserved |
| `0x01` | ALS_THDH | R/W | `0x0000` | ALS high interrupt threshold (16 bit) |
| `0x02` | ALS_THDL | R/W | `0x0000` | ALS low interrupt threshold (16 bit) |
| `0x03` | PS_CONF1 (L) / PS_CONF2 (H) | R/W | `0x01` / `0x00` | PS duty, persistence, integration time, shutdown / output width, interrupt mode |
| `0x04` | PS_CONF3 (L) / PS_MS (H) | R/W | `0x00` / `0x00` | PS multi-pulse, smart persistence, active force, sunlight cancel / white-channel disable, mode select, IRED current |
| `0x05` | PS_CANC | R/W | `0x0000` | PS cancellation level (16 bit) |
| `0x06` | PS_THDL | R/W | `0x0000` | PS low interrupt threshold (16 bit) |
| `0x07` | PS_THDH | R/W | `0x0000` | PS high interrupt threshold (16 bit) |
| `0x08` | PS_DATA | R | `0x0000` | PS output (12 or 16 bit) |
| `0x09` | ALS_DATA | R | `0x0000` | ALS output (16 bit) |
| `0x0A` | WHITE_DATA | R | `0x0000` | White-channel output (16 bit) |
| `0x0B` | INT_FLAG (H) | R | `0x00` | Interrupt flags in the high byte (low byte reserved); reading clears the flags |
| `0x0C` | ID | R | `0x0186` | Device ID (`ID_L` = `0x86`, `ID_M` = `0x01`) |

Reserved registers are used for internal test and must be left at their defaults.

### Bit Fields

#### `ALS_CONF` (`0x00` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | ALS_IT | Integration time: `00` 80 ms, `01` 160 ms, `10` 320 ms, `11` 640 ms |
| 3:2 | ALS_PERS | Persistence: `00` 1, `01` 2, `10` 4, `11` 8 |
| 1 | ALS_INT_EN | 1 = ALS interrupt enabled |
| 0 | ALS_SD | 0 = ALS on, 1 = ALS shut down (reset: 1) |

#### `PS_CONF1` (`0x03` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | PS_DUTY | IRED on/off duty ratio: `00` 1/40, `01` 1/80, `10` 1/160, `11` 1/320 |
| 5:4 | PS_PERS | Interrupt persistence 1, 2, 3, 4 |
| 3:1 | PS_IT | Integration time: `000` 1T, `001` 1.5T, `010` 2T, `011` 2.5T, `100` 3T, `101` 3.5T, `110` 4T, `111` 8T |
| 0 | PS_SD | 0 = PS on, 1 = PS shut down (reset: 1) |

#### `PS_CONF2` (`0x03` high byte)

| Bits | Name | Description |
|------|------|-------------|
| 3 | PS_HD | 0 = 12-bit PS output, 1 = 16-bit |
| 1:0 | PS_INT | `00` disabled, `01` trigger when close, `10` trigger when away, `11` both |

#### `PS_CONF3` (`0x04` low byte)

| Bits | Name | Description |
|------|------|-------------|
| 6:5 | PS_MPS | Multi-pulse count: `00` 1, `01` 2, `10` 4, `11` 8 |
| 4 | PS_SMART_PERS | 1 = smart persistence enabled |
| 3 | PS_AF | 1 = active force mode |
| 2 | PS_TRIG | Write 1 to trigger one measurement cycle in active-force mode (self-clearing) |
| 0 | PS_SC_EN | 1 = sunlight cancellation enabled |

#### `PS_MS` (`0x04` high byte)

| Bits | Name | Description |
|------|------|-------------|
| 7 | WHITE_EN | **0 = white channel enabled**, 1 = disabled |
| 6 | PS_MS | 0 = normal operation with interrupt, 1 = proximity detection logic-output mode (`INT` pin = close/away output) |
| 2:0 | LED_I | IRED current: `000` 50 mA, `001` 75, `010` 100, `011` 120, `100` 140, `101` 160, `110` 180, `111` 200 mA |

#### `INT_FLAG` (`0x0B` high byte)

| Bit | Name | Description |
|-----|------|-------------|
| 6 | PS_SPFLAG | PS entered protection mode |
| 5 | ALS_IF_L | ALS crossed below the low threshold |
| 4 | ALS_IF_H | ALS crossed above the high threshold |
| 1 | PS_IF_CLOSE | PS rose above `PS_THDH` |
| 0 | PS_IF_AWAY | PS dropped below `PS_THDL` |

## Initialization Sequence

1. Power VDD (2.5–3.6 V) and the IRED supply; `ALS_SD` and `PS_SD` are 1 after reset (both functions off).
2. Read `ID` (`0x0C`) and check for `0x0186`.
3. Write `ALS_CONF` = `(IT << 6)` with `ALS_SD` = 0 (the high byte stays `0x00`).
4. Write `PS_CONF1`/`PS_CONF2` (`0x03`): `PS_SD` = 0, `PS_HD` = 1 for the 16-bit output; optionally `PS_CONF3`/`PS_MS` (`0x04`) for multi-pulse, IRED current and the white channel (`WHITE_EN` = 0 enables it).
5. Wait one refresh time, read `PS_DATA` (`0x08`) and `ALS_DATA` (`0x09`).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-low, open-drain — requires external pull-up |
| Level | 2 |
| Condition(s) | ALS above `ALS_THDH` or below `ALS_THDL` (persistence 1/2/4/8); PS above `PS_THDH` (close) and/or below `PS_THDL` (away) (persistence 1–4); PS saturation and sunlight protection are reported in the flags |
| Clear mechanism | read `INT_FLAG` (`0x0B`); the pin returns high once the flags are read |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_ALS_HIGH` | `0x10` | ALS above the high threshold |
| `SOURCE_ALS_LOW` | `0x20` | ALS below the low threshold |
| `SOURCE_PS_CLOSE` | `0x02` | PS above `PS_THDH` |
| `SOURCE_PS_AWAY` | `0x01` | PS below `PS_THDL` |

(The values equal the `INT_FLAG` bit masks. ALS interrupt = `ALS_INT_EN` enables both ALS sources; PS sources are selected by `PS_INT`.)

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback)` | Subscribe; callback receives the `INT_FLAG` byte |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read and clear `INT_FLAG`, return the high byte |
| `enable_interrupt` | `enable_interrupt(source)` | `ALS_INT_EN` for the two ALS sources, `PS_INT` bits for the two PS sources |
| `disable_interrupt` | `disable_interrupt(source)` | Clear the corresponding enable bits |

### Status register bit layout

| Bit | Constant | Meaning |
|-----|----------|---------|
| 6 | `FLAG_PROTECTION` | PS in protection mode |
| 5 | `SOURCE_ALS_LOW` | ALS below low threshold |
| 4 | `SOURCE_ALS_HIGH` | ALS above high threshold |
| 1 | `SOURCE_PS_CLOSE` | PS close |
| 0 | `SOURCE_PS_AWAY` | PS away |

## Implementation Stages

### Minimal

Goal: read proximity and ambient light with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Takes the `RegisterConnection`; checks `ID` (`0x0186`), powers on ALS (80 ms integration) and PS (16-bit output, duty 1/160, 1T, 50 mA IRED) |
| `read_proximity` | — | int | `PS_DATA` counts (0–65535); larger = closer |
| `read_lux` | — | float | `ALS_DATA` × 0.1 lx/step (80 ms integration) |

**Sensible defaults:** `ALS_CONF` = `0x00` (80 ms, persistence 1, interrupt off, on), `PS_CONF1` = `0x80` (duty 1/160, 1T, on), `PS_CONF2` = `0x08` (16-bit), `PS_CONF3` = `0x00`, `PS_MS` = `0x80` (white channel off, 50 mA), thresholds 0.

## Data Conversion

```
als_counts   = ALS_DATA                                 # 16 bit
white_counts = WHITE_DATA
ps_counts    = PS_DATA                                  # 12 bit (<= 4095) or 16 bit (<= 65535)

sensitivity_lx_per_step = {80: 0.1, 160: 0.05, 320: 0.025, 640: 0.0125}[ALS_IT]   # ms
lux                     = als_counts * sensitivity_lx_per_step
max_range_lx            = {80: 6553.5, 160: 3276.8, 320: 1638.4, 640: 819.2}[ALS_IT]
als_threshold_counts    = lux / sensitivity_lx_per_step
```

PS output is a reflected-light count, not a distance; calibrate `PS_CANC` (cancellation) with no target in front of the sensor and choose thresholds for the mechanical design. Units: lx for the ALS (the SI unit of illuminance), counts for the proximity.

## Implementation Notes

- **RegisterConnection:** accept `RegisterConnection` and use `connection.read(cmd, 2)` / `connection.write(cmd, [lo, hi])` directly; low byte first. See `specs/feature_register_access_design.md`.
- **Read-modify-write of paired bytes:** the low and high byte of `0x03` and `0x04` hold unrelated settings; always rewrite both (read the word, change the field, write the word back). Keep reserved bits at their defaults (they are used for internal test).
- **Shutdown after reset:** `ALS_SD` and `PS_SD` are 1 after power-up; nothing is measured until `init` clears them.
- **INT_FLAG clears on read:** reading `0x0B` clears the flags and releases `INT`; the driver reads it once per interrupt in `poll_interrupt` and passes the value to the callback.
- **Logic-output mode:** with `PS_MS` = 1 the `INT` pin is a close/away logic output and cannot signal ALS interrupts; the driver refuses `enable_interrupt` for ALS sources while it is on.
- **Internal IRED:** the 940 nm IRED is inside the package; the average IRED current is the selected pulse current times the duty ratio (e.g. 100 mA / 320 = 0.31 mA).
- **White channel:** `WHITE_EN` is active low — the white channel is enabled when the bit is 0.
- **12-bit vs. 16-bit PS:** change `PS_HD` before setting thresholds, as the threshold range depends on the output width.
- **Protection mode:** when the PS enters protection mode `PS_SPFLAG` is set in `INT_FLAG`.

## Sigrok Decoder

Decoder id `vcnl4040`, input `['i2c']`. Matches I²C address `0x60`. Annotates each word access with the register name, decodes `ALS_CONF`, `PS_CONF1`–`PS_CONF3`, `PS_MS`, the thresholds, cancellation level, the PS/ALS/white data (with the computed lux for the last seen integration time), `INT_FLAG` and `ID`; warns on writes of reserved bits, on a read of `INT_FLAG` that clears flags and on a PS threshold write outside the 12-bit range when `PS_HD` = 0. No conformance annotation pair is emitted (no checked timing constraint).
