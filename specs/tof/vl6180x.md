# Chip Spec: VL6180X

**Manufacturer:** STMicroelectronics  
**Datasheet:** `datasheets/tof/vl6180x.pdf` (VL6180X, DocID026171 Rev 7)  
**Category:** tof  
**Transports:** I²C

## Overview

The VL6180X is a proximity and ambient-light module: a VCSEL emitter, a SPAD-based time-of-flight receiver and an ambient light sensor (ALS) behind one aperture. It measures absolute distance 0–100 mm (8-bit result in mm, independent of target reflectance; farther depends on reflectance and ambient light) and ambient light (16-bit count, 0.32 lux/count at gain 1 and 100 ms, up to ≈ 20 klux). It has an I²C interface at up to 400 kHz with **16-bit register addresses**, a programmable device address, two GPIOs (GPIO0 = chip enable/XSHUTDOWN, GPIO1 = interrupt output), single-shot, continuous and interleaved (ALS + range) modes, threshold interrupts and a history buffer. Uses: gesture/proximity detection, phone/appliance presence sensing, light-level logging.

## Transport Configuration

### I²C
- **Address:** `0x29` (7-bit, default); reprogrammable at run time by writing `I2C_SLAVE__DEVICE_ADDRESS` (`0x212`) — not persistent, reverts after power-cycle or reset
- **Max clock:** 400 kHz
- **Register addressing:** 16-bit big-endian register address (`reg_bytes` = 2); 8-bit registers, plus 16-bit (MSB first) result/threshold registers and 32-bit count registers; the address auto-increments
- **Identity register:** `0x0000` `IDENTIFICATION__MODEL_ID` = `0xB4` (feeds `registry/chips.json`)
- **Probe safety:** `register_pointer` — a 2-byte write only sets the register index

### Bit Fields

#### Range error code (`RESULT__RANGE_STATUS` bits 7:4)

`0` no error, `1` VCSEL continuity, `2` VCSEL watchdog test, `3` VCSEL watchdog, `4` PLL1 lock, `5` PLL2 lock, `6` early convergence estimate, `7` max convergence, `8` no target ignore, `11` max SNR, `12` raw ranging underflow, `13` raw ranging overflow, `14` ranging underflow, `15` ranging overflow. A measurement is valid only when the code is 0.

#### Interrupt modes (`SYSTEM__INTERRUPT_CONFIG_GPIO`; ALS in bits 5:3, range in bits 2:0)

`0` disabled, `1` level low (value < low), `2` level high (value > high), `3` out of window, `4` new sample ready.

#### ALS gain (`SYSALS__ANALOGUE_GAIN`, write `0x40 | code`)

| Code | Nominal gain | Actual |
|------|--------------|--------|
| 0 | 20 | 20 |
| 1 | 10 | 10.32 |
| 2 | 5 | 5.21 |
| 3 | 2.5 | 2.60 |
| 4 | 1.67 | 1.72 |
| 5 | 1.25 | 1.28 |
| 6 | 1 | 1.01 |
| 7 | 40 | 40 |

## Initialization Sequence

1. Power up (or drive GPIO0/CE low then high), wait ≥ 1 ms (datasheet: ≥ 400 µs after CE high, then the device is ready; 1 ms recommended).
2. Read `SYSTEM__FRESH_OUT_OF_RESET` (`0x016`); if `1`, apply the **mandatory private-register settings** (below) and write `0x016` ← 0. If `0`, skip (the settings persist until reset).
3. Apply the recommended settings: `0x011`=`0x10`, `0x10A`=`0x30`, `0x03F`=`0x46`, `0x031`=`0xFF`, `0x040`=`0x63`, `0x02E`=`0x01`, `0x01B`=`0x09`, `0x03E`=`0x31`, `0x014`=`0x24`.
4. Single-shot range: write `0x018` ← `0x01`, poll `0x04F` bits 2:0 until `4` (new sample ready), read `0x062`, clear with `0x015` ← `0x07`.

**Mandatory private-register settings** (STMicroelectronics AN4545 / the VL6180X API; **not documented in this datasheet** — verify against AN4545 on hardware): `0x0207`=`0x01`, `0x0208`=`0x01`, `0x0096`=`0x00`, `0x0097`=`0xFD`, `0x00E3`=`0x01`, `0x00E4`=`0x03`, `0x00E5`=`0x02`, `0x00E6`=`0x01`, `0x00E7`=`0x03`, `0x00F5`=`0x02`, `0x00D9`=`0x05`, `0x00DB`=`0xCE`, `0x00DC`=`0x03`, `0x00DD`=`0xF8`, `0x009F`=`0x00`, `0x00A3`=`0x3C`, `0x00B7`=`0x00`, `0x00BB`=`0x3C`, `0x00B2`=`0x09`, `0x00CA`=`0x09`, `0x0198`=`0x01`, `0x01B0`=`0x17`, `0x01AD`=`0x00`, `0x00FF`=`0x05`, `0x0100`=`0x05`, `0x0199`=`0x05`, `0x01A6`=`0x1B`, `0x01AC`=`0x3E`, `0x01A7`=`0x1F`, `0x0030`=`0x00`.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `GPIO1` (or GPIO0 when configured), active level per the polarity bit; requires a pull-up |
| Level | 2 (selectable sources: range and ALS, each with its own mode) |
| Condition(s) | new sample ready, level low, level high, out of window (range and ALS independently); error interrupts |
| Clear mechanism | write `SYSTEM__INTERRUPT_CLEAR` (`0x015`): bit 0 range, bit 1 ALS, bit 2 error |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_RANGE` | `0x01` | range event (`RESULT__INTERRUPT_STATUS_GPIO` bits 2:0 ≠ 0) |
| `SOURCE_ALS` | `0x02` | ALS event (bits 5:3 ≠ 0) |
| `SOURCE_ERROR` | `0x04` | error event (bits 7:6 ≠ 0) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on GPIO1 via `connection.int_pin` (or `int_pin`), otherwise a polling task calling `poll_interrupt`; `callback(status)` |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `0x04F`, clears all pending sources, returns the `SOURCE_*` bit mask |
| `enable_interrupt` | `enable_interrupt(source, mode)` | Select the range/ALS interrupt mode (`new sample`, `level low`, `level high`, `out of window`) |
| `disable_interrupt` | `disable_interrupt(source)` | Set that source's mode to 0 |

## Data Conversion

```
range_mm = RESULT__RANGE_VAL                     # 0 … 255, valid when error code == 0
lux = 0.32 * (als_count / gain) * (100 / integration_ms)    # 0.32 lux/count at gain 1, 100 ms (without cover glass)
integration_ms = SYSALS__INTEGRATION_PERIOD + 1
continuous_period_ms = (SYSRANGE__INTERMEASUREMENT_PERIOD + 1) * 10
crosstalk_9_7 = round(rate_mcps * 128)           # 9.7 fixed point
```

`gain` is the actual gain from the table (1.01 at code 6). The lux resolution needs recalibration behind cover glass (ratio of readings without and with glass).

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Power-up after CE high | ≥ 400 µs; 1 ms recommended before the first I²C access |
| Range convergence | typical 0.2–10.7 ms depending on distance and reflectance (e.g. 4.35 ms at 50 mm / 3 %), capped by `SYSRANGE__MAX_CONVERGENCE_TIME` (default 49 ms) minus the averaging period (≈ 4.3 ms at 48) |
| ALS integration | `SYSALS__INTEGRATION_PERIOD + 1` ms (default 100 ms recommended; 50–100 ms reduces flicker error) |
| Range inter-measurement period | `(code + 1) × 10 ms` |
| I²C clock | ≤ 400 kHz |

**Conformance:** the convergence times are typical values only (the result is signalled by polling the interrupt-status register), so `specs/tof/vl6180x_timing.conf` defines no checks.

## Implementation Notes

- **16-bit register addresses:** use `RegisterConnection` with `reg_bytes` = 2; 16-bit values are MSB first.
- **Mandatory settings are not in this datasheet.** They come from ST AN4545 and the ST/Adafruit drivers; apply them only when `SYSTEM__FRESH_OUT_OF_RESET` = 1 and then clear it.
- **Grouped parameter hold:** write `0x017` ← 1 before changing the interrupt config, range/ALS thresholds, ALS gain or integration period, and ← 0 afterwards; the values are used from the next measurement.
- **Range validity:** check the range error code; `RESULT__RANGE_VAL` is only meaningful when it is 0. Use `RESULT__INTERRUPT_STATUS_GPIO` (not the legacy ready bits) for data-ready.
- **Always clear interrupts** (`0x015`) after reading a result, otherwise the next sample is not signalled.
- **Address change is volatile** and must be redone after every power-up; to use several VL6180X on one bus hold the others in hardware standby (GPIO0 low) while changing one.
- **Cover glass** reduces the range and ALS signal; calibrate offset, crosstalk and lux resolution in the final assembly.
- **Address overlap:** `0x29` is shared with VL53L0X/VL53L1X and others; their ID registers differ (`0x0000` = `0xB4` here).
- **Eye safety:** class 1 laser product (see the datasheet's laser safety section).

## Sigrok Decoder

Decoder id `vl6180x`, input `['i2c']`. Matches I²C address `0x29` (and any address written to `0x212` during the capture). Annotates the 16-bit register index as a register name, decodes `RESULT__RANGE_VAL` as mm, range/ALS error codes by name, `RESULT__INTERRUPT_STATUS_GPIO`, `SYSTEM__INTERRUPT_CONFIG_GPIO`, `SYSRANGE__START` / `SYSALS__START`, the ALS count (with lux for the current gain), gain, thresholds and the model ID (verified against `0xB4`). No timing annotation pair is emitted.
