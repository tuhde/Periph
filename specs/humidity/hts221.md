# Chip Spec: HTS221

**Manufacturer:** STMicroelectronics  
**Datasheet:** `datasheets/humidity/hts221.pdf` (HTS221, DocID026333 Rev. 5)  
**Category:** humidity  
**Transports:** I²C (the chip also has an SPI interface, not covered)

> **Scope note:** the HTS221 also supports 3-wire SPI (pin `SPI enable` low); the issue requests I²C only, so this spec covers I²C. SPI can be added later.

## Overview

The HTS221 is an ultra-compact capacitive digital sensor for relative humidity and temperature in a 2 × 2 × 0.9 mm HLGA-6L package. It returns 16-bit humidity (0.004 %rH/LSB nominal, ±3.5 %rH accuracy from 20 to 80 %rH) and 16-bit temperature (0.016 °C/LSB, ±0.5 °C from 15 to 40 °C), factory-calibrated: each device stores individual two-point calibration coefficients in registers `0x30`–`0x3F` that the host reads once and uses for linear interpolation. The output data rate is one-shot or 1, 7 or 12.5 Hz, the internal averaging is selectable (2…256 temperature, 4…512 humidity samples), a DRDY pin signals new data, and an internal heater can drive off condensation. Supply 1.7–3.6 V, 2 µA at 1 Hz, power-down mode below 1 µA. Typical uses: HVAC, weather stations, portable devices, appliances.

## Transport Configuration

### I²C
- **Address:** `0x5F` (7-bit, fixed; the datasheet gives the 8-bit write address `0xBE` / read `0xBF`); one HTS221 per bus
- **Max clock:** 400 kHz (also standard mode 100 kHz)
- **Register addressing:** 8-bit sub-address: the 7 LSbs are the register address, **bit 7 enables address auto-increment**. A single-register access uses `SUB = reg`; a multi-byte read or write uses `SUB = reg | 0x80` (e.g. `0xA8` to read `HUMIDITY_OUT_L`…`TEMP_OUT_H`, `0xB0` for the calibration block). A read is `SUB` write, repeated START, slave address with R/W = 1
- **Identity register:** `WHO_AM_I` (`0x0F`) = `0xBC` — feeds `registry/chips.json`. Pin `SPI enable` must be tied to VDD (or left open, internal pull-up) to enable I²C
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer; writes to reserved registers (`0x00`–`0x0E`, `0x11`–`0x1C`, `0x23`–`0x26`, `0x2C`–`0x2F`, and the calibration registers `0x30`–`0x3F`) must never be made

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| DRDY | high (default) | data-ready output; polarity and push-pull/open-drain selectable in `CTRL_REG3`; enabled with `DRDY_EN`; returns inactive after both `HUMIDITY_OUT_H` and `TEMP_OUT_H` are read |
| SPI enable | — | tie high (or leave open) for I²C; low selects SPI |
| SCL/SPC, SDA/SDI/SDO | — | I²C; pull-ups required |
| VDD, GND | — | 1.7–3.6 V (abs. max 4.8 V) |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x0F` | WHO_AM_I | R | `0xBC` | Device identification |
| `0x10` | AV_CONF | R/W | `0x1B` | Humidity and temperature averaging |
| `0x20` | CTRL_REG1 | R/W | `0x00` | Power, block data update, output data rate |
| `0x21` | CTRL_REG2 | R/W | `0x00` | Boot, heater, one-shot |
| `0x22` | CTRL_REG3 | R/W | `0x00` | DRDY pin configuration |
| `0x27` | STATUS_REG | R | `0x00` | Data-available flags |
| `0x28`, `0x29` | HUMIDITY_OUT_L, _H | R | — | Humidity output, int16 little endian (two's complement) |
| `0x2A`, `0x2B` | TEMP_OUT_L, _H | R | — | Temperature output, int16 little endian (two's complement) |
| `0x30`–`0x3F` | CALIB_0…F | R | per device | Calibration coefficients (never write) |

Reserved addresses must not be written (the datasheet warns of permanent damage).

### Bit Fields

#### `AV_CONF` (`0x10`)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | RSVD | reserved |
| 5:3 | AVGT | temperature averaged samples: `000` 2, `001` 4, `010` 8, `011` 16 (default), `100` 32, `101` 64, `110` 128, `111` 256 |
| 2:0 | AVGH | humidity averaged samples: `000` 4, `001` 8, `010` 16, `011` 32 (default), `100` 64, `101` 128, `110` 256, `111` 512 |

#### `CTRL_REG1` (`0x20`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | PD | `0` = power-down (default), `1` = active |
| 6:3 | RSVD | reserved (keep 0) |
| 2 | BDU | `1` = block data update (output registers not updated between reading the LSB and MSB) |
| 1:0 | ODR | `00` one-shot, `01` 1 Hz, `10` 7 Hz, `11` 12.5 Hz |

#### `CTRL_REG2` (`0x21`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | BOOT | `1` = reload the calibration/trimming registers from internal flash; clears itself |
| 6:2 | RSVD | reserved (keep 0) |
| 1 | HEATER | `1` = heater on |
| 0 | ONE_SHOT | `1` = start a new dataset (ODR = `00`); cleared by hardware at the end of the conversion |

#### `CTRL_REG3` (`0x22`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | DRDY_H_L | `0` = DRDY active high (default), `1` = active low |
| 6 | PP_OD | `0` = push-pull (default), `1` = open drain |
| 5:3 | RSVD | reserved |
| 2 | DRDY_EN | `1` = DRDY signal on pin 3 |
| 1:0 | RSVD | reserved |

#### `STATUS_REG` (`0x27`)

| Bits | Name | Description |
|------|------|-------------|
| 1 | H_DA | humidity data available; cleared by reading `HUMIDITY_OUT_H` |
| 0 | T_DA | temperature data available; cleared by reading `TEMP_OUT_H` |

#### Calibration registers (`0x30`–`0x3F`)

| Address | Name | Format | Description |
|---------|------|--------|-------------|
| `0x30` | H0_rH_x2 | u8 | humidity calibration point 0, %rH × 2 |
| `0x31` | H1_rH_x2 | u8 | humidity calibration point 1, %rH × 2 |
| `0x32` | T0_degC_x8 | u8 | temperature point 0, low 8 bits (°C × 8) |
| `0x33` | T1_degC_x8 | u8 | temperature point 1, low 8 bits (°C × 8) |
| `0x35` | T1/T0 msb | bits 3:2 = T1 bits 9:8, bits 1:0 = T0 bits 9:8 | upper bits of T0/T1 |
| `0x36`–`0x37` | H0_T0_OUT | s16 LE | humidity ADC output at point 0 |
| `0x3A`–`0x3B` | H1_T0_OUT | s16 LE | humidity ADC output at point 1 |
| `0x3C`–`0x3D` | T0_OUT | s16 LE | temperature ADC output at point 0 |
| `0x3E`–`0x3F` | T1_OUT | s16 LE | temperature ADC output at point 1 |

(`0x34`, `0x38`, `0x39` are reserved.)

## Initialization Sequence

1. Power up VDD (1.7–3.6 V); the chip is in power-down (`PD = 0`).
2. Read the calibration block `0x30`–`0x3F` once (burst read with `SUB = 0xB0`) and decode H0/H1/T0/T1 and the ADC reference values.
3. Write `CTRL_REG1` ← `0x84` (`PD = 1`, `BDU = 1`, one-shot mode) — the Minimal default.
4. Measure: write `CTRL_REG2` ← `0x01` (`ONE_SHOT`), poll `CTRL_REG2.ONE_SHOT` until 0 (or `STATUS_REG` = `0x03`), burst-read `0xA8`–`0xAB`, convert (see Data Conversion).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `DRDY` — push-pull or open-drain (configurable), active high or low (configurable) |
| Level | 1 (single fixed condition: new data available) |
| Condition(s) | `STATUS_REG.H_DA` or `T_DA` set (logical OR); needs `CTRL_REG3.DRDY_EN` |
| Clear mechanism | read `HUMIDITY_OUT_H` and `TEMP_OUT_H` (clears `H_DA` / `T_DA`; the pin returns inactive when both are read) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Enables `DRDY_EN` (active high, push-pull), subscribes on DRDY (rising edge) via `connection.int_pin` (or `int_pin`), otherwise a polling task calling `poll_interrupt` at the output data rate; `callback(status)` receives `STATUS_REG` |
| `off_interrupt` | `off_interrupt()` | Unsubscribe and clear `DRDY_EN` |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `STATUS_REG` and returns it (`H_DA` = `0x02`, `T_DA` = `0x01`); the flags clear when the data registers are read |

## Implementation Stages

### Minimal

Goal: read humidity and temperature with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Reads and decodes the calibration block, then writes `CTRL_REG1` ← `0x84` (active, BDU, one-shot) |
| `read` | — | `{temperature_c, humidity_pct}` | Starts a one-shot conversion (`ONE_SHOT`), polls until it clears (timeout 100 ms), burst-reads the four output bytes, converts with the calibration; humidity clamped to 0–100 %rH |

**Sensible defaults:** active mode, BDU on, one-shot (ODR = `00`), averaging at the power-on values (16 temperature / 32 humidity samples), heater off, DRDY off.

## Data Conversion

```
t_out = int16((TEMP_OUT_H << 8) | TEMP_OUT_L)
h_out = int16((HUMIDITY_OUT_H << 8) | HUMIDITY_OUT_L)

# calibration (read once)
H0_rH = H0_rH_x2 / 2.0              H1_rH = H1_rH_x2 / 2.0
T0_degC = (((T1T0_msb & 0x03) << 8) | T0_degC_x8) / 8.0
T1_degC = (((T1T0_msb & 0x0C) << 6) | T1_degC_x8) / 8.0
H0_T0_OUT, H1_T0_OUT, T0_OUT, T1_OUT = s16 values from the table above

# linear interpolation
humidity_pct  = (h_out - H0_T0_OUT) * (H1_rH - H0_rH) / (H1_T0_OUT - H0_T0_OUT) + H0_rH      # clamp 0 ... 100
temperature_c = (t_out - T0_OUT) * (T1_degC - T0_degC) / (T1_OUT - T0_OUT) + T0_degC

# dew point (Magnus, over water; T in degC, RH in %)
g = ln(humidity_pct / 100) + 17.62 * T / (243.12 + T)
dew_point_c = 243.12 * g / (17.62 - g)
```

Datasheet example: `H0_rH_x2 = 40`, `H1_rH_x2 = 80`, `H0_T0_OUT = 0x4000`, `H1_T0_OUT = 0x6000`, `H_OUT = 0x5000` → 30 %rH; `T0_degC_x8 = 80`, `T1_degC_x8 = 160`, `T0_OUT = 300`, `T1_OUT = 500`, `T_OUT = 400` → 15.0 °C. The Magnus constants are common Sonntag-style values, not part of the datasheet.

| Constraint | Value |

## Implementation Notes

- **Register-addressed connection with auto-increment:** the sub-address bit 7 must be set for multi-byte transfers (`reg | 0x80`). `RegisterConnection` has no I²C multi-byte parameter (`specs/feature_register_access_design.md` §4), so the driver sets the bit itself, as for LIS3DH and LPS22HB.
- **Calibration is mandatory:** the raw outputs are meaningless without the per-device coefficients; read them once in `init` (and after `reboot`) and keep them in the driver. T0/T1 are 10-bit values (`°C × 8`): bits 9:8 are in `0x35`.
- **BDU:** keep it set (the Minimal default) when reading LSB and MSB separately; the driver reads the four bytes in one burst.
- **One-shot:** setting `ONE_SHOT` while in one-shot mode (`ODR = 00`) starts a conversion; the bit clears itself and `STATUS_REG` reports `H_DA`/`T_DA`. In power-down mode (`PD = 0`) the `ONE_SHOT` bit is ignored.
- **Reserved bits:** keep reserved bits at 0 and never write the reserved registers; `CTRL_REG1`/`CTRL_REG2`/`CTRL_REG3` writes are read-modify-write (or whole-value writes with the reserved bits 0).
- **Heater:** about 33 mA at 3.3 V (22 mA at 2.5 V, 12 mA at 1.8 V); it can only be switched on and off by the host. Do not read humidity or temperature during the heating cycle; wait until it is off and the sensor has cooled.
- **Clip the humidity** to 0–100 %rH (the datasheet requires software clipping).
- **Address:** `0x5F` is fixed (no address pin); the `WHO_AM_I` probe (`0xBC`) identifies the chip.

## Sigrok Decoder

Decoder id `hts221`, input `['i2c']`. Matches I²C address `0x5F`. Annotates every register access by name (the auto-increment bit in the sub-address is stripped and shown separately), decodes `WHO_AM_I` (checked against `0xBC`), `AV_CONF` (sample counts), `CTRL_REG1` (PD, BDU, ODR), `CTRL_REG2` (BOOT, HEATER, ONE_SHOT), `CTRL_REG3`, `STATUS_REG`, the calibration block into its coefficients, and the 4-byte burst read of `0x28`–`0x2B` into raw values and — once the calibration block was seen — °C and %rH; it warns on writes to reserved or calibration registers. No conformance annotation pair is emitted (no checked timing constraint).
