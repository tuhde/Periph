# Chip Spec: TMC2209

**Manufacturer:** Trinamic (Analog Devices)  
**Datasheet:** `datasheets/motor/tmc2209.pdf` (TMC2209 datasheet Rev. 1.09, 2023-FEB-16)  
**Category:** `motor`  
**Transports:** UART (single-wire, see `specs/transport_uart.md`); STEP/DIR/ENN/DIAG are plain GPIO

The TMC2209 is the StallGuard4 / multi-node successor of the TMC2208 (`specs/motor/tmc2208.md`).
It shares that chip's UART protocol, CRC, echo behaviour and most registers; this spec repeats
what a driver author needs and calls out every difference (see "Differences from the TMC2208").

## Overview

The TMC2209 is a low-cost two-phase bipolar stepper motor driver with a STEP/DIR interface,
256-microstep interpolation (MicroPlyer), the silent StealthChop2 PWM mode, the SpreadCycle
chopper, **StallGuard4** sensorless load measurement and **CoolStep** load-adaptive current.
Motor supply 5.5–29 V, up to 1.4 A RMS continuous (2.0 A RMS with duty-cycle limit, 2.8 A
peak) per coil. Stand-alone it is configured by pins only (MS1/MS2 microstepping, ENN, VREF
current scaling, SPREAD chopper select). The optional single-wire UART interface unlocks the
full register set: run/hold current, 1–256 microstep resolution, chopper mode and tuning,
driver diagnostics (short, open load, over-temperature), stall detection on the `DIAG` pin, and
an internal step pulse generator (`VACTUAL`) that moves the motor with **no STEP pulses at all**.
Up to four chips share one UART through the address pins `MS1_AD0` / `MS2_AD1`.

The driver talks to the chip over UART and optionally drives the ENN / STEP / DIR pins and reads
the DIAG pin as GPIO. The UART alone is sufficient to enable the driver and move the motor.

## Transport Configuration

### UART (single wire)

- **Frame:** 8N1 (8 data bits, no parity, 1 stop bit), LSB first, most-significant datagram byte first
- **Baud rate:** auto-detected from the sync nibble of every datagram. 9 000 baud minimum
  (assuming the worst-case 20 MHz clock) up to `fCLK/16` (≈ 750 kBd with the 12 MHz internal clock). Default 115 200.
- **Wiring:** MCU TX → 1 kΩ → `PDN_UART`; MCU RX → `PDN_UART` directly (datasheet Fig. 4.1).
  The pin is half-duplex; **everything the host transmits is echoed back into its own RX**.
- **Node address:** `0…3`, set by the address pins: `address = MS1_AD0 + 2·MS2_AD1` (MS1 = bit 0,
  MS2 = bit 1; both pins have internal pull-downs, so unconnected = address 0). The constructor
  parameter `address` (default `0`) selects it; the driver must only use the datagram address
  byte, it cannot change the pins. Read replies always carry the master address `0xFF`.
  More than four chips on one UART need external analog switches (datasheet §4.4); not modelled.
  Several chips with the same address can be programmed in parallel with write-only access.
- **Multi-node buses:** with more than one chip on the UART, `NODECONF.SENDDELAY` must be ≥ 2 on
  every node (datasheet §4.1.2), otherwise a non-addressed node can detect a transmission error
  on a reply. The driver exposes `set_send_delay` (Full) for this; `multi_node=True` in the
  constructor makes init write `SENDDELAY = 2` first (broadcast-safe because it is a write).
- **`PDN_UART` must be `pdn_disable`d** (`GCONF` bit 6) as part of init; otherwise the UART idle
  level controls standstill current reduction.
- **Not a register-addressed bus** in the `RegisterConnection` sense (datagrams carry a CRC, a
  sync byte and an echo); the driver wraps a plain UART `Connection` and does its own framing.

### Datagram format (all bytes sent LSB-first, 8N1)

**Write access — 8 bytes, host → chip:**

| Byte | Value | Meaning |
|------|-------|---------|
| 0 | `0x05` | sync nibble `0101` (low bits first on wire) + 4 reserved bits (0, included in CRC) |
| 1 | `address` | node address 0…3 |
| 2 | `reg \| 0x80` | register address with write bit |
| 3 | `data[31:24]` | high byte first |
| 4 | `data[23:16]` | |
| 5 | `data[15:8]` | |
| 6 | `data[7:0]` | |
| 7 | CRC8 | over bytes 0–6 |

**Read request — 4 bytes, host → chip:** `0x05`, `address`, `reg & 0x7F`, CRC8 (over bytes 0–2).

**Read reply — 8 bytes, chip → host:** `0x05`, `0xFF` (master address), `reg & 0x7F`, `data[31:24]`
… `data[7:0]`, CRC8 (over bytes 0–6). The chip waits `SENDDELAY` (default 8 bit times, set by
`NODECONF`) after the request before replying, and releases the line four bit times after the
last stop bit.

**CRC8:** polynomial `x⁸ + x² + x¹ + 1` (`0x07`), initial value 0, bytes processed LSB first:

```
crc = 0
for byte in datagram[:-1]:
    for _ in 8:
        if ((crc >> 7) ^ (byte & 1)): crc = ((crc << 1) ^ 0x07) & 0xFF
        else:                         crc = (crc << 1) & 0xFF
        byte >>= 1
```

Test vectors (computed by running the algorithm above; not printed in the datasheet), address 0:
write `GCONF` (0x00) = `0x000001C1` → `05 00 80 00 00 01 C1 7F`; read request for `IOIN` (0x06) →
`05 00 06 6F`. The reply CRC is checked on every read.

### Echo handling

Because TX and RX share `PDN_UART`, a connection in the standard wiring receives its own bytes
back. The driver option `echo` (default `true`) controls this:

- **write:** transmit 8 bytes, then consume 8 echo bytes (and verify they equal what was sent;
  mismatch ⇒ bus collision/corruption error).
- **read:** transmit 4 bytes, then receive 4 echo + 8 reply = 12 bytes in one `write_read(request, 12)`;
  discard the first 4, verify them, parse the last 8.
- With `echo = false` (separate RX/TX paths, e.g. TX through a buffer with RX connected only to
  the chip's output) the echo bytes are not read.

### Error recovery

The chip resets its receive state if more than 63 bit times pass between two start bits of one
datagram, and after any error (bad CRC, glitch) requires ≥ 12 bit times of bus idle before the
next datagram. The driver must: on any timeout, short read or CRC mismatch, flush the receive
buffer, wait ≥ 12 bit times (≥ 1.5 ms is always safe at ≥ 9 kBd), and retry once before raising
the error.

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| ENN | low | Enable input. High = power stage off, motor freewheels; also resets latched driver errors on `DIAG`. Optional: `en_pin`. |
| STEP | rising edge | One microstep per pulse (also falling with `dedge`). Optional: `step_pin`. |
| DIR | — | Direction, internal pull-down. Optional: `dir_pin`. |
| MS1_AD0, MS2_AD1 | — | Stand-alone microstep select (`MS2,MS1`: 00 = 1/8, 01 = 1/32, 10 = 1/64, 11 = 1/16), **and UART node address bits 0/1**. Microstep select is ignored once `GCONF.mstep_reg_select = 1` (the driver sets it); the address function always applies. |
| PDN_UART | — | UART data. Disable the pin function by `GCONF.pdn_disable = 1`. |
| DIAG | high | Stall (StallGuard4, gated by `TPWMTHRS ≤ TSTEP ≤ TCOOLTHRS`) **or** driver error (over-temperature, short, charge-pump undervoltage, power-on reset). Error conditions reset by ENN high. Optional: `diag_pin` (`InputPin`). |
| INDEX | — | Index pulse (first microstep position) / `otpw` / internal-generator step toggle, per `GCONF.index_otpw` / `index_step`. |
| VREF | analog | Current scaling 0.5–2.5 V (open ≈ 73 %); ignored when `GCONF.I_scale_analog = 0`. |
| SPREAD | high | Stand-alone chopper select (low = StealthChop, high = SpreadCycle); inverts `GCONF.en_SpreadCycle`. Internal pull-down. |
| STDBY | high | Low-power standby: disables the internal supply regulator. Internal pull-down; not driver-controlled. |
| CLK | — | Tie to GND for the 12 MHz internal clock. |

ENN, STEP and DIR use `OutputPin`, DIAG uses `InputPin` (`specs/feature_connection_design.md` §5);
all four are optional. With none of them wired the driver still works: the datasheet's pin table
lists no internal pull-down for ENN, so tie it to GND (or drive it) on the board. Motion then
uses `VACTUAL`; stalls are then detected by polling `SG_RESULT` instead of `DIAG`.

### Bit Fields

#### `GCONF` (`0x00`)

| Bit | Name | Description |
|-----|------|-------------|
| 0 | `I_scale_analog` | 1 = current reference from VREF pin (reset), 0 = internal reference from 5VOUT |
| 1 | `internal_Rsense` | 1 = internal sense resistors (VREF becomes a current reference); reset from OTP |
| 2 | `en_SpreadCycle` | 0 = StealthChop (velocity thresholds apply), 1 = SpreadCycle; reset from OTP; the `SPREAD` pin inverts it |
| 3 | `shaft` | 1 = inverse motor direction |
| 4 | `index_otpw` | 1 = INDEX shows over-temperature pre-warning, 0 = first microstep position |
| 5 | `index_step` | 1 = INDEX shows internal-generator step pulses (toggles per step) |
| 6 | `pdn_disable` | 1 = PDN_UART pin function disabled — **must be 1 in UART mode** |
| 7 | `mstep_reg_select` | 1 = microstep resolution from `CHOPCONF.MRES`, 0 = from MS1/MS2 pins |
| 8 | `multistep_filt` | 1 = step-pulse filtering (reset) |
| 9 | `test_mode` | **Never set**; 0 for normal operation |

#### `GSTAT` (`0x01`)

| Bit | Name | Description |
|-----|------|-------------|
| 0 | `reset` | IC was reset since last read; all registers at defaults |
| 1 | `drv_err` | Driver shut down by over-temperature or short; see `DRV_STATUS` |
| 2 | `uv_cp` | Charge-pump undervoltage; driver disabled, not latched |

#### `NODECONF` (`0x03`)

| Bits | Name | Description |
|------|------|-------------|
| 11:8 | `SENDDELAY` | reply delay in bit times: 0,1 = 8; 2,3 = 3·8; 4,5 = 5·8; 6,7 = 7·8; … 14,15 = 15·8 (pairs of values share one delay). **Use ≥ 2 on multi-node buses.** |

#### `IOIN` (`0x06`)

| Bits | Name | Description |
|------|------|-------------|
| 0 | `ENN` | state of ENN |
| 2 | `MS1` | state of MS1 (address bit 0) |
| 3 | `MS2` | state of MS2 (address bit 1) |
| 4 | `DIAG` | state of DIAG |
| 6 | `PDN_UART` | state of PDN_UART |
| 7 | `STEP` | state of STEP |
| 8 | `SPREAD_EN` | state of SPREAD |
| 9 | `DIR` | state of DIR |
| 31:24 | `VERSION` | silicon version; `0x21` = first version (the identity value the driver checks) |

Bits 1 and 5 read 0. The driver exposes the raw `IOIN` word, a decoded pin dict and `VERSION`.

#### `IHOLD_IRUN` (`0x10`, write-only)

| Bits | Name | Description |
|------|------|-------------|
| 4:0 | `IHOLD` | Standstill current scale, 0…31 = 1/32…32/32 (0 ⇒ freewheel/brake per `PWMCONF.freewheel`) |
| 12:8 | `IRUN` | Run current scale, 0…31 (reset 31) |
| 19:16 | `IHOLDDELAY` | 0 = instant power down, 1…15 = delay per current step in units of 2¹⁸ clocks |

#### `TPOWERDOWN` (`0x11`)

Bits 7:0. Delay from standstill detection to current reduction: `TPOWERDOWN × 2¹⁸` clocks
(≈ 0…5.6 s at 12 MHz). A value ≥ 2 is required for StealthChop automatic tuning.

#### `TSTEP` (`0x12`) / `TPWMTHRS` (`0x13`) / `TCOOLTHRS` (`0x14`)

Bits 19:0. `TSTEP` = `2²⁴ / (v_µsteps_per_s · 256 / USC)` in clock periods, referred to 1/256
microsteps; reads `2²⁰−1` on overflow or standstill. `TPWMTHRS`: StealthChop is used while
`TSTEP ≥ TPWMTHRS`; faster motion switches to SpreadCycle; `0` disables the threshold.
`TCOOLTHRS`: CoolStep and the StallGuard stall output on `DIAG` are enabled while
`TCOOLTHRS ≥ TSTEP > TPWMTHRS` (below a velocity, i.e. above this `TSTEP`, they are off because
they do not work reliably at low speed). `TSTEP` comparisons use a 1/16 hysteresis.

#### `VACTUAL` (`0x22`)

Bits 23:0, two's complement. `0` = motor follows the STEP input. Non-zero = the internal
pulse generator moves the motor at that velocity; the sign gives the direction. No acceleration
ramp is provided by the chip. Step pulses can be monitored on INDEX (`index_step`).

#### `SGTHRS` (`0x40`) / `SG_RESULT` (`0x41`)

`SGTHRS` bits 7:0. A stall is signalled on `DIAG` when `SG_RESULT ≤ 2 · SGTHRS` (higher value
= more sensitive). `SG_RESULT` bits 9:0, updated with every full step, independent of
`TCOOLTHRS`/`SGTHRS`: a higher value means less mechanical load. Intended for StealthChop only;
bits 9 and 0 always read 0 (so the value is even, 0…510).

#### `COOLCONF` (`0x42`, write-only)

| Bits | Name | Description |
|------|------|-------------|
| 15 | `seimin` | minimum CoolStep current: 0 = ½ · IRUN (use with IRUN ≥ 10), 1 = ¼ · IRUN (use with IRUN ≥ 20) |
| 14:13 | `sedn` | current down step speed: 0 = 1 per 32 `SG_RESULT`, 1 = per 8, 2 = per 2, 3 = per each |
| 11:8 | `semax` | upper threshold offset: current decreases when `SG_RESULT ≥ (semin + semax + 1) · 32` |
| 6:5 | `seup` | current up step width: 0…3 = 1, 2, 4, 8 |
| 3:0 | `semin` | lower threshold: `SG_RESULT < semin · 32` raises current; **0 disables CoolStep** |

Bits 12, 7, 4 and 31:16 are reserved (write 0). The datasheet recommends `SEMAX` 0…2 and,
once `SGTHRS` is tuned, `SEMIN` ≈ `SGTHRS/16 + 1` as a starting point. CoolStep only works in
StealthChop with `TCOOLTHRS ≥ TSTEP > TPWMTHRS`.

#### `MSCNT` (`0x6A`) / `MSCURACT` (`0x6B`)

`MSCNT` bits 9:0 = position in the 1024-entry sine table (0…1023, 4 full steps).
`MSCURACT`: bits 8:0 and bits 24:16 are two 9-bit signed phase currents (see Implementation
Notes on the datasheet's inconsistent A/B labels). Raw table values, not scaled by the current setting.

#### `CHOPCONF` (`0x6C`)

| Bits | Name | Description |
|------|------|-------------|
| 31 | `diss2vs` | 1 = disable low-side short protection |
| 30 | `diss2g` | 1 = disable short-to-GND protection |
| 29 | `dedge` | 1 = STEP pulses on both edges (not compatible with `multistep_filt`) |
| 28 | `intpol` | 1 = interpolate to 256 microsteps (reset 1) |
| 27:24 | `MRES` | `0` = 256, `1`…`8` = 128, 64, 32, 16, 8, 4, 2, full step |
| 17 | `vsense` | 0 = high sense voltage (0.325 V), 1 = low (0.18 V) |
| 16:15 | `TBL` | comparator blank time 16, 24, 32, 40 clocks |
| 10:7 | `HEND` | hysteresis end / offset (−3…12) |
| 6:4 | `HSTRT` | hysteresis start (+1…+8); `HEND+HSTRT ≤ 16` |
| 3:0 | `TOFF` | off time: `NCLK = 24 + 32·TOFF`; **`0` disables the driver** |

#### `DRV_STATUS` (`0x6F`)

| Bit | Name | Description |
|-----|------|-------------|
| 31 | `stst` | standstill (2²⁰ clocks after last step) |
| 30 | `stealth` | 1 = StealthChop, 0 = SpreadCycle |
| 20:16 | `CS_ACTUAL` | actual current scale (0…31; reflects CoolStep) |
| 11 | `t157` | 157 °C comparator |
| 10 | `t150` | 150 °C comparator |
| 9 | `t143` | 143 °C comparator |
| 8 | `t120` | 120 °C comparator |
| 7 | `olb` | open load phase B (informative only; false positives at standstill/fast motion) |
| 6 | `ola` | open load phase A |
| 5 | `s2vsb` | low-side short phase B |
| 4 | `s2vsa` | low-side short phase A |
| 3 | `s2gb` | short to GND phase B |
| 2 | `s2ga` | short to GND phase A |
| 1 | `ot` | over-temperature (driver disabled) |
| 0 | `otpw` | over-temperature pre-warning |

Short flags stay set until the driver is disabled (`TOFF = 0` or ENN high).

#### `PWMCONF` (`0x70`)

| Bits | Name | Description |
|------|------|-------------|
| 31:28 | `PWM_LIM` | amplitude limit when switching SpreadCycle → StealthChop (default 12) |
| 27:24 | `PWM_REG` | regulation loop gradient 1…15 (0.5 … 7.5 increments) |
| 21:20 | `freewheel` | standstill mode when `IHOLD = 0`: 0 normal, 1 freewheel, 2 LS short, 3 HS short |
| 19 | `pwm_autograd` | 1 = automatic gradient tuning |
| 18 | `pwm_autoscale` | 1 = automatic current control (reset 1) |
| 17:16 | `pwm_freq` | 0: 2/1024 · fCLK, 1: 2/683, 2: 2/512, 3: 2/410 |
| 15:8 | `PWM_GRAD` | velocity-dependent amplitude gradient |
| 7:0 | `PWM_OFS` | amplitude offset (reset 36); 0 disables low-current scaling |

#### `PWM_SCALE` (`0x71`) / `PWM_AUTO` (`0x72`)

`PWM_SCALE`: bits 7:0 `PWM_SCALE_SUM` (0…255), bits 24:16 `PWM_SCALE_AUTO` (signed 9 bit).
`PWM_AUTO`: bits 7:0 `PWM_OFS_AUTO`, bits 23:16 `PWM_GRAD_AUTO` — read after auto-tuning to
obtain values for `PWM_OFS`/`PWM_GRAD`.

## Initialization Sequence

1. Configure the UART (8N1, baud rate within 9 kBd…fCLK/16; default 115 200) and, if used, drive ENN high (driver off).
2. Wait ≥ 12 bit times of bus idle (≥ 1.5 ms) so the chip's receiver is in a known state.
3. Read `IFCNT` once (read access does not change it) to baseline the counter; record the value.
4. Read `IOIN`: require `VERSION = 0x21`; any other value (including `0x00`/`0xFF` from a floating or silent bus) ⇒ "device not found" error. A TMC2208 reports `0x20` and is rejected, so a wrong-part wiring is caught.
5. If `multi_node`: write `NODECONF.SENDDELAY = 2`.
6. Write `GCONF = I_scale_analog(1 or 0 per config) | pdn_disable | mstep_reg_select | multistep_filt` (`0x000001C1` with VREF scaling, `0x000001C0` with `i_scale_analog = False`), plus `internal_Rsense` / `en_SpreadCycle` bits per configuration.
7. Write `GSTAT = 0x07` to clear stale reset/error flags.
8. Write `IHOLD_IRUN` (default `IHOLD` = ⅓·`IRUN`, `IHOLDDELAY` = 6) and `TPOWERDOWN = 20`.
9. Write `CHOPCONF`: read-modify-write to set `TOFF = 3`, `TBL = 2`, `HSTRT = 5`, `HEND = 0`, `vsense` per config, `intpol = 1`, `MRES` per default (16 microsteps).
10. Write `PWMCONF` default `0xC10D0024`.
11. Read `IFCNT` and verify it advanced by the number of write datagrams sent in steps 5–10 (six, or seven with `multi_node`; mod 256): `GCONF`, `GSTAT`, `IHOLD_IRUN`, `TPOWERDOWN`, `CHOPCONF`, `PWMCONF` (+ `NODECONF`); mismatch ⇒ error.
12. Assert ENN low (enable) only when `enable()` is called; init leaves the driver disabled when `en_pin` is wired, and active otherwise (no way to gate it).

## Implementation Stages

### Minimal

Goal: bring the driver up on UART and spin the motor at a chosen speed with a given current —
no knowledge of chopper registers required.

Constructor: `TMC2209Minimal(connection, r_sense_ohm=0.11, address=0, en_pin=None, echo=True)`.
`r_sense_ohm` is the **external sense resistor value** (typically 0.11 Ω on common breakout
boards) used to convert amperes to the current scale; it is the one value the user must know.
`address` is the UART node address 0…3 (must match the MS1/MS2 pins; out of range ⇒ `ValueError`).

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | — | — | Initialization Sequence with the defaults below; part of the constructor |
| `enable` | — | — | Driver power stage on (`en_pin` low; `TOFF` stays set) |
| `disable` | — | — | Power stage off (`en_pin` high, or `TOFF = 0` when no pin); motor freewheels |
| `set_current` | `rms_a: float` | — | Run current in A RMS (≤ 1.4); hold current set to ⅓ of it; quantised to the nearest scale step |
| `run` | `steps_per_s: float` | — | Move with `VACTUAL`; sign = direction; unit: **full steps per second at the configured microstepping**; `0` stops |
| `stop` | — | — | `VACTUAL = 0` |
| `is_standstill` | — | `bool` | `DRV_STATUS.stst` |
| `read_fault` | — | `int` | Bitmask of `FAULT_*` constants (see below), `0` = none |

**Fault constants:** `FAULT_OVERTEMP_WARNING = 0x01` (`otpw`), `FAULT_OVERTEMP = 0x02` (`ot`),
`FAULT_SHORT_GND = 0x04` (`s2ga`/`s2gb`), `FAULT_SHORT_SUPPLY = 0x08` (`s2vsa`/`s2vsb`),
`FAULT_OPEN_LOAD = 0x10` (`ola`/`olb`).

**Sensible defaults baked into Minimal:** UART mode (`pdn_disable = 1`, `mstep_reg_select = 1`),
VREF scaling on (`I_scale_analog = 1`; leave the VREF pin open or at ≥ 2.5 V for full scale —
`set_current` does the scaling, VREF is not touched), StealthChop (`en_SpreadCycle = 0`), 16
microsteps with 256-step interpolation (`MRES = 4`, `intpol = 1`), `vsense = 0`, `TOFF = 3`,
`TBL = 2`, `HSTRT = 5`, `HEND = 0`, `TPOWERDOWN = 20`, `IHOLDDELAY = 6`, `PWMCONF` reset
default, default run current 0.5 A RMS, `echo = true`, StallGuard/CoolStep left at their reset
(disabled) values, baud rate as configured on the connection.

### Full

Goal: complete chip functionality. Extends Minimal. Constructor adds `step_pin=None`,
`dir_pin=None`, `diag_pin=None`, `multi_node=False`, `fclk_hz=12_000_000` (use the external
clock frequency if CLK is driven).

## Data Conversion

```
# Current scale CS = 0…31 for a target RMS current (external Rsense, UART control, datasheet §9)
V_FS     = 0.325 V      (vsense = 0)   or   0.180 V  (vsense = 1)
I_rms    = (CS + 1)/32 * V_FS / (R_sense + 0.020 Ω) / sqrt(2)
CS       = round(I_rms * sqrt(2) * (R_sense + 0.020) * 32 / V_FS) - 1   clamped to 0…31
```

The datasheet's electrical characteristics give `V_SRTL = 325 mV` (`vsense = 0`) and
`V_SRTH = 180 mV` (`vsense = 1`); the `vsense` parameter table in §9 rounds the former to
"0.32 V". The driver uses 0.325 V / 0.180 V. With VREF analog scaling enabled and the pin below
2.5 V, `V_FS` is further scaled by `V_VREF / 2.5 V`; the driver does not read VREF, so current is
accurate only with VREF ≥ 2.5 V or open (open ≈ 73 %, see Implementation Notes), or the user
must account for it. With `internal_Rsense`, `R_sense` is not applicable (use the `R_REF` table
in datasheet §10); the driver treats `set_current` as unsupported then (raises).

```
# Internal step generator
v[Hz µsteps/s]  = VACTUAL * f_CLK / 2^24            (VACTUAL = v[Hz] * 2^24 / f_CLK)
              ≈ VACTUAL * 0.715 Hz (12 MHz internal clock)
run(steps_per_s) → v[µsteps/s] = steps_per_s * microsteps; VACTUAL = clamp(round(v * 2^24 / f_CLK), ±(2^23 − 1))
```

```
TSTEP = f_CLK / f_256-microsteps = 2^24 / (VACTUAL * 256 / USC)        (USC = microsteps per full step, 256 native)
SENDDELAY_bit_times = 8 + 16 * (SENDDELAY // 2)     (0,1 → 8 … 14,15 → 120)
```

```
# StallGuard4 / CoolStep
stall (DIAG high)  when  SG_RESULT <= 2 * SGTHRS  and  TCOOLTHRS >= TSTEP > TPWMTHRS
CoolStep raises current when SG_RESULT <  SEMIN * 32
CoolStep lowers current when SG_RESULT >= (SEMIN + SEMAX + 1) * 32
TCOOLTHRS (raw TSTEP units) ≈ f_CLK / (v_fullsteps_per_s * 256) for the lowest velocity at which StallGuard should be active
```

Signed fields (`VACTUAL` 24 bit, `MSCURACT` 9 bit, `PWM_SCALE_AUTO` 9 bit) are sign-extended
two's complement; mask both source bytes before combining when reading into JVM/Kotlin types.

## Examples

### Demo

A sensorless homing routine for a linear axis, the headline feature the TMC2208 lacks. The demo
enables the driver at 0.8 A, selects 16 microsteps, and reads back `IOIN.VERSION` (`0x21`) and
`IFCNT` to prove the UART link. It sets `SGTHRS` and `TCOOLTHRS` so StallGuard is active at the
homing speed, then drives toward the end stop with the internal generator at 200 full steps/s
(after a 0.5 s spin-up during which stall detection is not yet valid), printing `read_stallguard()`
every 100 ms. When `SG_RESULT` falls to `2 * SGTHRS` (or `is_stalled()` goes true, when a DIAG pin
is wired) the demo stops the motor, prints the SG value at the stall, reverses for 2 s to back off,
and enables CoolStep (`configure_coolstep(semin=5, semax=2, seup=1, sedn=1, seimin=0)`) for a
final move, showing `read_current_scale()` drop as the load falls. It finishes with the temperature
flags and `read_global_status()`. If `read_fault()` becomes non-zero at any point, the demo stops
the motor, disables the driver, prints which fault fired and exits.

## Timing Constraints

- **Read reply delay (`reply_delay`):** after the last stop bit of a read request the chip waits
  `SENDDELAY` (default 8 bit times; configurable via `NODECONF` in multiples of 8 bit times) before
  sending the first reply byte. At 115 200 baud (8.68 µs bit time) the default is ≈ 69 µs; a conformance
  bound of 100 µs applies at that baud rate and default `SENDDELAY`. Sigrok annotation pair:
  `read_request_end` / `read_reply_start`.
- **Inter-byte gap:** ≤ 63 bit times between start bits within one datagram; longer resets the chip's receiver.
- **Recovery:** ≥ 12 bit times of bus idle after any error before the next datagram.
- **Standstill power-down:** `TPOWERDOWN · 2¹⁸ · t_CLK` after the last step (≈ 22 ms per count at 12 MHz).
  Autonomous, not driver-actionable.
- **StealthChop auto-tune:** ≥ 130 ms standstill at `IRUN` to initialise `PWM_OFS_AUTO`, followed by ≈ 8 full
  steps per +/−1 of `PWM_GRAD_AUTO`. Autonomous; the driver documents it but does not wait.
- **StallGuard4 update rate:** `SG_RESULT` updates once per full step; a stall can only be detected
  while the motor moves above the `TCOOLTHRS` velocity limit. Autonomous.
- **Power-up:** apply `VCC_IO` and `VS`; allow the internal clock to start (a few ms; not specified in the datasheet — use 10 ms) before the first datagram.

## Implementation Notes

- **Echo is the single biggest source of bugs.** On the standard shared `PDN_UART` wiring every transmitted byte comes back. Forgetting to drain the echo makes the next read return the previous datagram's bytes and shifts every later reply.
- **CRC covers the sync/reserved byte.** The sync nibble is `0101` sent LSB-first, so the byte `0x05` is in the CRC. The node-address byte is in the CRC too.
- **Write-only registers** (`IHOLD_IRUN`, `TPOWERDOWN`, `TPWMTHRS`, `TCOOLTHRS`, `VACTUAL`, `SGTHRS`, `COOLCONF`, `NODECONF`, `OTP_PROG`) cannot be read back. The driver shadows every value it writes (needed for read-modify-write of `CHOPCONF`/`PWMCONF`/`GCONF` too, since reset values are partly OTP) and exposes none of them through `read_register`.
- **`IFCNT` verification** is the only acknowledgement for writes: the chip sends no reply to a write datagram. `write_register` therefore reads `IFCNT` back after configuration sequences (init and bulk configure calls), not after every single write, to keep latency low.
- **`TOFF = 0` disables the driver.** `disable()` without an ENN pin writes `CHOPCONF` with `TOFF = 0`; `enable()` restores the shadowed `TOFF`.
- **Do not trust open-load flags** at standstill or high velocity (datasheet): `FAULT_OPEN_LOAD` is informative only.
- **Short flags latch** until `TOFF = 0` or ENN high; `drv_err` in `GSTAT` clears only when all error conditions are gone.
- **`MSCURACT` phase labels:** the datasheet labels both 9-bit fields `CUR_A` (bits 8:0 as "phase B (sine)" and bits 24:16 as "phase A (co-sine)"); the driver returns them in register order `(low, high)` without claiming a coil mapping.
- **`VACTUAL` and STEP are exclusive.** While `VACTUAL ≠ 0` the STEP input is ignored; `stop()` hands control back to the pins.
- **Baud-rate changes** drop below 15 % of the previous rate cannot be followed by the chip's rate detector; keep the baud rate constant after init.
- **Address pins are the bus address.** MS1/MS2 select both the node address and (until `mstep_reg_select` is set) the stand-alone microstep resolution; init sets `mstep_reg_select`, after which the pins affect only addressing. A wrong `address` makes the chip silently ignore the datagram — the symptom is a read timeout during init, not an error reply.
- **StallGuard4 prerequisites.** Stall output and `SG_RESULT` quality require StealthChop (`en_SpreadCycle = 0`), a velocity where back-EMF is meaningful (many motors need well over one revolution per second) and `TCOOLTHRS ≥ TSTEP > TPWMTHRS`. Do not change the run current after tuning `SGTHRS`. At very low or resonant speeds `SG_RESULT` is unstable; the datasheet's rule of thumb is `(holding_torque/(2·I_nom) · 2π·rpm/60)/(R_coil + 0.34 Ω) · 0.34 Ω > 0.05 V`.
- **`DIAG` is shared:** it goes high on a stall *and* on driver errors; resolve by reading `DRV_STATUS`/`GSTAT`. A latched error clears only via ENN high.
- **Open VREF:** with `I_scale_analog = 1` and VREF unconnected the current scales to ≈ 73 % of full scale; `set_current` assumes 100 % (see Data Conversion). Tie VREF high or set `set_analog_scaling(False)` for calibrated current.
- **`FACTORY_CONF` and OTP are never written** by the library; OTP bits are one-time programmable and `FCLKTRIM` is factory-tuned.
- **`STDBY` pin** powers down the internal regulator; the chip loses all register state and must be re-initialised (`GSTAT.reset` is set) after waking.

## Sigrok Decoder

Input: `uart` (stacked on the sigrok `uart` decoder, 8N1, any baud ≥ 9 kBd; the single-wire bus shows
the host datagram and the chip reply on the same line, so the decoder assumes a half-duplex capture
on one channel or a RX/TX pair merged by the user). Decoder id `tmc2209`.

It reassembles 4-byte read requests, 8-byte write datagrams and 8-byte read replies (skipping the
host echo), checks the sync nibble and the CRC8 (annotating a CRC failure), shows the node address
(0–3, or `0xFF` for replies), names the register (`GCONF`, `GSTAT`, `IFCNT`, `NODECONF`,
`OTP_READ`, `IOIN`, `FACTORY_CONF`, `IHOLD_IRUN`, `TPOWERDOWN`, `TSTEP`, `TPWMTHRS`, `TCOOLTHRS`,
`VACTUAL`, `SGTHRS`, `SG_RESULT`, `COOLCONF`, `MSCNT`, `MSCURACT`, `CHOPCONF`, `DRV_STATUS`,
`PWMCONF`, `PWM_SCALE`, `PWM_AUTO`) and decodes bit fields for `GCONF`, `GSTAT`, `IOIN`,
`IHOLD_IRUN`, `COOLCONF`, `CHOPCONF`, `DRV_STATUS` and `PWMCONF`, plus computed values
(microstep count from `MRES`, current scale fraction, signed `VACTUAL`, stall limit `2·SGTHRS`).
Emits `OUTPUT_ANN` and `OUTPUT_PYTHON` per `specs/sigrok_annotations.md`.

The `timing` annotation row carries the conformance pair `read_request_end` (end of the last
request byte) / `read_reply_start` (start bit of the first reply byte), shaped per the
Variable-Length Annotation Convention. Timing config `specs/motor/tmc2209_timing.conf`:
`reply_delay_max_us=100`, `reply_delay_samplerate=4m`, `reply_delay_capture_ms=500` (at 115 200
baud, default `SENDDELAY`).
