# Chip Spec: DRV2605

**Manufacturer:** Texas Instruments  
**Datasheet:** `datasheets/motor/drv2605.pdf`  
**Category:** motor  
**Transports:** I²C

## Overview

The DRV2605 is a haptic driver for ERM (eccentric rotating mass) and LRA (linear resonant actuator) vibration motors, controlled over I²C. It has a 123-effect licensed Immersion TS2200 ROM library (six libraries: five tuned for ERMs, one closed-loop library for LRAs) played by an eight-slot waveform sequencer, a real-time-playback (RTP) register for streaming amplitudes, PWM / analog / audio-to-vibe inputs on the `IN/TRIG` pin, and external edge/level triggers. A "smart-loop" back-EMF feedback engine provides automatic overdrive, braking, LRA resonance tracking, automatic level calibration and actuator diagnostics. Configuration registers `0x16`–`0x1A` (rated voltage, overdrive clamp, calibration results, feedback control) can be burned once into on-chip OTP memory. Typical uses: button-press and notification haptics, game feedback, alerts and silent ringers.

The datasheet committed here (SLOS825E, Rev E, April 2018) covers the **DRV2605** only. The DRV2605L (low-voltage, `DEVICE_ID` = 7), DRV2604 (RAM instead of ROM, `DEVICE_ID` = 4) and DRV2604L (`DEVICE_ID` = 6) share the register map but are different parts; they are **not** covered.

## Transport Configuration

### I²C
- **Address:** `0x5A` (fixed, 7-bit; no address pin); write byte `0xB4`, read byte `0xB5`. Also answers the TI "haptic broadcast" address `0x58` (see Implementation Notes).
- **Max clock:** 400 kHz
- **Identity register:** `0x00` bits 7:5 = `DEVICE_ID` = `3` — read register `0x00` with mask `0xE0`, expected `0x60`. **Reading `0x00` clears the latched `DIAG_RESULT`, `FB_STS`, `OVER_TEMP` flags** (see Implementation Notes).
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer.

Plain register-pointer I²C: write the register address, repeated START, read. Multi-byte reads and writes auto-increment the register address (sequential addressing). The `EN` pin must be high for any register read or write to take effect; with `EN` low the device still ACKs but ignores the transfer. 1.8 V logic thresholds, tolerant up to VDD; pull-ups 660 Ω–4.7 kΩ to a rail not above VDD.

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| EN | high | device enable; low = shutdown (registers retained). 2 MΩ internal pull-down; must be high for I²C access. Optional `Connection` `en_pin` (active-high, the default polarity) |
| IN/TRIG | — | multi-mode input: external trigger (edge or level), PWM, analog, or AC-coupled audio; connect to GND if unused |
| REG | — | 1.8 V regulator output; **1 µF capacitor required** |
| VDD | — | supply 2.5–5.5 V; 0.1 µF capacitor required close to the pin |
| SDA, SCL | — | I²C; external pull-ups |
| OUT+, OUT− | — | differential actuator drive (≥ 8 Ω load at VDD = 5.2 V) |
| GND | — | ground |

No interrupt output; faults are polled from register `0x00`.

### Bit Fields

#### `STATUS` (`0x00`)

| Bits | Name | Description |
|------|------|-------------|
| 7:5 | DEVICE_ID | `3` DRV2605, `4` DRV2604, `6` DRV2604L, `7` DRV2605L |
| 3 | DIAG_RESULT | Result of the last auto-calibration (1 = failed to converge) or diagnostic (1 = actuator absent / shorted / out-of-range back-EMF) run; valid only after `GO` self-clears; **clears on read** |
| 2 | FB_STS | Feedback controller timed out (ERM: back-EMF zero > ~10 ms; LRA: lost frequency lock); debug only, can set during normal braking; **clears on read** |
| 1 | OVER_TEMP | Latching overtemperature flag (device shut down); **clears on read** |
| 0 | OC_DETECT | Latching overcurrent flag (load impedance below threshold; device shuts down and retries) |

#### `MODE` (`0x01`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | DEV_RESET | 1 = reset all registers to defaults (like a power cycle); self-clears |
| 6 | STANDBY | 1 = software standby (default), 0 = ready; takes effect immediately and stops playback |
| 2:0 | MODE | `0` internal trigger (`GO` bit), `1` external trigger edge, `2` external trigger level, `3` PWM / analog input (see `N_PWM_ANALOG`), `4` audio-to-vibe, `5` real-time playback, `6` diagnostics, `7` auto-calibration |

#### `LIBRARY_SELECTION` (`0x03`)

| Bits | Name | Description |
|------|------|-------------|
| 4 | HI_Z | 1 = outputs in true high-impedance state, effective immediately |
| 2:0 | LIBRARY_SEL | `0` empty, `1` TS2200 library A, `2` B, `3` C, `4` D, `5` E (ERM libraries), `6` LRA library, `7` reserved |

| ERM library | Rated V | Overdrive V | Rise time | Brake time |
|-------------|---------|-------------|-----------|------------|
| A (1) | 1.3 V | 3 V | 40–60 ms | 20–40 ms |
| B (2) | 3 V | 3 V | 40–60 ms | 5–15 ms |
| C (3) | 3 V | 3 V | 60–80 ms | 10–20 ms |
| D (4) | 3 V | 3 V | 100–140 ms | 15–25 ms |
| E (5) | 3 V | 3 V | > 140 ms | > 30 ms |

#### `WAV_FRM_SEQ1…8` (`0x04`–`0x0B`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | WAIT | 1 = bits 6:0 are a delay of `10 ms × value` |
| 6:0 | WAV_FRM_SEQ | Waveform (effect) identifier 1–123 when `WAIT` = 0; `0` ends the sequence |

Playback starts at `0x04` when `GO` is set and proceeds through the slots until it reads an identifier `0` or all eight slots have played.

#### `GO` (`0x0C`)

| Bit 0 | Description |
|-------|-------------|
| GO | Fires the process selected by `MODE` (waveform sequence, auto-calibration, diagnostics). Stays 1 until the process finishes; clearing it cancels playback. In external-trigger modes it mirrors the trigger pin. Setting RTP / PWM / analog / audio modes does not use this bit |

#### `FEEDBACK_CONTROL` (`0x1A`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | N_ERM_LRA | 0 = ERM, 1 = LRA (set **before** auto-calibration) |
| 6:4 | FB_BRAKE_FACTOR | Brake-to-drive feedback gain ratio: `0` 1×, `1` 2×, `2` 3×, `3` 4× (default), `4` 6×, `5` 8×, `6` 16×, `7` braking disabled |
| 3:2 | LOOP_GAIN | `0` low, `1` medium (default), `2` high, `3` very high |
| 1:0 | BEMF_GAIN | ERM: `0` 0.33×, `1` 1×, `2` 1.8× (default), `3` 4×; LRA: `0` 5×, `1` 10×, `2` 20× (default), `3` 30×. Written by auto-calibration |

| Bits | Name | Description |
|------|------|-------------|
| 7 | STARTUP_BOOST | 1 = higher loop gain during overdrive (default) |

| 5:4 | AUTO_CAL_TIME | Auto-calibration duration: `0` 150–350 ms, `1` 250–450 ms, `2` 500–700 ms (default), `3` 1000–1200 ms |

| 0 | OTP_PROGRAM | 1 = burn registers `0x16`–`0x1A` into OTP (**once only**) |

## Initialization Sequence

1. Power up VDD; wait ≥ 250 µs before the device accepts I²C commands. Drive `EN` high (any time during or after the wait; if `EN` is hard-wired high this is automatic).
2. Write `MODE` ← `0x80` (`DEV_RESET`) to put every register in its default state; wait ≥ 1 ms and read `MODE` until bit 7 reads 0 (the datasheet gives no reset duration).
3. Read `STATUS` (`0x00`); verify `DEVICE_ID` (bits 7:5) equals `3`.
4. Write `MODE` ← `0x00` (STANDBY = 0, internal-trigger mode) to leave standby.
5. Select the actuator: ERM — write `FEEDBACK_CONTROL` ← `0x36` and `LIBRARY_SELECTION` ← `0x01` (library A; defaults, open loop); LRA — write `FEEDBACK_CONTROL` ← `0xB6` (`N_ERM_LRA` = 1) and `LIBRARY_SELECTION` ← `0x06` (LRA library).
6. (Full only, recommended for any actuator that is not factory-matched: run auto-calibration — see below — or rewrite stored calibration values.)

The output is ready to play after the 0.7 ms start-up time from `GO` (1.5 ms from `EN` high in PWM / analog modes).

### Auto-calibration procedure (Full `calibrate`)

1. `MODE` ← `0x07` (leave standby, auto-calibration mode).
2. Write the inputs: `FEEDBACK_CONTROL` (`N_ERM_LRA`, `FB_BRAKE_FACTOR` = 2, `LOOP_GAIN` = 2; `BEMF_GAIN` is an output), `RATED_VOLTAGE`, `OD_CLAMP`, `CONTROL4.AUTO_CAL_TIME` = 3, `CONTROL1.DRIVE_TIME`, `CONTROL2.SAMPLE_TIME` = 3, `BLANKING_TIME` = 1, `IDISS_TIME` = 1 (values the datasheet calls "valid for most actuators").
3. `GO` ← `1`. The `GO` bit self-clears when calibration ends (≤ 1.2 s with `AUTO_CAL_TIME` = 3).
4. Read `STATUS`; `DIAG_RESULT` = 0 means the result converged. The outputs `A_CAL_COMP`, `A_CAL_BEMF` and `BEMF_GAIN` have been written by the engine.
5. Return to normal use (`MODE` ← `0x00`).

## Interrupt

Level 0 — the chip has no interrupt output. Faults (`OC_DETECT`, `OVER_TEMP`) are latched in `STATUS` and polled by `read_status`.

## Implementation Stages

### Minimal

Goal: play the built-in haptic effects with no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection`, `lra: bool=False` | — | Runs the Initialization Sequence for an ERM (library A, open loop) or an LRA (LRA library, closed loop, auto-resonance) |
| `play_effect` | `effect_id: int` (1–123) | — | Writes the effect to slot 1, `0` to slot 2 (end of sequence), sets `GO`; returns immediately |
| `stop` | — | — | Clears `GO` (cancels playback) |
| `is_playing` | — | bool | `GO` bit |

**Sensible defaults:** active (not in standby), internal-trigger mode, ROM library A for ERM / LRA library for LRA, factory values for rated voltage (`0x3F`) and overdrive clamp (`0x89`), bidirectional input, no time offsets. For an LRA, run `calibrate` (Full) for best results — the datasheet recommends calibrating every actuator at least once.

## Data Conversion

```
rated_voltage_code (closed loop):
    ERM:  code = V / 21.33e-3
    LRA:  code = V * sqrt(1 - (4 * t_sample + 300e-6) * f_lra) / 20.71e-3     # V is RMS; t_sample = SAMPLE_TIME (150/200/250/300 us); f_lra in Hz

od_clamp_code:
    ERM open loop:    code = V / 21.96e-3
    LRA closed loop:  code = V / 21.96e-3           # maximum peak voltage
    LRA open loop:    code = V / (21.33e-3 * sqrt(1 - f_lra * 800e-6))      # V is RMS
    ERM closed loop:  V = 21.33e-3 * code * (t_drive - 300e-6) / (t_drive + t_idiss + t_blanking)   # t_idiss and t_blanking are not tabulated in this datasheet -> pass a raw code
```

Codes are rounded and clamped to 0–255. With a supply VDD below the clamp voltage the output cannot reach the clamp; if the rated voltage exceeds the clamp the clamp wins.

```
DRIVE_TIME (LRA):  t_drive_ms = 0.5 + 0.1 * code        # target: half the LRA period, e.g. 200 Hz -> 2.5 ms -> code 20
DRIVE_TIME (ERM):  t_drive_ms = 1 + 0.2 * code
time offsets:      offset_ms = int8(register) * 5       # ODT, SPT, SNT, BRT
sequencer wait:    delay_ms  = 10 * WAV_FRM_SEQ[6:0]    # WAIT = 1
VBAT:              vdd_V     = VBAT * 5.6 / 255
LRA_PERIOD:        period_us = LRA_PERIOD * 98.46 ;  f_lra_Hz = 1e6 / period_us
A_CAL_COMP:        coefficient = 1 + A_CAL_COMP / 255
A_CAL_BEMF:        back_emf_V = (A_CAL_BEMF / 255) * 1.22 / BEMF_GAIN_value
ATH_MIN/MAX_INPUT: volts_pp = code * 1.8 / 255
ATH_MIN/MAX_DRIVE: percent  = code / 255 * 100
```

RTP and PWM input scaling:

| Input | Open loop (`OD_CLAMP` full scale) | Closed loop unidirectional | Closed loop bidirectional |
|-------|-----------------------------------|----------------------------|---------------------------|
| PWM duty | 0 % = −full (brake), 50 % = 0, 100 % = +full | 0 % = 0, 50 % = ½ rated, 100 % = rated | 0–50 % = 0, 75 % = ½ rated, 100 % = rated |
| RTP signed (`DATA_FORMAT_RTP` = 0) | `0x81` = −full, `0x00` = 0, `0x7F` = +full | not recommended | `0x00` = 0, `0x3F` = ½, `0x7F` = full |
| RTP unsigned (= 1) | `0x00` = −full, `0x7F` = 0, `0xFF` = +full | `0x00` = 0, `0x7F` = ½, `0xFF` = full | `0x7F` = 0, `0xBF` = ½, `0xFF` = full |

The TS2200 libraries are stored in bidirectional format and cannot be used in unidirectional mode; library A (fixed overdrive) must only be used open-loop; libraries B–E and the LRA library work with closed-loop bidirectional drive.

### Effect IDs

`play_effect` / `play_sequence` identifiers 1–123 index the TS2200 effect list of the selected library (datasheet §11.2; the same list for all libraries, tuned to the library). ## Timing Constraints

- **Power-up:** wait ≥ 250 µs after VDD before I²C access (datasheet §8.3).
- **EN high → output:** 1.5 ms start-up in PWM / analog modes; **`GO` / trigger → output:** 0.7 ms.
- **Reset:** `DEV_RESET` self-clears; no duration is given — the driver waits ≥ 1 ms and polls bit 7.
- **Auto-calibration:** `GO` self-clears after the `AUTO_CAL_TIME` window: 150–350 ms (0), 250–450 ms (1), 500–700 ms (2, default), 1000–1200 ms (3, used by `calibrate`). **Conformance-checked**: `calibration` — sigrok annotation pair `cal_start` (write of `1` to `GO` `0x0C` while `MODE` = `7`) → `cal_done` (first read of `0x0C` returning `GO` = 0). With the `AUTO_CAL_TIME` = 3 that `calibrate` programs, the bound is 1200 ms plus bus overhead; see `specs/motor/drv2605_timing.conf`.
- **Playback duration:** library effects are 10 ms to ~1 s; poll `GO` (it stays 1 until the sequence completes) rather than sleeping.
- **I²C:** SCL ≥ 1.3 µs low / 0.6 µs high, bus free ≥ 1.3 µs (400 kHz).

## Implementation Notes

- **Register-addressed:** accept `RegisterConnection` (1-byte register address) and call `connection.read(reg, length)` / `connection.write(reg, data)` directly — no chip-local `_read_reg`/`_write_reg` and no `bus_type` branch (see `specs/feature_register_access_design.md`). Multi-byte writes (the eight sequencer slots) auto-increment.
- **Reset state is standby + ERM open loop:** `MODE` resets to `0x40`; nothing plays until `STANDBY` is cleared. `ERM_OPEN_LOOP` defaults to 1 (TI recommends open loop for ERMs with the ROM libraries) and library A to selected. An LRA needs `N_ERM_LRA` = 1 and the LRA library (6); its closed-loop auto-resonance mode works best after calibration.
- **Read-to-clear status:** reading `STATUS` clears `DIAG_RESULT`, `FB_STS` and `OVER_TEMP`. `init`'s `DEVICE_ID` check and any discovery probe at `0x00` therefore consume pending diagnostic flags; `read_status` returns them once.
- **Diagnostics / calibration results are valid only after `GO` clears:** `calibrate` and `diagnose` poll `GO` before reading `STATUS`. Calibration changes the actuator's behaviour; TI advises evaluating in final assembly.
- **Output short:** if the outputs are shorted before playback the chip needs a `MODE` change to resume normal playback; `OC_DETECT` stays set while the short remains. A short while idle is only detected when the next waveform starts.
- **`EN` pin:** with `EN` low the chip ACKs but ignores reads and writes; registers are retained. A write that appears to have no effect usually means `EN` is low.
- **Closed vs open loop constraints:** library A only works open-loop; the TS2200 libraries need bidirectional input; unidirectional input (`BIDIR_INPUT` = 0) is only valid closed-loop. `set_bidirectional(False)` while open-loop raises.
- **Calibration inputs:** `RATED_VOLTAGE` and `OD_CLAMP` must be written before calibration and re-calibrated after any change. If the rated voltage exceeds the clamp, the clamp wins; with VDD below the clamp the output cannot reach it.
- **Haptic broadcast address `0x58`:** the DRV2605 also responds at `0x58` (7-bit); a write of the `GO` bit there fires all broadcast-capable haptic drivers at once. It appears as an extra ACK in a bus scan (the discovery registry lists `0x5A` only). The driver does not use it.
- **OTP:** `program_otp` can be run exactly once per device; the OTP holds registers `0x16`–`0x1A`; VDD must be 4–4.4 V. After programming, reset the device (or power-cycle) and read `0x16`–`0x1A` back to verify. Treat as destructive.
- **No ROM-effect time or amplitude in SI:** effect strength is relative to the rated voltage / overdrive clamp; the datasheet gives voltages (V) and times (ms) only for the register encodings above.
- **Siblings:** DRV2605L (`DEVICE_ID` 7, low-voltage), DRV2604 / DRV2604L (RAM-based, no licensed ROM) are register-compatible in part but different datasheets; no compatibility is assumed.
- **Datasheet revision:** the committed datasheet is SLOS825E (revised April 2018), 65 pages. The equation images (Eq. 2–7) were checked against the page render.

## Sigrok Decoder

Decoder id `drv2605`, input `['i2c']`. Matches I²C addresses `0x5A` and the broadcast address `0x58`. Annotates every register in the Register Map by name; decodes `STATUS` (device id, diagnostic / feedback / over-temperature / over-current flags), `MODE` (reset, standby and the `MODE` name), `LIBRARY_SELECTION`, the eight sequencer slots (effect id or wait time), `GO`, `FEEDBACK_CONTROL`, `CONTROL1`–`CONTROL4`, `ATH_*`, `RATED_VOLTAGE` / `OD_CLAMP` (as volts at the last-seen actuator type), time offsets (ms), `VBAT` (V) and `LRA_PERIOD` (µs / Hz) into named flags and values; `RTP_INPUT` writes are shown as a percentage. `STATUS` reads are checked against `DEVICE_ID` = 3. For the Calibration-time Timing Constraint the decoder tracks `MODE` writes and emits the `timing` annotation row markers `cal_start` (write of `1` to `GO` `0x0C` while the last-written `MODE` is `7`) and `cal_done` (first read of `0x0C` returning `GO` = 0), shaped per `specs/sigrok_annotations.md`'s Variable-Length Annotation Convention.
