# Chip Spec: DS1371

**Manufacturer:** Maxim Integrated (Analog Devices)  
**Datasheet:** `datasheets/rtc/ds1371.pdf` (DS1371 I²C, 32-Bit Binary Counter Watchdog Clock, REV 070607)  
**Category:** rtc  
**Transports:** I²C

## Overview

The DS1371 is a time-keeping chip built around a 32-bit binary seconds counter (the "time-of-day" counter) instead of a BCD calendar, plus a second 24-bit counter that is selectable as a periodic alarm (one tick per second), as a watchdog timer (one tick per 1/4096 s, restarted by reading or writing the counter or by a rising edge on the `WDS` strobe input) or, when disabled, as three bytes of general-purpose RAM. A single `SQW/INT` pin outputs a square wave (1 Hz, 4.096 kHz, 8.192 kHz, 32.768 kHz) or the alarm/watchdog interrupt. It uses an external 32.768 kHz crystal, runs from 1.7–5.5 V (oscillator down to 1.3 V, 100 nA data-retention current with the oscillator off), has no battery-switchover circuit, supports I²C standard and fast mode and comes in an 8-pin µSOP. The counter has no epoch; the driver defines it as seconds since 1970-01-01 00:00:00 UTC (Unix time), which is valid until 2106. Typical uses: elapsed-time measurement, time stamping, watchdog supervision, servers and portable instruments.

## Transport Configuration

### I²C
- **Address:** `0x68` (7-bit `1101000`, fixed; one device per bus)
- **Max clock:** 400 kHz (Fast-mode); also 100 kHz (standard mode)
- **Identity register:** none; chip has no ID register (feeds `registry/chips.json` with `id_probe: null`). Shares `0x68` with DS1307, DS3231, PCF8523 — only one of them can be on a bus
- **Probe safety:** `register_pointer` — an address-pointer write plus read has no side effect
- **Register addressing:** 8-bit register pointer, auto-increment, wraps from `0x08` to `0x00`; on every START, STOP or pointer increment to `0x00` the counter is latched into a second register set, so a multi-byte read is consistent

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| SQW/INT | low, open-drain | square-wave or alarm/watchdog interrupt output — requires external pull-up |
| WDS | rising edge | watchdog strobe input: a low→high transition reloads and restarts the watchdog counter (minimum pulse width 100 ns); it must be **low** while the watchdog counter registers are written; tie to ground when unused |
| X1, X2 | — | 32.768 kHz crystal (X1 can take an external 32.768 kHz clock) |
| SCL, SDA | — | I²C, open-drain, external pull-ups |
| VCC, GND | — | 1.7–5.5 V |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | TOD0 | R/W | undefined | Time-of-day counter byte 0 (LSB) |
| `0x01` | TOD1 | R/W | undefined | Byte 1 |
| `0x02` | TOD2 | R/W | undefined | Byte 2 |
| `0x03` | TOD3 | R/W | undefined | Byte 3 (MSB) |
| `0x04` | WDALM0 | R/W | undefined | Watchdog/alarm counter byte 0 (LSB) |
| `0x05` | WDALM1 | R/W | undefined | Byte 1 |
| `0x06` | WDALM2 | R/W | undefined | Byte 2 (MSB) |
| `0x07` | CONTROL | R/W | `0x06` | Oscillator, counter and `SQW/INT` control |
| `0x08` | STATUS | R/W | `0x80` | Oscillator-stop and alarm flags |

Registers other than `CONTROL` and `STATUS` are undefined on first power-up.

### Bit Fields

#### `CONTROL` (`0x07`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | EOSC | 0 = oscillator running (power-up default), 1 = oscillator stopped (low-power standby) |
| 6 | WACE | 1 = watchdog/alarm counter enabled; 0 = the 24 bits are plain RAM. Must be set after writing the alarm value, and **toggled 0 → 1** after a watchdog value is written from zero to non-zero |
| 5 | WD/ALM | 0 = alarm: the counter decrements once per second, sets `AF` at 0, reloads and restarts; 1 = watchdog: decrements every 1/4096 s, sets `AF` at 0 and stops |
| 3 | INTCN | 0 = `SQW/INT` outputs the square wave (needs the oscillator running); 1 = `SQW/INT` is the alarm/watchdog interrupt |
| 2:1 | RS2:RS1 | Square-wave rate (when `INTCN` = 0): `00` 1 Hz, `01` 4.096 kHz, `10` 8.192 kHz, `11` 32.768 kHz (default `11`) |
| 0 | AIE | 1 = `AF` may assert `SQW/INT` (with `INTCN` = 1) |

Bit 4 reads 0. A counter of all zeros disables the watchdog/alarm counter regardless of `WACE`.

#### `STATUS` (`0x08`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | OSF | Oscillator stop flag: 1 if the oscillator is, or was ever, stopped (first power-up, VCC too low, `EOSC` set, noise); stays 1 until written 0 |
| 0 | AF | Alarm flag: set when the watchdog/alarm counter reaches 0 (always, independent of `INTCN`); can only be cleared (written 0), writing 1 leaves it unchanged |

## Initialization Sequence

1. Power VCC (1.7–5.5 V); the oscillator starts automatically (`EOSC` = 0 at power-up).
2. Read `STATUS`; `OSF` = 1 means the counter is not valid (first power-up or an oscillator stop): set the time and clear `OSF`.
3. Set the time by writing `0x00`–`0x03` (one transaction); writing the counter resets the divider chain (a 1 Hz square wave restarts at that instant).
4. Optionally write `CONTROL` for the square wave, alarm or watchdog; clear `AF` by writing `STATUS` = `0x00` (keeping `OSF` as desired).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `SQW/INT`, active-low, open-drain — requires external pull-up |
| Level | 2 |
| Condition(s) | alarm: the 24-bit counter, decremented once per second, reached 0 (`SQW/INT` goes low and stays low until `AF` is cleared); watchdog: the counter, decremented every 1/4096 s, reached 0 without a restart (`SQW/INT` pulses low for 250 ms, then `AF` clears itself) |
| Clear mechanism | write `AF` = 0 in `STATUS` (alarm mode); watchdog mode clears itself after the 250 ms pulse |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_ALARM` | `0x01` | Periodic alarm (`WD/ALM` = 0, one-second tick) |
| `SOURCE_WATCHDOG` | `0x02` | Watchdog timeout (`WD/ALM` = 1, 1/4096 s tick, 250 ms pulse) |

## Implementation Stages

### Minimal

Goal: read and set the clock; no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Takes the `RegisterConnection`; reads `STATUS` to confirm the chip answers; no writes |
| `get_seconds` | — | int | 32-bit counter, one burst read `0x00`–`0x03` (seconds since the Unix epoch) |
| `set_seconds` | `seconds: int` | — | Writes `0x00`–`0x03` in one transaction, clears `OSF` |
| `get_datetime` | — | `(year, month, day, weekday, hour, minute, second)` | Converts the counter as UTC Unix time; `weekday` 1–7 (1 = Monday) |
| `set_datetime` | `year, month, day, weekday, hour, minute, second` | — | Converts to seconds (UTC; `weekday` is ignored/validated) and writes the counter |

**Sensible defaults:** oscillator running, square wave at the power-up default (32.768 kHz on `SQW/INT`), watchdog/alarm counter disabled (`WACE` = 0).

## Data Conversion

```
seconds   = TOD0 | TOD1 << 8 | TOD2 << 16 | TOD3 << 24     # 32-bit binary counter, 1 LSB = 1 s
unix_time = seconds                                           # driver convention (epoch 1970-01-01 00:00:00 UTC)
datetime  = gmtime(unix_time)                                 # year 1970..2106
wd_counter = WDALM0 | WDALM1 << 8 | WDALM2 << 16             # 24-bit
alarm period      = wd_counter seconds                        # WD/ALM = 0
watchdog timeout  = wd_counter / 4096 seconds                 # WD/ALM = 1  (244 us per tick)
```

## Timing Constraints

| Constraint | Value |
|------------|-------|
| I²C clock | standard mode 0–100 kHz, fast mode 100–400 kHz |
| Oscillator-stop detection | `OSF` is set when the oscillator stops for ≥ 100 ms (tOSF) |
| Watchdog tick | 1/4096 s (≈ 244 µs) |
| Watchdog interrupt pulse | `SQW/INT` low for 250 ms, `AF` self-clears at its end; cannot be truncated |
| `WDS` strobe width | ≥ 100 ns, rising edge restarts the counter |
| Counter write | resets the divider chain (1 Hz output restarts) |

No constraint has a bus-decodable start/end pair with a datasheet bound that a decoder can mark (the interrupt pulse is on the `SQW/INT` pin, not on the bus), so `ds1371_timing.conf` defines no checks.

## Implementation Notes

- **RegisterConnection:** accept `RegisterConnection` and call `connection.read(reg, length)` / `connection.write(reg, data)` directly — no chip-local helpers. See `specs/feature_register_access_design.md`.
- **Binary, not BCD:** the counter is a plain little-endian 32-bit integer (`TOD0` is the LSB); there is no calendar hardware. The driver converts to and from UTC with its own calendar math (no timezone, no leap-second handling); the epoch convention is the driver's (Unix), the chip does not know it. Counter overflow occurs in the year 2106.
- **Time-of-day write:** write all four counter bytes in one transaction; the write resets the divider chain, and the next increment follows one second later.
- **`OSF` validity:** `OSF` = 1 after the first power-up and after any oscillator stop; the counter value is then meaningless. The driver's `get_datetime` does not raise on `OSF`; `oscillator_stopped` is the check. Clear `OSF` by writing `STATUS` = `0x00` (or with `AF` as needed) — the register accepts only 0 for `AF` and `OSF` is cleared by a 0 write.
- **Watchdog sequencing:** in watchdog mode the `WDS` pin must be low while the counter bytes are written; after writing a non-zero value from zero, toggle `WACE` 0 → 1. Reading or writing any watchdog byte reloads and restarts the counter, so diagnostics that read `0x04`–`0x06` feed the watchdog — `get_watchdog` therefore feeds it too (documented in the method). In alarm mode `WACE` must be set after the alarm value is written.
- **Alarm vs. watchdog interrupt:** alarm mode keeps `SQW/INT` low until `AF` is cleared; watchdog mode pulses it low for 250 ms and clears `AF` itself; writing `AF` or `AIE` to 0 during the pulse does not shorten it, and a write to the counter during the pulse takes effect only after it.
- **Square wave vs. interrupt:** the pin is either a square wave (`INTCN` = 0, oscillator must be on) or the interrupt (`INTCN` = 1); the two never share the pin. The 1 Hz output is reset by a counter write, the higher frequencies are not.
- **No backup supply:** there is no VBAT input; the counter stops when VCC drops below the oscillator minimum (1.3 V). Use a stable supply or a super-capacitor for backup.
- **Address:** the fixed `0x68` is shared with DS1307, DS3231, PCF8523; there is no ID register, so only one can be on a bus.

## Sigrok Decoder

Decoder id `ds1371`, input `['i2c']`. Matches I²C address `0x68`, tracks the register pointer (auto-increment, wrap at `0x08` → `0x00`) and annotates register accesses by name. Decodes the four counter bytes into a 32-bit value and a UTC date/time, the three watchdog/alarm bytes (with the tick interpretation from the last `CONTROL`), `CONTROL` (`EOSC`, `WACE`, `WD/ALM`, `INTCN`, `RS`, `AIE`) and `STATUS` (`OSF`, `AF`); warns on `STATUS` writes of `AF` = 1 (ignored by the chip), on watchdog-byte reads (which reload the counter) and on an enabled alarm with `WACE` = 0. No conformance annotation pair is emitted (no checked timing constraint).
