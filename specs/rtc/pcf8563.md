# Chip Spec: PCF8563

**Manufacturer:** NXP Semiconductors  
**Datasheet:** `datasheets/rtc/pcf8563.pdf` (PCF8563 Rev. 11.1, 19 January 2026)  
**Category:** rtc  
**Transports:** I²C

## Overview

The PCF8563 is a low-power CMOS real-time clock/calendar for a 32.768 kHz quartz crystal (with one integrated capacitor): BCD seconds, minutes, hours (24-hour), days, weekdays, months, years with a century flag and automatic leap-year compensation (valid 2000–2099), an **alarm** (minute, hour, day, weekday match), an 8-bit **countdown timer** (4096 Hz, 64 Hz, 1 Hz or 1/60 Hz source), a programmable **clock output** (CLKOUT: 32.768 kHz, 1.024 kHz, 32 Hz, 1 Hz), an open-drain **INT** output for alarm and timer, a **voltage-low (VL)** detector that flags clock-integrity loss and an internal power-on reset. Two-wire I²C up to 400 kHz (VDD 1.8–5.5 V). It has no battery switch-over circuit: backup operation is simply the chip running from a battery or supercap on VDD, with the `VL` flag signalling a brown-out.

## Transport Configuration

### I²C
- **Address:** `0x51` (7-bit, fixed; write byte `0xA2`, read byte `0xA3`)
- **Max clock:** 400 kHz (VDD 1.8–5.5 V)
- **Identity register:** none (`registry/chips.json` entry has `"id_probe": null`; `0x51` is shared with the PCF85063A-class and EEPROM address ranges)
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer
- **Register addressing:** 1-byte register address (`RegisterConnection`, `reg_bytes = 1`); reads and writes auto-increment, wrapping from `0x0F` to `0x00`. **During a read or write the time-counting circuits (`0x02`–`0x08`) are frozen** and released at the end of the access; one increment request is remembered, so a transfer **must finish in less than 1 s** and the time must be read/written in **one transaction**

| Pin | Active | Notes |

## Register Map

| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| `0x00` | Control_status_1 | R/W | `TEST1` (7), `STOP` (5), `TESTC` (3); other bits N (write 0) |
| `0x01` | Control_status_2 | R/W | `TI_TP` (4), `AF` (3), `TF` (2), `AIE` (1), `TIE` (0) |
| `0x02` | VL_seconds | R/W | `VL` (7), seconds tens (6:4) / units (3:0), BCD |
| `0x03` | Minutes | R/W | Minutes (6:0), BCD |
| `0x04` | Hours | R/W | Hours 0–23 (5:0), BCD |
| `0x05` | Days | R/W | Days 1–31 (5:0), BCD |
| `0x06` | Weekdays | R/W | Weekday 0–6 (2:0), 0 = Sunday |
| `0x07` | Century_months | R/W | `C` (7), month tens (4) / units (3:0), BCD |
| `0x08` | Years | R/W | Years 0–99, BCD |
| `0x09` | Minute_alarm | R/W | `AE_M` (7; **0 = enabled**), minute alarm BCD |
| `0x0A` | Hour_alarm | R/W | `AE_H` (7), hour alarm BCD (5:0) |
| `0x0B` | Day_alarm | R/W | `AE_D` (7), day alarm BCD (5:0) |
| `0x0C` | Weekday_alarm | R/W | `AE_W` (7), weekday alarm (2:0) |
| `0x0D` | CLKOUT_control | R/W | `FE` (7), `FD[1:0]` (1:0) |
| `0x0E` | Timer_control | R/W | `TE` (7), `TD[1:0]` (1:0) |
| `0x0F` | Timer | R/W | Countdown value (reads the live count) |

Bit positions marked N must always be written 0. After reset all registers take the values of the datasheet's reset table (notably `VL` = 1, the four alarm enables disabled (`AE_x` = 1), `FE` = 1 with 32.768 kHz, timer disabled with `TD` = `11`).

### Bit Fields

#### `Control_status_1` (`0x00`)

`TEST1` = 0 for normal operation (1 = EXT_CLK test mode); `STOP` = 1 stops the RTC divider chain (CLKOUT at 32.768 kHz stays available) — set it while writing the time for a precise start; `TESTC` = 0 (power-on-reset override disabled); the other bits are written 0.

#### `Control_status_2` (`0x01`)

| Bit | Name | Description |
|-----|------|-------------|
| 4 | TI_TP | `0`: INT is active while `TF` is active (subject to `TIE`); `1`: INT pulses per the timer period (see Timer) |
| 3 | AF | Alarm flag: read 1 = alarm occurred; **write 0 clears it, write 1 leaves it unchanged** |
| 2 | TF | Timer flag: same semantics |
| 1 | AIE | Alarm interrupt enable |
| 0 | TIE | Timer interrupt enable |

If both `AF` and `AIE` are active, INT is permanently active. To clear one flag without clearing the other, write the other flag bit as 1.

#### `VL_seconds` (`0x02`)

Bit 7 `VL`: `1` = clock integrity not guaranteed (set at power-up and when VDD falls below Vlow or the oscillator stops; **cleared only through the interface**), `0` = guaranteed.

#### `Century_months` (`0x07`)

Bit 7 `C`: toggled when the years register rolls from 99 to 00; its meaning is user-assignable (`0` = century x, `1` = x + 1).

#### `CLKOUT_control` (`0x0D`)

`FE` = 1 enables CLKOUT (default), 0 = high-impedance; `FD[1:0]`: `00` 32.768 kHz, `01` 1.024 kHz, `10` 32 Hz, `11` 1 Hz.

#### `Timer_control` (`0x0E`) and `Timer` (`0x0F`)

`TE` = 1 enables the timer; `TD[1:0]`: `00` 4.096 kHz, `01` 64 Hz, `10` 1 Hz, `11` 1/60 Hz (leave `11` when unused to save power). The timer counts down from the value in `Timer` and sets `TF` at the end of every countdown; the countdown period is `n / source clock`. The timer cannot be frozen for reading: read twice and compare.

## Initialization Sequence

1. Power-up: `VL` = 1 (time invalid), alarms disabled, CLKOUT 32.768 kHz on, timer off.
2. Set the time with `set_datetime` (one burst write `0x02`–`0x08`, optionally with `STOP` = 1 during the write for a defined start) which clears `VL`.
3. Disable CLKOUT (`FE` = 0) when not needed, to save power and reduce noise.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `INT`, active low, open-drain — requires an external pull-up |
| Level | 2 (selectable sources: alarm, timer) |
| Condition(s) | Alarm: all enabled alarm fields match; timer: the countdown reached zero |
| Clear mechanism | Write 0 to the `AF` / `TF` bit (other flag written 1); with `TI_TP` = 1 the timer INT is a pulse that ends by itself |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_ALARM` | `0x08` | Alarm flag `AF` (enable bit `AIE`) |
| `SOURCE_TIMER` | `0x04` | Timer flag `TF` (enable bit `TIE`) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on INT (falling edge) via `connection.int_pin` (or `int_pin`), otherwise a 1 s polling task on `poll_interrupt`; `callback(flags)` receives the `AF`/`TF` bitmask |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `Control_status_2`, returns `flags & (SOURCE_ALARM | SOURCE_TIMER)` and clears the reported flags (writes them 0, preserving the others) |
| `enable_interrupt` | `enable_interrupt(source)` | Sets `AIE` / `TIE` |
| `disable_interrupt` | `disable_interrupt(source)` | Clears `AIE` / `TIE` |

## Implementation Stages

### Minimal

Goal: read and set the clock; no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection | — | Reads the control registers to confirm the chip answers; no writes |
| `get_datetime` | — | `(year, month, day, weekday, hour, minute, second)` | One burst read `0x02`–`0x08`; `year` 2000–2099 (century bit ignored), `weekday` 0–6 with Sunday = 0 |
| `set_datetime` | `year, month, day, weekday, hour, minute, second` | — | Writes `0x02`–`0x08` in one transaction (clears `VL` since the seconds register is written with bit 7 = 0), `C` = 0; the whole transfer must finish in < 1 s |

**Sensible defaults:** 24-hour time (the only format), alarm/timer interrupts disabled, CLKOUT left at its power-on 32.768 kHz, no STOP bit use.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `clock_valid` | — | bool | `VL` = 0 |

| `set_alarm` | `minute=None, hour=None, day=None, weekday=None` | — | Each non-`None` value enables (AE = 0) and writes that field in BCD; `None` disables it (AE = 1); clears `AF`; the alarm fires when **all** enabled fields match |

**Additional configuration options:** alarm fields, countdown timer (value, source, pulse mode), CLKOUT frequency, STOP bit, interrupt enables.

## Data Conversion

```
BCD:  value = (reg >> 4) * 10 + (reg & 0x0F);   reg = ((value // 10) << 4) | (value % 10)

seconds = BCD(VL_seconds & 0x7F)     minutes = BCD(Minutes & 0x7F)      hours = BCD(Hours & 0x3F)
day     = BCD(Days & 0x3F)           weekday = Weekdays & 0x07          month = BCD(Century_months & 0x1F)
year    = 2000 + BCD(Years)

alarm register = (AE << 7) | BCD(value)     with AE = 0 enabled, 1 disabled   (weekday: AE << 7 | weekday)
timer period   = n / f_source              (4096 Hz, 64 Hz, 1 Hz, 1/60 Hz)
```

### Demo

**Alarm clock.** With the Full driver, print `clock_valid()`, set the clock from the host time if invalid, print the time every second for 10 s, set an alarm for the next full minute (`set_alarm(minute=…)`; the alarm has minute resolution), enable the INT callback and report the alarm event, configure a 3 s one-shot countdown timer (`configure_timer(3, "1hz")`), output 1 Hz on CLKOUT for a few seconds and then disable it.

## Timing Constraints

- **One-second access window:** a read or write of the time registers must complete within 1 s (the counters are frozen during the access and one pending increment is stored); never split the time into two transactions.
- **STOP bit:** when `STOP` is released the first increment occurs between 0 and one 8.192 kHz cycle later (precise start; datasheet Table 26).
- **Alarm resolution:** the alarm compares minute, hour, day and weekday (no seconds): the earliest alarm is the next minute change.
- **Timer:** period = n / source clock (e.g. 255 / 1 Hz = 255 s; 255 / (1/60 Hz) = 4.25 h); with `TI_TP` = 1 INT is a pulse of 1/8192 s (n = 1) or 1/4096 s (n > 1) at the 4 096 Hz source, longer for the slower sources (datasheet Table 7).
- **Voltage-low:** `VL` sets when VDD falls below Vlow or the oscillator stops; it clears only via the interface.
- **I²C:** ≤ 400 kHz — a clock-rate property, not an event-to-event delay.
- **Conformance:** none of these has a bus-decodable start/end annotation pair, so `specs/rtc/pcf8563_timing.conf` defines no checks.

## Implementation Notes

- **RegisterConnection:** `connection.read(0x02, 7)` / `connection.write(0x02, bytes)`; no chip-local `_read_reg`/`_write_reg`, no `bus_type` branch (see `specs/feature_register_access_design.md`).
- **Single-transaction time access** is mandatory; the datasheet warns that setting time and date in separate accesses can corrupt the time.
- **Write-1-to-keep flags:** `AF` and `TF` are cleared by writing 0; writing 1 leaves them unchanged — always write the other flag as 1 when clearing one.
- **Alarm enables are active-low:** `AE_x` = 0 enables the field; the power-on state has all alarms disabled.
- **Weekday numbering:** 0 = Sunday … 6 = Saturday (the same as the driver's convention); the chip does not derive the weekday from the date, the host sets it.
- **Century bit** only toggles at the 99 → 00 rollover; set it yourself to track centuries.
- **No battery switch-over:** unlike the DS3231/BQ32000 there is no VBAT pin; run VDD from a battery/supercap if backup is needed and watch `VL` after a brown-out.
- **CLKOUT is enabled at 32.768 kHz by default** (open drain); disable it for power and EMI if unused.
- **Timer readback:** read twice and compare, the counter cannot be frozen.
- **Address:** `0x51` is also used by the PCF85063A-class chips and EEPROMs; a wrong-chip access returns meaningless data.
- **Datasheet:** NXP PCF8563 Rev. 11.1, downloaded from `https://www.nxp.com/docs/en/data-sheet/PCF8563.pdf`.

## Sigrok Decoder

Decoder id `pcf8563`, input `['i2c']`. Matches I²C address `0x51`. Annotates register writes and pointer-set + read transactions by register name and decodes the BCD time/date as `YYYY-MM-DD hh:mm:ss` with the weekday name, `VL`, `C`, `STOP`, `AF`/`TF`/`AIE`/`TIE`/`TI_TP`, the alarm registers (field values and `AE` enables), CLKOUT frequency and timer settings; warns on time-register accesses split across transactions (write that does not cover `0x02`–`0x08`), on invalid BCD, on non-zero N bits and on transfers longer than one second (not detectable without timestamps — no timing pair). No timing annotation pair is emitted.
