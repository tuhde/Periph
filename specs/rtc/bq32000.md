# Chip Spec: BQ32000

**Manufacturer:** Texas Instruments  
**Datasheet:** `datasheets/rtc/bq32000.pdf` (SLUS900F, December 2008, revised August 2026)  
**Category:** rtc  
**Transports:** I²C

## Overview

The BQ32000 is a real-time clock/calendar for a 32.768 kHz crystal: seconds, minutes, hours (24-hour only), day of week, date, month and year in BCD, with leap-year compensation for every year divisible by 4 (correct until 2099), an optional century bit, an **oscillator-fail flag**, a **STOP** bit to disable the oscillator, and a programmable **calibration** of −126 … +63 ppm (CAL 0–31 with a sign bit). A built-in **automatic backup switchover** (VCC ↔ VBACK, threshold ≈ 2.8 V) keeps the time running from a coin cell or supercap, with an integrated **trickle charger** for supercaps (and cautiously rechargeable batteries). The open-drain **IRQ** pin is a configurable output (a logic level, or a 512 Hz / 1 Hz test signal for calibration) — it is **not** an alarm/interrupt: the chip has no alarms or timers. Supply and bus 1.8–3.6 V per the datasheet's electrical table (3.3 V typical), I²C up to 400 kHz.

## Transport Configuration

### I²C
- **Address:** `0x68` (7-bit, fixed; write byte `0xD0`, read byte `0xD1`); the chip does not respond to the general call
- **Max clock:** 400 kHz (fast mode); 100 kHz standard
- **Identity register:** none; chip has no ID register (`registry/chips.json` entry has `"id_probe": null`; it shares `0x68` with the DS3231, PCF8523, PCF85063A and others, which cannot be told apart)
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer
- **Register addressing:** 1-byte register address (`RegisterConnection`, `reg_bytes = 1`); reads auto-increment, so `0x00`–`0x06` read as a 7-byte block; reads are write-pointer / repeated START / read; **time-keeping registers 0x00–0x09 cannot be accessed while the chip runs from VBACK** (VCC below VREF)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| IRQ | configurable, open-drain | Output of `OUT` (when FT = 0) or a 512 Hz / 1 Hz test clock (FT = 1); requires a pull-up **to VCC** so it stays high on backup power (IRQ is unused in backup mode) |
| OSCI, OSCO | — | 32.768 kHz crystal |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | SECONDS | R/W | `0xxxxxxx` | STOP (bit 7), tens of seconds (6:4), seconds (3:0), BCD |
| `0x01` | MINUTES | R/W | `1xxxxxxx` | OF (bit 7), tens of minutes (6:4), minutes (3:0), BCD |
| `0x02` | CENT_HOURS | R/W | `xxxxxxxx` | CENT_EN (7), CENT (6), tens of hours (5:4), hours (3:0), 24-hour BCD |
| `0x03` | DAY | R/W | `00000xxx` | Day of week 1–7 (1 = Sunday … 7 = Saturday) |
| `0x04` | DATE | R/W | `00xxxxxx` | Tens of date (5:4), date (3:0), BCD |
| `0x05` | MONTH | R/W | `000xxxxx` | Tens of month (4), month (3:0), BCD |
| `0x06` | YEARS | R/W | `xxxxxxxx` | Tens of years (7:4), years (3:0), BCD |
| `0x07` | CAL_CFG1 | R/W | `0x80` | OUT (7), FT (6), S (5), CAL[4:0] |
| `0x08` | TCH2 | R/W | `0x90` | Trickle-charge switch 2 (bit 5); other bits reserved (keep the read values) |
| `0x09` | CFG2 | R/W | `0xAA` | TCFE (bit 6), TCHE[3:0] (bits 3:0); other bits reserved |
| `0x20` | SF KEY 1 | R/W | `0x00` | Special function key 1 (write `0x5E`) |
| `0x21` | SF KEY 2 | R/W | `0x00` | Special function key 2 (write `0xC7`) |
| `0x22` | SFR | R/W | `0x00` | Special function: FTF (bit 0) |

Unlisted addresses are reserved. Some bits are reset when the chip switches to the backup supply ("Cycle" row in the datasheet); `STOP`, the time-keeping bits and the calibration are unchanged (UC) by a switchover; `OF` is always set on the first power-up.

### Bit Fields

#### `SECONDS` (`0x00`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | STOP | `1` stops the oscillator; `0` = normal. Cleared on the first power application; to force-start the oscillator write 1 then 0 |
| 6:4, 3:0 | 10_SECOND, 1_SECOND | BCD seconds 00–59 |

#### `MINUTES` (`0x01`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | OF | Oscillator-fail flag: latched when at least four consecutive oscillator pulses dropped; **always set on the first power-up**; cleared through the serial interface by writing 0 |
| 6:4, 3:0 | 10_MINUTE, 1_MINUTE | BCD minutes 00–59 |

#### `CENT_HOURS` (`0x02`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | CENT_EN | `1` = century tracking enabled |
| 6 | CENT | Century bit, toggled by the clock when the year rolls 99 → 00 (the meaning is user-defined) |
| 5:4, 3:0 | 10_HOUR, 1_HOUR | BCD hours 00–23 (24-hour format only) |

#### `CAL_CFG1` (`0x07`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | OUT | IRQ level when FT = 0 (`1` default) |
| 6 | FT | `1` = IRQ outputs the test square wave (512 Hz, or 1 Hz when `SFR.FTF` = 1) |
| 5 | S | Calibration sign: `0` = slow the RTC (positive ppm in the table), `1` = speed it up |
| 4:0 | CAL | Calibration step 0–31: `S = 0`: `+N / 491520` per minute (≈ 2.03 ppm per step; 30 → +61, 31 → +63 ppm); `S = 1`: `−N / 245760` per minute (≈ 4.07 ppm per step; 1 → −4, 30 → −122, 31 → −126 ppm) |

IRQ function (datasheet Table 6-1): `FT = 1, FTF = 1` → 1 Hz; `FT = 1, FTF = 0` → 512 Hz; `FT = 0` → the `OUT` level.

#### `TCH2` (`0x08`) and `CFG2` (`0x09`) — trickle charger

`TCH2` bit 5: `1` closes trickle-charge switch 2. `CFG2` bit 6 `TCFE` `1` closes the FET bypass switch; `CFG2` bits 3:0 `TCHE` = `0x5` activates the charger (any other value = inactive; reset `0xA`). Charging needs **all** switches closed: `TCHE = 0x5` and `TCH2 = 1` (and `TCFE` per the datasheet's charge-voltage selection). All switches open at power-up and after each switch from main to backup supply. The charger is meant for supercaps; do not use it with a primary (non-rechargeable) cell, and follow the charging limits of a rechargeable battery.

#### `SFR` (`0x22`)

Bit 0 `FTF`: `1` forces the calibration test output to 1 Hz (and the 1 Hz output tracks the programmed ppm adjustment); default 0 = 512 Hz (which does **not** include the ppm adjustment). Access needs the key sequence: write `0x5E` to `0x20`, then `0xC7` to `0x21`, then the SFR value to `0x22` — **every** SFR write must be preceded by the two key writes.

## Initialization Sequence

1. Apply VCC. On the first power-up: `OF` = 1, `STOP` = 0, the time registers are undefined; `OUT` = 1, `FT` = 0.
2. If `OF` is set (first power-up or oscillator interruption) the time is invalid: set it with `set_datetime` and clear `OF` (write 0 to `MINUTES` bit 7 as part of the time write).
3. To make sure the oscillator runs on first use, write `STOP` = 1 then 0 once (only needed after the very first power application).
4. For minimal backup current, power VCC with 3–3.6 V for ≥ 1 ms immediately after the backup supply is connected (datasheet §8.2.2.3).
5. After the supply returns from VBACK wait > 1 s before trusting the time registers, and ≥ 60 µs before the first I²C access.

## Implementation Stages

### Minimal

Goal: read and set the clock; no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection | — | Reads the clock registers to confirm the chip answers; no writes |
| `get_datetime` | — | `(year, month, day, weekday, hour, minute, second)` | `year` 2000–2099 (century bit ignored), `hour` 0–23, `weekday` 0–6 with Sunday = 0 (register 1–7 minus 1); returns the registers as read; use `oscillator_failed()` to check validity |
| `set_datetime` | `year, month, day, weekday, hour, minute, second` | — | Writes all seven BCD registers in one transaction starting at `0x00` with `STOP` = 0 and `OF` = 0 (clears the oscillator-fail flag), `CENT_EN` = 0; `weekday` 0–6 stored as 1–7 |

**Sensible defaults:** 24-hour format (the only one), century tracking off, calibration and trickle charger untouched (power-on state: charger off), IRQ left at its power-up state (output level high).

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `oscillator_failed` | — | bool | `MINUTES.OF` |
| `clear_oscillator_fail` | — | — | Read-modify-write clearing `OF` |
| `stop_oscillator` | — | — | `STOP` ← 1 (read-modify-write on `SECONDS`) |
| `start_oscillator` | — | — | `STOP` ← 0 |
| `set_century` | `enable: bool`, `century: int = 0` | — | `CENT_EN` and `CENT` bits |
| `get_century` | — | `(enabled, century_bit)` | |
| `set_calibration` | `ppm: float` | — | Chooses sign and `CAL` (0–31) for the nearest achievable adjustment in −126…+63 ppm (positive slows the RTC, per the datasheet table); raises outside the range |
| `get_calibration` | — | float | Current adjustment in ppm |
| `set_irq` | `level: bool` | — | `FT` ← 0, `OUT` ← level |
| `set_calibration_output` | `hz: int \| None` (512, 1, or `None` for off) | — | `FT` and (through the SF key sequence) `SFR.FTF`; `None` returns IRQ to the `OUT` level |
| `enable_trickle_charge` | `fet_bypass: bool = False` | — | `CFG2.TCHE` ← `0x5`, `TCFE`, `TCH2` ← 1 — **only with a supercap or a suitable rechargeable cell** |
| `disable_trickle_charge` | — | — | `TCHE` ← `0xA` (inactive), `TCH2` ← 0, `TCFE` ← 0 |
| `read_register` / `write_register` | `reg: int`, `value: int` | int / — | Raw access to `0x00`–`0x09` (the SF registers only through the key sequence); reserved bits are preserved on `write_register` of `0x08`/`0x09` |

**Additional configuration options:** oscillator stop/start, oscillator-fail flag, century bit, ppm calibration, IRQ output/test signal, trickle charger.

## Data Conversion

```
BCD: value = (reg >> 4) * 10 + (reg & 0x0F);   reg = ((value // 10) << 4) | (value % 10)

seconds = BCD(SECONDS & 0x7F)      minutes = BCD(MINUTES & 0x7F)      hours = BCD(CENT_HOURS & 0x3F)
weekday = (DAY & 0x07) - 1         date = BCD(DATE & 0x3F)            month = BCD(MONTH & 0x1F)
year    = 2000 + BCD(YEARS)        (century bit not used)

calibration (ppm):  S = 0 : +CAL * (1e6 / 491520) = +2.0345 * CAL   (slows the RTC)
                    S = 1 : -CAL * (1e6 / 245760) = -4.0690 * CAL   (speeds the RTC)
CAL_CFG1 = OUT<<7 | FT<<6 | S<<5 | CAL
```

Leap years: every year divisible by 4 is treated as a leap year (correct 2000–2099).

## Examples

### Demo

**Backup clock.** With the Full driver, print `oscillator_failed()`; if set (first power-up) set the clock from the host time; then print the time once per second for 10 s, adjust the calibration with `set_calibration(+12.2)` and read it back, output the 1 Hz calibration signal on IRQ for 5 s (`set_calibration_output(1)`) then turn it off, and show that the clock keeps running on VBACK (documented manual step: disconnect VCC briefly). Trickle charging is only enabled when run with an explicit `--supercap` flag.

## Timing Constraints

- **Backup switchover:** the time-keeping registers need up to 1 s to update after the chip returns to the main supply; wait > 1 s after VCC > 2.8 V and VBACK before reading, else the read returns the time at which backup mode was entered.
- **Post-backup I²C wait:** the host must wait ≥ 60 µs after the RTC exits backup mode before I²C access; registers `0x00`–`0x09` are inaccessible while VCC < VREF (≈ 2.8 V).
- **Backup initialization:** to achieve the specified low backup current, apply VCC (3–3.6 V) for at least 1 ms right after the backup supply is connected after a total power loss.
- **Calibration effect:** observable on the 1 Hz output only every 8 or 16 minutes (the calibration adjusts the pulse width periodically); the 512 Hz output excludes the ppm adjustment.
- **I²C:** 100 kHz / 400 kHz — clock-rate properties, not event-to-event delays.
- **Conformance:** none of these has a bus-decodable start/end annotation pair, so `specs/rtc/bq32000_timing.conf` defines no checks.

## Implementation Notes

- **RegisterConnection:** accept `RegisterConnection` (1-byte address); `connection.read(0x00, 7)` for the time block and `connection.write(0x00, bytes)` for a full set; no chip-local `_read_reg`/`_write_reg`, no `bus_type` branch (see `specs/feature_register_access_design.md`).
- **OF flag at power-up:** always set after the first power-up and cleared only by writing 0 to bit 7 of `MINUTES`; `set_datetime` writes it as 0, so a successful set also clears the flag.
- **Backup mode blocks the bus:** registers `0x00`–`0x09` cannot be accessed while the chip runs from VBACK; reads then fail (NACK) — treat as "no data", not as a chip error.
- **Reserved bits:** keep reserved bits at 0 when writing the time registers; for `TCH2` (reset `0x90`) and `CFG2` (reset `0xAA`) the reserved bits reset to 1 — use read-modify-write so they are preserved.
- **IRQ is not an interrupt:** there are no alarms or timers; use the DS3231/PCF8523-type chips for alarms. The IRQ pull-up must go to VCC.
- **SFR access:** the two keys must be written (in order) before every SFR write; use them only for the 1 Hz calibration output.
- **Calibration sign:** the datasheet labels `S = 0` "slowing (+)" and `S = 1` "speeding (−)"; the ppm values in the table are the correction applied; verify the direction against a frequency counter on the 512 Hz/1 Hz output when calibrating.
- **Trickle charge** applies to supercaps; with a coin cell leave it off (the default after power-on).
- **Leap years:** divisible-by-4 rule; 2100 would be wrongly treated as a leap year.
- **Address overlap:** `0x68` is shared with the DS3231, PCF8523 and PCF85063A (all register-pointer chips with no ID register); a wrong-chip access returns meaningless data.
- **Datasheet:** SLUS900F, downloaded from `https://www.ti.com/lit/ds/symlink/bq32000.pdf`.

## Sigrok Decoder

Decoder id `bq32000`, input `['i2c']`. Matches I²C address `0x68`. Annotates register writes and pointer-set + read transactions by register name and decodes the BCD time/date as `YYYY-MM-DD hh:mm:ss`, STOP / OF / CENT_EN / CENT, CAL_CFG1 (OUT, FT, S, CAL with the ppm value), TCH2 and CFG2 (trickle charger state), the SF key writes (`0x5E`/`0xC7`) and SFR (FTF); warns on SFR writes without the preceding key writes, on invalid BCD, and on accesses to reserved addresses. No timing annotation pair is emitted.
