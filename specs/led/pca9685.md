# Chip Spec: PCA9685

**Manufacturer:** NXP Semiconductors  
**Datasheet:** `datasheets/led/pca9685.pdf` (PCA9685, Rev. 4, 16 April 2015)  
**Category:** led  
**Transports:** I²C

## Overview

The PCA9685 is a 16-channel, 12-bit PWM LED/servo controller with a 1 MHz Fast-mode Plus I²C interface. Each output has its own 12-bit ON and OFF counter compare value (0–4095), so both the duty cycle and the phase delay of every channel are programmable; the common PWM frequency (24 Hz to 1526 Hz with the internal 25 MHz oscillator, up to a 50 MHz EXTCLK input) is set by one prescaler. The outputs are push-pull (or open-drain) and run autonomously once programmed: the host only writes new compare values. Typical uses: RGB/LED dimming, LED matrices, hobby-servo and ESC control (50 Hz, 1–2 ms pulses), fan and motor-speed PWM. Supply 2.3–5.5 V; outputs and inputs tolerate 5 V.

## Transport Configuration

### I²C
- **Address:** `0x40`–`0x7F` (7-bit `1 A5 A4 A3 A2 A1 A0`, six address pins, 64 addresses; `0x40` with all pins low). The addresses `0x70` (the default LED All Call address `0xE0 >> 1`) and `0x78`–`0x7F` (reserved) must not be used as the chip address
- **Further addresses (programmable, volatile):** LED All Call `0x70` (`ALLCALLADR` `0xE0`, enabled at power-up), LED Sub Call 1–3 `0x71`, `0x72`, `0x74` (`SUBADR1..3` = `0xE2`, `0xE4`, `0xE8`, disabled at power-up); Software Reset: the general call address `0x00` (R/W = 0) followed by the data byte `0x06` (see Implementation Notes)
- **Max clock:** 1 MHz (Fast-mode Plus); 400 kHz and 100 kHz also supported
- **Register addressing:** 8-bit register address (control register), `MODE1.AI` selects auto-increment; with `AI = 1` a multi-byte write or read walks through consecutive registers (rolls over after `0xFE` to `0x00`; `0xFA`–`0xFE` are contiguous)
- **Identity register:** none; the chip has no ID register (`id_probe: null` in `registry/chips.json`). `MODE1` resets to `0x11` and `MODE2` to `0x04`, which is a weak sanity check only
- **Probe safety:** `register_pointer` — a 1-byte write only loads the control register (pointer)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| OE | low | output enable; high = outputs disabled (state set by `MODE2.OUTNE`); drive low or tie to GND to enable; pins can be wired together for synchronous blanking and used for PWM-dimming of all channels |
| EXTCLK | — | external clock input (DC–50 MHz), only used after the sticky `MODE1.EXTCLK` switch; tie to GND when unused |
| A0–A5 | — | address select (see above) |
| LED0–LED15 | — | PWM outputs, push-pull (`MODE2.OUTDRV = 1`, default) or open-drain |
| SDA, SCL | — | I²C; pull-ups required |
| VDD, VSS | — | 2.3–5.5 V |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | MODE1 | R/W | `0x11` | Mode register 1 |
| `0x01` | MODE2 | R/W | `0x04` | Mode register 2 |
| `0x02` | SUBADR1 | R/W | `0xE2` | I²C sub address 1 (7-bit address in bits 7:1) |
| `0x03` | SUBADR2 | R/W | `0xE4` | I²C sub address 2 |
| `0x04` | SUBADR3 | R/W | `0xE8` | I²C sub address 3 |
| `0x05` | ALLCALLADR | R/W | `0xE0` | LED All Call I²C address |
| `0x06 + 4n` | LEDn_ON_L | R/W | `0x00` | LEDn ON count, low byte (n = 0…15) |
| `0x07 + 4n` | LEDn_ON_H | R/W | `0x00` | bit 4 = full ON; bits 3:0 = ON count bits 11:8 |
| `0x08 + 4n` | LEDn_OFF_L | R/W | `0x00` | LEDn OFF count, low byte |
| `0x09 + 4n` | LEDn_OFF_H | R/W | `0x10` | bit 4 = full OFF (wins over full ON); bits 3:0 = OFF count bits 11:8 |
| `0xFA` | ALL_LED_ON_L | W | `0x00` | ON count low byte for all 16 channels (write only) |
| `0xFB` | ALL_LED_ON_H | W | `0x00` | bit 4 = all full ON; bits 3:0 = ON count bits 11:8 |
| `0xFC` | ALL_LED_OFF_L | W | `0x00` | OFF count low byte for all channels |
| `0xFD` | ALL_LED_OFF_H | W | `0x10` | bit 4 = all full OFF; bits 3:0 = OFF count bits 11:8 |
| `0xFE` | PRE_SCALE | R/W | `0x1E` | PWM frequency prescaler (200 Hz at 25 MHz); minimum written value 3; writable only while `MODE1.SLEEP = 1` |
| `0xFF` | TestMode | — | — | reserved, do not write |

LED0 occupies `0x06`–`0x09`, LED15 `0x42`–`0x45`. All LED registers power up with ON = 0 and OFF = 0 plus full-OFF set, i.e. all outputs off.

### Bit Fields

#### `MODE1` (`0x00`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | RESTART | read: restart logic state (1 = a restart is possible); write 1 to clear it and restart the PWM channels (sleep bit must have been 0 for ≥ 500 µs) |
| 6 | EXTCLK | 1 = use the EXTCLK pin as clock; **sticky** — only cleared by power cycle or software reset. Set by first writing `SLEEP = 1`, then writing `SLEEP = 1` and `EXTCLK = 1` together |
| 5 | AI | register auto-increment (0 = off, default) |
| 4 | SLEEP | 1 = low-power mode, oscillator off (default); 0 = normal; the oscillator needs ≤ 500 µs to start |
| 3 | SUB1 | respond to sub address 1 |
| 2 | SUB2 | respond to sub address 2 |
| 1 | SUB3 | respond to sub address 3 |
| 0 | ALLCALL | respond to the LED All Call address (default 1) |

#### `MODE2` (`0x01`)

| Bits | Name | Description |
|------|------|-------------|
| 7:5 | — | reserved (read 0) |
| 4 | INVRT | 1 = invert output logic (use without an external driver; applies when OE = 0) |
| 3 | OCH | 0 = outputs change on I²C STOP (default); 1 = change on ACK (all four registers of a channel must be written) |
| 2 | OUTDRV | 1 = totem-pole (default), 0 = open-drain |
| 1:0 | OUTNE | output state when OE = 1: `00` LEDn = 0 (default); `01` LEDn = 1 (OUTDRV = 1) or high-Z (OUTDRV = 0); `1x` high-Z |

## Initialization Sequence

1. Power up VDD (2.3–5.5 V); all outputs are off, `MODE1 = 0x11` (asleep, ALLCALL on), `PRE_SCALE = 0x1E`.
2. Optionally write the software-reset general call (`0x06` to `0x00`), wait for the oscillator and registers to settle (≥ 500 µs) — only possible with a connection to the general-call address.
3. Write `PRE_SCALE` (while `SLEEP = 1`) for the wanted frequency.
4. Write `MODE1` with `AI = 1`, `SLEEP = 0`, `ALLCALL = 0` (`0x20`), wait ≥ 500 µs for the oscillator.
5. Write the LED registers; to restart channels that were running before a sleep, set `RESTART` as described in the datasheet restart procedure.

## Implementation Stages

### Minimal

Goal: dim LEDs / drive servos on 16 channels with one call each, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Stores the register-addressed `Connection`; sets `PRE_SCALE` for 1 kHz (value 5), then `MODE1 = 0x20` (AI on, awake, ALLCALL off), waits 1 ms; all channels stay off |
| `set_duty` | `channel: int` (0–15), `duty: float` (0.0–1.0) | — | Duty cycle with ON = 0 and OFF = `round(duty × 4096)`; `duty = 0.0` writes full OFF, `1.0` writes full ON (no glitch pulses) |

**Sensible defaults:** 1 kHz PWM (suited to LED dimming), totem-pole outputs, not inverted, outputs change on STOP, auto-increment on, ALLCALL off.

### Full

Goal: complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `set_pwm` | `channel: int`, `on: int`, `off: int` (0–4095 each) | — | Writes the four channel registers in one auto-increment transaction (phase-shifted PWM); the datasheet forbids ON = OFF |
| `get_pwm` | `channel: int` | `(on, off)` | Reads the channel's compare values (without the full-ON/OFF flags) |
| `set_full_on` / `set_full_off` | `channel: int` | — | Sets the full-ON bit (OFF bit cleared) / full-OFF bit |
| `set_all_duty` | `duty: float` | — | `ALL_LED_*` registers: same duty on all 16 channels |
| `set_all_pwm` | `on: int`, `off: int` | — | Same ON/OFF counts on all channels |
| `set_frequency` | `hz: float`, `osc_hz: float = 25_000_000.0` | — | Computes `prescale = round(osc_hz / (4096 × hz)) − 1` (clamped 3–255), puts the chip to sleep, writes `PRE_SCALE`, wakes it and waits 500 µs; restarts running channels (restart procedure) |
| `get_frequency` | `osc_hz: float = 25_000_000.0` | float | `osc_hz / (4096 × (PRE_SCALE + 1))` in Hz |
| `set_pulse_width` | `channel: int`, `seconds: float` | — | Convenience for servos: duty = `seconds × frequency`; ON = 0, OFF = `round(seconds × frequency × 4096)` |
| `sleep` / `wake` | — | — | `MODE1.SLEEP = 1` / `0` (wake waits 500 µs and restarts previously running channels if `RESTART` is set) |
| `restart` | — | — | The datasheet restart sequence (read `MODE1`, clear `SLEEP`, wait 500 µs, write `RESTART`) |
| `set_output_mode` | `open_drain: bool = False`, `invert: bool = False`, `off_state: int = OFF_LOW` | — | `MODE2.OUTDRV`, `INVRT`, `OUTNE` (`OFF_LOW` = `0b00`, `OFF_HIGH_OR_HIGHZ` = `0b01`, `OFF_HIGHZ` = `0b10`) |
| `set_update_on_ack` | `enabled: bool` | — | `MODE2.OCH` |
| `use_external_clock` | — | — | The two-step sticky `EXTCLK` switch; irreversible until power cycle / software reset; use `get_frequency(osc_hz=<ext>)` / `set_frequency(hz, osc_hz=<ext>)` afterwards |
| `set_allcall` | `enabled: bool`, `address: int = 0x70` | — | `MODE1.ALLCALL`, `ALLCALLADR` |
| `set_subaddress` | `index: int` (1–3), `address: int`, `enabled: bool = True` | — | `SUBADRn` and `MODE1.SUBn` |
| `reset` | — | — | Returns the chip registers to power-on state by writing the documented defaults (`MODE1 = 0x11`, `MODE2 = 0x04`, `PRE_SCALE = 0x1E`, outputs off) — no software reset call |
| `software_reset` | `general_call: Connection` (static) | — | Writes `0x06` with a connection bound to address `0x00`; resets **every** PCA9685 on the bus |
| `read_mode` | — | `(mode1, mode2)` | Raw mode registers |

**Additional configuration options:** PWM frequency/oscillator, output driver type and inversion, OE-off state, update-on-ACK, sub/all-call addresses, external clock.

## Data Conversion

```
# channel registers (n = 0..15)
base = 0x06 + 4 * n
on_count  = ((ON_H  & 0x0F) << 8) | ON_L        # 0..4095
off_count = ((OFF_H & 0x0F) << 8) | OFF_L
full_on   = ON_H  & 0x10
full_off  = OFF_H & 0x10                         # wins over full_on

# output is high while  on_count <= counter < off_count  (wraps when off < on)
duty      = ((off_count - on_count) mod 4096) / 4096      # when neither full flag is set

# frequency
prescale  = round(osc_hz / (4096 * update_rate_hz)) - 1   # 3 .. 255
rate_hz   = osc_hz / (4096 * (prescale + 1))              # 1526 Hz (3) .. 24 Hz (255) at 25 MHz

# servo pulse (50 Hz = prescale 121 at 25 MHz)
off_count = round(pulse_s * rate_hz * 4096)               # 1.5 ms @ 50 Hz -> 307
```

Datasheet example: 200 Hz at 25 MHz → `round(25 MHz / (4096 × 200)) − 1 = 30 = 0x1E`. A 10 % delay and 20 % duty give ON = 409 (`0x199`) and OFF = 1228 (`0x4CC`). The internal oscillator is not precise; calibrate `osc_hz` against a measurement when exact servo timing matters.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Oscillator start after `SLEEP` cleared | ≤ 500 µs (PWM timing not guaranteed before) |
| `SLEEP` low before writing `RESTART` | ≥ 500 µs |
| `PRE_SCALE` writable | only while `SLEEP = 1` |
| I²C clock | ≤ 1 MHz |

There is no bus-decodable end-of-event (no status register or interrupt; the oscillator start time is a host wait), so `pca9685_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed connection:** accept `RegisterConnection` and use `read(reg, n)` / `write(reg, data)` directly with `AI = 1`; no chip-local helpers (see `specs/feature_register_access_design.md`). Write the four bytes of a channel in one transaction so ON and OFF always change together.
- **PRE_SCALE needs sleep:** the register can only be written while `SLEEP = 1`; the driver sets `SLEEP`, writes the prescaler, clears `SLEEP`, waits 500 µs and, if `RESTART` was set, writes it (datasheet restart procedure).
- **Full ON/OFF bits:** `duty = 0` and `duty = 1` use the full-OFF / full-ON bits; never program ON = OFF (not allowed). Full OFF has priority over full ON.
- **Update timing:** by default (`OCH = 0`) outputs change at the I²C STOP, which keeps several registers of one write atomic; use the ALL-call address to change several chips on one STOP.
- **Reset:** the Software Reset call (general call `0x00` with data `0x06`) resets every PCA9685 on the bus and is not ACKed with R/W = 1; it is not available on a connection bound to the chip address, so `reset` writes the defaults instead.
- **LED drive:** the totem-pole mode suits LEDs with a series resistor; use open-drain (`OUTDRV = 0`) for LEDs with integrated Zener diodes, and for external drivers (`INVRT` per the datasheet's external-driver table).
- **Frequency vs. resolution:** the 12-bit resolution holds at any frequency; the maximum is 1526 Hz (prescale 3). Hobby servos need 50 Hz (prescale 121); the pulse width then resolves about 4.9 µs per count.
- **Address overlap:** `0x40`–`0x6F` and `0x71`–`0x77` overlap many other chips (INA219, HTU21, SI7021, …); the chip has no ID register, so probe it only with `active=True`, and note that every PCA9685 also answers at `0x70` (all-call) and at the enabled sub addresses.
- **I²C note:** the bus must be released between writes with the "reserved" general-call / sub-call addresses; do not use `0x70` as a chip address.

## Sigrok Decoder

Decoder id `pca9685`, input `['i2c']`. Matches I²C addresses `0x40`–`0x77` (configurable) and the all-call / sub-call addresses. Annotates each register access with the register name, decodes `MODE1`/`MODE2` bit fields, per-channel ON/OFF counts with duty percentage (and the full ON/OFF flags), `PRE_SCALE` with the resulting frequency (25 MHz oscillator assumed, option to override), and the software-reset call; warns on ON = OFF, a `PRE_SCALE` write while awake, a PWM write within 500 µs after wake-up and a `RESTART` write within 500 µs of clearing `SLEEP`. No conformance annotation pair is emitted (no checked timing constraint).
