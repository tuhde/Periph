# Chip Spec: IS31FL3731

**Manufacturer:** Lumissil Microsystems (ISSI)  
**Datasheet:** `datasheets/led/is31fl3731.pdf` (IS31FL3731, Rev. G, 10/24/2024)  
**Category:** led  
**Transports:** I²C

## Overview

The IS31FL3731 is a 144-LED matrix driver (9 common lines CA1–CA9 / CB1–CB9 × 16 sink lines, "CharliePlex" wiring: matrix A and B halves of 8 LEDs per line) with per-LED 8-bit PWM (256 steps), per-LED on/off and blink control, and eight independent frames kept in on-chip SRAM. It runs in one of three display modes: **Picture** mode (show one chosen frame), **Auto Frame Play** mode (the chip plays up to 8 frames with a programmable delay, loop count and fade in/out "breathing" — an animation without host involvement) and **Audio Frame Play** mode (an audio input at the IN pin modulates the matrix). The LED current is set by an external resistor (`ILED = 64.7 / REXT`, 3.2 mA at 20 kΩ). A hardware shutdown pin (SDB) and a software shutdown bit cut the quiescent current; INTB signals the end of an auto-play movie. The register file is paged: a command register at `0xFD` selects frame page 1–8 or the function page (page 9). Typical uses: LED matrix displays (RGB/white 16×9 boards such as the Adafruit CharlieWing), indicators with animated patterns, audio-reactive lighting.

## Transport Configuration

### I²C
- **Address:** 7-bit `11101 AD AD`, selected by the AD pin: `0x74` (AD = GND), `0x75` (AD = SCL), `0x76` (AD = SDA), `0x77` (AD = VCC). Breakout boards typically default to `0x74`
- **Max clock:** 400 kHz
- **Register addressing:** 8-bit register address; auto-increment after each data byte (a block write fills consecutive registers within the page); the address pointer is not shared between pages — `0xFD` (Command Register) is reachable on every page and selects which page the other addresses refer to
- **Identity register:** none; the chip has no ID register (`id_probe: null` in `registry/chips.json`); the Command Register `0xFD` is the only register whose read-back (the selected page) is meaningful, and the driver does not use it for detection
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer; only writes carrying a data byte change state (a write of `0xFD` followed by a page number switches the page and does not change the display)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| SDB | low | hardware shutdown; pull low to shut the chip down (all LEDs off, registers lose data); tie to VCC (or drive high) for operation |
| INTB | low, open-drain | goes low when an auto-play movie ends (≥ 7 ms, then returns high by itself); requires an external pull-up |
| AD | — | I²C address select (GND, VCC, SCL or SDA) |
| R_EXT | — | 20 kΩ to GND sets the LED current: `ILED = 64.7 / REXT` (3.2 mA at 20 kΩ; REXT must be ≥ 18 kΩ) |
| IN, C_FILT | — | audio input and filter capacitor (Audio Frame Play / audio synchronization) |
| CA1–CA9, CB1–CB9 | — | LED matrix current output/input ports (matrix A and B) |
| VCC, GND | — | supply 2.7–5.5 V; thermal pad to GND |

## Register Map

The register file consists of the Command Register `0xFD`, eight identical **frame pages** (page `0x00`–`0x07`, "Frame 1"–"Frame 8") and one **function page** (page `0x0B`, "Page Nine"). Write `0xFD` ← page number first, then access the page's registers. Frame register contents are undefined at power-on and must be initialized.

### Command Register (all pages)

| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| `0xFD` | COMMAND | R/W | `0x00`–`0x07` select frame 1–8; `0x0B` selects the function page; others reserved |

### Frame page (frames 1–8, `0xFD` = `0x00`…`0x07`)

| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| `0x00`–`0x11` | LED control | R/W | On/off bit per LED (18 bytes: 2 per common line, A then B) |
| `0x12`–`0x23` | Blink control | R/W | Blink-enable bit per LED (same layout) |
| `0x24`–`0xB3` | PWM | R/W | 8-bit PWM per LED (144 bytes, 16 per common line) |

For LED `Cx-y` (common line `x` = 1…9, sink `y` = 1…16): LED control byte `0x00 + 2(x − 1) + (y − 1) / 8`, bit `(y − 1) mod 8`; blink byte `0x12 + 2(x − 1) + (y − 1) / 8`, same bit; PWM byte `0x24 + 16(x − 1) + (y − 1)`. The "A" half is `y` = 1…8, the "B" half `y` = 9…16.

### Function page (`0xFD` = `0x0B`)

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | CONFIG | R/W | `0x00` | Display mode and start frame |
| `0x01` | PICTURE | R/W | `0x00` | Frame shown in Picture mode |
| `0x02` | AUTOPLAY1 | R/W | `0x00` | Loop count and number of frames |
| `0x03` | AUTOPLAY2 | R/W | `0x00` | Frame delay time |
| `0x04` | — | R/W | — | Reserved (writable, no function; read data not assured) |
| `0x05` | DISPLAY | R/W | `0x00` | Intensity control and blink |
| `0x06` | AUDIO_SYNC | R/W | `0x00` | Audio synchronization enable |
| `0x07` | FRAME_STATE | R | — | Movie-finished flag and current frame |
| `0x08` | BREATH1 | R/W | `0x00` | Fade-out and fade-in time |
| `0x09` | BREATH2 | R/W | `0x00` | Breath enable and extinguish time |
| `0x0A` | SHUTDOWN | R/W | `0x00` | Software shutdown |
| `0x0B` | AGC | R/W | `0x00` | Audio gain and AGC |
| `0x0C` | AUDIO_RATE | R/W | `0x00` | Audio ADC sample rate |

### Bit Fields

#### `CONFIG` (function `0x00`)

| Bits | Name | Description |
|------|------|-------------|
| 4:3 | MODE | `00` Picture, `01` Auto Frame Play, `1x` Audio Frame Play |
| 2:0 | FS | first frame in Auto Frame Play (`000` = frame 1 … `111` = frame 8) |

#### `PICTURE` (function `0x01`)

| Bits | Name | Description |
|------|------|-------------|
| 2:0 | PFS | frame shown in Picture mode (`000` = frame 1 … `111` = frame 8) |

#### `AUTOPLAY1` (function `0x02`)

| Bits | Name | Description |
|------|------|-------------|
| 6:4 | CNS | loops: `000` endless, `001`–`111` = 1–7 loops |
| 2:0 | FNS | frames played: `000` all, `001`–`111` = 1–7 frames |

#### `AUTOPLAY2` (function `0x03`)

| Bits | Name | Description |
|------|------|-------------|
| 5:0 | A | frame delay `FDT = 11 ms × A` (A = 1–63); `A = 0` → `11 ms × 64` |

#### `DISPLAY` (function `0x05`)

| Bits | Name | Description |
|------|------|-------------|
| 5 | IC | `1` = use frame 1's intensity (PWM) settings for all frames; `0` = each frame separately |
| 3 | BE | blink enable |
| 2:0 | BPT | blink period `0.27 s × A` (A = 0–7); duty cycle 50 % |

#### `AUDIO_SYNC` (function `0x06`)

| Bits | Name | Description |
|------|------|-------------|
| 0 | AE | `1` = audio input modulates the matrix intensity |

#### `FRAME_STATE` (function `0x07`, read-only)

| Bits | Name | Description |
|------|------|-------------|
| 4 | INT | `1` = movie finished (Auto Frame Play); cleared by reading this register; INTB pulses low at the same time |
| 2:0 | CFD | current frame being displayed (`000` = frame 1 … `111` = frame 8) |

#### `BREATH1` (function `0x08`)

| Bits | Name | Description |
|------|------|-------------|
| 6:4 | FOT | fade-out time `26 ms × 2^FOT` |
| 2:0 | FIT | fade-in time `26 ms × 2^FIT` |

#### `BREATH2` (function `0x09`)

| Bits | Name | Description |
|------|------|-------------|
| 4 | B_EN | breath function enable (Picture and Auto Frame Play modes) |
| 2:0 | ET | extinguish time `3.5 ms × 2^ET` |

#### `SHUTDOWN` (function `0x0A`)

| Bits | Name | Description |
|------|------|-------------|
| 0 | SSD | `0` = software shutdown (default), `1` = normal operation |

#### `AGC` (function `0x0B`)

| Bits | Name | Description |
|------|------|-------------|
| 4 | AGCM | `0` slow AGC, `1` fast AGC |
| 3 | AGC | AGC enable |
| 2:0 | AGS | audio gain: `000` 0 dB, `001` 3 dB … `111` 21 dB (3 dB steps) |

#### `AUDIO_RATE` (function `0x0C`)

| Bits | Name | Description |
|------|------|-------------|
| 7:0 | A | audio ADC sample interval `46 µs × A` (`A = 0` → `46 µs × 256`) |

## Initialization Sequence

1. Apply VCC (2.7–5.5 V) and drive SDB high (the chip is in software shutdown after power-up: `SHUTDOWN.SSD = 0`).
2. Select the function page (`0xFD` ← `0x0B`) and write `SHUTDOWN` ← `0x00` (shutdown) while configuring; write `CONFIG` ← `0x00` (Picture mode), `PICTURE` ← `0x00` (frame 1), `DISPLAY` ← `0x00`.
3. For each frame in use select the frame page (`0xFD` ← `0x00`…`0x07`), then write the 18 LED-control bytes (`0xFF` = all LEDs on) and clear the 18 blink bytes and the 144 PWM bytes to `0x00` (the frame registers are undefined at power-up). Write each in blocks (auto-increment) rather than per byte.
4. Select the function page and write `SHUTDOWN` ← `0x01` (normal operation).
5. Draw by writing PWM values (`0x24`–`0xB3`) of the frame shown (frame 1 in Picture mode).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `INTB` — active-low, open-drain; requires an external pull-up |
| Level | 1 (single fixed condition: Auto Frame Play movie finished) |
| Condition(s) | movie finished after the programmed loops/frames (`FRAME_STATE.INT` = 1); INTB pulses low for ≥ 7 ms and returns high by itself |
| Clear mechanism | read `FRAME_STATE` (function page `0x07`); the INT bit clears on read (the pin releases itself) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on INTB (falling edge) via `connection.int_pin` (or `int_pin`), otherwise a 50 ms polling task calling `poll_interrupt`; `callback(status)` receives `FRAME_STATE` (`INT` = `0x10`, `CFD` in bits 2:0) |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Switches to the function page, reads `FRAME_STATE` (clears `INT`), restores the previously selected page, returns the register value |

## Implementation Stages

### Minimal

Goal: light individual LEDs of the 9 × 16 matrix in Picture mode, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Runs the Initialization Sequence for frame 1: shutdown off, Picture mode with frame 1, all LED-control bits on, PWM and blink cleared |
| `set_pixel` | `row: int`, `col: int`, `brightness: int` | — | `row` 0–8 (common line `x − 1`), `col` 0–15 (sink `y − 1`), brightness 0–255 (PWM); raises on out-of-range |
| `clear` | — | — | All 144 PWM values of frame 1 to 0 (one block write) |
| `fill` | `brightness: int` | — | All PWM values of frame 1 (one block write) |

**Sensible defaults:** Picture mode, frame 1 displayed and drawn, all LEDs enabled in the LED-control registers (brightness by PWM only), no blink, no breath, audio sync off, REXT = 20 kΩ assumed (3.2 mA at full scale).

## Data Conversion

```
# LED Cx-y: x = row + 1 (1..9), y = col + 1 (1..16)
pwm_addr   = 0x24 + 16 * row + col
ctrl_addr  = 0x00 + 2 * row + col // 8     bit = col % 8
blink_addr = 0x12 + 2 * row + col // 8     bit = col % 8

# LED current (REXT = 20 kOhm -> ILED = 3.2 mA)
i_led_a      = 64.7 / r_ext_ohm / 1000
i_pixel_a    = i_led_a * pwm / 256          # PWM duty = pwm / 256

frame_delay_s  = 0.011 * (a if a else 64)
blink_period_s = 0.27 * bpt
fade_time_s    = 0.026 * 2 ** n             # FOT / FIT
extinguish_s   = 0.0035 * 2 ** n
audio_period_s = 46e-6 * (a if a else 256)
```

The datasheet recommends gamma-corrected PWM values for breathing effects (a 32-step table with the endpoints 0 and 255, or the recommended 64-step table); the driver exposes `GAMMA_32` / `GAMMA_64` tables as constants for convenience.

## Implementation Notes

- **Page select before every access:** the Command Register `0xFD` selects the page for all following register accesses, including reads. Cache the current page in the driver to avoid redundant writes, and restore it after function-page accesses (`poll_interrupt`, `shutdown`, …).
- **Initialize the frame registers:** the frame page contents are undefined at power-on and the LED-control bits default to off; `init` must write the LED-control bytes (`0xFF`) and clear PWM and blink bytes of every frame it uses. Unused frames are initialised by `clear_frame` / `clear_all_frames`.
- **Block writes:** the chip auto-increments the register pointer; use one block write per page area (`0x00`–`0x11`, `0x12`–`0x23`, `0x24`–`0xB3`). Some host I²C stacks limit transfers (e.g. 32 bytes on Arduino `Wire`); the driver splits at the transport limit.
- **Frame-register reads:** the datasheet states that frame registers can only be read in shutdown; drivers should not rely on read-back and keep a shadow copy of the frame being drawn.
- **Software shutdown retains the frame registers** (the matrix is off, the registers keep their data); SDB low (hardware shutdown) loses them and requires re-initialization.
- **`SSD` polarity:** `0` is shutdown, `1` normal operation (the opposite of what the name suggests).
- **Reserved function register `0x04`:** writable without effect; the driver never accesses it.
- **LED current:** set by REXT only (`64.7 / REXT`, REXT ≥ 18 kΩ); PWM scales it. The driver has no register for global current.
- **Matrix wiring:** the logical `(row, col)` order follows the datasheet's `Cx-y` numbering; the physical pixel position depends on the board. Boards like the Adafruit 16×9 CharlieWing re-map rows/columns — keep the board mapping in user code.
- **Audio modes:** the audio input (IN pin) needs the external AC-coupling and filter capacitor (C_FILT) described in the datasheet; without it the audio modes do nothing useful.
- **No identity register:** the chip cannot be told apart from other devices that ACK `0x74`–`0x77`; discovery only reports the address candidates.

## Sigrok Decoder

Decoder id `is31fl3731`, input `['i2c']`. Matches I²C addresses `0x74`–`0x77`. Tracks the selected page from writes to `0xFD` and annotates each access with the page and register name (LED control, blink, PWM per LED, function registers), decodes `CONFIG`, `PICTURE`, `AUTOPLAY1/2`, `DISPLAY`, `AUDIO_SYNC`, `FRAME_STATE`, `BREATH1/2`, `SHUTDOWN`, `AGC` and `AUDIO_RATE` into their fields (modes, frames, delays and times in ms/s, gains in dB), shows PWM block writes as pixel/value runs, and warns on writes to the reserved register `0x04`, unknown page numbers and frame-register writes while the function page is selected. No conformance annotation pair is emitted (no checked timing constraint).
