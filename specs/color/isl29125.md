# Chip Spec: ISL29125

**Manufacturer:** Renesas Electronics (Intersil)  
**Datasheet:** `datasheets/color/isl29125.pdf` (ISL29125 Digital Red, Green and Blue Color Light Sensor with IR Blocking Filter, FN8424 Rev. 3.00, Jan 13, 2017)  
**Category:** color  
**Transports:** I²C

## Overview

The ISL29125 is a low-power RGB colour light sensor with an on-chip IR-blocking filter, an integrating 12/16-bit ADC (the 100 ms, 16-bit conversion rejects 50/60 Hz flicker), two selectable sensing ranges (375 lux and 10 000 lux full scale), programmable active IR compensation, a programmable interrupt window with persistence on one selectable colour channel, and an `INT` pin that can also act as a conversion-start synchronisation input. It draws 56 µA operating and 0.5 µA in power-down, runs from 2.25–3.63 V (I²C bus 1.7–3.63 V) and talks I²C up to 400 kHz (SMBus compatible). Typical uses: display colour/brightness matching, white-balance, colour detection and sorting.

## Transport Configuration

### I²C
- **Address:** `0x44` (7-bit `1000100`, fixed)
- **Max clock:** 400 kHz
- **Identity register:** `0x00` (`DEVICE_ID`) = `0x7D`. Registered in `registry/chips.json`
- **Probe safety:** `register_pointer` — except that **writing** `0x46` to register `0x00` resets the chip; reads are safe (the status register `0x08` read clears the interrupt flag, so a probe reads only `0x00`)
- **Register addressing:** 8-bit register address, auto-increment on burst read/write, rolls over at the end of the register list

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| INT | low, open-drain | interrupt output (cleared by a status read) or, with `SYNC` = 1, a rising-edge conversion-start input |
| SCL, SDA | — | I²C, external pull-ups |
| VDD, GND | — | 2.25–3.63 V |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | DEVICE_ID | R/W | `0x7D` | Read: device ID; write `0x46`: reset all registers |
| `0x01` | CONFIG1 | R/W | `0x00` | Operating mode, range, resolution, sync |
| `0x02` | CONFIG2 | R/W | `0x00` | IR compensation |
| `0x03` | CONFIG3 | R/W | `0x00` | Interrupt channel, persistence, conversion-done interrupt |
| `0x04`–`0x05` | LOW_TH | R/W | `0x0000` | Low threshold (16 bit, LSB first) |
| `0x06`–`0x07` | HIGH_TH | R/W | `0xFFFF` | High threshold (16 bit, LSB first) |
| `0x08` | STATUS | R | `0x04` | Interrupt, conversion, brown-out and channel flags |
| `0x09`–`0x0A` | GREEN | R | `0x0000` | Green data, LSB first |
| `0x0B`–`0x0C` | RED | R | `0x0000` | Red data, LSB first |
| `0x0D`–`0x0E` | BLUE | R | `0x0000` | Blue data, LSB first |

### Bit Fields

#### `CONFIG1` (`0x01`)

| Bits | Name | Description |
|------|------|-------------|
| 5 | SYNC | 0 = ADC starts on the I²C write of this register, 1 = ADC starts on the rising edge of `INT` (INT is then an input) |
| 4 | BITS | 0 = 16-bit ADC, 1 = 12-bit ADC (shorter integration time) |
| 3 | RNG | 0 = 375 lux full scale, 1 = 10 000 lux full scale |
| 2:0 | MODE | `000` power-down, `001` green only, `010` red only, `011` blue only, `100` standby (no conversion), `101` green/red/blue, `110` green/red, `111` green/blue; all conversions are continuous |

#### `CONFIG2` (`0x02`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | IR_COM | IR compensation offset: 0 = codes 0–63, 1 = codes 106–169 |
| 5:0 | ALSCC | IR compensation adjust (code weights 32, 16, 8, 4, 2, 1); `0xBF` gives the maximum compensation (recommended for the 10 000 lux range) |

#### `CONFIG3` (`0x03`)

| Bits | Name | Description |
|------|------|-------------|
| 4 | CONVEN | 1 = `INT` also asserts when a conversion completes |
| 3:2 | PRST | Interrupt persistence: `00` 1, `01` 2, `10` 4, `11` 8 integration cycles |
| 1:0 | INTSEL | Interrupt channel: `00` none, `01` green, `10` red, `11` blue |

#### `STATUS` (`0x08`, read clears the flags)

| Bits | Name | Description |
|------|------|-------------|
| 5:4 | RGBCF | Channel under conversion: `00` none, `01` green, `10` red, `11` blue |
| 2 | BOUTF | 1 = power-down or brown-out occurred (1 after power-up; write 0 during initial configuration to clear) |
| 1 | CONVENF | 1 = conversion completed |
| 0 | RGBTHF | 1 = interrupt threshold window crossed |

## Initialization Sequence

1. Power VDD (2.25–3.63 V); the chip powers up in power-down/standby.
2. Read `DEVICE_ID` (`0x00`) and check `0x7D`; optionally write `0x46` to reset.
3. Write `STATUS` = 0x00 once to clear the brown-out flag (per the datasheet note).
4. Write `CONFIG1` (e.g. `0x0D` = RGB mode, 10 000 lux range, 16 bit), `CONFIG2` (IR compensation), `CONFIG3`.
5. Wait ≈ 101 ms per channel set (16 bit); read `GREEN`/`RED`/`BLUE` as one 6-byte burst from `0x09`.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | active-low, open-drain — requires external pull-up |
| Level | 2 |
| Condition(s) | the selected channel is at or below `LOW_TH` or at or above `HIGH_TH` for `PRST` cycles; optionally a completed conversion |
| Clear mechanism | read `STATUS` (`0x08`) |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_THRESHOLD` | `0x01` | Selected channel outside the threshold window (`RGBTHF`) |
| `SOURCE_CONVERSION` | `0x02` | Conversion complete (`CONVEN`/`CONVENF`) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback)` | Subscribe; callback receives the `STATUS` byte |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read `STATUS` (clears the flags) |
| `enable_interrupt` | `enable_interrupt(source)` | Threshold: `INTSEL` ≠ 0 (channel selected beforehand); conversion: `CONVEN` = 1 |
| `disable_interrupt` | `disable_interrupt(source)` | Threshold: `INTSEL` = 0; conversion: `CONVEN` = 0 |

### Status register bit layout

| Bit | Constant | Meaning |
|-----|----------|---------|
| 2 | `STATUS_BROWNOUT` | Brown-out/power-up |
| 1 | `SOURCE_CONVERSION` | Conversion complete |
| 0 | `SOURCE_THRESHOLD` | Threshold crossed |

## Implementation Stages

### Minimal

Goal: read red, green and blue with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Takes the `RegisterConnection`; checks `DEVICE_ID` = `0x7D`, clears the brown-out flag, starts continuous RGB conversion (16 bit, 10 000 lux range, maximum IR compensation `0xBF`) |
| `read` | — | `{red, green, blue}` | Waits for `CONVENF` (up to 400 ms), burst-reads `0x09`–`0x0E`, returns the three 16-bit counts |

**Sensible defaults:** `CONFIG1` = `0x0D`, `CONFIG2` = `0xBF`, `CONFIG3` = `0x00`, thresholds at their defaults.

## Data Conversion

```
count = low | high << 8                    # 16-bit (or 12-bit, D0..D11) unsigned
full_scale = 2**bits - 1
```

The datasheet gives sensitivities in counts per µW/cm² (proportional to the integration time) and no lux conversion; the 375/10 000 lux figures are the maximum allowable illuminance of each range. The driver reports counts; the XYZ transform is application specific (measure with the intended light sources, see the application-information section).

## Timing Constraints

| Constraint | Value |
|------------|-------|
| ADC integration/conversion time | typ. 101 ms (16-bit); shorter for 12-bit |
| I²C clock | ≤ 400 kHz |

The integration time is a setting-dependent figure; completion is marked only by `STATUS.CONVENF`, so `isl29125_timing.conf` defines no checks.

## Implementation Notes

- **RegisterConnection:** accept `RegisterConnection` and call `connection.read(reg, length)` / `connection.write(reg, data)` directly. See `specs/feature_register_access_design.md`.
- **Register 0x00 is dual-function:** a read returns the ID; a write of `0x46` resets. Never write other values.
- **Status read clears flags:** one read of `0x08` clears `RGBTHF`, `CONVENF` and the interrupt pin; the driver reads it once per poll and caches the byte.
- **Brown-out flag:** `BOUTF` is 1 after power-up; write 0 to `STATUS` during the first configuration.
- **Mode changes:** conversions are continuous; the first result after a mode, range or resolution change needs one full integration time (all channels are converted in sequence, so allow roughly three times the per-channel time in RGB mode).
- **IR compensation:** `CONFIG2` = `0xBF` (maximum) is recommended for the 10 000 lux range; tune it for the actual cover glass/light source.
- **Data register labels:** the datasheet's data table mislabels the blue registers as RED; `0x0D`/`0x0E` are blue.
- **Sync mode:** with `SYNC` = 1 the `INT` pin is an input and cannot signal interrupts.

## Sigrok Decoder

Decoder id `isl29125`, input `['i2c']`. Matches I²C address `0x44`. Annotates each register access, decodes `CONFIG1`–`CONFIG3`, thresholds, `STATUS` and the 16-bit green/red/blue values; warns on a write of a value other than `0x46` to `0x00`, on a mismatched `DEVICE_ID`, on a data read without `CONVENF`, and on a set `BOUTF` flag. No conformance annotation pair is emitted (no checked timing constraint).
