# Chip Spec: 23X1024

**Manufacturer:** Microchip Technology  
**Datasheet:** `datasheets/memory/23x1024.pdf` (DS20005142E, 23A1024/23LC1024)  
**Category:** memory  
**Transports:** SPI

## Overview

The 23X1024 (**23LC1024**, 2.5–5.5 V, and **23A1024**, 1.7–2.2 V — "23X1024" is Microchip's generic name; the two parts are identical apart from supply range) is a 1-Mbit (128 K × 8) serial SRAM on a plain SPI bus. It is volatile, but has unlimited read/write cycles and **zero write time**: data is committed as it is clocked in, so there is no page buffer to flush and no ACK/status polling. Typical uses: frame buffers, scratch/lookup-table storage and packet buffers for microcontrollers that are short on RAM. The chip also supports SDI (dual) and SQI (quad) bus modes; this spec covers **SPI mode only** (see Implementation Notes).

## Transport Configuration

### SPI
- **Mode:** CPOL=0 CPHA=0 (Mode 0) — SI is latched on the rising SCK edge, SO changes after the falling edge (datasheet §3.5)
- **Max clock:** 20 MHz (16 MHz for extended-temperature parts); no minimum
- **Bit order:** MSB first
- **CS active:** low
- **Register addressing:** none — the chip is not register-mapped. Every transaction is one instruction byte, then (for READ/WRITE) a 24-bit big-endian address (bits 23:17 are don't-care), then data; CS must stay low for the whole transaction. Does not fit the `read_bit`/`multi_byte_bit` convention of `specs/feature_register_access_design.md` §4, so the driver takes the bare `Connection` and uses `write` / `write_read` directly.

| Instruction | Code | Frame (after CS↓) |
|-------------|------|-------------------|
| `READ` | `0x03` | `0x03, A23..A16, A15..A8, A7..A0` → data bytes out on SO |
| `WRITE` | `0x02` | `0x02, A23..A16, A15..A8, A7..A0, data…` |
| `RDMR` | `0x05` | `0x05` → MODE register byte out on SO |
| `WRMR` | `0x01` | `0x01, MODE` |
| `EDIO` | `0x3B` | enter SDI mode — **not used** |
| `EQIO` | `0x38` | enter SQI mode — **not used** |
| `RSTIO` | `0xFF` | return to SPI mode from SDI/SQI |

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| CS | low | chip select; high = standby (SO high-Z) |
| SCK | — | clock |
| SI/SIO0 | — | data in |
| SO/SIO1 | — | data out |
| HOLD/SIO3 | low | pauses a transaction mid-way; **tie high** if unused (must not float) |
| SIO2 | — | SQI only; **do not float** in SPI mode — pull high (also lets the bus recover from an accidental EQIO) |

No interrupt pins.

## Memory Map

| Address Range | Name | R/W | Description |
|---------------|------|-----|-------------|
| `0x00000`–`0x1FFFF` | SRAM | R/W | 131,072 bytes = 4,096 pages × 32 bytes |

### Registers

#### `MODE` (read with `RDMR`, write with `WRMR`)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | MODE | `00` Byte, `10` Page, `01` Sequential (power-on default), `11` reserved |
| 5:0 | — | reserved, write 0 |

| Mode | Value | Behaviour |
|------|-------|-----------|
| Byte | `0x00` | each READ/WRITE transfers exactly one data byte |
| Page | `0x80` | data auto-increments within the 32-byte page and wraps to the page start |
| Sequential | `0x40` | auto-increments across the whole array, page boundaries ignored; wraps `0x1FFFF` → `0x00000` |

The chip has no ID register.

## Initialization Sequence

1. Power up (VCC 2.5–5.5 V for 23LC1024, 1.7–2.2 V for 23A1024). The datasheet gives no power-on delay; the chip is in standby and needs a CS high→low transition before the first command.
2. `WRMR` ← `0x40` (Sequential mode; this is also the power-on default, written explicitly for idempotency).
3. `RDMR` and check it returns `0x40`. A different value (typically `0x00` or `0xFF` from a floating/missing MISO) means wiring, SPI-mode or SDI/SQI-state problems — raise.

## Interrupt

Level 0 — the chip has no interrupt output.

## Implementation Stages

### Minimal

Goal: single-byte storage with no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Runs the initialization sequence (sets Sequential mode, verifies via `RDMR`); raises on mismatch |
| `read_byte` | `address: int` (0–131071) | `int` (0–255) | `READ`; raises on an out-of-range address |
| `write_byte` | `address: int`, `value: int` | — | `WRITE`; complete when CS is released — no polling |

**Sensible defaults:** Sequential mode; full 128 KiB addressable.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `read` | `address: int`, `length: int` | `bytes` | Block read; range `address`…`address + length` must lie inside `0x00000`–`0x1FFFF` (no silent wrap). Split into transactions of ≤ `max_chunk` data bytes and, in Page/Byte mode, at page/byte boundaries |
| `write` | `address: int`, `data: bytes` | — | Block write; same range and splitting rules |
| `fill` | `address: int`, `length: int`, `value: int=0` | — | Writes `value` over a range (chunked) |
| `size` | — | `int` | `131072` |
| `set_mode` | `mode: int` | — | `MODE_BYTE`=`0x00`, `MODE_PAGE`=`0x80`, `MODE_SEQUENTIAL`=`0x40`; `WRMR` then `RDMR` check; rejects `0xC0` and any other value; caches the mode for splitting |
| `get_mode` | — | `int` | `RDMR` (bits 7:6 only, as one of the `MODE_*` constants) |
| `reset_io` | — | — | Sends `RSTIO` (`0xFF`) to return the chip to SPI mode after a stray EDIO/EQIO or an MCU reset while in SDI/SQI mode |
| `max_chunk` | property, default 256 | `int` | Maximum data bytes per bus transaction; settable (1…256) |

**Additional configuration options:** operating mode (`set_mode`) and `max_chunk`. The 23A1024 vs 23LC1024 distinction is purely the supply voltage — no driver difference.

## Data Conversion

None; data is raw bytes. The 24-bit address is big-endian on the wire (`addr >> 16`, `addr >> 8`, `addr`, each masked to 8 bits). Bits 23:17 are don't-care; the driver always sends them as 0.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Write cycle time | none — zero write time; the next command may follow CS↑ after the CS disable time |
| Max SPI clock | 20 MHz (I-temp), 16 MHz (E-temp) |
| CS setup / hold / disable | ≥ 25 ns / ≥ 50 ns / ≥ 25 ns (I-temp; setup and disable 32 ns for E-temp) |
| Data retention voltage | ≥ 1.0 V (typ.) |
| Endurance | unlimited |

No timing constraint gets a conformance check (the absence of a write delay is not observable as a bound), so there is no `23x1024_timing.conf`.

## Implementation Notes

- **Bare `Connection`, SPI only:** use `connection.write(bytes([0x02, a2, a1, a0]) + data)` for writes and `connection.write_read(bytes([0x03, a2, a1, a0]), n)` for reads (see `specs/transport_spi.md`: the command bytes' MISO echo is discarded). Do not use `RegisterConnection`/`SPIConnection` read-bit logic — the instruction is not a register address. The SPI connection must run in Mode 0 and keep CS asserted across the whole frame (single `write`/`write_read` call).
- **Wrap-around is silent in hardware:** in Sequential mode an access past `0x1FFFF` continues at `0x00000`; in Page mode it wraps within the 32-byte page. The driver refuses out-of-array ranges and, in Page/Byte mode, splits transfers at page/byte boundaries so the caller's `read`/`write` always has linear-address semantics. The cached mode is tracked by the driver; if another master/host reset changed it, call `set_mode` to resync.
- **Chunking:** limit data bytes per transaction with `max_chunk` (default 256); each chunk is a fresh transaction with its own instruction and address bytes. Total frame = 4 + chunk bytes.
- **SDI/SQI not supported:** EDIO/EQIO need a 2- or 4-line bidirectional bus that no Periph transport provides. The driver never issues them. If the MCU resets while the SRAM is in SDI/SQI mode, `reset_io` (`0xFF`) restores SPI mode; per the datasheet, holding SIO2 high lets an SPI `0xFF` be recognised from SQI.
- **Fixed unused pins:** HOLD must be tied high (a floating HOLD pauses the device unpredictably) and SIO2 must not float. Hold function is unavailable in SQI mode.
- **No write protection, no ID:** there is no write-protect pin or register and no identity register, so `init`'s `WRMR`/`RDMR` round-trip is the only presence check. Volatile: contents are lost when VCC drops below ~1.0 V.
- **Family:** other Microchip serial SRAMs (23x512, 23x256, 23K640, …) differ in address width and page size; no compatibility is assumed beyond 23A1024/23LC1024.

## Sigrok Decoder

Decoder id `23x1024`, input `['spi']`. Annotates each CS-framed transaction: `READ`/`WRITE` (instruction, 24-bit address, data bytes with a length summary), `RDMR`/`WRMR` (MODE byte decoded into Byte/Page/Sequential, flagging the reserved `11` value and non-zero reserved bits), and `EDIO`/`EQIO`/`RSTIO` (flagged as informational since the decoder cannot follow the bus after a mode switch). Warns on address bits 23:17 set, and on a transaction whose data would cross the end of the array or — when the last `WRMR` seen was Page mode — a page boundary.
