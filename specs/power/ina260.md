# Chip Spec: INA260

**Manufacturer:** Texas Instruments  
**Datasheet:** `datasheets/power/ina260.pdf` (SBOS656C)  
**Category:** `power`  
**Transports:** I²C, SMBus

## Overview

The INA260 is a digital current, bus-voltage and power monitor with an **integrated precision 2 mΩ shunt** (4.5 mΩ total IN+ to IN− package resistance), 16-bit ADC, and an I²C/SMBus interface. It measures current up to ±15 A continuous, bus voltage 0–36 V, and an internal multiplier gives power. Unlike the INA226 it needs **no calibration register and no external shunt**: the current, bus-voltage and power registers have fixed LSBs (1.25 mA, 1.25 mV, 10 mW) and are directly readable. Programmable averaging (1–1024) and conversion times (140 µs – 8.244 ms) trade speed for noise; a single ALERT pin signals one programmable limit or conversion-ready. Supply 2.7–5.5 V, 16 addresses via A0/A1, TSSOP-16.

The register layout is the INA226's minus the Calibration register (`0x05`) and the shunt-voltage register (`0x01` is **current** here, `0x04` does not exist). The Configuration register reset value is `0x6127`. Driver implementations of the two chips are siblings, not parent/child.

- **Addresses:** `0x40`–`0x4F` (16 addresses, set by A0 and A1 pins; same table as the INA226/INA219)

| SCL | SCL | `0x4F`  |

- **Max clock:** 400 kHz (fast mode), 2.94 MHz (high-speed mode; the drivers use ≤ 400 kHz)
- **SMBus timeout:** 28 ms — the interface resets if SCL is held low longer than this
- **Identity register:** `0xFF` (2 bytes, big-endian), mask `0xFFF0`, expected `0x2270` (DID = `0x227`; the low nibble is the die revision); also `0xFE` = `0x5449` (Texas Instruments)
- **Probe safety:** `register_pointer` — a 1-byte write only selects the register pointer

All registers are 16-bit, big-endian (MSB first). Access is via a register pointer byte, so the drivers use `RegisterConnection` (`specs/feature_register_access_design.md`).

### Bit Fields

#### `Configuration` (`0x00`) — reset `0x6127`

| Bits  | Name   | Description |
|-------|--------|-------------|
| 15    | RST    | Write 1 to reset all registers to defaults; self-clears |
| 14:12 | —      | Reserved, read as `110` (always write `110`, i.e. keep bit 14 and 13 set) |
| 11:9  | AVG    | Averaging count |
| 8:6   | VBUSCT | Bus voltage conversion time |
| 5:3   | ISHCT  | Shunt current conversion time |
| 2:0   | MODE   | Operating mode |

**AVG:** `000` = 1 (default), `001` = 4, `010` = 16, `011` = 64, `100` = 128, `101` = 256, `110` = 512, `111` = 1024.

**VBUSCT / ISHCT** (same encoding): `000` = 140 µs, `001` = 204 µs, `010` = 332 µs, `011` = 588 µs, `100` = 1.1 ms (default), `101` = 2.116 ms, `110` = 4.156 ms, `111` = 8.244 ms (the datasheet gives a +10 % maximum for each, e.g. 1.21 ms for 1.1 ms).

**MODE:**

| Value | Mode |
|-------|------|
| 000, 100 | Power-down |
| 001 | Shunt current, triggered |
| 010 | Bus voltage, triggered |
| 011 | Shunt current and bus voltage, triggered |
| 101 | Shunt current, continuous |
| 110 | Bus voltage, continuous |
| 111 | Shunt current and bus voltage, continuous (default) |

Writing the Configuration register halts any conversion in progress and starts a new one with the new settings. It can be read at any time without disturbing a conversion.

#### `Current` (`0x01`)

Signed 16-bit two's complement, 1.25 mA/LSB; positive current flows IN+ → IN−. Averaged value if averaging is enabled. Range ±40.96 A in the register, ±15 A continuous by the package.

#### `Bus Voltage` (`0x02`)

Bit 15 always 0; 15-bit unsigned, 1.25 mV/LSB (full scale 40.96 V; the input is rated to 36 V).

#### `Power` (`0x03`)

Unsigned 16-bit, 10 mW/LSB; always positive regardless of current direction; maximum `0xA3D7` = 419.43 W; computed as `Current × Bus Voltage` (so it is correct only for the averaged/last converted pair).

#### `Mask/Enable` (`0x06`)

| Bit | Name | Description |
|-----|------|-------------|
| 15  | OCL  | Alert on over-current limit |
| 14  | UCL  | Alert on under-current limit |
| 13  | BOL  | Alert on bus over-voltage |
| 12  | BUL  | Alert on bus under-voltage |
| 11  | POL  | Alert on power over-limit |
| 10  | CNVR | Alert on conversion ready (can be combined with one limit function) |
| 4   | AFF  | Alert Function Flag (read-only) |
| 3   | CVRF | Conversion Ready Flag (read-only) |
| 2   | OVF  | Math overflow flag (read-only; power may exceed 419.43 W) |
| 1   | APOL | Alert polarity: 0 = active-low (default), 1 = active-high |
| 0   | LEN  | Alert latch: 0 = transparent (default), 1 = latch |

Only one limit function can be enabled; if several of bits 15:11 are set, the most significant one wins. CVRF clears on a write to the Configuration register (except power-down selection) and on a read of Mask/Enable. In latch mode AFF clears only when Mask/Enable is read; in transparent mode it clears after the next conversion that raises no alert.

#### `Alert Limit` (`0x07`)

Threshold compared against the selected function, in the register's own units: current (signed, 1.25 mA/LSB), bus voltage (1.25 mV/LSB) or power (10 mW/LSB).

## Initialization Sequence

1. At power-up the chip is in continuous current + bus-voltage mode, 1.1 ms conversion times, no averaging (`0x6127`); no calibration and no delay is required. The first conversion pair completes after ≈ 2.2 ms.
2. Minimal `init` therefore only stores the connection (optionally verifying `0xFE` = `0x5449`).
3. Full `configure` writes the Configuration register with the chosen averaging, conversion times and mode (bits 14:12 kept at `110`).
4. Optionally write Mask/Enable (`0x06`) and Alert Limit (`0x07`) — write the limit **first**, then Mask/Enable, so the new function never compares against a stale threshold.

## Implementation Stages

### Minimal

Goal: read bus voltage, current and power with no configuration beyond the connection — the shunt is integrated, so there is nothing to calibrate.

Constructor parameter: `connection` only.

**Baked-in defaults (chip power-on state, not rewritten):** MODE = `111` (continuous), VBUSCT = ISHCT = `100` (1.1 ms), AVG = `000` (no averaging).

| Operation        | Parameters | Returns | Notes |
|------------------|------------|---------|-------|
| `voltage()`      | —          | float   | Bus voltage in V (`raw × 1.25 mV`) |
| `current()`      | —          | float   | Current in A (signed, `raw × 1.25 mA`) |
| `power()`        | —          | float   | Power in W (`raw × 10 mW`) |

### Full

Extends Minimal. Adds full register access.

| Operation             | Parameters                              | Returns | Notes |
|-----------------------|-----------------------------------------|---------|-------|
| *(inherits Minimal)*  | | | |
| `configure()`         | `avg`, `vbus_ct`, `ish_ct`, `mode`      | —       | Write Configuration Register (bits 14:12 = `110`); constants below; stores the mode for `wake()` |
| `trigger()`           | `mode = MODE_SHUNT_BUS_TRIGGERED`       | —       | Start one triggered conversion with the current settings (rewrites Configuration) |
| `conversion_ready()`  | —                                       | bool    | Read CVRF (bit 3) from Mask/Enable — **clears CVRF** |
| `overflow()`          | —                                       | bool    | Read OVF (bit 2) from Mask/Enable |
| `set_alert()`         | `function`, `limit`, `polarity`, `latch`| —       | Write Alert Limit then Mask/Enable; `limit` in natural units (A, V or W) |
| `clear_alert()`       | —                                       | —       | Write Mask/Enable = 0 (no function enabled) |
| `alert_flags()`       | —                                       | int     | Read Mask/Enable (clears CVRF and, in latch mode, AFF) |
| `reset()`             | —                                       | —       | Set RST; chip returns to power-on defaults |
| `shutdown()`          | —                                       | —       | MODE = `000` (power-down) |
| `wake()`              | —                                       | —       | Restore the previous MODE (default `111`); allow 40 µs recovery |
| `manufacturer_id()`   | —                                       | int     | Read `0xFE`; expect `0x5449` |
| `die_id()`            | —                                       | int     | Read `0xFF`; `(value >> 4)` is `0x227`, low nibble the revision |

**Constants:** `AVG_1/4/16/64/128/256/512/1024` (0–7); `CT_140US … CT_8244US` (0–7); `MODE_POWER_DOWN` (0), `MODE_SHUNT_TRIGGERED` (1), `MODE_BUS_TRIGGERED` (2), `MODE_SHUNT_BUS_TRIGGERED` (3), `MODE_SHUNT_CONT` (5), `MODE_BUS_CONT` (6), `MODE_SHUNT_BUS_CONT` (7).

**Alert functions for `set_alert(function, ...)`:**

| Value | Function | `limit` unit |
|-------|----------|--------------|
| `OCL` | Over-current | A |
| `UCL` | Under-current | A |
| `BOL` | Bus over-voltage | V |
| `BUL` | Bus under-voltage | V |
| `POL` | Power over-limit | W |
| `CNVR`| Conversion ready | ignored (limit not written) |

## Data Conversion

```
current (A)  = raw_s16 × 1.25e-3        # signed 16-bit, positive = IN+ -> IN-
voltage (V)  = raw_u16 × 1.25e-3        # bit 15 is always 0
power   (W)  = raw_u16 × 10e-3          # unsigned; max 419.43 W

config word  = 0x6000 | (AVG << 9) | (VBUSCT << 6) | (ISHCT << 3) | MODE      # default 0x6127

# set_alert limit -> Alert Limit register
OCL/UCL : raw = round(limit_A / 1.25e-3)  (signed 16-bit)
BOL/BUL : raw = round(limit_V / 1.25e-3)
POL     : raw = round(limit_W / 10e-3)
```

Example from the datasheet: current `0x2710` = 10000 → 12.5 A; bus `0x2570` = 9584 → 11.98 V; power `0x3A7F` = 14975 → 149.75 W.

Total time for a fresh averaged sample set: `AVG × (VBUSCT + ISHCT)` in continuous shunt + bus mode (e.g. 1024 × 2 × 8.244 ms ≈ 16.9 s).

## Timing Constraints

- Conversion times per channel: 140 µs … 8.244 ms (max +10 %); the shunt and bus conversions run back-to-back, so one sample pair takes `VBUSCT + ISHCT` (2.2 ms at the default), multiplied by `AVG` when averaging.
- Recovery from power-down mode: 40 µs
- All registers are volatile — reprogrammed on every power-up
- Conversion Ready Flag (CVRF) clears on write to the Configuration Register or on read of Mask/Enable
- Conversion-ready latency at the default configuration (VBUSCT = ISHCT = `100` = 1.1 ms, shunt + bus continuous): CVRF sets within ≈ 2.2 ms (datasheet max 2.42 ms) of the Configuration Register write that cleared it. Conformance-checked as `conversion_ready` — see the `conversion_ready_start` / `conversion_ready_done` annotation pair in Sigrok Decoder below and `specs/power/ina260_timing.conf`.
- I²C: fast mode 400 kHz, high-speed 2.94 MHz — clock-rate properties, not event-to-event delays.

## Implementation Notes

- **No calibration:** unlike the INA226 there is no Calibration register; Current and Power are valid immediately after power-up and are **not** scaled by the driver. Do not port INA226's `r_shunt`/`max_current` parameters.
- **Register numbers differ from the INA226:** `0x01` is Current (INA226: shunt voltage), `0x03` is Power and there is no `0x04` / `0x05`.
- **Reserved config bits:** bits 14:12 reset to `110` and must be written as `110` (`0x6000` base) — writing zeros is undefined per the datasheet; `RST` is bit 15.
- **Sign:** Current is two's complement; Power and Bus Voltage are unsigned. Negative current means flow from IN− to IN+.
- **Current range:** ±15 A continuous with 1-oz copper planes (the register could represent ±40.96 A); transient overloads beyond the continuous rating do not damage the shunt (see datasheet §8.3.4) but self-heating shifts accuracy.
- **Bus voltage:** measured at the VBUS pin; with VBUS tied to IN+ it is the supply side of the shunt; the input range is 0–36 V while the register spans to 40.96 V.
- **One alert function at a time**; if several of bits 15:11 are set the MSB takes priority; CNVR can be combined with one function — read Mask/Enable afterwards to tell AFF from CVRF. Reading Mask/Enable clears CVRF, so read it last when checking several flags.
- **Triggered modes:** each Configuration write (with a triggered mode) starts one conversion; poll CVRF (or ALERT with CNVR) for completion.
- **Probe group:** shares the `0xFF` (2-byte) identity register with the INA226 (`0x2260`) and INA3221; the masked value `0x227x` uniquely identifies the INA260.
- **Datasheet:** SBOS656C, downloaded from `https://www.ti.com/lit/ds/symlink/ina260.pdf`.

## Sigrok Decoder

Decoder id `ina260`, input `['i2c']`. Matches addresses `0x40`–`0x4F`. Annotates pointer-write (register selection), register writes and register reads. Named registers: Configuration (AVG, VBUSCT, ISHCT, MODE decoded as strings), Current (signed mA), Bus Voltage (mV), Power (mW), Mask/Enable (all alert-enable bits and flag bits decoded by name, polarity and latch mode), Alert Limit, Manufacturer ID (verified against `0x5449`) and Die ID (DID verified against `0x227`, revision shown).

For the `conversion_ready` conformance check (see Timing Constraints above), the decoder additionally emits a named `conversion_ready_start` annotation on every Configuration Register write, and a `conversion_ready_done` annotation on the first subsequent Mask/Enable read whose CVRF bit (bit 3) is set, both in the `timing` annotation row (variable-length strings per `specs/sigrok_annotations.md`) — additive to the generic reg-write/reg-read annotations above.
