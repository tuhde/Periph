# Chip Spec: MAX17048

**Manufacturer:** Maxim Integrated (Analog Devices)  
**Datasheet:** `datasheets/power/max17048.pdf` (MAX17048/MAX17049, Rev. 3)  
**Category:** power  
**Transports:** I²C

## Overview

The MAX17048 (1-cell, voltage measured at VDD) and MAX17049 (2-cell, voltage measured at the CELL pin) are ultra-low-power lithium fuel gauges using the ModelGauge algorithm: the state of charge is estimated from the cell voltage alone, with no sense resistor and no learning cycle. The chip reports the cell voltage (12-bit ADC, 78.125 µV/cell LSb), the state of charge in 1/256 % steps, and an approximate charge/discharge rate in %/h. It draws 23 µA active and 3 µA in hibernate (entered automatically when the battery is idle), < 1 µA in sleep. Five alert conditions (low SOC, 1 % SOC change, voltage reset, over-voltage, under-voltage) drive the open-drain ALRT pin. A quick-start command re-estimates the SOC from the present voltage; a power-on-reset command reboots the chip. One driver serves both parts (`cells` = 1 or 2). Typical uses: portable and wearable devices, IoT sensors, battery-powered gadgets with a single Li-ion/LiPo cell.

## Transport Configuration

### I²C
- **Address:** `0x36` (7-bit, fixed; the datasheet gives the 8-bit write address `0x6C` / read `0x6D`); one chip per bus
- **Max clock:** 400 kHz. The bus must not be held low (SDA and SCL both) for longer than tSLEEP = 1.75–2.5 s when sleep mode is enabled, otherwise the chip sleeps
- **Register addressing:** 8-bit register address; all registers are **16-bit words**, big-endian (MSB at the even address, then the LSB); 8-bit writes have no effect, so always write both bytes. A read of two bytes returns the register at the pointer; the pointer auto-increments
- **Identity register:** `VERSION` (`0x08`) = `0x001x` (the low nibble varies by production version); registered in `registry/chips.json` as `id_probe` register `0x08` (`reg_bytes` 1, `length` 2, mask `0xFFF0`, expected `0x0010`). The address `0x36` is shared with the AS5600 magnetic encoder, whose register layout is unrelated; `VERSION` is the only separating check
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer; only a complete 16-bit write changes a register (writes to `0xFE` reset the chip)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| ALRT | low, open-drain | alert output; requires an external pull-up (about 10 kΩ); asserted while `CONFIG.ALRT = 1`; cleared by software |
| QSTRT | high | quick-start input; a rising edge restarts the SOC calculation (same as `MODE.QuickStart`); tie to GND if unused |
| CELL | — | MAX17049 only: positive pack terminal for the 2-cell voltage measurement (tie to the pack) |
| VDD | — | MAX17048: measured cell voltage 2.5–4.5 V (the supply is the battery); MAX17049: 2.5–5.5 V system supply |
| SDA, SCL | — | I²C; pull-ups required |

## Register Map

All registers are 16-bit big-endian words.

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x02` | VCELL | R | — | Cell voltage, 78.125 µV/LSb per cell (12-bit result in bits 15:4) |
| `0x04` | SOC | R | — | State of charge, 1 %/256 (high byte = 1 %) |
| `0x06` | MODE | W | `0x0000` | Quick-start, hibernate status, sleep enable |
| `0x08` | VERSION | R | `0x001x` | Production version |
| `0x0A` | HIBRT | R/W | `0x8030` | Hibernate thresholds |
| `0x0C` | CONFIG | R/W | `0x971C` | RCOMP, sleep, alert settings |
| `0x14` | VALRT | R/W | `0x00FF` | Voltage alert window (MIN high byte, MAX low byte), 20 mV/LSb |
| `0x16` | CRATE | R | — | Charge/discharge rate, 0.208 %/h per LSb (signed) |
| `0x18` | VRESET/ID | R/W | `0x96xx` | Reset voltage (40 mV/LSb in bits 15:9), comparator disable (bit 8), ID (bits 7:0, read only) |
| `0x1A` | STATUS | R/W | `0x01xx` | Alert status flags |
| `0x40`–`0x7F` | TABLE | W | — | Battery model; the default suits many Li-ion cells; not exposed by the driver |
| `0xFE` | CMD | R/W | `0xFFFF` | `0x5400` = power-on reset |

### Bit Fields

#### `MODE` (`0x06`, write-only)

| Bits | Name | Description |
|------|------|-------------|
| 14 | QUICKSTART | write 1 to restart the SOC estimate from the present voltage (use sparingly) |
| 13 | ENSLEEP | write 1 to enable sleep mode (entered with `CONFIG.SLEEP` or by holding the bus low) |
| 12 | HIBSTAT | hibernate status flag (read only; the datasheet lists the register as write-only, so the value read back is not guaranteed) |

#### `HIBRT` (`0x0A`)

| Bits | Name | Description |
|------|------|-------------|
| 15:8 | HIBTHR | hibernate threshold: hibernate when \|CRATE\| < HIBTHR × 0.208 %/h for more than 6 min (default `0x80` = 26.6 %/h) |
| 7:0 | ACTTHR | active threshold: leave hibernate when \|OCV − VCELL\| > ACTTHR × 1.25 mV (default `0x30` = 60 mV) |

`0x0000` disables hibernate mode, `0xFFFF` keeps the chip always in hibernate.

#### `CONFIG` (`0x0C`)

| Bits | Name | Description |
|------|------|-------------|
| 15:8 | RCOMP | compensation value, default `0x97`; `RCOMP = RCOMP0 + (T − 20) × TempCoUp` (T ≥ 20 °C, default TempCoUp −0.5) or `RCOMP0 + (T − 20) × TempCoDown` (T < 20 °C, default TempCoDown −5.0); cells with another chemistry need a vendor-specific value |
| 7 | SLEEP | `1` = enter sleep, `0` = exit sleep (only if `MODE.EnSleep = 1`) |
| 6 | ALSC | `1` = alert on a SOC change of at least 1 % |
| 5 | ALRT | alert flag: set by the chip when an alert occurs (ALRT pin low); write 0 to clear |
| 4:0 | ATHD | empty-alert threshold: `(32 − ATHD) %`, default `0x1C` = 4 % |

#### `VALRT` (`0x14`)

| Bits | Name | Description |
|------|------|-------------|
| 15:8 | MIN | under-voltage threshold, 20 mV/LSb (default `0x00` = disabled) |
| 7:0 | MAX | over-voltage threshold, 20 mV/LSb (default `0xFF` = disabled) |

#### `VRESET/ID` (`0x18`)

| Bits | Name | Description |
|------|------|-------------|
| 15:9 | VRESET | reset voltage, 40 mV/LSb (default `0x96 >> 1` = 3.0 V); for a removable battery set at least 300 mV below the empty voltage, for a captive battery 2.5 V |
| 8 | DIS | `1` = disable the analog comparator in hibernate mode (saves about 0.5 µA) |
| 7:0 | ID | factory-programmed identifier (read only) |

#### `STATUS` (`0x1A`)

| Bits | Name | Description |
|------|------|-------------|
| 14 | ENVR | `1` = a voltage-reset event asserts ALRT |
| 13 | SC | SOC changed by at least 1 % (only when `CONFIG.ALSC = 1`) |
| 12 | HD | SOC crossed the `CONFIG.ATHD` threshold (low SOC) |
| 11 | VR | voltage reset occurred (only when `ENVR = 1`) |
| 10 | VL | `VCELL` was below `VALRT.MIN` |
| 9 | VH | `VCELL` was above `VALRT.MAX` |
| 8 | RI | reset indicator, set at power-up; clear it after start-up |

Each bit must be cleared by software (write the register with the bit at 0) after servicing; the alert flag `CONFIG.ALRT` is cleared separately.

## Initialization Sequence

1. Power up (cell or system supply, see Pin Configuration). The first SOC result is available about 1 s after power-on reset; wait ≥ 1 s before trusting the SOC (VCELL is valid after the first conversion, about 250 ms).
2. Read `STATUS`; if `RI` is set the chip has just reset: clear `RI` (write `STATUS` with `RI = 0`).
3. Optionally program thresholds (`CONFIG.ATHD`, `VALRT`, `VRESET`).
4. Read `VCELL` and `SOC`.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `ALRT` — active-low, open-drain; requires an external pull-up |
| Level | 2 (selectable sources: low SOC, 1 % SOC change, over-voltage, under-voltage, voltage reset) |
| Condition(s) | `STATUS` flag set by the chip (see sources) |
| Clear mechanism | write the `STATUS` flag bit to 0 and write `CONFIG.ALRT = 0`; the pin is released after `ALRT` is cleared |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_RESET` | `0x0100` | `STATUS.RI`: the chip reset since the flag was last cleared |
| `SOURCE_OVERVOLTAGE` | `0x0200` | `STATUS.VH`: `VCELL > VALRT.MAX` |
| `SOURCE_UNDERVOLTAGE` | `0x0400` | `STATUS.VL`: `VCELL < VALRT.MIN` |
| `SOURCE_VRESET` | `0x0800` | `STATUS.VR`: the voltage-reset alert (needs `ENVR`) |
| `SOURCE_LOW_SOC` | `0x1000` | `STATUS.HD`: SOC crossed `CONFIG.ATHD` |
| `SOURCE_SOC_CHANGE` | `0x2000` | `STATUS.SC`: SOC changed by ≥ 1 % (needs `ALSC`) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on ALRT (falling edge) via `connection.int_pin` (or `int_pin`), otherwise a 1 s polling task calling `poll_interrupt`; `callback(status)` receives the `STATUS` word masked to the sources above |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Reads `STATUS`, clears the reported flag bits and `CONFIG.ALRT` (releasing ALRT), returns the masked word (0 = none) |
| `enable_interrupt` | `enable_interrupt(source)` | `SOURCE_SOC_CHANGE` sets `CONFIG.ALSC`; `SOURCE_VRESET` sets `STATUS.ENVR`; the other sources are always enabled by their threshold (low SOC by `ATHD`, voltage by `VALRT`) |
| `disable_interrupt` | `disable_interrupt(source)` | Reverse of `enable_interrupt` where a control bit exists; for threshold sources set the threshold to its disabled value (`VALRT.MIN = 0`, `VALRT.MAX = 0xFF`) |

## Data Conversion

```
raw_v   = (msb << 8) | lsb                  # VCELL
voltage = (raw_v >> 4) * 1.25e-3 * cells    # 78.125 µV/LSb on the 16-bit word per cell

raw_soc = (msb << 8) | lsb                  # SOC
percent = raw_soc / 256.0                   # high byte = 1 %, low byte = 1/256 %

rate = int16(raw_crate) * 0.208             # %/h; CRATE is two's complement

# alert thresholds
alert_soc_percent  = 32 - ATHD
valrt_v            = byte * 0.020           # MIN / MAX
reset_v            = (VRESET >> 9) * 0.040  # bits 15:9 of VRESET/ID
hib_thr            = byte * 0.208           # %/h
act_thr_v          = byte * 0.00125         # V
```

The datasheet states the VCELL LSb as 78.125 µV per cell on the 16-bit word (12-bit result in bits 15:4, 1.25 mV/LSb); the 2-cell MAX17049 reports twice the per-cell voltage, hence `× cells`.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| ADC sample period (VCELL update) | 250 ms active, 45 s hibernate |
| First SOC after power-on reset | ≈ 1 s |
| Hibernate entry | \|CRATE\| < HIBTHR for > 6 min |
| Sleep entry by bus low | SDA and SCL low > 1.75–2.5 s (tSLEEP) |
| After `CMD` = `0x5400` | no ACK; allow ≥ 1 s before the next read |
| I²C clock | ≤ 400 kHz |

No constraint has a bus-decodable start/end annotation pair (conversions are free-running and not marked by a bus event), so `max17048_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed connection** with 16-bit words: accept `RegisterConnection` and use `read(reg, 2)` / `write(reg, [msb, lsb])` directly; no chip-local helpers (see `specs/feature_register_access_design.md`). Always write both bytes: 8-bit writes have no effect.
- **Read-modify-write** the shared registers (`CONFIG`, `STATUS`, `VRESET/ID`): `CONFIG.ALRT`, `STATUS` flags and the read-only ID bits are not changed by writing 1; the reserved bits read undefined values and are written back unchanged.
- **MODE is write-only:** `MODE` returns undefined data on some parts; `is_hibernating` reads it but the driver treats an unreadable value as `False`. Do not read-modify-write `MODE`; write complete values (`EnSleep` on or off).
- **Do not use quick-start in normal operation:** the chip already estimates the SOC correctly at insertion. Use it only when the first SOC after a (slow) battery insertion is clearly wrong.
- **First SOC:** the register is not meaningful until ≈ 1 s after power-on reset; the driver does not block in `init`.
- **Sleep vs. hibernate:** sleep halts all operation (< 1 µA) and the chip cannot track charge in that time; use hibernate (automatic) unless 4 µA is too much. Sleep needs `MODE.EnSleep` first and is left only with `CONFIG.SLEEP = 0` (or POR). Holding both bus lines low longer than tSLEEP also sleeps the chip when `EnSleep` is set; avoid long bus-low periods.
- **Alert flags persist:** the chip does not clear `CONFIG.ALRT`; service the cause (`STATUS`) then clear `ALRT` or the pin stays low. `STATUS.RI` is set at every power-up and must be cleared by the host.
- **Reset command:** the chip drops off the bus for the reset; the driver must ignore the missing ACK of the second byte and wait ≥ 1 s. After a reset the on-chip model is the default one (the custom `TABLE` is not touched by this driver).
- **Voltage range:** MAX17048 is powered from the cell (2.5–4.5 V); the voltage reading is the supply voltage, so a 2-cell pack needs the MAX17049.
- **RCOMP:** the default `0x97` suits typical Li-ion cells at room temperature; other chemistries need a vendor-characterised value. `compensate_temperature` only applies the datasheet formula with the default coefficients.
- **Address overlap:** `0x36` is shared with the AS5600; the `VERSION` probe (`0x001x`) separates them.

## Sigrok Decoder

Decoder id `max17048`, input `['i2c']`. Matches I²C address `0x36`. Annotates every register access with the register name, decodes VCELL (volts), SOC (%), CRATE (%/h), VERSION, `MODE`, `HIBRT`, `CONFIG` (RCOMP, SLEEP, ALSC, ALRT, ATHD), `VALRT`, `VRESET/ID`, and `STATUS` (alert names), recognises the reset command (`CMD` = `0x5400`, expected NACK), and warns on 8-bit writes to a register, writes to read-only registers, and bus-low sleep conditions it can see. No conformance annotation pair is emitted (no checked timing constraint).
