# Chip Spec: LTC4151

**Manufacturer:** Linear Technology (Analog Devices)  
**Datasheet:** `datasheets/power/ltc4151.pdf` (LTC4151 / LTC4151-1 / LTC4151-2, Rev. F)  
**Category:** power  
**Transports:** I²C

## Overview

The LTC4151 is a high-side power monitor for 7–80 V supplies. A 12-bit ΔΣ ADC measures, in sequence, the voltage across an external sense resistor (SENSE+ − SENSE−, full scale 81.92 mV, 20 µV/LSB), the supply voltage at VIN (full scale 102.4 V, 25 mV/LSB) and an uncommitted ADIN input (full scale 2.048 V, 0.5 mV/LSB). In the default continuous-scan mode the three results are refreshed at about 7.5 Hz; a snapshot mode converts one selected channel on demand. Current follows from the sense voltage and the sense-resistor value; power is VIN × I. The I²C interface is SMBus-compatible and supports nine addresses from two three-state pins. The LTC4151-1 and LTC4151-2 variants split SDA into SDAI/SDAO for opto-isolated buses; the register interface is identical. Typical uses: telecom/server power rails, battery packs, PoE and industrial supply monitoring.

## Transport Configuration

### I²C
- **Address:** 7-bit `0x67`–`0x6F`, selected by the three-state pins ADR1/ADR0 (the datasheet lists 8-bit write addresses `0xCE`–`0xDE`; 7-bit = 8-bit >> 1):

  | ADR1 | ADR0 | 7-bit address |
  |------|------|---------------|
  | H | L | `0x67` |
  | NC | H | `0x68` |
  | H | H | `0x69` |
  | NC | NC | `0x6A` (all pins open) |
  | NC | L | `0x6B` |
  | L | H | `0x6C` |
  | H | NC | `0x6D` |
  | L | NC | `0x6E` |
  | L | L | `0x6F` |

  H = tie to VIN, L = tie to GND, NC = open. The chip also acknowledges the mass-write address `0x66` (writes only, all devices).
- **Max clock:** 400 kHz
- **Register addressing:** 8-bit register address (bits 7:3 ignored), auto-increment, wraps from `0x06` to `0x00`; supports SMBus read/write byte, word and page (block) commands. Page read/write is enabled by default (`CONTROL.G3`).
- **Identity register:** none; the chip has no ID register (`id_probe: null` in `registry/chips.json`). The reserved bits of the data registers read as `0`, which is not a usable fingerprint.
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer; only writes of a data byte change `CONTROL`.

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| SHDN | low | (LTC4151 only) pull low to enter shutdown (supply current ≤ 300 µA, I²C not accessible); leave open (internal pull-up) if unused |
| ADR1, ADR0 | — | three-state address inputs |
| ADIN | — | 0–2.048 V ADC input (e.g. external voltage or thermistor divider) |
| SENSE+, SENSE− | — | Kelvin-connected sense resistor; SENSE+ must be connected to VIN |
| SDA / SDAI, SDAO | — | open-drain I²C data; `-1`/`-2` variants split data in/out |
| SCL | — | I²C clock |
| VIN | — | 7–80 V supply (also the measured voltage) |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | SENSE_H (A) | R | — | Sense voltage, 8 MSBs |
| `0x01` | SENSE_L (B) | R | — | Bits 7:4 sense voltage 4 LSBs; bit 3 busy |
| `0x02` | VIN_H (C) | R | — | VIN, 8 MSBs |
| `0x03` | VIN_L (D) | R | — | Bits 7:4 VIN 4 LSBs; bit 3 busy |
| `0x04` | ADIN_H (E) | R | — | ADIN, 8 MSBs |
| `0x05` | ADIN_L (F) | R | — | Bits 7:4 ADIN 4 LSBs; bit 3 busy |
| `0x06` | CONTROL (G) | R/W | `0x0C` | Snapshot mode, channel select, test mode, page R/W, stuck-bus timer |
| `0x07` | — | — | — | Reserved |

The data registers are writable only while test mode (`CONTROL.G4`) is set; the driver never writes them.

### Bit Fields

#### `SENSE_L` / `VIN_L` / `ADIN_L` (`0x01` / `0x03` / `0x05`)

| Bits | Name | Description |
|------|------|-------------|
| 7:4 | DATA[3:0] | four LSBs of the 12-bit result |
| 3 | BUSY | snapshot mode: `1` = this channel is being converted, `0` = conversion done; always `0` in continuous mode |
| 2:0 | RSVD | read as 0 |

#### `CONTROL` (`0x06`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | SNAPSHOT | `1` = snapshot mode: only the channel in bits 6:5 is converted once, then the ADC halts; `0` = continuous scan (default) |
| 6:5 | CHANNEL | snapshot channel: `00` SENSE (default), `01` VIN, `10` ADIN |
| 4 | TEST | `1` = test mode: halts the ADC and makes the data registers writable; keep `0` |
| 3 | PAGE_RW | `1` = I²C page read/write enabled (default) |
| 2 | STUCK_BUS | `1` = stuck-bus reset timer enabled (default) |
| 1:0 | RSVD | read as 0 |

Default `CONTROL` = `0x0C` (continuous scan, SENSE, page R/W and stuck-bus timer enabled).

## Initialization Sequence

1. Power up VIN (7–80 V). The ADC starts in continuous scan mode; the first full set of results is available after about 3 × 67 ms.
2. Optionally write `CONTROL` (`0x06`); the power-on default `0x0C` needs no change.
3. Read the six data registers `0x00`–`0x05` in one block read and convert.

## Implementation Stages

### Minimal

Goal: read supply voltage, current and power with one call each, no configuration beyond the connection and the sense resistor.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection`, `r_sense: float = 0.02` | — | Stores the register-addressed connection and the sense resistor in Ω; no bus access (continuous scan is the power-on default) |
| `voltage` | — | float | VIN in V (`code × 0.025`) |
| `current` | — | float | Load current in A (`sense_voltage / r_sense`) |
| `power` | — | float | `voltage × current` in W, from one block read of `0x00`–`0x03` |

**Sensible defaults:** continuous scan (`CONTROL = 0x0C`), 20 mΩ sense resistor (full-scale current 4.096 A), no ADIN use.

### Full

Goal: complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `sense_voltage` | — | float | SENSE+ − SENSE− in V (`code × 20e-6`) |
| `adin_voltage` | — | float | ADIN in V (`code × 0.0005`) |
| `read_all` | — | `{vin, sense_v, current, power, adin}` | One block read of `0x00`–`0x05` (consistent scan result) |
| `read_raw` | `channel: int` | int | 12-bit code of a channel (`SENSE` = 0, `VIN` = 1, `ADIN` = 2) |
| `set_sense_resistor` / `get_sense_resistor` | `ohms: float` / — | — / float | Raises for ≤ 0 |
| `snapshot` | `channel: int` | float | Runs one snapshot conversion of the channel (sets `CONTROL.G7` and `G6:G5`, polls the `BUSY` bit, reads the result, returns the value in V/V/V): timeout 100 ms, then returns to continuous scan |
| `set_continuous` | — | — | Writes `CONTROL` with snapshot cleared (continuous scan) |
| `is_snapshot_mode` | — | bool | `CONTROL.G7` |
| `is_busy` | `channel: int` | bool | `BUSY` bit of the channel in snapshot mode |
| `set_stuck_bus_timer` | `enabled: bool` | — | `CONTROL.G2` (read-modify-write) |
| `set_page_rw` | `enabled: bool` | — | `CONTROL.G3`; disabling restricts the chip to byte/word transfers (the driver then uses single reads) |
| `read_control` / `write_control` | — / `value: int` | int / — | Raw `CONTROL`; `write_control` masks bit 4 (test mode) to 0 |
| `temperature_from_adin` | `adin_code: int, vin_code: int` | float | Datasheet NTC example: `T(°C) = 58.82 × (adin_code / vin_code − 0.1066)`, valid 20…60 °C only for the datasheet circuit |

**Additional configuration options:** sense-resistor value, snapshot vs. continuous mode, stuck-bus timer, page R/W.

## Data Conversion

```
sense_code = (SENSE_H << 4) | (SENSE_L >> 4)     # 12 bit, 0..4095
vin_code   = (VIN_H   << 4) | (VIN_L   >> 4)
adin_code  = (ADIN_H  << 4) | (ADIN_L  >> 4)

sense_voltage_v = sense_code * 20e-6        # full scale 81.92 mV
vin_v           = vin_code   * 0.025        # full scale 102.4 V
adin_v          = adin_code  * 0.0005       # full scale 2.048 V

current_a = sense_voltage_v / r_sense_ohm
power_w   = vin_v * current_a
```

Datasheet accuracy: ±1.25 % TUE on the sense channel, ±0.75 % (C-grade) / ±1 % on VIN and ADIN, offset ±5 LSB. With a 20 mΩ resistor the current LSB is 1 mA; use a smaller resistor for higher currents (the sense voltage must stay below 81.92 mV).

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Continuous scan rate | 6–9 Hz (7.5 Hz typ.): all three channels refreshed in turn |
| Snapshot conversion, SENSE | 67 ms typ., 85 ms max |
| Snapshot conversion, VIN / ADIN | 33 ms typ., 42 ms max |
| Stuck-bus reset | SCL or SDA held low > 20–33 ms resets the I²C state machine |
| I²C clock | ≤ 400 kHz |

**Conformance-checked constraint:** the maximum SENSE snapshot-conversion time (85 ms) via the `conversion_start` / `conversion_done` annotation pair (the `CONTROL` write with `SNAPSHOT = 1` → the first `SENSE_L` read with `BUSY = 0`); see `ltc4151_timing.conf`.

## Implementation Notes

- **Register-addressed connection:** accept `RegisterConnection` and use `read(reg, length)` / `write(reg, data)` directly; no chip-local register helpers (see `specs/feature_register_access_design.md`).
- **12-bit left-justified data:** the 8 MSBs are in the first register and the 4 LSBs in bits 7:4 of the second; always read both registers in one block read so they come from the same conversion (the registers refresh asynchronously at 7.5 Hz).
- **Snapshot mode:** to switch channel, first clear the snapshot bit, then write the new channel with the snapshot bit set. Poll the `BUSY` bit of the selected channel (bit 3 of its low register); it is always 0 in continuous mode.
- **SENSE+ must be tied to VIN** (Kelvin connection); the sense voltage is unsigned (only the high-side current direction).
- **Test mode (`CONTROL.G4`) halts the ADC:** the driver never sets it and masks it out of `write_control`.
- **Shutdown pin:** with SHDN low the chip does not respond to I²C; there is no register-controlled shutdown.
- **Address 0x66 (mass write):** a write to this address changes all LTC4151s on the bus; the driver never uses it.
- **ADIN scaling:** ADIN is not a current or VIN input; its 2.048 V range suits dividers/thermistors, so `adin_voltage` returns the raw pin voltage.
- **Variants:** LTC4151-1 and -2 use SDAI/SDAO for opto-isolation; register map and conversions are identical.

## Sigrok Decoder

Decoder id `ltc4151`, input `['i2c']`. Matches I²C addresses `0x66`–`0x6F`. Annotates each access with the register name, decodes the 12-bit SENSE, VIN and ADIN results (volts, plus a current estimate using a default 20 mΩ resistor), decodes `CONTROL` into SNAPSHOT/CHANNEL/TEST/PAGE_RW/STUCK_BUS, and warns when test mode is enabled or a data register is written. It emits the conformance pair `conversion_start` (the `CONTROL` write with `SNAPSHOT = 1`) and `conversion_done` (the first read of the selected channel's low register with `BUSY = 0`).
