# Chip Spec: MAG3110

**Manufacturer:** Freescale / NXP Semiconductors  
**Datasheet:** `datasheets/magnetometer/mag3110.pdf` (MAG3110 Rev. 9.2, 02/2013)  
**Category:** magnetometer  
**Transports:** I²C

## Overview

The MAG3110 (Xtrinsic) is a small, low-power, digital 3-axis linear magnetometer in a 10-pin DFN: full-scale range ±1000 µT, 16-bit signed output with a sensitivity of **0.10 µT/LSB**, output data rates from 80 Hz down to 0.08 Hz with selectable oversampling (16–128 samples), a 400 kHz I²C interface, a data-ready interrupt (INT1), **user offset registers** (to remove hard-iron/zero-flux offsets), an 8-bit **die temperature** register (1 °C/LSB, uncalibrated offset), factory calibration of gain, offset and temperature compensation, and a magnetic sensor reset function. Supply VDD 1.95–3.6 V, VDDIO 1.62 V…VDD. Together with a 3-axis accelerometer it forms a tilt-compensated electronic compass. The FXMS3110CD (address `0x0F`) is the same die with a different default address and is not covered.

## Transport Configuration

### I²C
- **Address:** `0x0E` (7-bit; the FXMS3110CD variant uses `0x0F`)
- **Max clock:** 400 kHz (fast mode)
- **Identity register:** `WHO_AM_I` (`0x07`) = `0xC4` (feeds `registry/chips.json`)
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer
- **Register addressing:** 1-byte register address (`RegisterConnection`, `reg_bytes = 1`); **auto-increment** across `0x00`–`0x06` (burst read of status + 6 data bytes); with the Fast Read (`FR`) bit set the increment skips the LSB registers (3 data bytes)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| INT1 | high | Data-ready interrupt (the `ZYXDR` flag, push-pull); goes high when new data is available; cleared by reading `OUT_X_MSB` |
| SDA, SCL | — | I²C; external pull-ups |
| VDD, VDDIO, GND | — | 1.95–3.6 V core, 1.62 V…VDD interface supply |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | DR_STATUS | R | `0x00` | Data-ready and overwrite flags per axis |
| `0x01`–`0x06` | OUT_X/Y/Z_MSB/LSB | R | data | 16-bit signed X, Y, Z (big-endian pairs) |
| `0x07` | WHO_AM_I | R | `0xC4` | Device ID |
| `0x08` | SYSMOD | R | data | `00` standby, `01` active RAW, `10` active non-RAW |
| `0x09`–`0x0E` | OFF_X/Y/Z_MSB/LSB | R/W | `0x00` | User offsets (bits [14:7] in MSB, [6:0] in LSB; LSB bit 0 forced 0) |
| `0x0F` | DIE_TEMP | R | data | Die temperature, signed 8 bit, 1 °C/LSB |
| `0x10` | CTRL_REG1 | R/W | `0x00` | `DR[2:0]`, `OS[1:0]`, `FR`, `TM`, `AC` |
| `0x11` | CTRL_REG2 | R/W | `0x00` | `AUTO_MRST_EN`, `RAW`, `Mag_RST` |

### Bit Fields

#### `DR_STATUS` (`0x00`)

| Bit | Name | Description |
|-----|------|-------------|
| 7 | ZYXOW | X, Y or Z data overwritten before it was completely read (cleared when the MSBs of all active channels are read) |
| 6 | ZOW | Z overwritten (cleared by reading `OUT_Z_MSB`) |
| 5 | YOW | Y overwritten |
| 4 | XOW | X overwritten |
| 3 | ZYXDR | New data on any enabled axis (cleared when all MSB registers were read; also drives INT1) |
| 2 | ZDR | New Z data |
| 1 | YDR | New Y data |
| 0 | XDR | New X data |

#### `CTRL_REG1` (`0x10`)

| Bits | Name | Description |
|------|------|-------------|
| 7:5 | DR[2:0] | Output data rate selection (with `OS`, see table) |
| 4:3 | OS[1:0] | Oversampling ratio (16, 32, 64, 128) |
| 2 | FR | `1` = Fast Read: only the 8-bit MSB registers are read in a burst |
| 1 | TM | `1` = trigger an immediate measurement |
| 0 | AC | `0` = STANDBY, `1` = ACTIVE (continuous measurements at the programmed ODR) |

Except for the `AC` bit the device must be in STANDBY to change `CTRL_REG1`. `AC`/`TM`: `00` low-power standby; `01` one triggered measurement (the chip leaves standby, measures once and returns to standby); `10` continuous measurement; `11` an in-progress measurement continues at the fastest ODR for the OSR, then back to the programmed ODR.

**ODR / OSR** (`DR2 DR1 DR0 OS1 OS0`): ODR = `80 Hz / 2^(DR + OS)` (80, 40, 20, 10 Hz for `DR` = 0 and `OS` = 0…3; … down to 0.08 Hz for `DR` = 7, `OS` = 3), oversampling ratio = `16 × 2^OS`; the ADC rate is 1280 Hz (`DR` = 0), 640, 320, 160, 80 Hz (`DR` ≥ 4); supply current 900 µA at 80 Hz (`DR` = 0, `OS` = 0) down to 8.6 µA (`DR` = 7); noise 0.4 µT rms (OSR 16) … 0.25 µT rms (OSR 128).

#### `CTRL_REG2` (`0x11`)

| Bit | Name | Description |
|-----|------|-------------|
| 7 | AUTO_MRST_EN | `1` = automatic magnetic sensor reset before each acquisition (write-only, reads 0; **recommended always on**) |
| 5 | RAW | `0` = data corrected by the user offset registers, `1` = raw (no user offset; the factory calibration is always applied) |
| 4 | Mag_RST | `1` = start a one-shot magnetic sensor reset (restores operation after an excessive field); self-clears |

## Initialization Sequence

1. Power-up: STANDBY, all registers at reset values.
2. (Optional) read `WHO_AM_I` and check `0xC4`.
3. Write `CTRL_REG2` ← `0x80` (automatic magnetic sensor resets on; `RAW` = 0 or set `0xA0` for raw data).
4. Write `CTRL_REG1` ← `DR<<5 | OS<<3 | AC` (e.g. `0x01` = 80 Hz, OSR 16, active; `0xC9` = 0.63 Hz, OSR 32, active; see the ODR formula).
5. Wait for data: poll `DR_STATUS.ZYXDR` or wait for INT1; the first sample after leaving STANDBY is slightly off (anti-aliasing filter settling), so discard the first ODR period.
6. Read `0x00`–`0x06` (status + data) in one burst, starting at `0x01` (reading `OUT_X_MSB` first is required to update the other data registers).

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `INT1`, active high |
| Level | 1 (single fixed condition: new data ready) |
| Condition | `ZYXDR` set — new measurement data available on any enabled axis |
| Clear mechanism | Read `OUT_X_MSB` (`0x01`) |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on INT1 (rising edge) via `connection.int_pin` (or `int_pin`), otherwise a polling task at the ODR period on `poll_interrupt`; `callback(x, y, z)` receives the field in µT |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> bool` | Reads `DR_STATUS`; `True` if `ZYXDR` is set (does not read the data, so it does not clear INT1) |

## Implementation Stages

### Minimal

Goal: read the magnetic field on three axes with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection | — | Checks `WHO_AM_I`, writes `CTRL_REG2` = `0x80` and `CTRL_REG1` = `0x01` (80 Hz, OSR 16, active) |
| `read_field` | — | `(x, y, z)` floats in µT | Waits for `ZYXDR` (timeout 100 ms), burst-reads `0x01`–`0x06`, `raw × 0.1 µT` |
| `read_raw` | — | `(x, y, z)` ints | Signed 16-bit counts |

**Sensible defaults:** ACTIVE at 80 Hz with OSR 16 (`CTRL_REG1` = `0x01`), automatic magnetic sensor resets on, user offsets applied (`RAW` = 0, offsets 0), full 16-bit reads.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `set_rate` | `odr_hz: float`, `oversampling: int = 16` | — | Chooses the `DR`/`OS` pair for the nearest ODR/OSR from the table (`odr = 80 / 2^(DR+OS)`, `osr = 16·2^OS`); changes need STANDBY, so the driver drops to STANDBY and restores the mode |
| `get_rate` | — | `(odr_hz, oversampling)` | |
| `standby` / `active` | — | — | `AC` ← 0 / 1 |
| `trigger` | — | `(x, y, z)` µT | Triggered single measurement from STANDBY (`TM` = 1), waits for `ZYXDR`, returns to STANDBY; the first sample after standby is slightly off at low OSR |
| `set_fast_read` | `on: bool` | — | `FR` (8-bit reads: only the MSB registers are read, so `read_field` has a resolution of 256 counts = 25.6 µT) |
| `set_raw_mode` | `raw: bool` | — | `RAW` bit |
| `set_offsets` | `x: int`, `y: int`, `z: int` | — | User offsets in counts (±10 000), written to `0x09`–`0x0E` as `offset << 1` per Data Conversion (the register LSB bit 0 is forced 0) |
| `get_offsets` | — | `(x, y, z)` | |
| `calibrate_offsets` | `samples: int = 100` | `(x, y, z)` | Hard-iron helper: rotate the board through all orientations while sampling min/max per axis in raw mode, then store `(max + min) / 2` as the offsets |
| `read_temperature` | — | float | `DIE_TEMP` in °C (signed 8 bit, uncalibrated offset) |
| `read_status` | — | int | `DR_STATUS` |
| `sensor_reset` | — | — | `Mag_RST` ← 1 and wait until it clears |
| `who_am_i` | — | int | `0xC4` |
| `heading` | — | float | Degrees 0–360 from `atan2(y, x)` of the horizontal plane (the board must be level; no tilt compensation) |
| `on_interrupt` / `off_interrupt` / `poll_interrupt` | see Interrupt | | |

**Additional configuration options:** ODR/oversampling, fast read, raw/offset mode, user offsets, triggered measurement, sensor reset.

## Data Conversion

```
x = signed16((OUT_X_MSB << 8) | OUT_X_LSB)            # same for y (0x03/0x04) and z (0x05/0x06)
field_uT = x * 0.10                                   # sensitivity 0.10 µT/LSB, full scale ±1000 µT (±10000 counts)
raw range: -20000 .. +20000 counts with RAW = 1; -30000 .. +30000 with RAW = 0 (user offsets of ±10000 included)

user offset registers (per axis, big-endian pair): the signed offset occupies bits [14:0] of the 16-bit pair (bit 0 of the LSB register is 0), i.e. the register word is the offset shifted left by one:
    word = (offset_counts << 1) & 0xFFFF           # MSB = word >> 8 (bits 14:7 of the offset + sign), LSB = word & 0xFF (bit 0 = 0)
    offset_counts = signed16(word) >> 1
temperature_c = signed8(DIE_TEMP)                    # 1 °C/LSB, offset not trimmed

ODR = 80 / 2^(DR + OS) Hz;  OSR = 16 * 2^OS;   CTRL_REG1 = DR<<5 | OS<<3 | FR<<2 | TM<<1 | AC
heading = atan2(y, x) in degrees, mapped to 0..360   # level board, after hard-iron offset removal
```

Example: `CTRL_REG1` = `0xC9` → `DR` = 6, `OS` = 1, active → ODR = 80/2^7 = 0.63 Hz, OSR 32; X counts `0x1234` = 4660 → 466.0 µT.

## Timing Constraints

- **Measurement period:** the programmed ODR (12.5 ms at 80 Hz … 12.5 s at 0.08 Hz); data readiness is flagged by `DR_STATUS` / INT1.
- **First sample after STANDBY:** slightly inaccurate (filter settling); discard the first ODR period; triggered mode is therefore not recommended for accurate low-OSR readings.
- **Magnetic sensor reset:** `Mag_RST` self-clears when the cycle finishes (no time stated); needed after exposure to a field above the full-scale range but below the absolute maximum.
- **Automatic resets** before each acquisition when `AUTO_MRST_EN` is set (adds no host time).
- **Power:** 900 µA at 80 Hz/OSR 16 … 8.6 µA at the slowest rate; standby only the digital blocks.
- **I²C:** ≤ 400 kHz — a clock-rate property, not an event-to-event delay.
- **Conformance:** none of these has a bus-decodable start/end annotation pair with a datasheet bound, so `specs/magnetometer/mag3110_timing.conf` defines no checks.

## Implementation Notes

- **RegisterConnection:** `connection.read(0x01, 6)` for a data burst (starting at `0x01` is required to refresh the data registers), `connection.read(0x00, 7)` for status + data; no chip-local `_read_reg`/`_write_reg`, no `bus_type` branch (see `specs/feature_register_access_design.md`).
- **Enable `AUTO_MRST_EN`:** the datasheet recommends always setting it (write `CTRL_REG2` ← `0x80` explicitly after every power-up; the bit is write-only and reads 0).
- **STANDBY for configuration:** only `AC` may change while active.
- **Burst start at `0x01`:** if `OUT_X_MSB` is not read first the other registers keep older values.
- **Hard-iron offsets:** an external processor usually does the offset correction itself; then set `RAW` = 1 and leave the offset registers at 0.
- **Heading** needs a level board or accelerometer tilt compensation; the die temperature has an uncalibrated offset.
- **FXMS3110CD** has address `0x0F`; the same driver works with the `address` parameter.
- **Datasheet:** Freescale MAG3110 Rev. 9.2, downloaded from `https://www.nxp.com/docs/en/data-sheet/MAG3110.pdf`.

## Sigrok Decoder

Decoder id `mag3110`, input `['i2c']`. Matches I²C address `0x0E` (and `0x0F`). Annotates register writes and pointer-set + read transactions by register name, decodes `DR_STATUS` flags, the X/Y/Z bursts (counts and µT, 0.1 µT/LSB), `CTRL_REG1` (ODR in Hz, OSR, FR, TM, AC), `CTRL_REG2` (AUTO_MRST_EN, RAW, Mag_RST), `SYSMOD`, the offset registers, `DIE_TEMP` and `WHO_AM_I` (verified against `0xC4`); warns on `CTRL_REG1` writes other than `AC` while `SYSMOD` shows active, on data bursts that do not start at `0x01` and on a missing `AUTO_MRST_EN`. No timing annotation pair is emitted.
