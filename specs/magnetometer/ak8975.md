# Chip Spec: AK8975

**Manufacturer:** Asahi Kasei Microdevices (AKM)
**Datasheet:** `datasheets/magnetometer/ak8975.pdf` (AK8975/AK8975C, MS1187-J-02, 2010/05 — the Japanese edition; the English edition MS1187-E-02 carries the same content)
**Category:** magnetometer
**Transports:** I²C

> **Scope note:** the AK8975 also has a 4-wire SPI interface (CSB low, SPI mode 3, 16-bit transfers: R/W bit + 7-bit address, then data; no multi-address writes). The issue requests I²C only, so this spec covers I²C; SPI can be added later.

## Overview

The AK8975 is a 3-axis electronic compass IC using Hall sensors: 13-bit output (0.3 µT/LSB typ., ±1229 µT range) in a 16-bit two's-complement register, single-measurement mode (7.3 ms typ., 9 ms max.), a self-test mode with an internal magnetic source, a fuse ROM with per-axis sensitivity-adjustment values (ASAX/Y/Z), a data-ready indication (DRDY bit and DRDY pin), a magnetic-sensor overflow flag and a data-read-error flag. Analog supply 2.4–3.6 V, digital interface supply (VID) 1.65 V up to the analog supply, 3 µA in power-down. The AK8975C is the WL-CSP variant of the same die. Typical uses: pedestrian navigation and heading in phones and portable devices.

## Transport Configuration

### I²C
- **Address:** `0x0C` + (CAD1 << 1 | CAD0): `0x0C` (00), `0x0D` (01), `0x0E` (10), `0x0F` (11) (7-bit `0001 1 CAD1 CAD0`; the CSB pin must be tied to VID to select I²C)
- **Max clock:** 400 kHz (fast mode)
- **Register addressing:** 8-bit register address; two auto-increment sequences, `0x00`→…→`0x0C`→`0x00` and `0x10`→`0x12`→`0x10`; multi-byte reads/writes supported
- **Identity register:** `0x00` WIA = `0x48` (fixed) — feeds `registry/chips.json`; the address range is shared with IST8310 (WAI `0x10`) and AK8963/AK09918-family parts
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer; only writing `CNTL` (`0x0A`) changes operation

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| DRDY | high | data-ready output (push-pull, VID level); goes high when a measurement finished and data can be read; cleared by reading ST2 or the data registers |
| CSB | low | low selects 4-wire SPI; tie to VID for I²C |
| CAD0, CAD1 | — | I²C address select (VSS/VDD) |
| VDD, VID, VSS | — | VDD 2.4–3.6 V (analog); VID 1.65 V…VDD (digital I/O) |
| SCL, SDA | — | I²C; SDA open-drain, pull-up required |
| SK, SI, SO | — | SPI pins (unused in I²C mode: leave SO unconnected, tie SK/SI per datasheet) |

## Register Map

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | WIA | R | `0x48` | Device ID |
| `0x01` | INFO | R | — | AKM device information |
| `0x02` | ST1 | R | `0x00` | Bit 0 DRDY |
| `0x03`–`0x08` | HXL, HXH, HYL, HYH, HZL, HZH | R | `0x00` | X, Y, Z, each int16 little-endian (13-bit range −4096…+4095) |
| `0x09` | ST2 | R | `0x00` | Bit 3 HOFL, bit 2 DERR |
| `0x0A` | CNTL | R/W | `0x00` | Bits 3:0 MODE |
| `0x0B` | RSV | R/W | `0x00` | Reserved — do not use |
| `0x0C` | ASTC | R/W | `0x00` | Bit 6 SELF (self-test field) |
| `0x0D`, `0x0E` | TS1, TS2 | R/W | `0x00` | Test registers — do not use |
| `0x0F` | I2CDIS | R/W | `0x00` | Write `0x1B` to disable the I²C interface (re-enable only by power cycle) |
| `0x10`–`0x12` | ASAX, ASAY, ASAZ | R | fuse ROM | Sensitivity adjustment values (readable in fuse-ROM access mode) |

### Bit Fields

#### `ST1` (`0x02`)

| Bits | Name | Description |
|------|------|-------------|
| 0 | DRDY | `1` = data ready (single measurement or self-test finished); cleared by reading ST2 or any data register |

#### `ST2` (`0x09`)

| Bits | Name | Description |
|------|------|-------------|
| 3 | HOFL | `1` = magnetic sensor overflow (measurement invalid); cleared when the next measurement starts |
| 2 | DERR | `1` = data read error (reading started outside the allowed period, data invalid); cleared by reading ST2 |

#### `CNTL` (`0x0A`, MODE[3:0])

`0000` power-down, `0001` single measurement (returns to power-down automatically), `1000` self-test (returns to power-down automatically), `1111` fuse-ROM access; other values are prohibited. Mode changes must go through power-down; wait ≥ 100 µs (Twat) between consecutive mode settings. Writing `CNTL` re-initialises registers `0x02`–`0x09`.

## Initialization Sequence

1. Power up (VDD 2.4–3.6 V, VID 1.65 V…VDD); the POR circuit resets the chip, which starts in power-down mode.
2. Read `WIA`; expect `0x48`.
3. Set fuse-ROM access mode: write `CNTL` ← `0x0F`, wait 100 µs, read `ASAX`, `ASAY`, `ASAZ` (`0x10`, 3 bytes), write `CNTL` ← `0x00`, wait 100 µs.
4. Single measurement: write `CNTL` ← `0x01`, wait for `DRDY` (poll `ST1` bit 0 or watch the DRDY pin; ≤ 9 ms), read `0x03`–`0x09` (HXL…ST2) in one burst, check `ST2.HOFL`/`DERR`. The chip returns to power-down by itself.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `DRDY`, push-pull at VID level, active high |
| Level | 1 (single fixed condition) |
| Condition | measurement data ready (single measurement or self-test) |
| Clear mechanism | read `ST2` or any measurement data register |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on DRDY (rising edge) via `connection.int_pin` (or `int_pin`), otherwise poll; `callback(x, y, z)` with the adjusted field in µT (the driver reads and clears) |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> bool` | Reads `ST1`; returns `True` when DRDY is set (does not clear it) |

## Implementation Stages

### Minimal

Goal: read the magnetic field in µT with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | `RegisterConnection` (`reg_bytes` = 1); checks WIA = `0x48`, reads ASAX/Y/Z through the fuse-ROM access mode and returns to power-down |
| `read_field` | — | `(x, y, z)` | µT, sensitivity-adjusted; single measurement (`CNTL` ← `0x01`), waits for DRDY (timeout 20 ms), burst-reads `0x03`–`0x09`; raises on HOFL/DERR |

**Sensible defaults:** single-measurement mode on every call (the chip returns to power-down after each), sensitivity adjustment from the fuse ROM.

### Full

Goal: complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `read_raw` | — | `(x, y, z)` | Raw signed counts (no sensitivity adjustment) |
| `read_status` | — | `(drdy, hofl, derr)` | ST1/ST2 decoded |
| `read_sensitivity` | — | `(asax, asay, asaz)` | The stored fuse-ROM values |
| `heading` | `declination_deg: float = 0.0` | `float` | Degrees 0–360 from X/Y (board flat) |
| `self_test` | — | `(bool, (x, y, z))` | Self-test sequence: power-down, `ASTC.SELF` ← 1, mode `1000`, wait DRDY, read, `ASTC` ← 0; passes when −100 ≤ X ≤ 100, −100 ≤ Y ≤ 100, −1000 ≤ Z ≤ −300 (sensitivity-adjusted counts) |
| `power_down` | — | — | `CNTL` ← `0x00` |
| `who_am_i` / `info` | — | `int` | WIA (`0x48`) / INFO |

| `on_interrupt` / `off_interrupt` / `poll_interrupt` | see Interrupt | | |

**Additional configuration options:** software offset, DRDY interrupt use, self-test.

## Data Conversion

```
raw   = signed16(H_xH << 8 | H_xL)                   # little endian; range -4096 … +4095
Hadj  = raw * ((ASA - 128) * 0.5 / 128 + 1)          # per axis, ASA from ASAX/ASAY/ASAZ
field_ut = Hadj * 0.3                                  # 0.3 µT/LSB typ. (0.285–0.315), ±1229 µT
heading_deg = (atan2(y, x) * 180 / pi + declination + 360) % 360
```

Examples (datasheet): raw `0x0FFF` = +4095 = 1229 µT, `0x0001` = 0.3 µT, `0xFFFF` = −0.3 µT, `0xF000` = −4096 = −1229 µT.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Single measurement (TSM) | 7.3 ms typ., 9 ms max |
| Wait between mode settings (Twat) | ≥ 100 µs |
| Self-test | same sequence as a single measurement |
| I²C clock | ≤ 400 kHz |

**Conformance-checked constraint:** the maximum single-measurement time (9 ms) via the `conversion_start` / `conversion_done` annotation pair (the `CNTL` write of mode `0001` → the first `ST1` read with DRDY = 1); see `ak8975_timing.conf`.

## Implementation Notes

- **Burst read of `0x03`–`0x09`** and check ST2: reading ST2 releases the data-register protection and clears DRDY; always read it after the data.
- **Always go through power-down** between modes (also after fuse-ROM access) and wait 100 µs.
- **Writing `CNTL` initialises `0x02`–`0x09`:** do not write it between a data read and the ST2 read.
- **Little-endian data**, axis order X, Y, Z; the 13-bit values are sign-extended in 16 bits.
- **Sensitivity adjustment** is mandatory for the datasheet accuracy; read ASA once at init.
- **HOFL/DERR:** discard the sample; DERR means the read started during the measurement period.
- **I2CDIS:** writing `0x1B` disables the I²C interface until VDD/VID are cycled; never write the register in normal operation.
- **ASTC:** only the SELF bit may be set; writing other bits breaks measurement. Clear SELF after self-test.
- **Address overlap:** `0x0C`–`0x0F` is shared with IST8310 and AK8963; the AK8963 also reports WIA `0x48`, so WIA alone does not separate the two (the AK8963 has 14/16-bit output and a different register layout).
- **Datasheet language:** the available datasheet copy is the Japanese edition (MS1187-J-02); the register tables and numbers are the same as in the English edition.

## Sigrok Decoder

Decoder id `ak8975`, input `['i2c']`. Matches I²C addresses `0x0C`–`0x0F`. Annotates register names for each access, decodes WIA (verified against `0x48`), ST1, ST2 (HOFL/DERR), CNTL modes by name, ASTC and the ASA values, converts 6-byte data reads from `0x03` into raw and sensitivity-adjusted µT when the ASA values were seen, and warns on prohibited modes, writes to RSV/TS1/TS2 and I2CDIS writes. It emits the conformance pair `conversion_start` (the CNTL write of mode `0001`) and `conversion_done` (the first ST1 read with DRDY = 1).
