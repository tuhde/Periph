# Chip Spec: ES8311

**Manufacturer:** Everest Semiconductor (Everest-semi)  
**Datasheet:** `datasheets/adc_dac/es8311.pdf`  
**Category:** `adc_dac`  
**Transports:** I²C (control port only — audio data runs over a separate I²S / PCM port)

## Overview

The ES8311 is a low-power mono audio codec in a 3 × 3 mm QFN-20: a mono ADC (100 dB SNR, −88 dB THD+N) behind a fully differential microphone input with a 0–30 dB analog PGA, noise-reduction filters, an automatic level control (ALC) with noise gate and a 2nd-order equalizer; and a mono DAC (110 dB SNR, −85 dB THD+N) with digital volume, dynamic range control (DRC), a 1st-order equalizer and a fully differential output able to drive a 16 Ω / 32 Ω headphone load or a power-amplifier input. It also has a PDM digital-microphone interface (sharing `MIC1P` and `SCLK`), one I²S / left-justified / DSP-A / DSP-B digital audio port (slave or master, 8–96 kHz), ADC-to-DAC loopback and a "digital feedback" mode that mixes the DAC data into the ADC output for echo cancellation. It is optimised for voice (IP cameras, doorbells, smart speakers, toys, baby monitors) and is common on ESP32 audio boards (e.g. Waveshare, Espressif, M5Stack). The driver covers the **I²C control port only**: it configures clocks, formats, volume and analog paths; the audio stream itself flows over I²S, which this library does not provide. Supplies: AVDD 1.7–3.6 V, DVDD / PVDD 1.6–3.6 V.

## Transport Configuration

### I²C
- **Address:** `0x18` (CE pin pulled down to ground with 10 kΩ) — `0x19` (CE pulled up to PVDD with 10 kΩ)
- **Max clock:** 400 kHz (the guide says "lower than 400 kbps"); pull-ups 1–4.7 kΩ on `CCLK` / `CDATA`; an R-C low-pass (33 Ω + 20 pF) on both lines is strongly recommended
- **Identity register:** none documented in this user guide (feeds `registry/chips.json` with `"id_probe": null` and `"driver": null` until implemented, see `specs/feature_i2c_discovery.md`); the vendor reference drivers read `0xFD` (`0x83`), `0xFE` (`0x11`) and `0xFF` (version) — see Implementation Notes
- **Probe safety:** `register_pointer` — standard register-addressed bus; a 1-byte write only sets the pointer

The CE pin is the I²C address pin; the 7-bit addresses are as above (the board resistor table reads R14 = 10 K / R16 = NC → `0x19`; R14 = NC / R16 = 10 K → `0x18`). A 1-byte register address is followed by data; the chip supports multi-byte transfers with address auto-increment (needed for the equalizer coefficients; the guide does not state it explicitly, see Implementation Notes).

| Register | Bits | Name | Encoding |
|----------|------|------|----------|
| `0x02` | 7:5 | DIV_PRE | MCLK pre-divider = DIV_PRE + 1 (1–8) |
| `0x02` | 4:3 | MULT_PRE | Pre-multiplier 0 = ×1, 1 = ×2, 2 = ×4, 3 = ×8 |
| `0x03` | 6 / 5:0 | ADC_FSMODE / ADC_OSR | 0 = single speed, 1 = double speed; OSR code: 15 = 60·fs (single speed only), 16 = 64·fs (default; 32·fs double speed), 31 = 124·fs, 32 = 128·fs, 63 = 252·fs; codes 0–14 are not allowed |
| `0x05` | 7:4 / 3:0 | DIV_CLKADC / DIV_CLKDAC | Internal ADC / DAC clock = internal master clock ÷ (n + 1) |
| `0x06` | 4:0 | DIV_BCLK | 0–19: dig_mclk ÷ (n + 1); 20 → ÷22, 21 → ÷24, 22 → ÷25, 23 → ÷30, 24 → ÷32, 25 → ÷33, 26 → ÷34, 27 → ÷36, 28 → ÷44, 29 → ÷48, 30 → ÷66, 31 → ÷72 (default 3) |
| `0x07` / `0x08` | 3:0 / 7:0 | DIV_LRCK[11:8] / [7:0] | Master LRCK = dig_mclk ÷ (DIV_LRCK + 1) |

Internal master clock = (MCLK ÷ (DIV_PRE + 1)) × multiplier; ADC / DAC internal clock = internal master clock ÷ (DIV + 1); the ratio internal-clock : LRCK must be 256 / 272 / 288 / 384 / 512 / 768 / 1024 / 1536 … (a multiple of 16) for the DAC and the single-speed ADC (≥ 256 with the EQ enabled, ≥ 240 with the EQ bypassed), and 128 / 136 / 144 / 192 / 256 … (a multiple of 8) for the double-speed ADC. The pre-divider output must stay below 10 MHz at DVDD = 3.3 V (4.5 MHz at 1.8 V); the ADC / DAC internal clocks below 35 MHz at 3.3 V (13 MHz at 1.8 V). Slave mode detects the MCLK : LRCK ratio automatically.

## Initialization Sequence

The user guide describes the registers but does not list a complete start-up procedure ("there is a reference code for power down sequence" is mentioned but not included); the sequence below combines the guide's documented reset / clock / format procedure with the register values used by the vendor reference driver for the analog path. Steps marked **(vendor)** are not in the guide.

1. Power up (DVDD / AVDD / PVDD); the internal POR releases when DVDD reaches its threshold. The I²C port is active; the state machine is off (`CSM_ON` = 0) and the digital blocks are held in reset (`RESET` = `0x1F`).
2. Software reset: write `RESET` (`0x00`) ← `0x1F` (all reset bits 1, `CSM_ON` = 0); wait ≥ 20 ms (guide: "several milliseconds"; 20 ms is the vendor value); write `RESET` ← `0x00` (clear all reset bits); then write `RESET` ← `0x80` (`CSM_ON` = 1, slave mode; `0xC0` for master mode with `RST_MST` = 0). The guide's reset procedure sets the reset bits, clears `CSM_ON`, delays, then clears the reset bits and sets `CSM_ON`.
3. Clocks: write `CLK_MANAGER1` (`0x01`) ← `0x3F` (MCLK from the pin, MCLK on, BCLK on, ADC and DAC clocks on; `0xBF` when the SCLK pin supplies the master clock); write `0x02`, `0x03`, `0x04`, `0x05`, `0x06`, `0x07`, `0x08` for the chosen MCLK / sample rate (preset table above or the computed dividers). Default for Minimal: MCLK 12.288 MHz, 48 kHz → `0x02` = `0x00`, `0x03` = `0x10`, `0x04` = `0x10`, `0x05` = `0x00`, `0x06` = `0x03`, `0x07` = `0x00`, `0x08` = `0xFF`; ADC scale `0x16` = `0x04`.
4. Serial format: write `SDP_IN` (`0x09`) and `SDP_OUT` (`0x0A`) ← `0x0C` (I²S, 16-bit, normal polarity). 24-bit is `0x00`; the format and word length are the only differences between the common configurations.
5. Power / analog path **(vendor)**: `0x0D` ← `0x01` (analog circuits, bias and references on, VMID = start-up normal), `0x0E` ← `0x02` (PGA and ADC modulator powered on, modulator not in reset), `0x12` ← `0x00` (DAC / output on), `0x13` ← `0x10` (output drive on), `0x1C` ← `0x6A` (ADC EQ bypass, HPF dynamic, stage-2 coefficient `0x0A`), `0x37` ← `0x08` (DAC EQ bypass). The guide's own power table says `0x0D` bits = 0 enable the circuits; `0x0E` bits 6 and 5 = 0 enable the PGA and ADC modulator.
6. Analog input **(vendor values for the defaults)**: `0x14` ← `0x1A` (analog microphone `MIC1P` / `MIC1N`, PGA gain 30 dB is `0x1A`; the Minimal default is 24 dB = `0x18`), `0x17` ← `0xBF` (ADC volume 0 dB), `0x32` ← `0x00` (DAC muted at −95.5 dB until `set_volume` is called).
7. Wait for VMID to settle (the guide gives no value; the vendor driver does not wait explicitly).

## Implementation Stages

Each chip is implemented in two stages. The Full class extends Minimal — it inherits everything and adds the rest.

### Minimal

Goal: bring the codec up for voice playback and recording with sensible defaults, and let the application set output volume, mute and microphone gain. No audio data flows through the control port; the application provides the I²S stream (MCLK, BCLK, LRCK, DSDIN, ASDOUT) separately.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection, mclk_hz=12288000, sample_rate_hz=48000 | — | Runs the Initialization Sequence (reset, clocks for the given MCLK / sample rate, I²S 16-bit slave, analog path, analog microphone 24 dB, ADC 0 dB, DAC volume −95.5 dB); raises if the MCLK : fs combination has no valid divider set |
| `set_volume` | db: float | — | DAC digital volume, −95.5 … +32 dB in 0.5 dB steps (`0x32`), rounded to the nearest step |
| `set_mute` | muted: bool | — | Mutes / unmutes the DAC (`0x31` bits 6 and 5, DSM and DEM mute together) |
| `set_mic_gain` | db: float | — | Analog microphone PGA gain 0 … 30 dB in 3 dB steps (`0x14` bits 3:0), rounded to the nearest step |

**Sensible defaults baked into Minimal:** slave serial port (`MSC` = 0), I²S format, 16-bit word length, normal LRCK polarity, MCLK from the MCLK pin at 256 × fs, single-speed ADC at OSR 64, ADC scale 24 dB, ADC HPF dynamic, ADC / DAC equalizers bypassed, ALC / automute / DRC off, soft ramps off, analog differential microphone `MIC1P` / `MIC1N` with 24 dB PGA gain, ADC volume 0 dB, DAC volume −95.5 dB (silent until `set_volume`), no ADC-to-DAC loopback.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |

## Data Conversion

```
dac_volume_reg  = clamp(round(db / 0.5) + 191, 0, 255)        # 0x00 = -95.5 dB, 0xBF (191) = 0 dB, 0xFF = +32 dB
volume_db       = (reg - 191) * 0.5                            # same for the ADC volume register 0x17
pga_gain_reg    = round(db / 3)                                # 0..10 = 0..30 dB
adc_scale_db    = 6 * ADC_SCALE                                # 0..7 -> 0..42 dB
alc_level_db[n] = [-30.1, -24.1, -20.6, -18.1, -16.1, -14.5, -13.2, -12.0,
                   -11.0, -10.1, -9.3, -8.5, -7.8, -7.2, -6.6, -6.0][n]
noise_gate_db[n]= [-96, -90, -84, -78, -72, -66, -60, -54, -51, -48, -45, -42, -39, -36, -33, -30][n]
ramp_step       = 0.25 dB per 2**(rate + 1) LRCK periods       # rate 1..15
eq_coefficient  = 30-bit register value (B0, A1, A2, B1, B2 in the ADC EQ; B0, B1, A1 in the DAC EQ)
```

Clock arithmetic:

```
imclk      = mclk_hz / (DIV_PRE + 1) * (1, 2, 4, 8)[MULT_PRE]
adc_clk    = imclk / (DIV_CLKADC + 1);   dac_clk = imclk / (DIV_CLKDAC + 1)
ratio      = adc_clk (or dac_clk) / sample_rate_hz            # must be an allowed ratio (see Clock registers)
osr_single = adc_clk / sample_rate_hz / 8   ;   osr_double = adc_clk / sample_rate_hz / 4   # must be >= 15 / >= 16
bclk       = imclk / bclk_divider(DIV_BCLK) ;   lrck = imclk / (DIV_LRCK + 1)    # master mode
```

## Timing Constraints

- **Reset sequence:** set all reset bits and clear `CSM_ON`, then delay "several milliseconds" before releasing the resets and setting `CSM_ON` (guide §9.1). The vendor driver uses 20 ms; the driver uses 20 ms. Not conformance-checked: the guide gives no number.
- **Power-down:** set all reset bits to 1 and clear `CSM_ON` (and the `0x0D` / `0x0E` power-down bits) to minimise standby power.
- **Clock limits:** pre-divider output < 10 MHz at DVDD = 3.3 V (< 4.5 MHz at 1.8 V); internal ADC / DAC clock < 35 MHz at 3.3 V (< 13 MHz at 1.8 V); MCLK : LRCK ratios as listed in Clock registers.
- **MCLK must be running** before `CSM_ON` is set and during any audio operation; MCLK is always an input (also in master mode).
- **Master mode:** `RST_MST` must be 0 and the clock manager must be running before BCLK / LRCK are output.
- **Fade / ramp:** the soft-ramp rate is 0.25 dB per 2^(n+1) LRCK periods; a 0.5 dB volume change at the slowest rate takes 2 × 65536 LRCK periods.
- **ALC / automute:** automute detection window 2048 × (n + 1) samples (42 ms … 688 ms at 48 kHz).
- **I²C:** < 400 kHz; ES8311 timing diagrams (Figures 12–13) are not quantified in the guide.

No timing constraint is conformance-checked (the guide gives no minimum delay), so there is no `specs/adc_dac/es8311_timing.conf` and no conformance checker.

## Implementation Notes

- **Register-addressed:** accept `RegisterConnection` (1-byte register address) and call `connection.read(reg, length)` / `connection.write(reg, data)` directly — no chip-local `_read_reg`/`_write_reg` and no `bus_type` branch (see `specs/feature_register_access_design.md`).
- **The user guide is incomplete:** it documents the clock manager, serial port, `0x0D`–`0x0F`, `0x14`–`0x1C`, the equalizer and the DAC registers, but not the start-up procedure, registers `0x04` (DAC OSR), `0x0B`–`0x0C`, `0x10`–`0x13`, or the chip ID registers. The driver uses the vendor reference-driver values for those (`0x0B` / `0x0C` ← `0x00`, `0x10` ← `0x1F`, `0x11` ← `0x7F`, `0x12` ← `0x00`, `0x13` ← `0x10`) and marks them in the register map. **These values were recalled from the Everest / Espressif reference driver, not from this PDF — verify on hardware (output enable, VMID start-up) before relying on them.** A wrong value in an undocumented register can leave the output silent.
- **Identity:** the vendor and Linux drivers read `0xFD` / `0xFE` and expect `0x83` / `0x11`; the user guide does not mention them, so `init` does not require them. A driver may log a warning if they differ but must not fail (both unconfirmed here).
- **Internal inconsistencies of the guide:** (1) `MCLK_SEL` is described as `Reg0x00.Bit[7]` in the text but listed in `Reg0x01.Bit[7]` in the register table — the driver uses `0x01` bit 7 (bit 7 of `0x00` is `CSM_ON`); (2) the MULT_PRE examples say "MULT_PRE = 1 gives ×1" while the register table says 1 = ×2 — the driver follows the register table and the preset table (`0x02` = `0x00` for 12.288 MHz / 48 kHz); (3) `0x0D` bit 2 `PDN_VREF` is described as "1 = enable" unlike the other PDN bits; (4) `0x1C` reset `0x4C` has `ADC_EQBYPASS` = 1, but the text calls the default state "normal"; (5) the 12 MHz rows of the clock table appear twice; (6) the 32-bit word length (`100`) is listed for 24-bit slots — the driver supports it but 24 / 16 are the tested modes.
- **Equalizer coefficients are 30-bit** big-endian across four registers (the first holds only bits 29:24); write them in one auto-incrementing burst of four bytes where the bus supports it; the guide does not say whether the address auto-increments, so fall back to four single-byte writes if the burst does not read back. Coefficients come from Everest's calculation tool (not public); the driver validates only the 30-bit range.
- **Volume ordering:** with ALC enabled the ADC volume register is the ALC maximum gain; with DRC enabled the DAC volume register is the DRC maximum gain. `set_volume(db)` at −95.5 dB (`0x00`) is not a mute — use `set_mute`.
- **Clock configuration:** `configure_clock` first tries the preset table (exact MCLK / fs match, using the first set for 12 MHz), then computes: for each `(DIV_PRE, MULT_PRE)` the internal clock must satisfy the pre-divider limit and give an allowed ratio; prefer ratio 256, then 384, 512, 768, 1024, 1536; set `DIV_CLKADC` = `DIV_CLKDAC` = 0 and `0x03` / `0x04` to OSR 64 (`0x10`) unless the ratio needs another OSR; raise a descriptive error if nothing fits. The 3.3 V limits are assumed (the driver does not know DVDD); a constructor option `dvdd_volts` (default 3.3) selects the 1.8 V limits.
- **Master mode:** `MSC` = 1 with `RST_MST` = 0; BCLK and LRCK dividers computed from the internal master clock (`DIV_BCLK` table, `DIV_LRCK` 12-bit); in slave mode `RST_MST` = 1 for minimum power.
- **No MICBIAS:** the ES8311 has no microphone-bias pin; use AVDD through an R-C filter (220 Ω + 1 µF) for electret microphones, or PVDD for a PDM microphone. The PDM interface uses `SCLK` as the microphone clock, so BCLK must be running and `BCLK_ON` = 1.
- **Digital microphone:** `DMIC_ON` = 1 selects `MIC1P` as DMIC data; the analog PGA is not used. The L/R pin of the microphone selects its channel; the data latch edge is `DMIC_SENSE`.
- **QFN-20 package:** only `MIC1P` / `MIC1N` and `OUTP` / `OUTN` are bonded out; `LINSEL` values selecting `MIC2` are accepted by the register but have no input.
- **Supplies:** AVDD 1.7–3.6 V, DVDD and PVDD 1.6–3.6 V; decoupling 0.1 µF on every supply and 1 µF (min. 0.47 µF) on ADCVREF, DACVREF and VMID, ferrite beads on AVDD / DVDD; thermal pad to audio ground.
- **Not covered:** the audio stream (I²S / PCM), the equalizer coefficient calculation, and the undocumented registers beyond the vendor values above.
- **Siblings:** the ES8311 is not register-compatible with the ES8388 / ES7210 / ES8156; no compatibility is assumed.
- **Datasheet revision:** the committed document is "ES8311 User Guide (Rev 1.00)", Rev 1.11, September 2018, 31 pages, supplied by URL in the issue; it is a user guide, not the full datasheet (no electrical-characteristics or timing tables).

## Sigrok Decoder

Decoder id `es8311`, input `['i2c']`. Matches I²C addresses `0x18` and `0x19`. The decoder annotates every register of the register map by name (undocumented registers as `reg 0xNN`); decodes `RESET` (CSM_ON, master / slave, reset bits), `CLK_MANAGER1`–`8` (MCLK source and divider values), `SDP_IN` / `SDP_OUT` (format, word length, polarity, mute), `0x0D`–`0x0F`, `0x14` (input select, PGA gain in dB), `0x15`–`0x1C`, `0x31`–`0x37`, `0x44` into named fields; shows the volume registers `0x17` / `0x32` in dB; assembles the equalizer coefficient bursts (`0x1D`–`0x30`, `0x38`–`0x43`) as 30-bit values. A read of `0xFD` / `0xFE` is annotated as the chip ID. Warnings: a `RESET` write that sets `CSM_ON` while `CLK_MANAGER1` was last written with all clock enables off ("clocks off"); a `CLK_MANAGER3` write with an ADC OSR code of 0–14 (not allowed). No conformance annotations are emitted (no conformance-checked timing).
