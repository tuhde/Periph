# Chip Spec: ADS7828

**Manufacturer:** Texas Instruments (Burr-Brown)  
**Datasheet:** `datasheets/adc_dac/ads7828.pdf` (SBAS181C)  
**Category:** adc_dac  
**Transports:** I²C

## Overview

The ADS7828 is a single-supply, low-power, 12-bit successive-approximation ADC with an 8-channel input multiplexer, an internal 2.5 V reference (optional — an external reference of 50 mV … VDD can be used instead), an internal sample-and-hold and an I²C interface (standard, fast and high-speed modes), in a TSSOP-16. The multiplexer can be configured as 8 single-ended inputs (against a common COM pin) or 4 differential pairs (either polarity). A conversion takes 6 µs (up to 50 kSPS); the chip powers its converter down between conversions. Two address pins give four addresses. Typical uses: supply monitoring, remote/isolated data acquisition, transducer interfaces and battery-powered systems. There are no registers: one **command byte** selects the channel, input mode and power-down state and starts a conversion; the 12-bit result is read back as two bytes.

## Transport Configuration

### I²C
- **Address:** `0x48` (A1 = A0 = 0) — `0x49`, `0x4A`, `0x4B`; address byte `10010 A1 A0 R/W` (A1/A0 tied to GND or VDD; sampled at power-up)
- **Max clock:** standard 100 kHz, fast 400 kHz, high-speed 3.4 MHz. The drivers use ≤ 400 kHz; high-speed mode needs an Hs master code the connections do not send and is out of scope
- **Identity register:** none; chip has no ID register (`registry/chips.json` entry has `"id_probe": null`; the addresses `0x48`–`0x4B` coincide with the ADS1013/4/5, ADS1113/4/5 and PCF8591, none of which can be told apart)
- **Probe safety:** `write_sensitive` — a 1-byte write is a command byte that starts a conversion and can change the reference/power state (no register pointer)
- **Protocol:** no register addresses. **Conversion + read** is `[addr+W] [command byte] Sr [addr+R] [byte0] [byte1] P` — the repeated START after the command makes this a standard "register read" with the command byte as the register: `RegisterConnection.read(command, 2)`. Reading is only meaningful after a command has started a conversion

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| CH0–CH7 | — | Analog inputs (single-ended or paired differential) |
| COM | — | Common (negative) input for single-ended conversions |
| REFIN/REFOUT | — | Internal 2.5 V reference output (with 0.1 µF to GND, internal reference ON) or external reference input (0.05 V … VDD, internal reference OFF) |
| A0, A1 | — | Slave address bits; tie to GND or VDD |
| SDA, SCL | — | I²C; external pull-ups |
| VDD, GND | — | 2.7–5.25 V supply (use an external 5 V reference when VDD is 5 V) |

No interrupt or enable pin.

## Command Set

There are no registers. After the address byte (write), the master sends one **command byte**:

| Bit | 7 | 6 | 5 | 4 | 3 | 2 | 1 | 0 |
|-----|---|---|---|---|---|---|---|---|
| Name | SD | C2 | C1 | C0 | PD1 | PD0 | X | X |

The conversion starts when bit 4 (C0) has been received and the command byte is acknowledged. `X` bits are unused (write 0).

### SD — input mode
`1` = single-ended (CHn against COM), `0` = differential.

### C2:C0 — channel selection

| SD | C2 C1 C0 | Selected inputs |
|----|----------|-----------------|
| 0 (diff) | `000` | CH0 (+) / CH1 (−) |
| 0 | `001` | CH2 (+) / CH3 (−) |
| 0 | `010` | CH4 (+) / CH5 (−) |
| 0 | `011` | CH6 (+) / CH7 (−) |
| 0 | `100` | CH0 (−) / CH1 (+) |
| 0 | `101` | CH2 (−) / CH3 (+) |
| 0 | `110` | CH4 (−) / CH5 (+) |
| 0 | `111` | CH6 (−) / CH7 (+) |
| 1 (SE) | `000` | CH0 / COM |
| 1 | `001` | CH2 / COM |
| 1 | `010` | CH4 / COM |
| 1 | `011` | CH6 / COM |
| 1 | `100` | CH1 / COM |
| 1 | `101` | CH3 / COM |
| 1 | `110` | CH5 / COM |
| 1 | `111` | CH7 / COM |

The single-ended encoding is **interleaved**: channel `n` → `C = ((n & 1) << 2) | (n >> 1)`. Differential pair `p` (0–3 = CH(2p) − CH(2p+1)) → `C = p` (normal) or `C = 4 | p` (inverted polarity, CH(2p+1) − CH(2p)).

### PD1:PD0 — power-down

| PD1 PD0 | Meaning |
|---------|---------|
| `00` | Power down between A/D conversions (internal reference off) |
| `01` | Internal reference OFF, A/D converter ON |
| `10` | Internal reference ON, A/D converter OFF |
| `11` | Internal reference ON, A/D converter ON |

The internal reference is **off after power-up**. It is switched on by a command with PD1 = 1 followed by a STOP or repeated START; every later command with PD1 = 0 turns it off again, so use PD1 = 1 in every command while it is in use. After turning it on (or on again) wait for it to settle before a 12-bit-accurate conversion (datasheet plot "Internal VREF vs turn-on time": settling over a few hundred µs). With an **external** reference PD1 must be 0 and the reference must already be settled.

### Result format
Two bytes, MSB first: `byte0 = 0000 D11 D10 D9 D8`, `byte1 = D7…D0` — a 12-bit straight-binary code (differential results are also straight binary, 0 … VREF, never negative: the polarity bit of the command selects which input is positive).

## Initialization Sequence

1. At power-up the chip is idle with the internal reference off; no delay is specified.
2. **Internal reference (default):** write a lone command byte with PD = `10` (e.g. `0x08`), STOP, then wait ≥ 1 ms (conservative settling; the datasheet gives only a plot) before the first conversion.
3. **External reference:** nothing to do; all commands use PD1 = 0 and the reference must already be stable.
4. `init` stores the connection and the reference choice; it sends step 2 when the internal reference is selected.

### Conversion sequence (all `read_*` methods)
1. `connection.read(command, 2)` — write command byte, repeated START, read two bytes (the 6 µs conversion has finished before the first data byte at ≥ 100 kHz).
2. `raw = ((byte0 & 0x0F) << 8) | byte1`.

## Implementation Stages

### Minimal

Goal: read the eight input channels as voltages with one call each, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection, `vref: float \| None = None` | — | `None` = use the **internal 2.5 V reference** (needs the REFIN/REFOUT pin decoupled with 0.1 µF and nothing else driving it; runs init step 2); a number = external reference voltage in volts (0.05 … VDD) with internal reference OFF |
| `read_raw` | `channel: int` (0–7) | `int` (0–4095) | Single-ended CHn against COM (`SD` = 1); clamps `channel` to [0, 7]; command PD = `11` with the internal reference, `00` with an external one |
| `read_voltage` | `channel: int` (0–7) | `float` V | `raw / 4096 × vref` |
| `read_all` | — | `list[float]` (8 values) | Voltage of CH0…CH7, one conversion each |

**Sensible defaults:** internal 2.5 V reference (LSB 610 µV, full scale 0 … 2.5 V), single-ended inputs against COM, PD = `11` with the internal reference (kept on between conversions) or `00` with an external reference.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `read_differential_raw` | `pair: int` (0–3), `inverted: bool = False` | `int` (0–4095) | `SD` = 0; positive input is CH(2·pair), or CH(2·pair+1) when `inverted`; a negative differential voltage reads 0 |
| `read_differential` | `pair: int`, `inverted: bool = False` | `float` V | `raw / 4096 × vref` |
| `read_signed_differential` | `pair: int` | `float` V | Two conversions (normal and inverted) → `V(CH2p) − V(CH2p+1)`, range −vref … +vref |
| `set_reference` | `vref: float \| None` | — | Switch between the internal reference (`None`, re-runs the turn-on and settle wait) and an external one (`float` volts, PD1 = 0 from then on) |
| `get_reference` | — | `float` V | Current reference voltage used for scaling (2.5 for the internal one) |
| `uses_internal_reference` | — | `bool` | `True` while the internal reference is selected |
| `set_power_mode` | `pd: int` (0–3) | — | PD bits used in all following conversion commands (`POWER_DOWN_BETWEEN`=0, `REF_OFF_ADC_ON`=1, `REF_ON_ADC_OFF`=2, `REF_ON_ADC_ON`=3); with the internal reference selected, values with PD1 = 0 raise (they would turn the reference off) |
| `power_down` | — | — | Sends a lone command with PD = `00` — full power-down (≈ 400 nA); with the internal reference this turns it off, so the next read re-runs the turn-on and settle wait automatically |
| `read_scan` | `channels: list[int]` | `list[int]` | Raw single-ended conversions of the given channels in order, one command/read pair each |
| `lsb` | — | `float` V | `vref / 4096` |

**Additional configuration options:** single-ended or differential inputs (both polarities), internal or external reference, power-down mode, reference voltage for scaling.

## Data Conversion

```
raw    = ((byte0 & 0x0F) << 8) | byte1            # 0..4095, straight binary
lsb    = vref / 4096                              # 610 µV at 2.5 V, 1.22 mV at 5 V
V_in   = raw * lsb                                # CHn - COM (single-ended) or +IN - -IN (differential, >= 0)

command byte = (SD << 7) | (C << 4) | (PD << 2)
  single-ended channel n :  SD = 1, C = ((n & 1) << 2) | (n >> 1)
  differential pair p    :  SD = 0, C = p            (CH2p+ / CH2p+1-)
  inverted pair p        :  SD = 0, C = 4 | p        (CH2p+1+ / CH2p-)
```

Examples: CH0 single-ended, internal reference ON (PD = `11`) → `0x8C`; CH1 → `0xCC`; CH7 → `0xFC`; pair 0 differential → `0x0C`.

## Examples

### Demo

**Eight-channel supply monitor.** Using the Full driver with the internal 2.5 V reference, scan CH0–CH7 once per second through `read_scan` (inputs behind 2:1 dividers for rails up to 5 V) and print a table of raw codes and voltages (after the divider ratio), keeping a running minimum/maximum per channel. Then read pair 0 with `read_signed_differential` (a bridge sensor on CH0/CH1) and print the signed millivolts, switch to an external 5.0 V reference with `set_reference(5.0)` for a second scan, and finish with `power_down()`.

## Timing Constraints

- **Conversion time:** 6 µs (50 kSPS max) after the command byte is acknowledged — shorter than the gap before the first data byte at I²C rates ≤ 400 kHz, so no driver wait; in high-speed mode the chip stretches SCL until the conversion is done (not used here).
- **Internal reference turn-on:** starts at the STOP / repeated START following a command with PD1 = 1; settling to 12-bit accuracy takes a few hundred µs (datasheet plot, no table value). The driver waits ≥ 1 ms after enabling it (conservative, derived) — also after `power_down()` or `set_reference(None)`.
- **Power:** quiescent 150 µA at 100 kHz, 300 µA at 400 kHz (3.75 mW at 3.4 MHz); internal reference ON adds ≈ 1.3 mA; full power-down 400 nA typical (SCL/SDA high).
- **I²C:** per mode (100 kHz / 400 kHz / 3.4 MHz) — see the datasheet bus timing table; clock-rate properties, not event-to-event delays.
- **Conformance:** none of these has a bus-decodable start/end annotation pair (the conversion time is shorter than any bus gap and the reference settling has no tabulated limit), so `specs/adc_dac/ads7828_timing.conf` defines no checks.

## Implementation Notes

- **Command byte as the "register":** `connection.read(command, 2)` on a `RegisterConnection` issues exactly the datasheet's write-command / repeated-START / read sequence (Figure 3); no chip-local `_read_reg`/`_write_reg`, no `bus_type` branch (see `specs/feature_register_access_design.md`). A STOP instead of the repeated START is also legal but leaves the ADC converting for nothing.
- **Read only after a command:** a read without a preceding command byte returns stale data (the converter is idle); always send the command in the same transaction.
- **Interleaved channel codes:** CH0, CH2, CH4, CH6 are codes 0–3 and CH1, CH3, CH5, CH7 are 4–7 in single-ended mode — do not use `C = n`.
- **Reference management:** with the internal reference every conversion command must carry PD1 = 1, otherwise the reference switches off and the next conversion is inaccurate until it settles again. The driver therefore forces PD = `11` with the internal reference. With a VDD of 5 V the internal 2.5 V reference limits the range to half of VDD; use an external reference up to VDD for full range.
- **Do not drive REFIN/REFOUT with the internal reference on:** the pin is an output (110 Ω) then; external references require PD1 = 0.
- **Differential results are unsigned:** code 0 means the negative input is above (or equal to) the positive one; the inverted-polarity encoding is the only way to measure the other sign (hence `read_signed_differential`).
- **Input range:** analog inputs −0.2 V … VDD + 0.2 V (negative input −0.2 … +0.2 V in differential mode); full-scale input span = VREF.
- **Address overlap:** `0x48`–`0x4B` is shared with the ADS1x1x and PCF8591 families; the ADS7828's command-byte protocol is different from all of them, so wrong-chip access returns meaningless data rather than an error.
- **Datasheet:** SBAS181C, downloaded from `https://www.ti.com/lit/ds/symlink/ads7828.pdf`.

## Sigrok Decoder

Decoder id `ads7828`, input `['i2c']`. Matches I²C addresses `0x48`–`0x4B`. Decodes every command byte (write) into input mode (`SE`/`DIFF`), channel or differential pair with polarity (e.g. `CH3/COM`, `CH2+ CH3−`), and power-down mode (reference/ADC state); flags a warning for command bytes with the unused `X` bits set. No timing annotation pair is emitted (the reference-settling time has no tabulated limit). A following 2-byte read is shown as the 12-bit code with the voltage at the 2.5 V internal reference (assuming it, since the decoder cannot see the external reference) and the channel taken from the last command; a read without a preceding command in the capture is flagged as stale data.
