# Chip Spec: HY3131

**Manufacturer:** HYCON Technology
**Datasheet:** `datasheets/adc_dac/hy3131.pdf` (DS-HY3131 V10, covers HY3130 and HY3131)
**Category:** adc_dac
**Transports:** SPI

## Overview

The HY3131 is a 5,000/50,000-count digital-multimeter analog front end. It integrates a 24-bit high-resolution sigma-delta ADC (AD1, ~5 Hz output rate at the default clock), two 19-bit high-speed sigma-delta ADCs (AD2/AD3) feeding a digital low-pass filter, a true-RMS converter, a peak-hold unit, a programmable analog switch network (PA0–PA9, PB0–PB8) for voltage/resistance/capacitance/diode ranging, two op-amps, a comparator, a voltage reference generator, a temperature sensor and a 24-bit frequency/duty counter. It talks to the host over a 4-wire SPI with an unusual protocol (7-bit address, R/W bit, one blank turnaround bit on reads, address auto-increment).

This spec covers the **HY3131** (24-bit AD1, 19-bit AD2 **and** AD3, power measurement). The HY3130 is the cheaper 16-bit variant (no AD3, `SPHACAL` unused); it is register-compatible for AD1/AD2 but is **not** supported by this driver (its data is left-aligned in the same registers — see Implementation Notes).

The driver exposes the chip as a **measurement engine**, not a complete DMM: the analog switch network and op-amps are wired to a board-specific range network, so Minimal reads AD1 as a plain differential voltage input and Full exposes the registers needed to build range logic on top (input/reference muxes, gains, AD2/LPF/RMS/peak, counter, interrupt flags, raw register access).

## Transport Configuration

### SPI
- **Mode:** CPOL=0 CPHA=0 (Mode 0) — CK idles low and must be low before CS falls (§7.2 (6)); data is latched on the rising (effective) edge and DO/DI change when CK returns to idle (§7.2 (7)(8))
- **Max clock:** 4 MHz recommended (T_CKHI ≥ 20 ns + T_CKLO ≥ 60 ns → period ≥ 80 ns → 12.5 MHz absolute from the pulse widths; the datasheet gives no SPI clock limit, and DO needs T_DODL ≤ 60 ns, so the driver recommends ≤ 4 MHz for margin on wiring)
- **Bit order:** MSB first
- **CS active:** low
- **Register addressing:** non-standard — the driver uses the bare `Connection`, **not** `RegisterConnection` (see Implementation Notes): first byte is `(addr << 1) | R/W` (R/W = 1 read); reads insert one blank clock after the command byte; addresses auto-increment while CS stays low

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| CS  | low | SPI chip select; while CS is high, DO doubles as the IRQ output |
| CK / DI / DO | — | SPI clock / MOSI / MISO |
| DO (IRQ mode) | high | With CS high, DO high = interrupt pending (an enabled `INTE` source set its `INTF` flag). Optional — the driver never needs it, it polls `INTF` over SPI. |
| XIN / XOUT | — | 4.9152 MHz crystal (internal oscillator enabled via `ENOSC`) or external clock into XIN (`ENXI=1`) |
| CNT / CMP | — | Frequency-counter input / comparator output (see Frequency Counter) |

Supply is 3.6 V ±0.05 V (VDD and VDDA); the part resets when VDD < 1.9 V. SPI levels must be 3.3–3.6 V — **no 5 V logic**.

### Bit Fields

#### `R22` (`0x22`) — AD1 offset / chop / OSR

| Bits | Name | Description |
|------|------|-------------|
| 7:5 | AD1OS | DC offset shift `DCOS`: 000=0, 001=+0.25, 010=+0.5, 011=+0.75, 100=0, 101=−0.25, 110=−0.5, 111=−0.75 |
| 4:3 | AD1CHOP | `00` = no chop (result VX+VOS), `01` = inverted chop (VX−VOS), `1x` = chop on (offset cancelled, **output rate halved**) |
| 2:0 | AD1OSR | OSR1 = 256, 512, 1024, 2048, 4096, 8192, 16384, 32768 for 0–7 |

AD1 output rate = F_SYSCLK / 30 / OSR1 (4.9152 MHz → 163.84 kHz modulator clock → 640, 320, 160, 80, 40, 20, 10, 5 Hz).

#### `R23` (`0x23`) — AD1 front end

| Bits | Name | Description |
|------|------|-------------|
| 7 | ENAD1 | 1 = enable AD1 (0 also clears `AD1<23:0>`) |
| 6:5 | — | write 0 |
| 4 | AD1RG | Reference gain: 0 → 1.0, 1 → 0.333 |
| 3 | AD1RHBUF | Buffer on reference high |
| 2 | AD1RLBUF | Buffer on reference low |
| 1 | AD1IPBUF | Buffer on positive input |
| 0 | AD1INBUF | Buffer on negative input |

#### `R24` (`0x24`) — AD1 filter mux

| Bits | Name | Description |
|------|------|-------------|
| 7:4 | SAD1FP | Filter positive input: 0 SENSE, 1 FB, 2 RLU, 3 OP1O, 4 OP2O, 5 VDDA, 6 REFO, 7 VREF, 8–15 PB0–PB7 |
| 3 | SDIO | PB0/PB8 digital I/O control (leave 0) |
| 2:0 | SAD1FN | Filter negative input: 0 SENSE, 1 RLU, 2 VSSA, 3 AGND, 4 PB2, 5 PB3, 6 PB4, 7 PB5 |

#### `R25` (`0x25`)

| Bits | Name | Description |
|------|------|-------------|
| 7:6 | AD2IG | AD2 input gain: 0.5, 1.0, 1.5, 2.0 |
| 5:4 | AD1IG | AD1 input gain: 0.9, 1.8, 2.7, 3.6 |
| 3:2 | SACM | ACM (common-mode) voltage; recommended ≈1.5 V — the code→voltage table is not in the datasheet, driver writes `0b00` and exposes the field raw |
| 1:0 | OPS<2:1> | Op-amp negative input select (leave 0) |

#### `R26` (`0x26`) — AD2

| Bits | Name | Description |
|------|------|-------------|
| 7 | ENAD2 | Enable AD2 |
| 6 | — | write 0 |
| 5 | ENCHOPAD2 | AD2 input chopper |
| 4 | AD2RG | AD2 reference gain: 0 → 1.0, 1 → 0.333 |
| 3 | SAD2CLK | AD2/AD3 modulator clock: 0 → SYSCLK/2, 1 → SYSCLK/4 |
| 2:0 | AD2OSR | OSR2/OSR3 = 32, 64, 128, 256, 512, 1024, 1024, 1024; output rate = F_AD2CLK / OSR |

#### `R27` (`0x27`) — AD2 mux
`7:6 SAD2IP` (OP1O, OP2O, PB4, PB7) · `5:4 SAD2IN` (RLU, AGND, PB3, PB5) · `3:2 SAD2RH` (FB, REFO, VREF, PB6) · `1:0 SAD2RL` (RLU, AGND, PB3, PB5)

#### `R28` (`0x28`) — AD1 reference mux
`6:4 SAD1RH` (FB, REFO, VREF, PB6, RLU, VDDA, AGND, —) · `2:0 SAD1RL` (RLU, AGND, PB3, PB5, FB, VSSA, VREF, —)

#### `R29` (`0x29`) — RMS / LPF / peak hold

| Bits | Name | Description |
|------|------|-------------|
| 7 | ENRMS | Enable RMS converter (0 clears `RMS`) |
| 6 | ENLPF | Enable low-pass filter (0 clears `LPF`) |
| 5:3 | LPFBW | OSR4 = 128, 256, 512, 1024, 2048, 4096, 8192, 16384; LPF/RMS rate = AD2 rate / OSR4 |
| 2 | ENPKH | Enable peak hold (0 clears the min/max registers) |
| 1:0 | PKHSEL | Peak-hold source: AD2, AD1<23:5>, LPF, LPF |

#### `R31` (`0x31`) — reference
`7 ENREFO` (bandgap + REFO buffer) · `6 ENBIAS` (analog bias, **required for any ADC**) · `5:4 SAGND` (AGND level; `11` = external AGND) · `3:0 SFUVR` (OP3 fixed-voltage select)

#### `R30` (`0x30`)
`7 SREFO` (0 = bandgap ≈1.2 V, 1 = PB6) · `6:0 ACC` (capacitor array, 0.2 pF × 2ⁿ per bit)

#### `R33` (`0x33`)
`7:6 OP1CHOP` · `5 ENOSC` (crystal oscillator) · `4 ENXI` (0 = crystal, 1 = XIN as SYSCLK) · `3:2 SFT1` (filter resistor: 100 kΩ, 10 kΩ, 0 Ω, none) · `1:0 SAD1I` (AD1 input: 00 = filter outputs, 01 = FB/RLU, 10 = TS1P/TS2N, 11 = TS1N/TS2P)

#### `R34` (`0x34`) / `R35` (`0x35`) — AD3 (HY3131)
`R34`: `7 ENAD3`, `5 ENCHOPAD3`, `4 AD3RG`, `3 SVXI`, `2 SDO23` (1 = AD2/LPF/RMS registers show AD3 instead of AD2). `R35`: `7:6 SAD3IP`, `5:4 SAD3IN`, `3:2 AD3IG` (0.5/1.0/1.5/2.0). Other bits write 0.

#### `INTF` (`0x1E`) / `INTE` (`0x1F`)

| Bit | INTF | INTE | Meaning |
|-----|------|------|---------|
| 7 | BORF | — | VDD fell below 1.9 V (brown-out) |
| 4 | RMSF | RMSIE | RMS result updated |
| 3 | LPFF | LPFIE | LPF result updated |
| 2 | AD1F | AD1IE | AD1 conversion done |
| 1 | AD2F | AD2IE | AD2/AD3 conversion done |
| 0 | CTF | CTIE | Frequency-counter measurement done |

`INTF` bits set regardless of `INTE`; `INTE` only gates the DO IRQ. Reading `INTF` clears it — so a poll loop that reads it must keep **all** flags it saw.

#### `R20` (`0x20`) and `CTSTA` (`0x14`)
`R20`: `7:5 SCMPI` (comparator input select), `4 ENCMP`, `3 ENCNTI` (CNT buffer = counter source), `2 ENPCMPO`, `1 ENCTR` (start/clear frequency counter), `0` write 0. `CTSTA`: `7 PCNTI` (CNT pin level), `6 ACPO`, `5 CMPHO`, `4 CMPLO`, `0 CTBOV` (CTB overflow — measurement invalid).

## Initialization Sequence

1. Write `0x60` to `R37` (software reset); wait ≥ 5 ms
2. Write `R33 = ENOSC(0x20)` with `SFT1 = 10b` (bypass filter resistor) and `SAD1I = 00b` → `0x28`; wait for oscillator start-up (≥ 10 ms; crystal start-up is not specified)
3. Write `R31 = ENBIAS | ENREFO` (`0xC0`, `SAGND=00`, `SFUVR=0`) and `R30 = 0x00` (`SREFO=0`: REFO from the 1.2 V bandgap); wait ≥ 5 ms for the 0.1 µF REFO/AGND/ACM capacitors to settle
4. Write `R2F = ENVS` (`0x80`) and zero the switch network `R2A`–`R2E`, `R32`, `R20`, `R21`, `R34`, `R35`, `R36`
5. Write AD1 muxes: `R24` (`SAD1FP`, `SAD1FN`), `R28` (reference), `R25` (`AD1IG`)
6. Write `R22` (OSR/chop/offset), then `R23` with `ENAD1 = 1` last
7. Clear `INTF` by reading it, then poll `AD1F` for the first result (the first conversion needs 1/rate, plus one extra period when chopping)

**Do not toggle AD1 or AD2/AD3 while the other is running** (datasheet footnote: different AD1 offsets result) — enable all needed ADCs together, before reading.

## Implementation Stages

### Minimal

Goal: read AD1 as a differential voltage, no configuration. Class `HY3131Minimal(connection, vref=1.2)`.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` (constructor) | connection | — | Runs the init sequence below with defaults |
| `read_voltage` | — | float V | Waits for `AD1F`, reads AD1, converts with the Data Conversion formula |
| `read_raw` | — | int | Signed 24-bit AD1 code |
| `data_ready` | — | bool | Reads `INTF`; remembers (latches) the flags so a following `read_*` still sees `AD1F` |

**Sensible defaults baked in:** crystal oscillator enabled (4.9152 MHz), bandgap reference 1.2 V on REFO (`vref` parameter documents the actual REFO voltage), AD1 input = `PB2` (+) vs `AGND` (−) with filter resistor bypassed, AD1 reference = REFO / AGND, `AD1IG = 0.9`, `AD1RG = 1.0` (full scale ±1.333 V), all buffers off, no chop, `DCOS = 0`, `OSR1 = 32768` (5 Hz, best resolution). Runtime ≈ 200 ms per sample, so `read_voltage` times out after 2 s and raises/returns an error per language convention.

## Data Conversion

```
AD1 code (signed 24-bit)        = 2^23 · ( IG·VIN/VR + DCOS ) / RG      (VIN = AD1IP−AD1IN, VR = AD1RH−AD1RL)
VIN [V]                         = ( code/2^23 · RG − DCOS ) · VR / IG
AD2/AD3 code (signed 19-bit)    = 2^18 · IG2·VIN/(RG2·VR)               (no DCOS)
LPF                             = same scale as AD2
RMS_reg (signed 38-bit)         = Σ x² / N   (N = OSR4), x in AD2 LSB; rms [LSB] = sqrt(RMS_reg)
Temperature [°C]                = (TCode / G) − 273.15 − T_os,  G = (TCode@25°C) / (25 + 273.15 + T_os),  T_os ≈ −3.15 K
TCode                           = ( AD1[SAD1I=11b] − AD1[SAD1I=10b] ) / 2
```

Two's complement: 24-bit AD1 `0x7FFFFF` max / `0x800000` min; AD2/LPF/PKH 19-bit max `0x03FFFF` / min `0xFC0000`; registers are sign-extended into 24 bits, so a plain 24-bit sign-extend works. RMS is a 40-bit register: assemble 5 bytes LSB first, sign-extend from bit 39. Use 64-bit-safe arithmetic in every language (Java/Kotlin/Groovy `long`, C++ `int64_t`, JS `BigInt` or `Number` (≤ 2⁵³ is sufficient) — and **cast to `double`/`long` before multiplying** to avoid int overflow).

**Open assumption:** the datasheet publishes the transfer function only as a figure; the `2^23` full-scale constant is inferred from the documented `7FFFFFh` / `800000h` limits and must be confirmed on hardware before 50,000-count claims are made.

## Implementation Notes

- **SPI framing.** One transaction: `[ (addr<<1)|R/W ] [data…]`. On **reads** the 9th clock is a blank turnaround, so the response is shifted left by one bit: the response bit stream after the command byte is `X d7 d6 … d0 e7 …` — each data byte is `((rx[i] << 1) | (rx[i+1] >> 7)) & 0xFF` over the full-duplex bytes following the command byte, and a read of N data bytes needs N+1 clocked bytes after the command. On **writes** there is no gap. Because of this the driver uses the bare `Connection` full-duplex transfer and does not use `RegisterConnection`.
- Auto-increment lets a multi-byte AD1 read (`0x00`–`0x02`) be one transaction; always read all three bytes in one CS cycle, otherwise a conversion update between reads yields torn values.
- Reading `INTF` clears it; the driver must latch the flags it reads and never discard them (see `data_ready`).
- Chopping (`AD1CHOP=1x`) halves the output rate; the first sample after any configuration change after enabling is the settled value only after one extra period — discard it or wait 2 periods.
- `CTA<23:8>` can only be written while `ENCTR=0`.
- The HY3130 shares addresses but left-aligns its data (AD2 `<18:3>`, RMS `<37:6>` valid), so HY3130 support would need a different conversion; not implemented here.
- The datasheet gives no register reset values, so no assumptions about power-on state are made; the init sequence writes every used register.

## Sigrok Decoder

Decoder id `hy3131` (`sigrok/hy3131/`), stacking on the `spi` decoder, input `['spi']`. Decodes each CS frame: command byte (address, R/W), the one-bit read gap, and the data bytes shifted into the register fields. Annotates AD1/AD2/LPF/PKH 24-bit values (decoded to signed codes), `INTF`/`INTE` flags by name, `R22`/`R23`/`R25`/`R26`/`R29`/`R33` fields (OSR, gains, enables), software reset (`R37=0x60`), and warnings on writes to `R37` other than `0x00`/`0x60`. The `timing` row emits `spi_cs_start` / `spi_cs_end` markers per CS frame for the conformance checker.
