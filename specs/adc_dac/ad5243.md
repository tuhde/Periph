# Chip Spec: AD5243

**Manufacturer:** Analog Devices  
**Datasheet:** `datasheets/adc_dac/ad5243.pdf` (shared AD5243 / AD5248 datasheet, Rev. C)  
**Category:** adc_dac  
**Transports:** I²C

## Overview

The AD5243 is a dual, 256-position, I²C-controlled digital potentiometer in a 10-lead MSOP. Each channel is a full 3-terminal potentiometer (A, W, B) usable as a voltage divider or as a 2-terminal rheostat. The I²C address is fixed at `0x2F` (no address pins), so only one AD5243 fits on a bus. End-to-end resistance RAB is ordered as 2.5 kΩ, 10 kΩ, 50 kΩ or 100 kΩ; the wiper powers up at midscale. Typical uses are calibration, level setting, trimmer replacement and gain/offset adjustment.

The AD5243 and AD5248 share one datasheet and register interface but are tracked as two chips. This spec covers only the AD5243; its sibling AD5248 has its own spec (`specs/adc_dac/ad5248.md`). Wiper values are **volatile** — there is no EEPROM, so the setting is lost at power-down (keep VDD applied, or restore it from the host after reset).

## Transport Configuration

### I²C
- **Address:** `0x2F` only (7-bit address `0101111`, i.e. address byte `0101 1 1 1` + R/W; fixed, no address pins — the same value as an AD5248 with AD1 = AD0 = 1, so the two cannot share a bus)
- **Max clock:** 400 kHz (fast mode)
- **Identity register:** none; chip has no ID register (`registry/chips.json` entry has `"id_probe": null`)
- **Probe safety:** `write_sensitive` — a 1-byte write is an instruction byte (`A0` channel select, `SD` shutdown bit), not a register pointer; a bare write of a byte with `SD` = 1 would shut a channel down
- **Protocol:** no register addresses. A write transaction is `[addr+W] [instruction] [data]`; a read transaction is `[addr+R] [data]`. The `RegisterConnection` is used with the instruction byte as the "register" (`connection.write(instruction, bytes([code]))`, `connection.read(instruction, 1)`)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| A1, W1, B1, A2, W2, B2 | — | Potentiometer terminals of channel 1 and 2; voltage range GND to VDD |
| SDA, SCL | — | I²C; external pull-ups required |

There is no reset, interrupt or enable pin. Power VDD/GND before any signal on A, B, W (ESD diodes clamp to the rails).

## Register Map

The chip has no register map. Each channel has one 8-bit **RDAC** wiper register, selected by the instruction byte.

| Instruction `A0` | RDAC | R/W | Reset | Description |
|------------------|------|-----|-------|-------------|
| `0` | RDAC1 | R/W | `0x80` | Channel 1 wiper position |
| `1` | RDAC2 | R/W | `0x80` | Channel 2 wiper position |

### Bit Fields

#### Instruction byte (write mode, first byte after the address)

| Bits | Name | Description |
|------|------|-------------|
| 7    | A0 | RDAC subaddress: `0` = channel 1, `1` = channel 2 |
| 6    | SD | Shutdown: `1` opens terminal A and shorts the wiper to B (≈ 0 Ω rheostat / 0 V divider) without changing the RDAC contents; `0` = normal |
| 5:0  | X | Don't care — write `0` |

#### Data byte

| Bits | Name | Description |
|------|------|-------------|
| 7:0  | D[7:0] | Wiper position 0–255 (`0x00` wiper at B, `0xFF` at A) |

**Repeated write:** after the instruction byte, every further data byte in the same transaction updates the selected RDAC. **Read:** a read transaction returns the RDAC of the channel selected by the **most recent write-mode instruction byte**; to read the other channel, send an instruction byte alone (no data byte — the datasheet says the data frame is not required before a readback) and then read. Reads are repeatable within one transaction.

## Initialization Sequence

1. At power-up both wipers are preset to midscale (`0x80`); no delay is needed (settling 1 µs typical, 5 µs on power-up).
2. No initialization writes are required; `init` performs no I²C traffic and assumes both channels are not in shutdown.
3. Set the wiper with `[instruction, code]` writes.

## Implementation Stages

Each chip is implemented in two stages. The Full class extends Minimal — it inherits everything and adds the rest.

### Minimal

Goal: set and read back the wiper position or the wiper-to-B resistance of either channel.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection, `r_ab: float = 10000.0`, `r_wiper: float = 160.0` | — | Stores the connection and the part's end-to-end resistance RAB (Ω) and wiper resistance RW (Ω); no I²C traffic |
| `set_wiper` | `channel: int` (0–1), `code: int` (0–255) | — | Writes `[channel << 7, code]` (SD = 0); clamps `code` to [0, 255]; invalid `channel` raises |
| `get_wiper` | `channel: int` (0–1) | `int` (0–255) | Writes the instruction byte alone, then reads one byte; returns the RDAC value |
| `set_resistance` | `channel: int`, `ohms: float` | — | Sets the W–B rheostat resistance to the nearest code (inverse of the formula below), clamped to the reachable range |
| `get_resistance` | `channel: int` | `float` Ω | W–B resistance for the current code |

**Sensible defaults:** RAB = 10 kΩ, RW = 160 Ω (typical, 5 V); both channels at their power-up midscale until written. Both channels are assumed active (not in shutdown).

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `set_both` | `code1: int`, `code2: int` | — | Writes both wipers (two transactions) |
| `set_ratio` | `channel: int`, `ratio: float` (0.0–1.0) | — | Wiper at `round(ratio × 256)` clamped to 255 — divider ratio V(W−B)/V(A−B) in potentiometer mode |
| `get_ratio` | `channel: int` | `float` | `code / 256` |
| `set_resistance_wa` | `channel: int`, `ohms: float` | — | Sets the W–A resistance (rheostat mode with B open) to the nearest code |
| `get_resistance_wa` | `channel: int` | `float` Ω | `(256 − D)/256 × RAB + 2 × RW` |
| `increment` | `channel: int`, `steps: int = 1` | `int` | Reads the code, adds `steps` (negative to decrement), clamps to [0, 255], writes and returns the new code |
| `shutdown` | `channel: int` | — | Writes `[channel << 7 \| 0x40, current_code]`; terminal A opens and the wiper shorts to B; RDAC is kept |
| `resume` | `channel: int` | — | Writes `[channel << 7, current_code]` (SD = 0) |
| `is_shutdown` | `channel: int` | `bool` | Driver-tracked state (the chip cannot be read back); `False` after `init` and `reset` |
| `reset` | — | — | Writes `0x80` to both channels with SD = 0 (power-up preset); the chip has no reset pin or command |
| `set_rab` | `r_ab: float`, `r_wiper: float \| None = None` | — | Changes the resistance parameters used by the conversions (no I²C traffic) |

**Additional configuration options:**
- Per-channel shutdown; resistance model parameters (RAB, RW); ratio and increment helpers

## Data Conversion

```
R_WB(D) = D / 256 * RAB + 2 * RW                  # wiper to B, A open
R_WA(D) = (256 - D) / 256 * RAB + 2 * RW          # wiper to A, B open
V_W(D)  = D / 256 * V_A + (256 - D) / 256 * V_B   # divider mode

D = round((R - 2 * RW) / RAB * 256)               # inverse for R_WB, clamp 0..255
```

Example (RAB = 10 kΩ, RW = 160 Ω): `D` = 0 → 320 Ω, 1 → 359 Ω, 128 → 5380 Ω, 255 → 10 281 Ω (zero scale is **not** 0 Ω: keep wiper current ≤ 20 mA). Nominal RAB tolerance is ±20 % (10/50/100 kΩ) or −20 %/+55 % (2.5 kΩ), so absolute resistance is only approximate; ratios are accurate. The datasheet notes the shutdown state gives ≈ 0 Ω in rheostat mode.

## Timing Constraints

- **Wiper settling:** 1 µs typical (±1 LSB, VA = 5 V); **power-up settling:** 5 µs typical — below one I²C transaction, no driver delay needed.
- **I²C timing:** fSCL ≤ 400 kHz, tBUF ≥ 1.3 µs, tLOW ≥ 1.3 µs, tHIGH ≥ 0.6 µs (datasheet Table 3). Clock-rate properties, not event-to-event delays the driver controls.
- **Conformance:** none of these has a bus-decodable start/end annotation pair (settling is analog), so `specs/adc_dac/ad5243_timing.conf` defines no checks.

## Implementation Notes

- **Register-addressed wrapper:** accept `RegisterConnection` (not the bare `Connection`); the instruction byte plays the role of the register address — no chip-local `_read_reg`/`_write_reg` and no `bus_type` branch. See `specs/feature_register_access_design.md`.
- **Readback selects by last write instruction:** `get_wiper(channel)` must first send the instruction byte for that channel (alone), then read. Whether the datasheet intends a STOP or repeated START between the two is not stated; the driver should issue `connection.read(instruction, 1)` and, if the target platform's register read uses a repeated start and the part misbehaves, fall back to two transactions — verify on hardware.
- **Shutdown state is write-only:** the chip cannot report it, so the driver tracks it. The instruction byte for any later write or readback of a shut-down channel must keep `SD` = 1 or the channel leaves shutdown; `set_wiper` on a shut-down channel keeps `SD` = 1 (updates the RDAC without un-shutting it — datasheet: "new settings can be programmed during shutdown").
- **`shutdown` writes a data byte:** to avoid relying on an instruction-only write taking effect, `shutdown` / `resume` send the instruction together with the tracked current code (read it first if the driver does not know it, e.g. after power-up: midscale `0x80`).
- **Volatile:** no EEPROM; wipers are `0x80` after every power cycle. VDD must stay applied to retain the setting.
- **Terminal limits:** A, B, W must stay within GND…VDD; power VDD before the terminals.
- **Addressing:** the AD5243 has no address pins — a single part per bus. For several dual pots on one bus use the AD5248 (`specs/adc_dac/ad5248.md`), which has AD0/AD1.
- **Siblings:** the AD5243 and AD5248 may share a `_AD524xBase` (instruction encoding, readback, shutdown tracking, resistance conversion); the public APIs stay as specified per chip.
- **Datasheet:** AD5243/AD5248 Rev. C (2004–2016), supplied as an attachment to the issue.

## Sigrok Decoder

Decoder id `ad5243`, input `['i2c']`. Matches I²C address `0x2F`. For writes, decodes the instruction byte (channel from `A0`, `SD` flag) and the following data byte(s) as wiper code with the nearest-fraction `code/256` (assuming RAB is unknown, so no ohms are shown); several data bytes after one instruction are shown as successive updates of that channel. For reads, shows the returned RDAC value for the channel last selected by a write instruction. Flags a write longer than 2 bytes where data bytes follow an instruction with `SD` = 1, and a read with more than 1 byte, as warnings. Wiper settling has no digital completion event, so no timing annotation pair is emitted.
