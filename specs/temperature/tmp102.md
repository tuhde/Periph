# Chip Spec: TMP102

**Manufacturer:** Texas Instruments  
**Datasheet:** `datasheets/temperature/tmp102.pdf` (SBOS397I, June 2024)  
**Category:** temperature  
**Transports:** I²C

## Overview

The TMP102 is a two-wire digital temperature sensor with 12-bit (0.0625 °C) resolution, typical accuracy ±0.5 °C (±2 °C max, −25…85 °C), a 1.4–3.6 V supply and 10 µA-class current. It is register-compatible with the TMP75/LM75 family: a temperature register, a configuration register (shutdown, comparator/interrupt thermostat, polarity, fault queue, conversion rate, one-shot, extended 13-bit mode) and TLOW/THIGH limit registers driving an ALERT pin. Typical uses: board and enclosure temperature monitoring, thermal protection, portable devices.

## Transport Configuration

### I²C
- **Address:** `0x48` + A0 pin: GND → `0x48`, V+ → `0x49`, SDA → `0x4A`, SCL → `0x4B`
- **Max clock:** 400 kHz (fast mode); Hs-mode (master code) up to 2.85 MHz; SMBus timeout 30 ms typ.
- **Register access:** 8-bit pointer (bits 1:0 select the register, bits 7:2 must be 0); registers are 16 bit, MSB first; the pointer persists
- **General call:** `0x00` + `0x06` resets the device to power-up values
- **Identity register:** none (`id_probe: null` in `registry/chips.json`); the address range is shared with LM75B and TMP117 (TMP117 has an ID register).
- **Probe safety:** `register_pointer` — a one-byte write only moves the pointer.

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| ALERT | `POL` (low by default) | open-drain; pull-up required; thermostat output (also SMBus alert response) |
| ADD0 | — | address select (GND, V+, SDA, SCL) |
| SDA, SCL | — | I²C; open drain, pull-ups required |
| V+, GND | — | 1.4–3.6 V |

## Register Map

| Pointer | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | TEMPERATURE | R | `0x0000` | 12-bit (13-bit in extended mode) two's-complement result, left-justified in 16 bits |
| `0x01` | CONFIGURATION | R/W | `0x60A0` | Operating mode |
| `0x02` | T_LOW | R/W | `0x4B00` | Low limit (75 °C), same format as TEMPERATURE |
| `0x03` | T_HIGH | R/W | `0x5000` | High limit (80 °C), same format |

### Bit Fields

#### `CONFIGURATION` (`0x01`, 16 bit: byte 1 = bits 15:8, byte 2 = bits 7:0)
| Bits | Name | R/W | Description |
|------|------|-----|-------------|
| 15 | OS | R/W | One-shot: write 1 in shutdown to start a conversion; reads 0 while converting, 1 when done |
| 14:13 | R1:R0 | R | Converter resolution, always `11` (12 bit) |
| 12:11 | F1:F0 | R/W | Fault queue: `00` 1, `01` 2, `10` 4, `11` 6 consecutive faults |
| 10 | POL | R/W | ALERT polarity: `0` active low (default), `1` active high |
| 9 | TM | R/W | Thermostat mode: `0` comparator (default), `1` interrupt |
| 8 | SD | R/W | Shutdown: `1` = shut down after the current conversion |
| 7:6 | CR1:CR0 | R/W | Conversion rate: `00` 0.25 Hz, `01` 1 Hz, `10` 4 Hz (default), `11` 8 Hz |
| 5 | AL | R | Alert status (inverted by POL); comparator state, `1` until the temperature reaches T_HIGH (POL = 0) |
| 4 | EM | R/W | Extended mode: `0` 12-bit, `1` 13-bit (above 128 °C) |
| 3:0 | — | R | 0 |

Reset value `0x60A0`. Writes are byte by byte.

#### `TEMPERATURE` (`0x00`)
Byte 1 = T11…T4, byte 2 = T3…T0 in bits 7:4 (bits 3:0 = 0). In extended mode: byte 1 = T12…T5, byte 2 = T4…T0 in bits 7:3 and bit 0 = 1 (D0 = 1 indicates 13-bit format). After power-up/reset the register reads 0 °C until the first conversion completes (10 ms typ.).

## Initialization Sequence

1. Power up (V+ 1.4–3.6 V). The first conversion starts immediately; the first result is available after ≈ 10 ms typ. (15 ms max).
2. Read `TEMPERATURE` (pointer `0x00`, 2 bytes).
3. For one-shot use: write `CONFIGURATION` with SD = 1 (`0x6180`), then per measurement write OS = 1 (`0xE180`), wait ≥ 15 ms (or poll OS = 1) and read.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `ALERT`, open-drain, active low by default (`POL`) — requires an external pull-up |
| Level | 1 (single fixed condition) |
| Condition | temperature ≥ T_HIGH for `F1:F0` consecutive conversions |
| Clear mechanism | **Comparator mode (TM = 0):** inactive again once the temperature falls below T_LOW for the same number of faults. **Interrupt mode (TM = 1):** stays active until any register is read, the SMBus alert response is answered, or the device enters shutdown; re-arms when the temperature falls below T_LOW |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, int_pin=None)` | Subscribe on the ALERT output (active edge per `POL`) via `connection.int_pin` (or `int_pin`), otherwise a 1 s polling task calling `poll_interrupt`; `callback(temperature_c)` |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> bool` | Reads `CONFIGURATION`; returns `True` while the comparator state is alerting (`AL` bit corrected for `POL`) and reads `TEMPERATURE` to clear an interrupt-mode alert |

## Data Conversion

```
raw16 = (byte1 << 8) | byte2
if EM == 0:  raw = signed(raw16 >> 4, 12 bit)     # 0.0625 °C/LSB, range −128 … +127.9375 °C
if EM == 1:  raw = signed(raw16 >> 3, 13 bit)     # 0.0625 °C/LSB, range −256 … +255.9375 °C
temperature_c = raw * 0.0625
```

Limit registers use the same format: `reg16 = (round(celsius / 0.0625) << 4) & 0xFFF0` (normal mode) or `<< 3` (extended). Reset limits: T_HIGH `0x5000` = 80 °C, T_LOW `0x4B00` = 75 °C. The datasheet's operating range is −40…+125 °C.

## Implementation Notes

- **16-bit big-endian registers; pointer persists.** A `RegisterConnection` with `reg_bytes` = 1 and 2-byte reads.
- **Format tracking:** the driver must know EM to decode the temperature; bit 0 of byte 2 of `TEMPERATURE` (1 = extended) is a consistency check.
- **Read-modify-write:** the AL, R1:R0 bits are read-only; preserve R/W bits when writing (the reset value contains `R1:R0 = 11`).
- **One-shot** only works in shutdown; the driver puts the device in shutdown first if needed and restores the previous mode afterwards.
- **Interrupt mode cleanup:** any register read clears the pin; `poll_interrupt` therefore reads TEMPERATURE.
- **General call reset** resets all general-call devices on the bus and returns the registers to power-up values (also comparator mode); use it sparingly.
- **Address overlap:** `0x48`–`0x4B` is shared with LM75B and TMP117 (the latter has an identity register `0x0117`); the TMP102 has no identity register.
- **Wake from shutdown:** the first conversion after clearing SD takes the normal conversion time (≤ 15 ms) before `TEMPERATURE` is current.

## Sigrok Decoder

Decoder id `tmp102`, input `['i2c']`. Matches I²C addresses `0x48`–`0x4B`. Annotates the pointer byte as a register name, decodes TEMPERATURE reads as °C (12/13-bit by the D0 flag), CONFIGURATION into OS/F/POL/TM/SD/CR/AL/EM, limits as °C, the SMBus alert response and the general-call reset. It emits the conformance pair `conversion_start` (the CONFIGURATION write with OS = 1) and `conversion_done` (the first CONFIGURATION read returning OS = 1).
