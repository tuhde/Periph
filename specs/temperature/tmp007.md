# Chip Spec: TMP007

**Manufacturer:** Texas Instruments  
**Datasheet:** `datasheets/temperature/tmp007.pdf` (SBOS685B, May 2014)  
**Category:** temperature  
**Transports:** I²C

## Overview

The TMP007 is a contactless infrared (IR) thermopile temperature sensor with an on-chip math engine. It measures the thermopile voltage (±5.12 mV, 156.25 nV/LSB) and its own die temperature (TDIE), and computes the **object temperature** from them with factory-programmed calibration coefficients (S0, A1, A2, B0, B1, B2, C2, TC0, TC1) held in nonvolatile memory. Object and die temperature are 14-bit values at 0.03125 °C/LSB. A programmable conversion rate/averaging (0.26–4 s), optional transient correction, four temperature limits and an active-low ALERT pin (interrupt or comparator mode) are provided. The application-specific calibration coefficients can be rewritten (eight times) in the nonvolatile memory. Typical uses: non-contact thermometry, thermal management, HVAC/occupancy, battery and motor monitoring.

## Transport Configuration

### I²C
- **Address:** `0x40` + (ADR1, ADR0): ADR1/ADR0 pins tied to GND, V+, SDA or SCL give eight addresses `0x40`–`0x47` (ADR1 = 0: ADR0 = GND `0x40`, V+ `0x41`, SDA `0x42`, SCL `0x43`; ADR1 = 1: `0x44`, `0x45`, `0x46`, `0x47`)
- **Max clock:** 400 kHz (fast mode); fast-mode plus (1 MHz) and Hs-mode (≤ 2.5 MHz, via master code) also supported; SCL must be ≥ 1 kHz (timeout 25–35 ms)
- **Register access:** 8-bit pointer byte, then 16-bit data, MSB first (big-endian); the pointer persists, so repeated reads need no pointer write. Writes go MSB first; a `RegisterConnection` with `reg_bytes` = 1 and 16-bit big-endian values.
- **General call:** `0x00` + `0x06` resets the device to power-up values
- **Identity register:** `0x1F` Device ID, reads `0x0078`
- **Probe safety:** `register_pointer` — reading `0x1F` only moves the pointer

## Register Map

All registers are 16 bit, big-endian.

| Address | Name | R/W | Reset | Description |
|---------|------|-----|-------|-------------|
| `0x00` | SENSOR_VOLTAGE | R | `0x0000` | IR sensor voltage, signed, 156.25 nV/LSB (±5.12 mV) |
| `0x01` | TDIE | R | `0x0000` | Die temperature, 14 bit in bits 15:2, 0.03125 °C/LSB |
| `0x02` | CONFIG | R/W | `0x1140` | Mode, conversion rate, alert enable, transient correction |
| `0x03` | TOBJ | R | `0x0000` | Object temperature, 14 bit in bits 15:2, 0.03125 °C/LSB; bit 0 = nDV (data invalid) |
| `0x04` | STATUS | R | `0x0000` | Alert and conversion flags |
| `0x05` | STATUS_MASK | R/W | `0x0000` | Flag enables (which flags drive ALRTF/ALERT) |
| `0x06` | TOBJ_HIGH_LIMIT | R/W | `0x7FC0` | Object temperature high limit (10 bit, 0.5 °C/LSB, bits 15:6) |
| `0x07` | TOBJ_LOW_LIMIT | R/W | `0x8000` | Object temperature low limit |
| `0x08` | TDIE_HIGH_LIMIT | R/W | `0x7FC0` | Die temperature high limit |
| `0x09` | TDIE_LOW_LIMIT | R/W | `0x8000` | Die temperature low limit |
| `0x0A` | S0 | R/W | `0x260E` | Sensitivity coefficient S0 (LSB 4.5475E-18) |
| `0x0B` | A1 | R/W | `0x0106` | A1 coefficient (LSB 3.815E-06) |
| `0x0C` | A2 | R/W | `0xFF9B` | A2 coefficient (LSB 5.96E-08) |
| `0x0D` | B0 | R/W | `0xFF3A` | B0 coefficient (LSB 1.5625E-07) |
| `0x0E` | B1 | R/W | `0xFF71` | B1 coefficient (LSB 6.1035E-10) |
| `0x0F` | B2 | R/W | `0x0553` | B2 coefficient (LSB 9.5367E-12) |
| `0x10` | C2 | R/W | `0x0000` | C2 coefficient, 12 bit in bits 15:4 (LSB 4.768E-02) |
| `0x11` | TC0 | R/W | `0x0034` | Transient correction coefficient 0 (LSB 5E-06) |
| `0x12` | TC1 | R/W | `0x0000` | Transient correction coefficient 1 (LSB 3.125E-02) |
| `0x1F` | DEVICE_ID | R | `0x0078` | Device ID |
| `0x2A` | MEMORY_ACCESS | R/W | `0x0E00` | Nonvolatile memory program/load control |

The datasheet names the coefficient registers inconsistently (Table 5: A0/A1; Table 6 and Table 7: A1/A2); this spec uses A1 at `0x0B` and A2 at `0x0C` (Table 7). The reset values above are those of datasheet Table 5 and match the default values of Table 7.

### Bit Fields

#### `CONFIG` (`0x02`)
| Bits | Name | Description |
|------|------|-------------|
| 15 | RST | Software reset (self-clearing); same as power-on reset |
| 12 | MOD | `1` = conversion on (default), `0` = power-down |
| 11:9 | CR | Conversion rate / averaging: `000` 1 avg 0.26 s; `001` 2 avg 0.51 s; `010` 4 avg 1.01 s (default); `011` 8 avg 2.01 s; `100` 16 avg 4.01 s; `101` 1 avg per 1 s (idle 0.75 s, 85 µA); `110` 2 avg per 4 s (60 µA); `111` 4 avg per 4 s (85 µA) |
| 8 | ALRTEN | ALERT pin enable (mirrored in `STATUS_MASK[15]`); default 1 |
| 7 | ALRTF | Cumulative alert flag (read only, mirrored in STATUS) |
| 6 | TC | Transient correction + output filter enable (default 1) |
| 5 | INT/COMP | `0` = interrupt mode (latched flags), `1` = comparator mode |

A write to CONFIG restarts the conversion (unless it puts the device into power-down).

#### `STATUS` (`0x04`, read only)
| Bit | Name | Description |
|-----|------|-------------|
| 15 | ALRTF | Cumulative alert flag (OR of enabled flags) |
| 14 | CRTF | Conversion ready; cleared by reading STATUS, writing CONFIG or reading any result register; always latched |
| 13 | OHF | Object temperature above high limit |
| 12 | OLF | Object temperature below low limit (0 in COMP mode) |
| 11 | LHF | Die temperature above high limit |
| 10 | LLF | Die temperature below low limit (0 in COMP mode) |
| 9 | nDVF | Data invalid (math engine error / sensor voltage out of range) |
| 8 | MCRPT | Memory corrupt flag |
| 7 | DOF | IR data overflow (sensor voltage over range) |

In INT mode the limit and nDVF flags latch until STATUS is read; in COMP mode they follow the condition at the end of each conversion (OHF/LHF clear once the temperature falls below the *low* limit, which sets the hysteresis).

#### `STATUS_MASK` (`0x05`)
| Bit | Name | Description |
|-----|------|-------------|
| 15 | ALRTEN | ALERT pin enable (mirror of CONFIG[8]) |
| 14 | CRTEN | Conversion-ready flag enable |
| 13 | OHEN | Object high-limit flag enable |
| 12 | OLEN | Object low-limit flag enable (INT mode only) |
| 11 | LHEN | Die high-limit flag enable |
| 10 | LLEN | Die low-limit flag enable (INT mode only) |
| 9 | DVEN | Data-invalid flag enable |
| 8 | MEM_C_EN | Memory-corrupt flag enable |

#### `MEMORY_ACCESS` (`0x2A`)
Read: bits 15:13 NPr (number of programmings), bit 12 memory corrupt, bits 7:3 address. Write: `0x6A` in the high byte (otherwise ignored), register address in bits 7:3, bit 2 = general load, bit 1 = store (MEM program), bit 0 = single load. A store writes the current register value to nonvolatile memory (max 8 times per location). **The driver never uses the store command.**

## Initialization Sequence

1. Power up (V+ 2.5–5.5 V; POR at 1.9 V). The datasheet gives no power-up delay; the registers load from nonvolatile memory at POR.
2. Read `DEVICE_ID` (`0x1F`); it must be `0x0078`.
3. Optionally write `CONFIG` (default `0x1140` is already conversion-on, 4 averages, ALERT enabled, transient correction on).
4. Wait for the first conversion: poll `STATUS[CRTF]` (bit 14) or wait the conversion time of the selected rate (default 1.01 s).
5. Read `TOBJ` and `TDIE`; check `TOBJ[0]` (nDV) is 0 and `STATUS[nDVF]` is 0.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `ALERT`, active low, open-drain (external pull-up) |
| Level | 2 (selectable sources on a single line) |
| Condition(s) | conversion ready, object/die high or low limit, data invalid, memory corrupt |
| Clear mechanism | INT mode: read `STATUS` (or SMBus alert response for the pin only); COMP mode: cleared automatically when the condition ends |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_CONVERSION_READY` | `0x4000` | `CRTF` (STATUS_MASK bit 14) |
| `SOURCE_OBJECT_HIGH` | `0x2000` | `OHF` |
| `SOURCE_OBJECT_LOW` | `0x1000` | `OLF` (INT mode only) |
| `SOURCE_DIE_HIGH` | `0x0800` | `LHF` |
| `SOURCE_DIE_LOW` | `0x0400` | `LLF` (INT mode only) |
| `SOURCE_DATA_INVALID` | `0x0200` | `nDVF` |
| `SOURCE_MEMORY_CORRUPT` | `0x0100` | `MCRPT` |

The values are the bit positions in `STATUS` and `STATUS_MASK`.

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback)` | Subscribe to the ALERT pin; callback receives the `STATUS` word |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read `STATUS` (clears latched INT-mode flags) |
| `enable_interrupt` | `enable_interrupt(source)` | Set the source's bit in `STATUS_MASK` and `ALRTEN` |
| `disable_interrupt` | `disable_interrupt(source)` | Clear the source's bit in `STATUS_MASK` |

### Status register bit layout

The bits of `STATUS`: 15 `ALRTF`, 14 `CRTF`, 13 `OHF`, 12 `OLF`, 11 `LHF`, 10 `LLF`, 9 `nDVF`, 8 `MCRPT`, 7 `DOF`.

## Implementation Stages

### Minimal

Goal: object and die temperature with the factory calibration. No configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Reads `DEVICE_ID` (must be `0x0078`); leaves the power-on configuration (conversion on, 4 averages, 1.01 s per result, transient correction on) |
| `object_temperature` | — | `float` | °C from `TOBJ` (bits 15:2 signed × 0.03125); raises if `TOBJ[0]` (nDV) is set; the first call after power-up waits for the first conversion |
| `die_temperature` | — | `float` | °C from `TDIE` |

**Sensible defaults baked into Minimal:** factory calibration coefficients, 4 averages per conversion (1.01 s), transient correction on, ALERT pin enabled but no flag enabled (`STATUS_MASK` = 0, so ALERT stays high).

## Data Conversion

```
raw   = signed16(TOBJ_register) >> 2            # arithmetic shift; bit 0 of the register is nDV
T_obj = raw * 0.03125                           # °C
raw   = signed16(TDIE_register) >> 2
T_die = raw * 0.03125                           # °C
V_sensor = signed16(SENSOR_VOLTAGE) * 156.25e-9 # V
limit_C = (signed16(LIMIT_register) >> 6) * 0.5   # 10-bit, 0.5 °C/LSB
limit_register = (round(limit_C / 0.5) & 0x3FF) << 6
```

Range ±256 °C. The object temperature is computed by the chip from the sensor voltage, TDIE and the coefficients (equations 1–9 of the datasheet); the host does not compute it. With transient correction on, the output is filtered (`T_final[n] = 0.2·T[n] + 0.8·T_final[n−1]`), so a step change settles in about five conversion periods; use it when the die temperature changes faster than 1.5 °C/min.

## Implementation Notes

- **16-bit big-endian registers; 8-bit pointer.** Writes carry pointer + MSB + LSB; read the 16-bit value after setting the pointer.
- **Result alignment:** TOBJ/TDIE keep the 14-bit value in bits 15:2; shift arithmetically before scaling. TOBJ bit 0 is the nDV flag.
- **Wait for the first result:** after power-up, reset, power-up from shutdown or any CONFIG write the first result appears after the full conversion time of the selected rate (1.01 s default); poll `CRTF` rather than sleeping when possible.
- **Alert flag semantics:** in INT mode, flags are latched and cleared only by reading `STATUS`; in COMP mode they track the condition and cannot be cleared by a read. `OLF`/`LLF` read 0 in COMP mode.
- **Nonvolatile memory:** each memory location can be programmed eight times only; the driver does not expose the store command (`MEMORY_ACCESS` write with `0x6A`…bit 1). `set_coefficients` changes only the volatile registers.
- **Mislabelled coefficients in the datasheet:** use the register address, not the label (A1 `0x0B`, A2 `0x0C`).
- **Device ID text:** the datasheet describes the ID as "TI" in ASCII but the register map and POR bits give `0x0078`; the driver accepts `0x0078` only. If real hardware disagrees, update the spec.
- **Address overlap:** `0x40`–`0x47` is shared with the INA2xx family and others; the 16-bit `0x1F` ID of `0x0078` identifies the TMP007 (no collision with the other registered `id_probe` values).
- **Supply:** 2.5–5.5 V; ALERT/SDA pull-ups may go to 1.6–5.5 V.

## Sigrok Decoder

Decoder id `tmp007`, input `['i2c']`. Matches I²C addresses `0x40`–`0x47`. Annotates the pointer byte as a register name, decodes `TOBJ`/`TDIE` reads as °C (and flags nDV), `SENSOR_VOLTAGE` as volts, `CONFIG` into MOD/CR/TC/INT-COMP/ALRTEN, `STATUS` flags, limit registers in °C and `DEVICE_ID`; flags a `MEMORY_ACCESS` write with the store bit as a warning ("nonvolatile write").
