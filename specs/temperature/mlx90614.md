# Chip Spec: MLX90614

**Manufacturer:** Melexis  
**Datasheet:** `datasheets/temperature/mlx90614.pdf` (MLX90614 datasheet, Doc# 3901090614, Rev 021, 02-Jun-2026)  
**Category:** temperature  
**Transports:** I²C (SMBus-compatible)

## Overview

The MLX90614 is a factory-calibrated infra-red thermometer in a TO-39 can: an IR thermopile detector and a signal-conditioning ASSP in one package. It measures the **object temperature** (−70…+380 °C) and the **ambient (die) temperature** (−40…+125 °C) with 0.02 °C resolution and reports them over an SMBus-compatible 2-wire interface (10–100 kHz) or as PWM (selected in EEPROM; factory default is SMBus). Variants differ in supply voltage (3 V / 5 V), field of view, accuracy (including a medical version) and single/dual IR zone (the second sensor gives `TOBJ2`). Emissivity (0.1–1.0), digital FIR/IIR filters, gain, the slave address and the temperature range are stored in EEPROM, and there is a sleep mode (≈ 2.5 µA). Typical uses: contactless thermometers, HVAC, process monitoring.

## Transport Configuration

### I²C
- **Address:** `0x5A` (7-bit default, `SA = 0xB4` on the wire); programmable by writing the EEPROM cell `0x0E`; `0x00` is the general-call address (all devices answer) — a bus with several MLX90614 needs distinct addresses
- **Max clock:** 100 kHz (SMBus; minimum 10 kHz); SCL low for more than 27 ms resets the interface; PEC (CRC-8) appended to every transfer
- **Protocol:** SMBus read word / write word: read = `[SA+W][cmd][SA+R][LSB][MSB][PEC]` (repeated start), write = `[SA+W][cmd][LSB][MSB][PEC]`. Used through the plain `RegisterConnection` (`reg_bytes` = 1, 3-byte reads including the PEC); the driver verifies/appends the PEC
- **Identity register:** none with a fixed value (EEPROM `0x3C`–`0x3F` holds a per-device ID number); `"id_probe": null` in `registry/chips.json`
- **Probe safety:** `write_sensitive` — a bare 1-byte write is an SMBus command: `0xFF` enters **sleep mode**, EEPROM opcodes `0x20`–`0x3F` can be followed by a write

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| SCL / Vz | — | SMBus clock (5 V versions: 5.7 V zener) |
| SDA / PWM | — | SMBus data (open drain) or PWM / thermal-relay output when selected in EEPROM |
| VDD, VSS | — | 3 V or 5 V depending on the variant |

There is no interrupt pin in SMBus mode; the PWM pin can act as a thermal relay (configured in EEPROM, not through this driver).

## Register Map

Addressing by **command byte**: `000a aaaa` = RAM word `a`, `001a aaaa` = EEPROM word `a`, `0xF0` read flags, `0xFF` enter sleep. All words are 16 bit, LSB first on the wire.

### RAM (read only, command `0x00`–`0x1F`)

| Command | Name | Description |
|---------|------|-------------|
| `0x04` | RAW_IR1 | Raw data IR channel 1 (sign-magnitude) |
| `0x05` | RAW_IR2 | Raw data IR channel 2 |
| `0x06` | TA | Ambient temperature, 0.02 K/LSB (bit 15 = error flag) |
| `0x07` | TOBJ1 | Object temperature 1, 0.02 K/LSB (bit 15 = error flag) |
| `0x08` | TOBJ2 | Object temperature 2 (dual-zone parts), 0.02 K/LSB |

RAM temperature words read `0x27AD…0x7FFF` for −70.01…+382.19 °C (the MSB is the error flag, so values are halved).

### EEPROM (command `0x20` + address)

| Address | Name | Customer-writable | Description |
|---------|------|-------------------|-------------|
| `0x00` | TOMAX | yes | Object temperature range upper limit (PWM/relay scaling) |
| `0x01` | TOMIN | yes | Object temperature range lower limit |
| `0x02` | PWMCTRL | yes | PWM / SDA-pin control |
| `0x03` | TARANGE | yes | Ambient temperature range |
| `0x04` | EMISSIVITY | yes | `round(65535 × ε)`, factory default `0xFFFF` (ε = 1.0) |
| `0x05` | CONFIG1 | yes (bits 14:11, 7, 3 factory-calibrated: do not change) | IIR, FIR, gain, sensor selection |
| `0x0E` | SMBUS_ADDRESS | yes | Slave address (LSB only: bits 6:0) |
| `0x0F` | — | yes (do not alter) | Melexis reserved |
| `0x19` | — | yes (do not alter) | Melexis reserved |
| `0x1C`–`0x1F` | ID_0…ID_3 | no | 64-bit device ID number |

### Bit Fields

#### `CONFIG1` (EEPROM `0x05`)

| Bits | Name | Description |
|------|------|-------------|
| 2:0 | IIR | `000` 50 %, `001` 25 %, `010` 17 %, `011` 13 %, `100` 100 % (bypass), `101` 80 %, `110` 67 %, `111` 57 % |
| 3 | Repeat sensor self-test | `0` off, `1` on |
| 5:4 | PWM mode | `00` Ta, Tobj1; `01` Ta, Tobj2; `10` Tobj2 only; `11` Tobj1, Tobj2 |
| 6 | Dual IR | `0` single sensor, `1` dual |
| 7 | Ks sign | `0` positive, `1` negative |
| 10:8 | FIR | `100` 128, `101` 256, `110` 512, `111` 1024 (smaller values not recommended) |
| 13:11 | GAIN | `000` 1 (bypassed), `001` 3, `010` 6, `011` 12.5, `100` 25, `101` 50, `110`/`111` 100 |
| 14 | Kt2 sign | `0` positive, `1` negative |
| 15 | Sensor self-test | `0` enabled, `1` disabled |

Refresh rates at the default settings: FIR 128 → 36 ms (single) / 53 ms (dual), 256 → 44 / 53 ms, 512 → 60 / 90 ms, 1024 → 93 / 138 ms.

#### Flags (command `0xF0`, read like a word)

| Bit | Name | Description |
|-----|------|-------------|
| 15 | — | always 0 |
| 7 | EEBUSY | `1` = EEPROM write/erase in progress |
| 5 | EE_DEAD | `1` = EEPROM double error (automotive parts only) |
| 4 | INIT | `1` = POR initialization complete |

(Bit positions as in the datasheet's flags table; typical flags value after power-up `0x0010`.)

## Initialization Sequence

1. Power up (VDD rising within 20 ms to ensure POR). The first valid results are in RAM after 250 ms typ. (Tvalid).
2. Read `TOBJ1` (`0x07`), 3 bytes, verify the PEC; convert to °C.
3. After waking from sleep: pull SDA low with SCL high for ≥ 33 ms; the first data are valid after 0.25 s typ.; the IIR filter is skipped for the very first sample.

## Implementation Stages

### Minimal

Goal: read the object temperature with one call, no configuration beyond the connection.

## Data Conversion

```
raw = (MSB << 8) | LSB                      # RAM TA / TOBJ1 / TOBJ2; bit 15 set = error
temperature_k = raw * 0.02
temperature_c = raw * 0.02 - 273.15          # raw 0x27AD -> -70.01 °C, 0x7FFF -> +382.19 °C
emissivity_word = round(65535 * epsilon)

PEC = CRC-8 (polynomial x^8 + x^2 + x + 1, init 0x00) over all bytes of the transfer:
      SA+W, command, SA+R, LSB, MSB                  # example: SA 0x5A, cmd 0x07, data 0x3AD2 -> PEC 0x30
```

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Output valid after POR (Tvalid) | 250 ms typ. |
| Wake-up request (SDA low, SCL high) | ≥ 33 ms; first data 0.25 s typ. after wake |
| EEPROM erase / write cell time | 5 ms each (wait 10 ms to be safe); poll `EEBUSY` |
| SMBus request to leave PWM mode | SCL low ≥ 1.44 ms |
| SMBus clock | 10–100 kHz; SCL-low timeout ≤ 27 ms |
| Refresh rate | 36–138 ms depending on FIR/IIR and zones |

**Conformance:** the datasheet gives these as typical or host-side requirements without a bus-visible completion marker; `specs/temperature/mlx90614_timing.conf` defines no checks.

## Implementation Notes

- **SMBus, not plain I²C:** use repeated start between the command and the read, a maximum of 100 kHz and always check the PEC; a PEC mismatch should raise.
- **Error flag:** bit 15 of a RAM temperature word flags an invalid linearised temperature; the word is therefore at most `0x7FFF`.
- **Erase before write:** EEPROM cells must be written with `0x0000` first; wait ≥ 5 ms (10 ms safe) after each step and verify by reading back. EEPROM endurance 100 000 cycles at 25 °C.
- **Do not alter** emissivity-independent calibration: CONFIG1 bits 14:11, 7, 3 and EEPROM `0x0F`, `0x19` keep the factory calibration valid.
- **Address change** (EEPROM `0x0E`) only takes effect after a power cycle; the general-call address `0x00` makes all devices answer.
- **Sleep:** `0xFF` (PEC `0xE8` at SA `0x5A`) enters sleep (≈ 2.5 µA); only a wake-up request on SDA/SCL brings it back — a plain I²C controller cannot drive this, hence the optional `wake_pin`.
- **Continuous polling error:** the SCL line passes close to the sensor in the TO-39 can; wait longer than the refresh rate and settling time between readings (or use PWM) for accurate narrow-FOV readings.
- **Address overlap:** `0x5A` is shared with MPR121, CCS811, DRV2605L and others; the MLX90614 has no ID register, so probing is unsafe (`write_sensitive`).

## Sigrok Decoder

Decoder id `mlx90614`, input `['i2c']`. Matches I²C address `0x5A`. Annotates the command byte (RAM/EEPROM word, read flags, sleep), decodes RAM temperature words as °C (with the error flag), CONFIG1 into IIR/FIR/gain/mode fields, emissivity words, the slave address, the 64-bit ID, and verifies the PEC of every transfer (warning on mismatch). No timing annotation pair is emitted.
