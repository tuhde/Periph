# Chip Spec: MPL3115A2

**Manufacturer:** NXP Semiconductors  
**Datasheet:** `datasheets/pressure/mpl3115a2.pdf` (MPL3115A2 Rev. 8.1, 17 May 2024)  
**Category:** pressure  
**Transports:** I²C

## Overview

The MPL3115A2 is a compact piezoresistive absolute pressure sensor (20–110 kPa) with a 24-bit-class ASIC: it outputs temperature-compensated **pressure** as a 20-bit value in Pa (Q18.2, 0.25 Pa resolution) or **altitude** as a 20-bit signed value in metres (Q16.4, 0.0625 m resolution, US Standard Atmosphere 1976), plus a 12-bit temperature (Q8.4, 0.0625 °C). Oversampling of 1–128 trades speed for noise (6 ms – 512 ms between samples), a 32-sample FIFO, auto-acquisition (1 s – 9 h steps), programmable thresholds/windows, min/max capture and user offset trims, and two interrupt pins (INT1/INT2) with eight routable event sources complete it. Supply VDD 1.95–3.6 V (2.5 V typ.), I/O 1.62–3.6 V, current ≈ 8.5 µA per update at the highest speed, 2 µA in standby.

## Transport Configuration

### I²C
- **Address:** `0x60` (7-bit; fixed; 8-bit write `0xC0`, read `0xC1`; alternative addresses only by factory request). The chip does not acknowledge the general call
- **Max clock:** 400 kHz (fast mode); 100 kHz standard mode
- **Identity register:** `0x0C` WHO_AM_I = `0xC4` (feeds `registry/chips.json`)
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register pointer
- **Register addressing:** 1-byte register address (`RegisterConnection`, `reg_bytes = 1`); **register auto-increment** is supported for reads and writes (so `0x00`–`0x05` read as a 6-byte block: status, pressure ×3, temperature ×2)

### Bit Fields

#### `DR_STATUS` (`0x06`) / `STATUS` (`0x00`, F_MODE = 0)

| Bit | Name | Description |
|-----|------|-------------|
| 7 | PTOW | Pressure/altitude or temperature data overwritten before it was read |
| 6 | POW | Pressure/altitude data overwrite |
| 5 | TOW | Temperature data overwrite |
| 3 | PTDR | New pressure/altitude **or** temperature data ready |
| 2 | PDR | New pressure/altitude data ready |
| 1 | TDR | New temperature data ready |

The flags are only generated when the event-flag generators are enabled in `PT_DATA_CFG` (PTDR/PTOW need `DREM`; PDR/POW need `PDEFE`; TDR/TOW need `TDEFE`). PDR/PTDR clear on reading `OUT_P_MSB`, TDR on reading `OUT_T_MSB` (F_MODE = 0).

#### `PT_DATA_CFG` (`0x13`)

| Bit | Name | Description |
|-----|------|-------------|
| 2 | DREM | `1` = generate the data-ready event flag on new pressure/altitude or temperature data |
| 1 | PDEFE | `1` = raise the event flag on new pressure/altitude data |
| 0 | TDEFE | `1` = raise the event flag on new temperature data |

#### `CTRL_REG1` (`0x26`)

| Bits | Name | Description |
|------|------|-------------|
| 7 | ALT | `0` = barometer (pressure in Pa), `1` = altimeter (altitude in m) |
| 6 | — | Reserved |
| 5:3 | OS[2:0] | Oversample ratio 2^OS (1, 2, 4, 8, 16, 32, 64, 128) |
| 2 | RST | Write 1 = software reset (boot); reads 0 |
| 1 | OST | One-shot trigger (see below) |
| 0 | SBYB | `0` = STANDBY, `1` = ACTIVE (periodic acquisition per `ST`) |

Except for SBYB and OST, the device must be in STANDBY to change CTRL_REG1 fields. `OST` in STANDBY (SBYB = 0) starts one measurement, then self-clears and the part returns to STANDBY; read OST before setting it again. In ACTIVE mode OST triggers an immediate measurement but does **not** self-clear (clear and set again).

**Oversample ratio vs minimum time between samples:** `000` = 1 → 6 ms; `001` = 2 → 10 ms; `010` = 4 → 18 ms; `011` = 8 → 34 ms; `100` = 16 → 66 ms; `101` = 32 → 130 ms; `110` = 64 → 258 ms; `111` = 128 → 512 ms.

#### `CTRL_REG2` (`0x27`)

| Bits | Name | Description |
|------|------|-------------|
| 5 | LOAD_OUTPUT | `1` = the next OUT_P/OUT_T become the target values for the threshold/window interrupts (clear and set again to reload) |
| 4 | ALARM_SEL | `0` = use P_TGT/T_TGT, `1` = use OUT_P/OUT_T (requires LOAD_OUTPUT set at least once) |
| 3:0 | ST[3:0] | Auto-acquisition step: 2^ST seconds (1 s … 2^15 s ≈ 9 h) between samples in ACTIVE mode |

#### `CTRL_REG3` (`0x28`) / `CTRL_REG4` (`0x29`) / `CTRL_REG5` (`0x2A`)

`CTRL_REG3`: bit 5 `IPOL1` (1 = INT1 active high), bit 4 `PP_OD1` (1 = open-drain), bit 1 `IPOL2`, bit 0 `PP_OD2` (the datasheet names both bit 1 and bit 0 `PP_OD2`; bit 1 is the INT2 polarity).  
`CTRL_REG4` (enable) and `CTRL_REG5` (route: 1 = INT1, 0 = INT2) and `INT_SOURCE` share one bit layout:

| Bit | Name | Source |
|-----|------|--------|
| 7 | DRDY | New data (needs the PT_DATA_CFG flags) |
| 6 | FIFO | FIFO overflow or watermark |
| 5 | PW | Pressure/altitude within the target ± window (window must be non-zero) |
| 4 | TW | Temperature within the target ± window |
| 3 | PTH | Pressure/altitude threshold crossing |
| 2 | TTH | Temperature threshold crossing |
| 1 | PCHG | Pressure/altitude change (delta) |
| 0 | TCHG | Temperature change (delta) |

`INT_SOURCE` bits are set on a rising edge and cleared by reading the appropriate source register (DRDY by reading STATUS and the data registers, FIFO by reading F_STATUS).

#### `F_SETUP` (`0x0F`) and `F_STATUS` (`0x0D`)

`F_SETUP`: bits 7:6 `F_MODE` (`00` FIFO disabled — reset, `01` circular buffer keeping the most recent samples, `10` stop when full; switching directly between `01` and `10` is not allowed — disable first), bits 5:0 `F_WMRK` watermark sample count (0 disables the watermark flag). `F_STATUS`: bit 7 `F_OVF` overflow, bit 6 `F_WMRK_FLAG`, bits 5:0 `F_CNT` samples stored (max 32). `F_DATA` returns the FIFO (5 bytes per sample: pressure ×3, temperature ×2; 32 × 5 = 160 bytes) and is read through the same address as `OUT_P_MSB` auto-increment when F_MODE ≠ 0. The FIFO does not stop collecting during a read.

## Initialization Sequence

1. Software reset: write `CTRL_REG1` ← `0x04` (RST); wait for the boot to finish (the bit reads 0 again; ≤ a few ms) — the reset also leaves STANDBY.
2. Write `PT_DATA_CFG` ← `0x07` (DREM + PDEFE + TDEFE): **without this the data-ready flags are never set** and polling `DR_STATUS` would hang.
3. Write `CTRL_REG1` ← `ALT<<7 | OS<<3` (still STANDBY; e.g. barometer, OS = 7 → `0x38`).
4. One-shot reading: set `OST` (`CTRL_REG1` |= `0x02`), poll `DR_STATUS` until `PTDR` (bit 3) is set (timeout 2 × the OSR time), read `0x01`–`0x05`.
5. Continuous mode: set `SBYB` (`|= 0x01`) with `CTRL_REG2` ST step; read when PTDR is set.

## Interrupt

| Property | Value |
|----------|-------|
| INT pin | `INT1` and `INT2` — selectable polarity (default active low) and push-pull/open-drain |
| Level | 3 (multiple INT lines; each of 8 sources is routed to one of them) |
| Condition(s) | Any enabled source: data ready, FIFO overflow/watermark, pressure/temperature window, threshold, change |
| Clear mechanism | Read the source's register (see INT_SOURCE); the pin follows the OR of all enabled routed sources |

### Interrupt sources

| Constant | Value | Condition |
|----------|-------|-----------|
| `SOURCE_DRDY` | `0x80` | New pressure/altitude or temperature data |
| `SOURCE_FIFO` | `0x40` | FIFO overflow or watermark |
| `SOURCE_PW` | `0x20` | Pressure/altitude window |
| `SOURCE_TW` | `0x10` | Temperature window |
| `SOURCE_PTH` | `0x08` | Pressure/altitude threshold |
| `SOURCE_TTH` | `0x04` | Temperature threshold |
| `SOURCE_PCHG` | `0x02` | Pressure/altitude change |
| `SOURCE_TCHG` | `0x01` | Temperature change |

### Full driver interrupt API

| Method | Signature | Description |
|--------|-----------|-------------|
| `on_interrupt` | `on_interrupt(callback, pin=1, int_pin=None)` | Subscribe to INT1 (`pin = 1`) or INT2 (`pin = 2`) via `connection.int_pin` / `int_pin`, otherwise a 100 ms polling task on `poll_interrupt`; `callback(status)` receives the INT_SOURCE bitmask filtered to the sources routed to that pin |
| `off_interrupt` | `off_interrupt()` | Unsubscribe |
| `poll_interrupt` | `poll_interrupt() -> int` | Read `INT_SOURCE` (`0x12`) and return it |
| `enable_interrupt` | `enable_interrupt(source, pin=1)` | Set the source bit in `CTRL_REG4` and route it (`CTRL_REG5`) to `pin` |
| `disable_interrupt` | `disable_interrupt(source)` | Clear the source bit in `CTRL_REG4` |

### Status register bit layout

`INT_SOURCE`: bit 7 DRDY … bit 0 TCHG as in the Interrupt sources table.

## Data Conversion

```
pressure_pa  = ((OUT_P_MSB << 12) | (OUT_P_CSB << 4) | (OUT_P_LSB >> 4)) / 4.0        # unsigned 20-bit, Q18.2
              (equivalently  int18 = (MSB << 10) | (CSB << 2) | (LSB >> 6),  frac = (LSB >> 4) & 3,  Pa = int18 + frac/4)

altitude_m   = signed16((OUT_P_MSB << 8) | OUT_P_CSB) + (OUT_P_LSB >> 4) / 16.0       # Q16.4, two's complement

temperature  = signed8(OUT_T_MSB) + (OUT_T_LSB >> 4) / 16.0                            # °C, Q8.4

BAR_IN       = round(sea_level_pa / 2)                                                 # 2 Pa units, default 101326 Pa
OFF_P        = round(offset_pa / 4)  (signed8)     OFF_T = round(offset_c / 0.0625)  (signed8)     OFF_H = metres (signed8)
altitude (informative) h = 44330.77 * (1 - (p / p0)^0.190263)     # US Standard Atmosphere 1976, p0 = BAR_IN
```

Examples: pressure bytes `0x62 0xFB 0x80` → ((0x62 << 12) | (0xFB << 4) | 8) / 4 = 101 326.0 Pa; temperature bytes `0x19 0x80` → 25.5 °C; `0xE7 0x00` → −25.0 °C; `BAR_IN` default 101 326 Pa = `0xC5E7` (50 663 × 2 Pa).

## Timing Constraints

- **One-shot conversion time:** the minimum time between data samples per oversample ratio: 6 / 10 / 18 / 34 / 66 / 130 / 258 / 512 ms for OSR 1 / 2 / 4 / 8 / 16 / 32 / 64 / 128. The decoder marks the `CTRL_REG1` write that sets `OST` as `conversion_start` and the first `DR_STATUS` (or `STATUS`) read with `PTDR` set as `conversion_done`; `specs/pressure/mpl3115a2_timing.conf` checks ≥ 460 ms at the driver's default OSR 128 (512 ms less a 10 % margin; the datasheet states no tolerance).
- **Boot after reset:** the `RST` bit clears itself when the boot completes (STANDBY mode, registers default); the datasheet gives no delay figure — poll until RST reads 0.
- **Auto acquisition:** `2^ST` seconds (ST 0–15) in ACTIVE mode.
- **Power:** standby ≈ 2 µA, ≈ 8.5 µA per update at the highest speed.
- **I²C:** 400 kHz max (fast mode) — clock-rate property, not an event-to-event delay.

## Implementation Notes

- **PT_DATA_CFG must be enabled** (`0x07`): without DREM/PDEFE/TDEFE the data-ready flags (PTDR, PDR, TDR) never set and polling hangs. A one-shot driver that only waits a fixed time still needs it for PTDR-based polling.
- **STANDBY for configuration:** except SBYB and OST, CTRL_REG1 fields can only be changed in STANDBY; the drivers drop to STANDBY, modify and restore.
- **OST semantics:** self-clearing only in STANDBY (one-shot); in ACTIVE mode clear and set it again. Read OST (or poll PTDR) before triggering again.
- **Altimeter vs barometer:** the same output registers hold pressure (Q18.2 unsigned) or altitude (Q16.4 signed) depending on `ALT`; the target/window/min/max registers follow the mode too (2 Pa units vs metres) — reprogram them after switching mode.
- **`P_WND` byte order:** the datasheet labels `0x19` `P_WND_LSB` but assigns it `P[15:8]`; the drivers write high byte first, `0x19` then `0x1A`, which matches the register-table allocation (verify on hardware).
- **Auto-increment reads:** read `0x00`–`0x05` in one transaction (status + 20-bit + 12-bit); with F_MODE ≠ 0 `0x00` aliases F_STATUS and data come from `F_DATA` (`0x0E`).
- **FIFO:** switch off before changing between circular and stop-when-full mode; the FIFO keeps collecting during reads.
- **Sea-level pressure:** altitude depends on `BAR_IN` (default 101 326 Pa); set the local QNH for useful absolute altitudes, and `OFF_H` for fine adjustment.
- **Offsets** (`OFF_P`/`OFF_T`/`OFF_H`) are the way to trim long-term drift; they apply to the outputs.
- **Datasheet:** NXP MPL3115A2 Rev. 8.1, from `https://www.nxp.com/docs/en/data-sheet/MPL3115A2.pdf`.

## Sigrok Decoder

Decoder id `mpl3115a2`, input `['i2c']`. Matches I²C address `0x60`. Annotates register writes and reads (pointer write + repeated-START read or write data) by name and decodes the fields: STATUS/DR_STATUS flags, pressure (Pa) / altitude (m) and temperature (°C) bursts (using the ALT bit of the last CTRL_REG1 write seen, barometer if none), OSR and mode bits of CTRL_REG1, ST of CTRL_REG2, interrupt polarity/routing/enable registers and INT_SOURCE bit names, F_SETUP/F_STATUS, PT_DATA_CFG, target/window/min/max and offsets, WHO_AM_I (verified against `0xC4`); warns on writes to read-only registers and on CTRL_REG1 changes (other than SBYB/OST) while SYSMOD is ACTIVE. Timing annotations in the `timing` row (variable-length strings per `specs/sigrok_annotations.md`): `conversion_start` on a CTRL_REG1 write that sets OST and `conversion_done` on the first following STATUS/DR_STATUS read with PTDR set.
