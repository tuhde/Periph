# Chip Spec: MPL115A2

**Manufacturer:** NXP Semiconductors  
**Datasheet:** `datasheets/pressure/mpl115a2.pdf` (MPL115A2 Rev. 10.1, 17 May 2024)  
**Category:** pressure  
**Transports:** I²C

## Overview

The MPL115A2 is a miniature I²C digital barometer for 50–115 kPa absolute pressure: a MEMS pressure sensor and a conditioning IC deliver **10-bit pressure and 10-bit temperature ADC counts** together with four **factory-programmed compensation coefficients** (`a0`, `b1`, `b2`, `c12`, different for every device) stored in ROM. The host computes the compensated pressure with a three-multiply-accumulate polynomial. Supply 2.375–5.5 V, 5 µA active and 1 µA shutdown, I²C up to 400 kHz, −40…+105 °C, 5 × 3 mm LGA-8. The chip sleeps between conversions and is woken by the `CONVERT` command; a hardware **SHDN** pin removes power from the internal circuits (registers are lost) and a **RST** pin disables I²C communication.

## Transport Configuration

### I²C
- **Address:** `0x60` (7-bit; fixed; device address bytes `0xC0` write / `0xC1` read)
- **Max clock:** 400 kHz
- **Identity register:** none (`registry/chips.json` entry has `"id_probe": null`; `0x60` is shared with the MPL3115A2, MCP4725/MCP4728 and others)
- **Probe safety:** `register_pointer` — a 1-byte write only sets the register address; conversion starts only when `0x00` is written to `CONVERT`
- **Register addressing:** 1-byte memory-mapped register address (`RegisterConnection`, `reg_bytes = 1`); reads auto-increment, so the four ADC bytes (`0x00`–`0x03`) or the eight coefficient bytes (`0x04`–`0x0B`) are read in one transaction (write address, repeated START, read)

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| SHDN | low | Shutdown: low disables the device (≤ 1 µA, I²C pins high-impedance, registers reset); high for normal operation; wait the wake-up time after raising it |
| RST | low | Reset: low disables I²C communication; connect to VDD for normal operation |
| SDA, SCL | — | I²C; external pull-ups |
| VDD, GND | — | 2.375–5.5 V supply |

No interrupt pin.

## Register Map

| Address | Name | R/W | Description |
|---------|------|-----|-------------|
| `0x00` | Padc_MSB | R | Pressure ADC high byte |
| `0x01` | Padc_LSB | R | Pressure ADC low byte (bits 7:6 = Padc[1:0], bits 5:0 = 0) |
| `0x02` | Tadc_MSB | R | Temperature ADC high byte |
| `0x03` | Tadc_LSB | R | Temperature ADC low byte (bits 7:6, rest 0) |
| `0x04` | a0_MSB | R | `a0` coefficient high byte |
| `0x05` | a0_LSB | R | `a0` coefficient low byte |
| `0x06` | b1_MSB | R | `b1` high byte |
| `0x07` | b1_LSB | R | `b1` low byte |
| `0x08` | b2_MSB | R | `b2` high byte |
| `0x09` | b2_LSB | R | `b2` low byte |
| `0x0A` | c12_MSB | R | `c12` high byte |
| `0x0B` | c12_LSB | R | `c12` low byte (bits 1:0 = 0) |
| `0x0C`–`0x11` | reserved | R | Read `0x00` (formerly the always-zero c11, c22) |
| `0x12` | CONVERT | W | Write `0x00` to start a pressure + temperature conversion |

Padc and Tadc are 10-bit unsigned values left-justified in 16 bits (`Padc = word >> 6`).

### Coefficient formats (two's complement, 16-bit words)

| Coefficient | Total / sign / integer / fractional bits | Scaling of the signed 16-bit word `w` |
|-------------|--------------------------------------------|----------------------------------------|
| `a0` | 16 / 1 / 12 / 3 | `w / 8` (offset) |
| `b1` | 16 / 1 / 2 / 13 | `w / 8192` (sensitivity) |
| `b2` | 16 / 1 / 1 / 14 | `w / 16384` (temperature coefficient of offset) |
| `c12` | 14 / 1 / 0 / 13 + 9 zero-pad | `w / 16777216` (`2^24`; temperature coefficient of sensitivity; `c12 = c12[13:0] << 2` in the word) |

## Initialization Sequence

1. Power-up: all circuits are active, I²C registers cleared, then Standby. After raising SHDN wait the wake-up time (3 ms typ., 5 ms max) before any I²C access.
2. Read the coefficients once: `connection.read(0x04, 8)` and unpack `a0`, `b1`, `b2`, `c12` (constant per device; cache them).
3. A reading: write `0x00` to `CONVERT` (`0x12`), wait the conversion time (3 ms max; the driver waits 5 ms), read `0x00`–`0x03` (4 bytes), compensate.

## Implementation Stages

### Minimal

Goal: read the barometric pressure with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | connection | — | Reads and unpacks the coefficients |
| `read_pressure` | — | float | Compensated pressure in **Pa** (see Data Conversion) |
| `read_temperature` | — | float | Approximate temperature in °C (see Data Conversion caveat) |

**Sensible defaults:** continuous use through repeated `CONVERT` commands (the chip sleeps in between), coefficients cached at `init`.

### Full

Goal: expose complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `read` | — | `{pressure_pa, temperature_c}` | One conversion giving both values |
| `read_raw` | — | `(padc, tadc)` | 10-bit ADC counts of one conversion |
| `coefficients` | — | `(a0, b1, b2, c12)` | Floats unpacked at init |
| `reload_coefficients` | — | — | Re-read the coefficient block (e.g. after a power cycle) |
| `compensate` | `padc: int`, `tadc: int` | float | Pure function: Pa from raw counts and the cached coefficients |
| `pressure_hpa` | — | float | `read_pressure() / 100` convenience |
| `altitude` | `sea_level_pa: float = 101325.0` | float | Metres from the barometric formula (informative) |

**Additional configuration options:** none (the chip has no configuration registers); power state is hardware (SHDN, RST pins).

## Data Conversion

```
w_a0 = signed16((a0_MSB << 8) | a0_LSB)        a0  = w_a0  / 8
w_b1 = signed16(...)                            b1  = w_b1  / 8192
w_b2 = signed16(...)                            b2  = w_b2  / 16384
w_c12= signed16(...)                            c12 = w_c12 / 16777216

Padc = ((P_MSB << 8) | P_LSB) >> 6              # 0..1023
Tadc = ((T_MSB << 8) | T_LSB) >> 6              # 0..1023

Pcomp = a0 + (b1 + c12 * Tadc) * Padc + b2 * Tadc       # 0 at 50 kPa, 1023 at 115 kPa (three MACs)
pressure_pa = (Pcomp * (115 - 50) / 1023 + 50) * 1000   # kPa -> Pa
```

Datasheet example: `a0 = 0x3ECE` → 2009.75, `b1 = 0xB3F9` → −2.37585, `b2 = 0xC517` → −0.92047, `c12 = 0x33C8` → 0.000790; ADC bytes `0x66 0x80 0x7E 0xC0` → `Padc = 410`, `Tadc = 507`; `Pcomp = 733.19` (733.21 with unrounded coefficients) → 96.59 kPa.

**Temperature caveat:** this datasheet gives only the temperature ADC count, not a °C formula. The usual approximation (NXP application note AN3785 / community drivers) is `T [°C] = 25 + (Tadc − 498) / -5.35`, i.e. about −5.35 counts per °C; the reference count at 25 °C varies between sources (472 and 498 appear) and the value is uncalibrated, so `read_temperature` is approximate (±several °C). Use it only for trend/compensation checks, not as a measurement.

## Timing Constraints

- **Conversion time:** `tc` 1.6 ms typical, **3 ms maximum** between the `CONVERT` command and valid ADC registers; the drivers wait 5 ms (derived margin). The decoder marks the write of `CONVERT` as `conversion_start` and the first following read of the ADC registers as `conversion_done`; `specs/pressure/mpl115a2_timing.conf` bounds the wait to ≤ 5 ms (the datasheet has no minimum).
- **Wake-up from shutdown:** `tw` 3 ms typical, 5 ms maximum after SHDN goes high; the ADC registers are reset in shutdown (the coefficients are ROM values and survive).
- **Power:** 5 µA active (average), 1 µA shutdown.
- **I²C:** ≤ 400 kHz — a clock-rate property, not an event-to-event delay.

## Implementation Notes

- **RegisterConnection:** `connection.read(0x04, 8)` / `connection.read(0x00, 4)` / `connection.write(0x12, b"\x00")`; no chip-local `_read_reg`/`_write_reg`, no `bus_type` branch (see `specs/feature_register_access_design.md`).
- **Per-device coefficients:** never reuse coefficients between sensors; the compensation is meaningless without the device's own `a0`, `b1`, `b2`, `c12`.
- **Integer vs float:** the polynomial can be evaluated in fixed point on small MCUs (see NXP AN3785); the drivers use floating point (doubles / `float`) except on platforms without an FPU, where the fixed-point variant with the datasheet bit widths is used.
- **Left-justified ADC:** shift by 6 (the low six bits of each LSB are zero).
- **Resolution:** 10-bit ADC over 65 kPa → ≈ 0.0635 kPa per count; the datasheet quotes a resolution of 0.1 kPa and ±1 kPa accuracy.
- **No ID register**, no status flag: completion is by waiting; reading before `tc` returns the previous values.
- **Datasheet:** NXP MPL115A2 Rev. 10.1, from `https://www.nxp.com/docs/en/data-sheet/MPL115A2.pdf`.

## Sigrok Decoder

Decoder id `mpl115a2`, input `['i2c']`. Matches I²C address `0x60`. Annotates register writes and reads by name: the coefficient block (`a0`, `b1`, `b2`, `c12` decoded to their values), the ADC registers (`Padc`, `Tadc` counts and, once the coefficients were seen in the capture, the compensated pressure), the `CONVERT` write; warns on writes to read-only registers and on ADC reads earlier than one millisecond after `CONVERT`. Timing annotations in the `timing` row (variable-length strings per `specs/sigrok_annotations.md`): `conversion_start` on the write of `CONVERT` and `conversion_done` on the first following read of the ADC registers.
