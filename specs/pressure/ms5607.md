# Chip Spec: MS5607

**Manufacturer:** TE Connectivity (MEAS Switzerland)  
**Datasheet:** `datasheets/pressure/ms5607.pdf` (MS5607-02BA03, 2017; the AMSYS-branded copy)  
**Category:** pressure  
**Transports:** I²C (the chip also has an SPI interface, not covered)

> **Scope note:** the MS5607 also supports SPI (pin `PS` low, modes 0 and 3, up to 20 MHz); the issue requests I²C only, so this spec covers I²C. The MS5611 (10–1200 mbar) is the sibling part with the same command set and register-free protocol but different compensation constants (see Data Conversion) — it has its own spec.

## Overview

The MS5607 (MS5607-02BA03) is a high-resolution barometric pressure sensor module with a stainless-steel cap: a piezo-resistive MEMS sensor and a 24-bit ΔΣ ADC measuring pressure (10–2000 mbar (1000–200 000 Pa), full accuracy 300–1100 mbar) and temperature (−40…+85 °C, < 0.01 °C resolution). Each module is factory-calibrated at two temperatures and pressures; six 16-bit coefficients (C1…C6) are stored in a 128-bit PROM and must be read once by the host and used in an integer compensation algorithm (with an optional second-order correction at low temperature) to turn the raw pressure `D1` and temperature `D2` into compensated values. The oversampling ratio (OSR 256, 512, 1024, 2048, 4096) trades conversion time (0.54 ms … 8.22 ms typ.) against noise (0.024 mbar (OSR 4096) to 0.13 mbar (OSR 256)). The chip is command driven (no register pointer): single-byte commands reset the chip, start a conversion, read the PROM and read the ADC result. Supply 1.8–3.6 V, 0.02 µA standby. Typical uses: altimeters, barometers, variometers, indoor navigation, weather stations.

## Transport Configuration

### I²C
- **Address:** 7-bit `111011C` where `C` is the complement of pin `CSB`: `0x77` (`CSB` = GND) or `0x76` (`CSB` = VDD); `CSB` must be tied, not left floating. Pin `PS` must be high (VDD) to select I²C
- **Max clock:** the datasheet quotes the I²C and SPI interfaces "up to 20 MHz"; use ≤ 400 kHz (fast mode) in practice
- **Protocol:** command bytes are written alone; results are read in a second transaction. After the **ADC read command** (`0x00`) the master reads 3 bytes (24 bit, MSB first); after a **PROM read command** (`0xA0 + 2 × address`) it reads 2 bytes (16 bit); the last byte is NACKed
- **Identity register:** none; the chip has no ID register (`id_probe: null` in `registry/chips.json`). The PROM word 7 carries a serial code and a 4-bit CRC, which the driver checks, but it is not a fixed fingerprint. The addresses `0x76`/`0x77` overlap with the BMP280/BME280/BME680 (`0x76`–`0x77`), MS5607/MS5611 and BMP384/BMP581 families; discovery separates those with their ID registers, but the MS56xx parts cannot be told apart from each other without reading and decoding the PROM
- **Probe safety:** `write_sensitive` — every written byte is a command (`0x1E` resets the chip, `0x40`–`0x5F` start a conversion); undocumented command bytes must not be sent

## Pin Configuration

| Pin | Active | Notes |
|-----|--------|-------|
| PS | high | protocol select: high (VDD) = I²C, low (GND) = SPI |
| CSB | — | I²C: complement of address bit 0 (low → `0x77`, high → `0x76`); do not float |
| SDA, SCL | — | I²C; open-drain, pull-ups required |
| VDD, GND | — | 1.8–3.6 V (3.0 V typ.); 100 nF decoupling between VDD and GND |

## Command Set

| Command | Byte | Description |
|---------|------|-------------|
| Reset | `0x1E` | Reset; the PROM is reloaded in 2.8 ms |
| Convert D1 (pressure), OSR 256 / 512 / 1024 / 2048 / 4096 | `0x40` / `0x42` / `0x44` / `0x46` / `0x48` | Start a pressure conversion |
| Convert D2 (temperature), OSR 256 / 512 / 1024 / 2048 / 4096 | `0x50` / `0x52` / `0x54` / `0x56` / `0x58` | Start a temperature conversion |
| ADC read | `0x00` | Returns the 24-bit result of the last conversion; returns 0 if no conversion was started, if the command is repeated, or if sent during a conversion (which also corrupts that conversion's final result) |
| PROM read | `0xA0` … `0xAE` | `0xA0 + 2 × n`, n = 0…7: returns 16-bit PROM word n |

The OSR is encoded in bits 2:1 of the conversion command (`0x40 | type << 4 | osr << 1`, `osr` = 0…4 for 256…4096; `type` = 0 for D1, 1 for D2).

### PROM layout

| Address (n) | Command | Content |
|-------------|---------|---------|
| 0 | `0xA0` | 16 bit reserved for the manufacturer |
| 1 | `0xA2` | C1: pressure sensitivity, SENS_T1 |
| 2 | `0xA4` | C2: pressure offset, OFF_T1 |
| 3 | `0xA6` | C3: temperature coefficient of pressure sensitivity, TCS |
| 4 | `0xA8` | C4: temperature coefficient of pressure offset, TCO |
| 5 | `0xAA` | C5: reference temperature, T_REF |
| 6 | `0xAC` | C6: temperature coefficient of the temperature, TEMPSENS |
| 7 | `0xAE` | serial code and CRC-4 (bits 3:0 = CRC) |

CRC-4 (application note AN520): polynomial `x⁴ + x³ + 1`; computed over the 16 bytes of the 8 PROM words, MSB first, with the CRC nibble (bits 3:0 of word 7) set to 0 during the computation:

```
n_rem = 0
prom[7] &= 0xFF00                       # clear the CRC byte
for cnt in 0 .. 15:
    n_rem ^= (prom[cnt >> 1] & 0x00FF) if cnt & 1 else (prom[cnt >> 1] >> 8)
    for bit in 8 .. 1:
        n_rem = ((n_rem << 1) ^ 0x3000) if (n_rem & 0x8000) else (n_rem << 1)
        n_rem &= 0xFFFF
crc = (n_rem >> 12) & 0x0F              # compare with the original prom[7] & 0x000F
```

## Initialization Sequence

1. Power up VDD (1.8–3.6 V) with `PS` high.
2. Send reset (`0x1E`) and wait ≥ 2.8 ms (the PROM reload). If the chip does not respond after power-up (SDA held low in the ACK state), send several SCL clocks followed by a reset (datasheet).
3. Read the eight PROM words (`0xA0`…`0xAE`, 2 bytes each), check the CRC-4 and keep C1…C6.
4. Measure: write convert D1 (e.g. `0x48`), wait the conversion time (≥ 9.04 ms at OSR 4096), write ADC read (`0x00`), read 3 bytes → `D1`; repeat with convert D2 (`0x58`) → `D2`; compensate.

## Implementation Stages

### Minimal

Goal: read pressure and temperature with one call, no configuration beyond the connection.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| `init` | `connection` | — | Stores the plain `Connection`; reset (`0x1E`), waits 3 ms, reads the PROM, verifies the CRC-4 (raises on mismatch) |
| `read` | — | `{temperature_c, pressure_pa}` | Converts D2 then D1 at OSR 4096 (waits 10 ms each), applies the first- and second-order compensation; pressure in pascals |

**Sensible defaults:** OSR 4096 for both conversions, second-order temperature compensation applied.

### Full

Goal: complete chip functionality. Extends Minimal.

| Operation | Parameters | Returns | Notes |
|-----------|------------|---------|-------|
| *(inherits Minimal)* | | | |
| `read_pressure` | — | float | Pressure in Pa (reads D2 first for the compensation, then D1) |
| `read_temperature` | — | float | Temperature in °C (D2 only, first-order plus the low-temperature correction) |
| `read_raw` | — | `(d1, d2)` | 24-bit raw pressure and temperature codes |
| `set_oversampling` / `get_oversampling` | `osr: int` (256, 512, 1024, 2048, 4096) / — | — / int | OSR used for both conversions; raises for other values |

| `start_conversion` | `kind: int, osr: int = None` | — | Writes a D1 (`PRESSURE` = 0) or D2 (`TEMPERATURE` = 1) conversion command (non-blocking use) |
| `read_adc` | — | int | ADC read command + 3 bytes (only after the conversion time; 0 for a repeated read) |
| `compensate` | `d1: int, d2: int` | `{temperature_c, pressure_pa}` | Pure computation with the stored coefficients |
| `reset` | — | — | `0x1E`, waits 3 ms, re-reads the PROM |
| `read_prom` | — | `list[int]` | The eight PROM words |
| `coefficients` | — | `(c1, …, c6)` | The calibration coefficients |
| `prom_crc_ok` | — | bool | Verifies the CRC-4 of the PROM |
| `serial_code` | — | int | PROM word 7 bits 15:4 |
| `altitude` | `sea_level_pa: float = 101325.0` | float | Altitude in m from one pressure reading (barometric formula, see Data Conversion) |

**Additional configuration options:** oversampling ratio, second-order compensation (always on; `compensate(…, second_order=False)` gives the first-order value).

## Data Conversion

All calculations use integers (the datasheet gives the bit widths: `dT` and `TEMP` signed 32-bit, `OFF`, `SENS` signed 64-bit).

```
# coefficients C1..C6 from PROM words 1..6 (unsigned 16 bit); D1, D2 = 24-bit ADC results
dT   = D2 - C5 * 2^8
TEMP = 2000 + dT * C6 / 2^23                    # 0.01 degC units
OFF  = C2 * 2^17 + (C4 * dT) / 2^6
SENS = C1 * 2^16 + (C3 * dT) / 2^7

# second-order compensation
if TEMP < 2000:                                 # low temperature
    T2    = dT^2 / 2^31
    OFF2  = 61 * (TEMP - 2000)^2 / 2^4
SENS2 = 2 * (TEMP - 2000)^2
    if TEMP < -1500:                            # very low temperature
        OFF2  += 15 * (TEMP + 1500)^2
SENS2 += 8 * (TEMP + 1500)^2
else:
    T2 = OFF2 = SENS2 = 0
TEMP -= T2;  OFF -= OFF2;  SENS -= SENS2

P = (D1 * SENS / 2^21 - OFF) / 2^15             # 0.01 mbar units = Pa
temperature_c = TEMP / 100
pressure_pa   = P                               # 1 unit = 0.01 mbar = 1 Pa
```

Datasheet example (first-order, before the correction applies): D1 = 6465444, D2 = 8077636, C1…C6 = 46372, 43981, 29059, 27842, 31553, 28165 → TEMP = 2000 (20.00 °C), P = 110002 (1100.02 mbar). The result P is in 0.01 mbar, i.e. numerically equal to pascals.

Altitude (international barometric formula, SI units): `altitude_m = 44330 × (1 − (pressure_pa / sea_level_pa)^(1/5.255))`.

## Timing Constraints

| Constraint | Value |
|------------|-------|
| Reset (PROM reload) | 2.8 ms |
| Conversion time OSR 4096 / 2048 / 1024 / 512 / 256 | 8.22 / 4.13 / 2.08 / 1.06 / 0.54 ms typ.; 9.04 / 4.54 / 2.28 / 1.17 / 0.60 ms max |
| ADC read during a conversion / repeated ADC read | returns 0; a read during the conversion also makes its final result wrong |
| I²C clock | datasheet: up to 20 MHz; the driver uses ≤ 400 kHz |

There is no bus-decodable end-of-conversion event (no status register or interrupt: the host waits, then reads; a read that is too early returns 0 and corrupts the result), so `ms5607_timing.conf` defines no checks.

## Implementation Notes

- **Plain Connection, command protocol:** there is no register pointer; commands are written with `write` and results read with `read` in a separate transaction. Do not use a register-addressed connection.
- **Read PROM once** after reset, verify the CRC-4, and keep the coefficients in the driver; never re-read them per measurement.
- **Wait the full conversion time** (the datasheet maximum, 9.04 ms at OSR 4096, plus margin) before the ADC read. Never poll with the ADC read: a read during the conversion returns 0 **and makes the final result wrong**, and a repeated ADC read returns 0. The driver waits a fixed time and treats a 0 result as an error. Do not start a new conversion while one is running either (the result will be incorrect).
- **Order:** compensation needs `D2` (temperature) first; `read_pressure` therefore measures D2 then D1. A faster pressure update (reusing an older D2) is possible with `compensate`.
- **Units:** the chip's pressure result is in 0.01 mbar, which equals 1 Pa; the driver reports pascals and °C and never uses mbar/hPa.
- **Integer arithmetic:** use 64-bit integers for `OFF`, `SENS` and the products with `D1`; MicroPython handles this natively, C++ needs `int64_t`, JS needs `BigInt` (or floats with care) for the 64-bit products.
- **Second-order compensation** matters below 20 °C; the very-low-temperature branch applies below −15 °C.
- **PS pin:** must be high for I²C; with `PS` low the chip speaks SPI and does not answer on I²C.
- **Stuck bus after power-up:** if the chip holds SDA low in an ACK state after a failed power-on reset, clock SCL several times and then send reset (datasheet).
- **Sibling chip:** the MS5611 (10–1200 mbar) has the same command set and PROM layout but different compensation formulas; do not share coefficients or formulas between the two drivers.
- **Address overlap:** `0x76`/`0x77` are also used by the BMP280/BME280/BME680 family (identified by their ID register) and, without ID register, the MS5611; probe the MS5607 only with `active=True`.

## Sigrok Decoder

Decoder id `ms5607`, input `['i2c']`. Matches I²C addresses `0x76` and `0x77`. Annotates every command (reset, convert D1/D2 with the decoded OSR, ADC read, PROM read with the word index), decodes 16-bit PROM reads (word number, C1…C6 names, CRC-4 check once all words were seen) and 24-bit ADC reads (raw `D1`/`D2` depending on the last conversion command, and the compensated temperature and pressure once the PROM was seen), and warns on undocumented command bytes, an ADC read during a conversion (earlier than the maximum conversion time after the command) and an ADC read that returns 0. No conformance annotation pair is emitted (no checked timing constraint).
