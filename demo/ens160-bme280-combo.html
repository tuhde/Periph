SparkFun Environmental Combo Breakout · ENS160 + BME280 · Qwiic

Everything in the air,
on one bus.

This board puts two independent sensors on a single 25.4 mm Qwiic breakout: a Bosch BME280 for temperature, humidity, and pressure, and a ScioSense ENS160 for air-quality index, TVOC, and eCO2. Both speak I²C at 3.3 V over the same two-wire bus, each answering to its own address — one cable is all a project needs to read both the room's climate and its air quality. Both chips are fully supported by periph, in every language and on every platform this library ships.

Board25.4 × 25.4 mm · 2.5 g
Power3.3 V via Qwiic
BusI²C, two JST‑SH connectors
Addresses0x52 · 0x76

one bus · two addresses · one Qwiic cable

Two channels, one board

Each sensor is its own device on the bus, with its own register map, defaults, and accuracy envelope.

ENS160

ScioSense · digital metal-oxide gas sensor

0x52 default · 0x53 alt
Air quality index (UBA)1–5
eCO2400–65,000 ppm, 1 ppm res.
TVOC0–65,000 ppb, 1 ppb res.
Operating range−40…+85 °C

BME280

Bosch Sensortec · combined climate sensor

0x76 default · 0x77 alt
Temperature−40…+85 °C, ±0.5 °C
Humidity0–100% RH, ±3%
Pressure300–1100 hPa, ±1 hPa
Altitude (derived)0–9144 m, ±1 m at sea level

Works in every language we ship

The same board, read six ways. Shown here: the Linux-host variant of each driver.

Every driver binds its device address when the connection is constructed, so there's no single handle that serves both chips. Each snippet below opens the same I²C bus number twice — once per address — which is normal on Linux, where /dev/i2c-1 can be opened by more than one independent handle at a time. 

from smbus2 import SMBus
from periph.connection.i2c_linux import I2CConnection
from periph.chips.gas.ens160 import ENS160Minimal
from periph.chips.environmental.bme280 import BME280Minimal
import time

bus = SMBus(1)                                # one shared bus handle
ens = ENS160Minimal(I2CConnection(bus, 0x52))  # gas sensor at 0x52
bme = BME280Minimal(I2CConnection(bus, 0x76))  # climate sensor at 0x76

while True:
    try:
        air = ens.read_air_quality()          # {'aqi', 'tvoc_ppb', 'eco2_ppm'}
    except RuntimeError:
        time.sleep(1)                          # still warming up
        continue
    t, p, h = bme.temperature(), bme.pressure(), bme.humidity()
    print(f"AQI={air['aqi']} TVOC={air['tvoc_ppb']}ppb eCO2={air['eco2_ppm']}ppm "
          f"| {t:.1f}C {p:.1f}hPa {h:.1f}%RH")
    time.sleep(1)
#include <cstdio>
#include <unistd.h>
#include "I2CConnectionLinux.h"
#include "ENS160.h"
#include "BME280.h"

int main() {
    I2CConnectionLinux ens_conn(1, 0x52);   // gas sensor, bus 1, addr 0x52
    I2CConnectionLinux bme_conn(1, 0x76);   // climate sensor, bus 1, addr 0x76

    ENS160Minimal ens(ens_conn);
    BME280Minimal bme(bme_conn);

    while (true) {
        uint8_t aqi; float tvoc_ppb, eco2_ppm;
        if (ens.read_air_quality(aqi, tvoc_ppb, eco2_ppm)) {
            float t = bme.temperature();
            float p = bme.pressure();
            float h = bme.humidity();
            printf("AQI=%u TVOC=%.1fppb eCO2=%.1fppm | %.2fC %.2fhPa %.2f%%RH\n",
                   aqi, tvoc_ppb, eco2_ppm, t, p, h);
        }
        usleep(1000000);
    }
}
const { I2CConnection } = require('periph/connection/i2c');
const { ENS160Minimal } = require('periph/chips/gas/ens160');
const { BME280Minimal } = require('periph/chips/environmental/bme280');

const ens = new ENS160Minimal(new I2CConnection(1, 0x52));  // gas sensor
const bme = new BME280Minimal(new I2CConnection(1, 0x76));  // climate sensor

(async () => {
  while (true) {
    try {
      const air = await ens.readAirQuality();     // {aqi, tvocPpb, eco2Ppm}
      const t = await bme.temperature();
      const p = await bme.pressure();
      const h = await bme.humidity();
      console.log(`AQI=${air.aqi} TVOC=${air.tvocPpb}ppb eCO2=${air.eco2Ppm}ppm `
        + `| ${t.toFixed(1)}C ${p.toFixed(1)}hPa ${h.toFixed(1)}%RH`);
    } catch (e) { /* ENS160 still warming up */ }
    await new Promise(r => setTimeout(r, 1000));
  }
})();
use linux_embedded_hal::I2cdev;
use periph::chips::gas::Ens160Minimal;
use periph::chips::environmental::Bme280Minimal;

fn main() {
    let ens_dev = I2cdev::new("/dev/i2c-1").expect("open i2c bus");
    let bme_dev = I2cdev::new("/dev/i2c-1").expect("open i2c bus");
    let mut ens = Ens160Minimal::new(ens_dev, 0x52).expect("init ENS160");
    let mut bme = Bme280Minimal::new(bme_dev, 0x76, false).expect("init BME280");

    loop {
        let status = ens.wait_for_new_data(2000).unwrap();
        if (status >> 2) & 0x03 != 0 { continue; }  // still warming up

        let (aqi, tvoc_ppb, eco2_ppm) = ens.read_air_quality().unwrap();
        let t = bme.temperature().unwrap();
        let p = bme.pressure().unwrap();
        let h = bme.humidity().unwrap();
        println!("AQI={aqi} TVOC={tvoc_ppb}ppb eCO2={eco2_ppm}ppm | {t:.1}C {p:.1}hPa {h:.1}%RH");
        std::thread::sleep(std::time::Duration::from_secs(1));
    }
}
